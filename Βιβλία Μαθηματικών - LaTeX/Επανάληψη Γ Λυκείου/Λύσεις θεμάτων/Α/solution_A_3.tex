Για τη συνέχεια σε κλειστό διάστημα έχουμε:

\item Οι χαρακτηρισμοί των προτάσεων είναι:
\begin{alist}
\item \textbf{Σωστό}. Αν $f(x)=c$, τότε $f'(x)=0$ για κάθε $x$ του πεδίου ορισμού της.
\item \textbf{Σωστό}. Η μεταβλητή ολοκλήρωσης είναι βοηθητική, άρα
\[ \dint_a^\beta f(t)\d t=\dint_a^\beta f(x)\d x \]
και επίσης
\[ \dint_\beta^a f(x)\d x=-\dint_a^\beta f(x)\d x. \]
\item \textbf{Σωστό}. Μπορεί να συμβεί αν η συνάρτηση ορίζεται και στο σημείο της κατακόρυφης ασύμπτωτης. Για παράδειγμα, αν $f(x)=\frac{1}{x}$ για $x\neq0$ και $f(0)=0$, τότε η ευθεία $x=0$ είναι κατακόρυφη ασύμπτωτη και η $C_f$ την τέμνει στο $(0,0)$.
\item \textbf{Σωστό}. Από τη διάταξη των ορίων, αν $f(x)<g(x)$ κοντά στο $x_0$ και τα όρια είναι πραγματικοί αριθμοί, τότε στο όριο παίρνουμε $l\leq m$.
\item \textbf{Λάθος}. Για παράδειγμα, η $f(x)=x^3$ είναι $1-1$, αλλά $f'(x)=3x^2$ και η παράγωγός της έχει ρίζα το $x=0$.
\end{alist}

\item Σωστή απάντηση είναι η \textbf{β}. Από τον κανόνα παραγώγισης σύνθετης συνάρτησης ισχύει
\[ \left(f(g(x))\right)'=f'(g(x))\cdot g'(x). \]
\end{erwthma}
\end{thema}
