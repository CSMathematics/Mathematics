\item Για $x > 0$, έχουμε $f'(x) = \dfrac{x}{x} e^x = e^x$. Από το θεώρημα του ολοκληρωτικού λογισμού, καθώς η $f$ είναι συνεχής στο $[0, x]$ και παραγωγίσιμη στο $(0, x)$, ισχύει:
\[ f(x) - f(0) = \int_{0}^{x} f'(t) \, \d t = \int_{0}^{x} e^t \, \d t = \left[ e^t \right]_{0}^{x} = e^x - 1 \]
Δεδομένου ότι $f(0) = 2$, έχουμε:
\[ f(x) - 2 = e^x - 1 \implies f(x) = e^x + 1 \]
Για $x < 0$, έχουμε $f'(x) = \dfrac{-x}{x} e^{-x} = -e^{-x}$. Ομοίως, ισχύει:
\[ f(0) - f(x) = \int_{x}^{0} f'(t) \, \d t = \int_{x}^{0} -e^{-t} \, \d t = \left[ e^{-t} \right]_{x}^{0} = e^0 - e^{-x} = 1 - e^{-x} \]
Άρα:
\[ 2 - f(x) = 1 - e^{-x} \implies f(x) = e^{-x} + 1 \]
Συνδυάζοντας τα δύο παραπάνω και το γεγονός ότι $f(0)=2$, ο τύπος της συνάρτησης είναι:
\[ f(x) = e^{|x|} + 1 \]

\item Εξετάζουμε την παραγωγισιμότητα στο $x_0=0$ με τον ορισμό:
\[ f'(0) = \lim_{h \to 0} \frac{f(h) - f(0)}{h} = \lim_{h \to 0} \frac{e^{|h|} + 1 - 2}{h} = \lim_{h \to 0} \frac{e^{|h|} - 1}{h} \]
Υπολογίζουμε τα όρια δεξιά και αριστερά:
\begin{itemize}
    \item $\lim_{h \to 0^+} \frac{e^h - 1}{h} = 1$
    \item $\lim_{h \to 0^-} \frac{e^{-h} - 1}{h} = \lim_{u \to 0^+} \frac{e^u - 1}{-u} = -1$ (θετώντας $u = -h$)
\end{itemize}
Επειδή τα όρια δεξιά και αριστερά είναι διαφορετικά, η συνάρτηση $f$ \textbf{δεν είναι παραγωγίσιμη} στο $x_0=0$.

\item Για τη μελέτη της μονοτονίας εξετάζουμε το πρόσημο της $f'(x)$ για $x \ne 0$:
\begin{itemize}
    \item $f'(x) = 0 \Leftrightarrow e^{|x|} = 0$ (αδύνατο)
    \item $f'(x) > 0 \Leftrightarrow \dfrac{|x|}{x} e^{|x|} > 0 \Leftrightarrow \dfrac{|x|}{x} > 0 \Leftrightarrow x > 0$
