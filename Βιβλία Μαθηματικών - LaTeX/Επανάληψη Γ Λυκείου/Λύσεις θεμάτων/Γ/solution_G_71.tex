\item Η σχέση $f^2(x) - 2x f(x) = 1$ είναι μια δευτεροβάθμια εξίσωση ως προς $f(x)$ της μορφής $f(x)^2 - 2x f(x) - 1 = 0$.
Η διακρίνουσα της εξίσωσης αυτής είναι:
\[ \Delta' = (-x)^2 - (1)(-1) = x^2 + 1 \]
Οι πιθανές τιμές της συνάρτησης για κάθε $x \in \mathbb{R}$ είναι:
\[ f(x) = \frac{2x \pm \sqrt{4x^2 + 4}}{2} = \frac{2x \pm 2\sqrt{x^2 + 1}}{2} = x \pm \sqrt{x^2 + 1} \]
Δεδομένου ότι η συνάρτηση $f$ είναι \textbf{συνεχής} στο $\mathbb{R}$ και $f(0) = 1$, ελέγχουμε τις δύο περιπτώσεις για $x=0$:
\begin{itemize}
    \item $f(0) = 0 + \sqrt{0^2 + 1} = 1$ (Ισχύει)
    \item $f(0) = 0 - \sqrt{0^2 + 1} = -1$ (Δεν ισχύει)
\end{itemize}
Επειδή οι δύο κλάδοι $x + \sqrt{x^2 + 1}$ και $x - \sqrt{x^2 + 1}$ δεν τέμνονται ποτέ (η διαφορά τους είναι $2\sqrt{x^2 + 1} \ge 2$), η \textbf{συνέχεια} της $f$ επιβάλλει την επιλογή του ίδιου προσήμου για κάθε $x$.
Επομένως, ο τύπος της συνάρτησης είναι:
\[ f(x) = x + \sqrt{x^2 + 1} \]

\item Για $x \in \mathbb{R}$, έχουμε $f(x) = \sqrt{x^2 + 1} + x$ και $f(-x) = \sqrt{(-x)^2 + 1} + (-x) = \sqrt{x^2 + 1} - x$.
Ο πολλαπλασιασμός των δύο εκφράσεων δίνει:
\[ f(x) \cdot f(-x) = (\sqrt{x^2 + 1} + x)(\sqrt{x^2 + 1} - x) = (\sqrt{x^2 + 1})^2 - x^2 = x^2 + 1 - x^2 = 1 \]
Από τη σχέση $f(x) \cdot f(-x) = 1$ συμπεραίνουμε ότι $f(x) \neq 0$ για κάθε $x \in \mathbb{R}$.
Επειδή η $f$ είναι \textbf{συνεχής} στο $\mathbb{R}$ και $f(0) = 1 > 0$, από το θεώρημα ενδιάμεσων τιμών προκύπτει ότι $f(x) > 0$ για κάθε $x \in \mathbb{R}$.

\item Η συνάρτηση $f(x) = x + \sqrt{x^2 + 1}$ είναι παραγωγίσιμη στο $\mathbb{R}$ με παράγωγο:
\[ f'(x) = 1 + \frac{2x}{2\sqrt{x^2 + 1}} = 1 + \frac{x}{\sqrt{x^2 + 1}} = \frac{\sqrt{x^2 + 1} + x}{\sqrt{x^2 + 1}} = \frac{f(x)}{\sqrt{x^2 + 1}} \]
Από το ερώτημα (β) γνωρίζουμε ότι $f(x) > 0$ για κάθε $x \in \mathbb{R}$ και προφανώς $\sqrt{x^2 + 1} > 0$.
Άρα $f'(x) > 0$ για κάθε $x \in \mathbb{R}$, οπότε η συνάρτηση $f$ είναι \textbf{γνησίως αύξουσα} στο $\mathbb{R}$.

\item Η συνάρτηση $f$ είναι \textbf{συνεχώς} και \textbf{παραγωγήσιμη} στο $\mathbb{R}$. Για κάθε $x \in \mathbb{R}$, εφαρμόζουμε το \eng{Lagrange} Mean Value Theorem στο διάστημα $[x, x+1]$.
Υπάρχει $\xi \in (x, x+1)$ τέτοιο ώστε:
\[ f(x+1) - f(x) = f'(\xi) \cdot (x+1 - x) = f'(\xi) \]
Υπολογίζουμε τη δεύτερη παράγωγο της $f$:
\[ f''(x) = \left( \frac{x}{\sqrt{x^2 + 1}} \right)' = \frac{1 \cdot \sqrt{x^2 + 1} - x \cdot \frac{2x}{2\sqrt{x^2 + 1}}}{x^2 + 1} = \frac{\frac{x^2 + 1 - x^2}{\sqrt{x^2 + 1}}}{x^2 + 1} = \frac{1}{(x^2 + 1)^{3/2}} \]
Επειδή $f''(x) > 0$ για κάθε $x \in \mathbb{R}$, η παράγωγος $f'$ είναι \textbf{γνησίως αύξουσα} στο $\mathbb{R}$.
Δεδομένου ότι $\xi < x+1$, προκύπτει ότι $f'(\xi) < f'(x+1)$.
Συνεπώς:
\[ f(x+1) - f(x) < f'(x+1) \]
\end{erwthma}
