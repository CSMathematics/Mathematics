\item Η παράγωγος της συνάρτησης $f(x) = x^2 + ax + \beta$ είναι $\displaystyle f'(x) = 2x + a$. 
Η εξίσωση της εφαπτομένης $\varepsilon_{x_0}$ της $C_f$ στο σημείο $M(x_0, f(x_0))$ είναι:
\[ y - f(x_0) = f'(x_0)(x - x_0) \implies y - (x_0^2 + ax_0 + \beta) = (2x_0 + a)(x - x_0) \]
Απαιτώντας η εφαπτομένη $\varepsilon_{x_0}$ να διέρχεται από το σημείο $A(0, -1)$, έχουμε:
\begin{align*}
-1 - (x_0^2 + ax_0 + \beta) &= (2x_0 + a)(0 - x_0) \\
-1 - x_0^2 - ax_0 - \beta &= -2x_0^2 - ax_0 \\
x_0^2 &= \beta + 1
\end{align*}
Άρα η εξίσωση 2ου βαθμού ως προς $x_0$ είναι:
\[ x_0^2 - (\beta + 1) = 0 \]

\item Οι τετμημένες των σημείων εφάπτου $x_1, x_2$ είναι οι ρίζες της εξίσωσης $x_0^2 - (\beta + 1) = 0$.
Από τους τύπους του \eng{Vieta}, έχουμε:
\[ x_1 + x_2 = 0 \quad \text{και} \quad x_1 x_2 = -(\beta + 1) \]
Οι κλίσεις των εφαπτομένων $\varepsilon_1, \varepsilon_2$ είναι $\displaystyle m_1 = f'(x_1) = 2x_1 + a$ και $\displaystyle m_2 = f'(x_2) = 2x_2 + a$.
Αφού οι εφαπτόμενες είναι κάθετες, ισχύει $m_1 m_2 = -1$:
\begin{align*}
(2x_1 + a)(2x_2 + a) &= -1 \\
4x_1 x_2 + 2a(x_1 + x_2) + a^2 &= -1 \\
4(-(\beta + 1)) + 2a(0) + a^2 &= -1 \\
-4\beta - 4 + a^2 &= -1 \\
a^2 - 4\beta &= 3
\end{align*}
Για $a = 0$, η σχέση γίνεται $-4\beta = 3$, άρα $\displaystyle \beta = -\frac{3}{4}$.

\item Για $a = 0$ και $\beta = -3/4$, η συνάρτηση είναι $\displaystyle f(x) = x^2 - \frac{3}{4}$.
