\item Για τη συνάρτηση $f(x) = e^x - ax$, το ζητούμενο όριο είναι:
\[
\lim_{x \to 0} \frac{f(x) - 1}{x} = \lim_{x \to 0} \frac{e^x - ax - 1}{x} = \lim_{x \to 0} \left( \frac{e^x - 1}{x} - \frac{ax}{x} \right)
\]
Γνωρίζουμε ότι το βασικό όριο είναι $\lim\limits_{x \to 0} \frac{e^x - 1}{x} = 1$, επομένως:
\[
\lim_{x \to 0} \left( \frac{e^x - 1}{x} - a \right) = 1 - a
\]
Για να ισχύει η συνθήκη $1 - a = 2$, πρέπει:
\[
a = -1
\]

\item Για $a = 1$, η συνάρτηση είναι $f(x) = e^x - x$. Το όριο είναι της μορφής $\frac{0}{0}$:
\[
\lim_{x \to 0} \frac{f(x) - 1}{x^2} = \lim_{x \to 0} \frac{e^x - x - 1}{x^2} \xlongequal{\eng{L'Hôpital}} \lim_{x \to 0} \frac{e^x - 1}{2x}
\]
Χρησιμοποιώντας ξανά το βασικό όριο $\lim\limits_{x \to 0} \frac{e^x - 1}{x} = 1$, έχουμε:
\[
\lim_{x \to 0} \frac{e^x - 1}{2x} = \frac{1}{2} \cdot \lim_{x \to 0} \frac{e^x - 1}{x} = \frac{1}{2} \cdot 1 = \frac{1}{2}
\]

\item Για $f(x) = e^x - x$, η συνάρτηση είναι $\textbf{συνεχώς παραγωγίσιμη}$ στο $\mathbb{R}$ με παράγωγο:
\[
f'(x) = e^x - 1
\]
Μελετάμε το πρόσημο της $f'(x)$:
\begin{itemize}
    \item $f'(x) = 0 \Leftrightarrow e^x = 1 \Leftrightarrow x = 0$
    \item $f'(x) > 0 \Leftrightarrow e^x > 1 \Leftrightarrow x > 0$
    \item $f'(x) < 0 \Leftrightarrow e^x < 1 \Leftrightarrow x < 0$
\end{itemize}
Συνεπώς, η $f$ είναι $\textbf{γνησίως φθίνουσα}$ στο $(-\infty, 0)$ και $\textbf{γνησίως αύξουσα}$ στο $(0, +\infty)$.

\]
