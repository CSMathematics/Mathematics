\item Για τη συνάρτηση $f(x) = x e^x$ έχουμε:
\[ f(0) = 0 \cdot e^0 = 0 \]
Η παράγωγος της συνάρτησης, με εφαρμογή του κανόνα του γινομένου, είναι:
\[ f'(x) = (x)' e^x + x (e^x)' = e^x + x e^x = (x+1)e^x \]
Επομένως, η σχέση διαφορικής μορφής επαληθεύεται καθώς:
\[ f'(x) - f(x) = (x+1)e^x - x e^x = x e^x + e^x - x e^x = e^x \]
Άρα η συνάρτηση $f(x) = x e^x$ ικανοποιεί ταυτοτικά την εξίσωση και τον αρχικό φερικό όρο.

\item Για τον προσδιορισμό της κυρτότητας και των σημείων καμπής, υπολογίζουμε τη δεύτερη παράγωγο της $f$:
\[ f''(x) = \frac{d}{dx} [(x+1)e^x] = 1 \cdot e^x + (x+1)e^x = (x+2)e^x \]
Εξετάζουμε το πρόσημο της $f''(x)$:
\begin{itemize}
    \item $f''(x) = 0 \Leftrightarrow x+2 = 0 \Leftrightarrow x = -2$
    \item $f''(x) > 0 \Leftrightarrow x > -2$
    \item $f''(x) < 0 \Leftrightarrow x < -2$
\end{itemize}
Συνεπώς, η συνάρτηση στρέφει τα κοίλα άνω ($\textbf{κοίλη}$) στο διάστημα $(-2, +\infty)$.
