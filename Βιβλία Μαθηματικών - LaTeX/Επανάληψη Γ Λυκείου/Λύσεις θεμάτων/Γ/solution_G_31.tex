    *   *Part (i): Monotony and Parity*
        *   $f(x) = x^3 + x$.
        *   $f'(x) = 3x^2 + 1$.
        *   Since $x^2 \ge 0$ for all $x \in \mathbb{R}$, $3x^2 + 1 \ge 1 > 0$.
        *   Thus, $f$ is $\textbf{γνησίως αύξουσα}$ on $\mathbb{R}$.
        *   Parity: $f(-x) = (-x)^3 + (-x) = -x^3 - x = -(x^3 + x) = -f(x)$.
        *   Therefore, $f$ is \textbf{περιττή}.

    *   *Part (ii): $f(f(x)) = f(2)$*
        *   Since $f$ is strictly increasing, it is injective (1-1).
        *   $f(f(x)) = f(2) \implies f(x) = 2$.
        *   $x^3 + x = 2 \implies x^3 + x - 2 = 0$.
        *   Trial: $x=1 \implies 1+1-2 = 0$.
        *   Polynomial division: $(x-1)(x^2 + x + 2) = 0$.
        *   Quadratic $x^2 + x + 2$: Discriminant $\Delta = 1^2 - 4(1)(2) = -7 < 0$.
        *   Only real solution: $x=1$.

    *   *Part (iii): $f(x^2 - 3) + f(2x) < 0$*
        *   $f(x^2 - 3) + f(2x) < 0 \implies f(x^2 - 3) < -f(2x)$.
        *   Since $f$ is odd, $-f(2x) = f(-2x)$.
        *   So, $f(x^2 - 3) < f(-2x)$.
        *   Since $f$ is strictly increasing, $x^2 - 3 < -2x$.
        *   $x^2 + 2x - 3 < 0$.
        *   Roots of $x^2 + 2x - 3 = 0$: $x = \frac{-2 \pm \sqrt{4 - 4(1)(-3)}}{2} = \frac{-2 \pm \sqrt{16}}{2} = \frac{-2 \pm 4}{2}$.
        *   $x_1 = 1, x_2 = -3$.
        *   The inequality $x^2 + 2x - 3 < 0$ holds for $x \in (-3, 1)$.

        *   This is the definition of the derivative $f'(1)$.

\begin{thema}{Γ}
\begin{erwthma}
\item Για τη μονοτονία της $f$, υπολογίζουμε την παράγωγο:
\[ f'(x) = 3x^2 + 1 \]
Επειδή $x^2 \geq 0$ για κάθε $x \in \mathbb{R}$, έχουμε $3x^2 + 1 \geq 1 > 0$ για κάθε $x \in \mathbb{R}$.
Συνεπώς, η $f$ είναι $\textbf{γνησίως αύξουσα}$ στο $\mathbb{R}$.

Για την περιττότητα της $f$, εξετάζουμε το $f(-x)$ για $x \in \mathbb{R}$:
\[ f(-x) = (-x)^3 + (-x) = -x^3 - x = -(x^3 + x) = -f(x) \]
Άρα η $f$ είναι $\textbf{περιττή}$.

\item Επειδή η $f$ είναι $\textbf{γνησίως αύξουσα}$ στο $\mathbb{R}$, είναι $\textbf{단ι-1}$ (αντιστρέψιμη).
Επομένως:
\[ f(f(x)) = f(2) \Leftrightarrow f(x) = 2 \]
\[ \Leftrightarrow x^3 + x - 2 = 0 \]
Παρατηρούμε ότι για $x=1$ ισχύει $1^3 + 1 - 2 = 0$, οπότε το πολυώνυμο διαιρείται με το $(x-1)$:
\[ (x-1)(x^2 + x + 2) = 0 \]
Η εξίσωση $x^2 + x + 2 = 0$ έχει διακρίνουσα $\Delta = 1^2 - 4 \cdot 1 \cdot 2 = -7 < 0$, άρα δεν έχει πραγματικές ρίζες.
Συνεπώς, η μοναδική λύση της εξίσωσης είναι $x = 1$.

\item Από την περιττότητα της $f$ έχουμε $-f(2x) = f(-2x)$. Η ανίσωση γίνεται:
\[ f(x^2 - 3) < -f(2x) \Leftrightarrow f(x^2 - 3) < f(-2x) \]
Επειδή η $f$ είναι $\textbf{γνησίως αύξουσα}$, η ανίσωση είναι ισοδύναμη με:
\[ x^2 - 3 < -2x \Leftrightarrow x^2 + 2x - 3 < 0 \]
Λύνουμε την εξίσωση $x^2 + 2x - 3 = 0$:
\[ \Delta = 2^2 - 4 \cdot 1 \cdot (-3) = 4 + 12 = 16 \]
\[ x_{1,2} = \frac{-2 \pm 4}{2} \Rightarrow x_1 = 1, \ x_2 = -3 \]
Το τριώνυμο είναι αρνητικό ανάμεσα στις ρίζες, άρα η λύση της ανίσωσης είναι $x \in (-3, 1)$.

\item Το ζητούμενο όριο είναι ο ορισμός της παραγώγου της $f$ στο σημείο $x=1$:
\[ \lim_{x \to 1} \frac{f(x) - f(1)}{x - 1} = f'(1) \]
Από το (α), γνωρίζουμε ότι $f'(x) = 3x^2 + 1$. Άρα:
\[ f'(1) = 3(1)^2 + 1 = 4 \]
Επομένως, $\lim\limits_{x \to 1} \dfrac{f(x) - f(1)}{x - 1} = 4$.
\end{erwthma}
\end{thema}
