%=========== ΛΥΣΗ ΘΕΜΑΤΟΣ Γ.63 ===========
\begin{thema}{Γ}
Δίνεται η συνάρτηση $f(x) = \frac{x^2+x+1}{x}$ με $x > 0$.
\begin{erwthma}

\item Ζητείται η πλάγια ασύμπτωτη $(\delta)$ στο $+\infty$.
Διαχωρίζουμε τα κλάσματα ώστε να δημιουργηθεί αλγεβρική απλοποίηση:
\[ f(x) = \frac{x^2}{x} + \frac{x}{x} + \frac{1}{x} = x + 1 + \frac{1}{x} \]
Γνωρίζουμε ότι η ευθεία $y = \lambda x + \beta$ συνιστά πλάγια/οριζόντια ασύμπτωτη εάν $\lim_{x\to+\infty}(f(x) - (\lambda x + \beta)) = 0$.
Αξιοποιώντας την παραπάνω μορφή, δημιουργούμε άμεσα τη διαφορά:
\[ f(x) - (x+1) = \frac{1}{x} \]
Παίρνοντας το όριο στο $+\infty$:
\[ \lim_{x\to +\infty} \left[ f(x) - (x+1) \right] = \lim_{x\to +\infty} \frac{1}{x} = 0 \]
Κατά συνέπεια, η ευθεία \textbf{$(\delta): y = x + 1$} αποτελεί ιδανική πλάγια ασύμπτωτη της γραφικής παράστασης της $f$ στο $+\infty$.

\item Ζητείται η κατακόρυφη ασύμπτωτη $(\varepsilon)$ της $C_f$.
Η συνάρτηση ορίζεται αυστηρά για $x > 0$. Θα αναζητήσουμε κατακόρυφες ασύμπτωτες αποκλειστικά στα ανοικτά (μη ορισμένα) άκρα του πεδίου, δηλαδή στο $x_0 = 0$ (από τα δεξιά).
Υπολογίζουμε το όριο $\lim_{x\to 0^+} f(x)$:
\[ \lim_{x\to 0^+} \left( x + 1 + \frac{1}{x} \right) \]
- Το $(x+1)$ τείνει σταθερά στο $1$.
- Το $\frac{1}{x}$ τείνει στο $+\infty$ (δίνει θετικό πρόσημο).
Επομένως:
\[ \lim_{x\to 0^+} f(x) = 1 + (+\infty) = +\infty \]
Επειδή το όριο είναι εξ ολοκλήρου άπειρο, κατοχυρώνεται ότι η κατακόρυφη ευθεία \textbf{$(\varepsilon): x = 0$} (ο άξονας των $y$) αποτελεί τη μοναδική \textbf{κατακόρυφη ασύμπτωτη} της $C_f$.

\end{erwthma}
\end{thema}
