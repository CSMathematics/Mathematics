\begin{thema}{Γ}
\begin{erwthma}
\item Η εφαπτομένη της $C_f$ στο σημείο $(0, f(0)) = (0, 0)$ έχει εξίσωση:
\[ y - f(0) = f'(0)(x - 0) \implies y = f'(0) \cdot x \]
Δεδομένου ότι η εφαπτομένη αυτή είναι ο άξονας $x'x$ (εξίσωση: $y = 0$), απαιτείται $f'(0) = 0$ (μηδενικός συντελεστής).
Άρα: $\boldsymbol{f'(0) = 0}$.

\item Ορίζουμε τη βοηθητική συνάρτηση $g(x) = f(x) - x$ στο $[0, 1]$.
Η $g$ είναι συνεχής στο $[0,1]$ και παραγωγίσιμη στο $(0,1)$ (ως διαφορά δύο φορές παραγωγίσιμων), και:
\[ g(0) = f(0) - 0 = 0, \quad g(1) = f(1) - 1 = 1 - 1 = 0 \]
Εφόσον $g(0) = g(1)$, από το \textbf{Θεώρημα Rolle} υπάρχει τουλάχιστον ένα $\xi \in (0,1)$ ώστε:
\[ g'(\xi) = 0 \implies f'(\xi) - 1 = 0 \implies \boldsymbol{f'(\xi) = 1} \]

\item Από τα δύο προηγούμενα ερωτήματα, γνωρίζουμε:
\[ f'(0) = 0 \quad \text{και} \quad f'(\xi) = 1, \quad \text{με } \xi \in (0,1) \]
Η συνάρτηση $f'$ είναι συνεχής στο $[0, \xi]$ και παραγωγίσιμη στο $(0, \xi)$ (αφού $f$ είναι δύο φορές παραγωγίσιμη). Με τις ανισότητες $f'(0) = 0 \neq 1 = f'(\xi)$, εφαρμόζουμε το \textbf{Θεώρημα Μέσης Τιμής Lagrange} στη συνάρτηση $f'$ στο διάστημα $[0, \xi]$:
\[ \exists\, \xi_2 \in (0, \xi) \subset (0, 1): \quad f''(\xi_2) = \frac{f'(\xi) - f'(0)}{\xi - 0} = \frac{1 - 0}{\xi} = \frac{1}{\xi} \neq 0 \]
Άρα έχουμε εντοπίσει ένα $\xi_2 \in (0,1)$ με $f''(\xi_2) \neq 0$. Για να αποδείξουμε ότι η $f''$ \textbf{μηδενίζεται} σε εσωτερικό σημείο, εφαρμόζουμε ξανά ΘΜΤ: Από το Γ2, υπάρχει $\xi$ με $f'(\xi) = 1$. Εφαρμόζουμε Lagrange στη $f'$ στο $[\xi, 1]$:
\begin{itemize}
    \item Αν $f'(1) = 1$, τότε $f'(\xi) = f'(1)$, οπότε από \textbf{Rolle} υπάρχει $\xi_3 \in (\xi, 1)$ με $f''(\xi_3) = 0$.
    \item Αν $f'(1) \neq 1$, τότε η $f''$ παίρνει τιμές $f''(\xi_2) = 1/\xi > 0$ (σε $\xi_2 < \xi$) και από ΘΜΤ Lagrange σε $[\xi, 1]$: $f''(\xi_3) = \frac{f'(1)-f'(\xi)}{1-\xi} = \frac{f'(1)-1}{1-\xi}$. Για $f'(1) < 1$ αυτό είναι αρνητικό, ενώ $f''(\xi_2) > 0$. Από \textbf{Ενδιάμεση Τιμή} της $f''$ υπάρχει σημείο μεταξύ $\xi_2$ και $\xi_3$ όπου $f'' = 0$.
\end{itemize}
Σε κάθε περίπτωση, αποδεικνύεται ότι υπάρχει τουλάχιστον ένα εσωτερικό σημείο $x_0 \in (0,1)$ με $\boldsymbol{f''(x_0) = 0}$.

\item Ζητείται το $L = \lim\limits_{x \to 0^+} \dfrac{f(x)\ln x}{x}$.
Ξαναγράφουμε:
\[ L = \lim_{x \to 0^+} \frac{f(x)}{x} \cdot \ln x \]
Υπολογίζουμε χωριστά τον παράγοντα $\dfrac{f(x)}{x}$ καθώς $x \to 0^+$:
\[ \lim_{x \to 0^+} \frac{f(x)}{x} = \lim_{x \to 0^+} \frac{f(x) - f(0)}{x - 0} = f'(0) = 0 \]
Το γινόμενο έχει μορφή $0 \cdot (-\infty)$. Χρησιμοποιούμε την υπόθεση $0 \le f(x) < x$ για $x \in (0,1)$ (αφού $f(x) < x$ και $f(0) = 0$, $f$ συνεχής → $f(x) \ge 0$).
Άρα:
\[ 0 \le \frac{f(x)}{x} < 1 \quad \text{για κάθε } x \in (0,1) \]
Επομένως:
\[ 0 \ge \frac{f(x)}{x} \cdot \ln x > \ln x \quad \text{(αφού } \ln x < 0 \text{ και } \frac{f(x)}{x} < 1\text{)} \]
Δηλαδή:
\[ \ln x < \frac{f(x)\ln x}{x} \le 0 \]
Αφού $\lim\limits_{x \to 0^+} \ln x = -\infty$ αλλά $\lim\limits_{x \to 0^+} x\ln x = 0$, χρησιμοποιούμε Παρεμβολή πιο ακριβώς:
\[ 0 \le \left|\frac{f(x)\ln x}{x}\right| = \frac{f(x)}{x}\cdot|\ln x| \le \frac{x}{x} \cdot |\ln x| = |\ln x| \cdot \frac{f(x)/x}{1} \]
Καλύτερα: αφού $0 \le f(x) < x$, έχουμε $0 \le \dfrac{f(x)|\ln x|}{x} < |\ln x|$. Αλλά χρειαζόμαστε και ανώτερο φράγμα που → 0.
Χρησιμοποιώντας $f(x) \ge 0$ και $f(x) < x$:
\[ 0 \ge \frac{f(x)\ln x}{x} > \ln x \xrightarrow{x\to 0^+} -\infty \]
Το Κριτήριο Παρεμβολής δεν δίνει απευθείας απάντηση. Χρησιμοποιούμε την ισότητα:
$\dfrac{f(x)}{x} \to f'(0) = 0$ και $x\ln x \to 0$, οπότε:
\[ \frac{f(x)\ln x}{x} = \frac{f(x)}{x} \cdot \ln x = \frac{f(x)}{x} \cdot \frac{x\ln x}{x} \cdot x \]
Αλλά πιο απλά: $\dfrac{f(x)}{x} \to 0$ και $\ln x \to -\infty$. Επειδή $\dfrac{f(x)}{x} \to 0$ \textbf{ταχύτερα} από το $|\ln x| \to +\infty$, χρησιμοποιούμε:
\[ \frac{f(x)\ln x}{x} = \frac{f(x)}{x^{1/2}} \cdot \frac{\ln x}{x^{1/2}} \to 0 \cdot 0 = \boldsymbol{0} \]
*(Αφού $\frac{f(x)}{x^{1/2}} \le \frac{x}{x^{1/2}} = x^{1/2} \to 0$ και $x^{1/2}|\ln x| \to 0$).*
\end{erwthma}
\end{thema}
