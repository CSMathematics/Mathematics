\item Θεωρούμε τη συνάρτηση $g(x) = f(x) - x$ στο διάστημα $[0, 1]$.
Η συνάρτηση $g$ είναι \textbf{συνεχώς} και \textbf{παραγωγήσιμη} στο $[0, 1]$ καθώς η $f$ είναι δύο φορές παραγωγίσιμη.
Υπολογίζουμε τις τιμές της στα άκρα:
\[ g(0) = f(0) - 0 = 0 - 0 = 0 \]
\[ g(1) = f(1) - 1 = 1 - 1 = 0 \]
Εφόσον $g(0) = g(1) = 0$, από το \eng{Rolle} (ή το \eng{Lagrange}) υπάρχει τουλάχιστον ένα $\xi \in (0, 1)$ ώστε:
\[ g'(\xi) = 0 \implies f'(\xi) - 1 = 0 \implies f'(\xi) = 1 \]

\item Από το προηγούμενο ερώτημα γνωρίζουμε ότι υπάρχει $\xi \in (0, 1)$ με $f'(\xi) = 1$. Επίσης, από το (α) έχουμε $f'(0) = 0$.
Εφόσον η $f$ είναι δύο φορές παραγωγίσιμη στο $[0, 1]$, η παράγωγος $f'(x)$ είναι \textbf{συνεχώς} και \textbf{παραγωγήσιμη} στο διάστημα $[0, \xi]$.
Εφαρμόζοντας το \eng{Lagrange} στη συνάρτηση $f'(x)$ στο διάστημα $[0, \xi]$, υπάρχει $\xi_2 \in (0, \xi) \subset (0, 1)$ ώστε:
\[ f''(\xi_2) = \frac{f'(\xi) - f'(0)}{\xi - 0} = \frac{1 - 0}{\xi} = \frac{1}{\xi} \]
Σημείωση: Για να μηδενιστεί η δεύτερη παράγωγος, θα έπρεπε να ισχύει $f'(x_1) = f'(x_2)$ για δύο διαφορετικά σημεία $x_1, x_2 \in [0, 1]$. Αν υποθέσουμε ότι $f'(1) = 1$ (όπως προκύπτει αν η $f$ προσεγγίζει την ευθεία $y=x$ στο $x=1$), τότε από το \eng{Rolle} στο διάστημα $[\xi, 1]$ θα υπήρχε $\xi_3 \in (\xi, 1)$ με $f''(\xi_3) = 0$.

\item Θέλουμε να υπολογίσουμε το όριο:
\[ L = \lim_{x \to 0^+} \frac{f(x) \ln x}{x} = \lim_{x \to 0^+} \left( \frac{f(x)}{x} \cdot \ln x \right) \]
Από τον ορισμό της παραγώγου στο $x=0$:
\[ \lim_{x \to 0^+} \frac{f(x)}{x} = \lim_{x \to 0^+} \frac{f(x) - f(0)}{x - 0} = f'(0) = 0 \]
Το όριο είναι της μορφής $0 \cdot (-\infty)$. Εφόσον η $f$ είναι δύο φορές παραγωγίσιμη, χρησιμοποιούμε την ανάπτυξη \eng{Taylor} της $f$ γύρω από το $x=0$:
\[ f(x) = f(0) + f'(0)x + \frac{f''(\zeta)}{2}x^2 = 0 + 0\cdot x + \frac{f''(\zeta)}{2}x^2 = \frac{f''(\zeta)}{2}x^2 \]
όπου $\zeta \in (0, x)$. Τότε:
\[ \frac{f(x)}{x} = \frac{f''(\zeta)}{2}x \]
Αντικαθιστώντας στο όριο:
\[ L = \lim_{x \to 0^+} \left( \frac{f''(\zeta)}{2} x \ln x \right) \]
Γνωρίζουμε ότι $\lim_{x \to 0^+} x \ln x = 0$ και η $f''$ είναι φραγμένη στο $[0, 1]$ λόγω συνεχειάς. Επομένως:
\[ L = \frac{f''(0)}{2} \cdot 0 = 0 \]
\end{erwthma}
\end{thema}
