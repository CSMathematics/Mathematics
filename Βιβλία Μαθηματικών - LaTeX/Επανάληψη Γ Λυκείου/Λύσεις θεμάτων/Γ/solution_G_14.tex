\begin{thema}{Γ}
\begin{erwthma}
\item Η συνάρτηση $f(x) = x \ln x - x + 1$ έχει πεδίο ορισμού το $(0, +\infty)$. Είναι παραγωγίσιμη (άρα και συνεχής) ως πράξεις παραγωγίσιμων συναρτήσεων, με:
\[ f'(x) = (x)' \ln x + x (\ln x)' - (x)' + (1)' = 1 \cdot \ln x + x \cdot \frac{1}{x} - 1 = \ln x + 1 - 1 = \ln x \]
Βρίσκουμε τη ρίζα και το πρόσημο της $f'$:
\begin{itemize}
    \item $f'(x) = 0 \Leftrightarrow \ln x = 0 \Leftrightarrow x = 1$
    \item $f'(x) > 0 \Leftrightarrow \ln x > 0 \Leftrightarrow x > 1$
    \item $f'(x) < 0 \Leftrightarrow \ln x < 0 \Leftrightarrow 0 < x < 1$
\end{itemize}

Συνεπώς, η $f$ είναι \textbf{γνησίως φθίνουσα} στο διάστημα $(0, 1]$ και \textbf{γνησίως αύξουσα} στο διάστημα $[1, +\infty)$.
Η συνάρτηση παρουσιάζει \textbf{ολικό ελάχιστο} στη θέση $x = 1$, με τιμή:
\[ f(1) = 1 \cdot \ln 1 - 1 + 1 = 0 \]

\item Αναζητούμε την εφαπτομένη της γραφικής παράστασης $C_f$ στο σημείο με τετμημένη $x_0 = 1$.
Έχουμε ήδη βρει ότι το σημείο επαφής είναι το $A(1, f(1))$, δηλαδή το $A(1, 0)$.
Ο συντελεστής διεύθυνσης της εφαπτομένης είναι η τιμή της παραγώγου στο 1:
\[ \lambda = f'(1) = \ln 1 = 0 \]
Η εξίσωση της εφαπτομένης ευθείας $\varepsilon$ δίνεται από τον τύπο $y - f(1) = f'(1)(x - 1)$:
\[ y - 0 = 0 \cdot (x - 1) \implies y = 0 \]
Άρα η εφαπτομένη της $C_f$ στο $x_0=1$ είναι ο οριζόντιος άξονας $x'x$.

\item Υπολογίζουμε τη δεύτερη παράγωγο της $f$:
\[ f''(x) = (\ln x)' = \frac{1}{x} \]
Επειδή $x > 0$, ισχύει προφανώς $f''(x) > 0$ για κάθε $x \in (0, +\infty)$. Επομένως, η συνάρτηση $f$ είναι \textbf{κυρτή} στο πεδίο ορισμού της.
Ένα από τα βασικά θεωρήματα της κυρτότητας είναι ότι η γραφική παράσταση μιας κυρτής συνάρτησης βρίσκεται "πάνω" από οποιαδήποτε εφαπτομένη της (με εξαίρεση το σημείο επαφής όπου ταυτίζονται). 
Η εφαπτομένη $\varepsilon$ στο $x_0=1$ (από το προηγούμενο ερώτημα) έχει εξίσωση $y=0$. Επομένως, για κάθε $x > 0$ ισχύει:
\[ f(x) \ge y_{\varepsilon} \implies f(x) \ge 0 \implies x \ln x - x + 1 \ge 0 \implies x \ln x \ge x - 1 \]

\item Θεωρούμε τυχαίο $x > 0$ και το διάστημα $[x, x+1]$. 
Η συνάρτηση $f$ ικανοποιεί τις προϋποθέσεις του \textbf{Θεωρήματος Μέσης Τιμής (\eng{T.M.T.})} στο διάστημα αυτό (συνεχής στο κλειστό, παραγωγίσιμη στο ανοιχτό). Επομένως, υπάρχει τουλάχιστον ένα $\xi \in (x, x+1)$ τέτοιο ώστε:
\[ f'(\xi) = \frac{f(x+1) - f(x)}{(x+1) - x} = f(x+1) - f(x) \]
Υπολογίζουμε τη διαφορά $f(x+1) - f(x)$:
\begin{align*}
f(x+1) - f(x) &= \left[ (x+1)\ln(x+1) - (x+1) + 1 \right] - \left[ x \ln x - x + 1 \right] \\
&= (x+1)\ln(x+1) - x - 1 + 1 - x \ln x + x - 1 \\
&= (x+1)\ln(x+1) - x \ln x - 1
\end{align*}
Άρα, $f'(\xi) = (x+1)\ln(x+1) - x \ln x - 1$.
Όμως γνωρίζουμε ότι $x < \xi < x+1$. Επειδή η $f'$ είναι γνησίως αύξουσα (αφού αποδείξαμε στο Γ3 ότι $f''(x)>0$), η ανισότητα διατηρεί τη φορά της αν εφαρμόσουμε την $f'$:
\[ x < \xi < x+1 \overset{f' \nearrow}{\implies} f'(x) < f'(\xi) < f'(x+1) \]
Γνωρίζοντας ότι $f'(t) = \ln t$, αντικαθιστούμε:
\[ \ln x < f(x+1) - f(x) < \ln(x+1) \]
\[ \ln x < (x+1)\ln(x+1) - x \ln x - 1 < \ln(x+1) \]
\end{erwthma}
\end{thema}
