    *   **Part 1: Extrema and Monotonicity**
        *   $f(x) = x^3 - 3x + 1$
        *   $f'(x) = 3x^2 - 3$
        *   $f'(x) = 0 \Rightarrow 3(x^2 - 1) = 0 \Rightarrow x = \pm 1$.
        *   So $x_1 = -1$ and $x_2 = 1$.
        *   Sign of $f'(x)$:
            *   $f'(x) > 0$ for $x \in (-\infty, -1) \cup (1, +\infty) \Rightarrow \textbf{γνησίως αύξουσα}$.
            *   $f'(x) < 0$ for $x \in (-1, 1) \Rightarrow \textbf{γνησίως φθίνουσα}$.
        *   Table needed.

    *   **Part 2: Number of Roots**
        *   Check values at critical points and limits:
            *   $\lim_{x \to -\infty} f(x) = -\infty$.
            *   $f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3$.
            *   $f(1) = 1^3 - 3(1) + 1 = 1 - 3 + 1 = -1$.
            *   $\lim_{x \to +\infty} f(x) = +\infty$.
        *   By `\eng{Bolzano}` theorem:
            *   Interval $(-\infty, -1)$: $f$ changes sign from $-\infty$ to $3 \Rightarrow \exists \rho_1$.
            *   Interval $(-1, 1)$: $f$ changes sign from $3$ to $-1 \Rightarrow \exists \rho_2$.
            *   Interval $(1, +\infty)$: $f$ changes sign from $-1$ to $+\infty \Rightarrow \exists \rho_3$.
        *   Since the function is strictly monotonic on these intervals, each root is unique.

    *   **Part 3: Inflection Point and Tangent**
        *   $f'(x) = 3x^2 - 3$.
        *   $f''(x) = 6x$.
        *   $f''(x) = 0 \Rightarrow x = 0$.
        *   Inflection point $K(0, f(0)) \Rightarrow f(0) = 1 \Rightarrow K(0, 1)$.
        *   Slope of tangent at $x=0$: $f'(0) = 3(0)^2 - 3 = -3$.
        *   Equation: $y - 1 = -3(x - 0) \Rightarrow y = -3x + 1$.

    *   **Part 4: Integral**
        *   $\int_{-1}^1 (x^3 - 3x + 1) dx$.
        *   $= \left[ \frac{x^4}{4} - \frac{3x^2}{2} + x \right]_{-1}^1$.
        *   Upper limit: $\frac{1}{4} - \frac{3}{2} + 1 = \frac{1-6+4}{4} = -\frac{1}{4}$.
        *   Lower limit: $\frac{(-1)^4}{4} - \frac{3(-1)^2}{2} + (-1) = \frac{1}{4} - \frac{3}{2} - 1 = \frac{1-6-4}{4} = -\frac{9}{4}$.
        *   Result: $-\frac{1}{4} - (-\frac{9}{4}) = \frac{8}{4} = 2$.
        *   *Alternative approach: odd function part.* $\int_{-1}^1 (x^3 - 3x) dx = 0$ because they are odd functions. Thus $\int_{-1}^1 f(x) dx = \int_{-1}^1 1 dx = [x]_{-1}^1 = 1 - (-1) = 2$. I will use the standard integration method to be clear and safe, or maybe the odd function property if it's elegant, but usually, the standard definite integral evaluation is expected in these exams. I'll stick to the standard definite integral.

  \item 
  Η συνάρτηση $f$ είναι πολυωνυμική, άρα είναι συνεχής και παραγωγίσιμη στο $\mathbb{R}$.
  Η παράγωγός της είναι:
  \[ f'(x) = 3x^2 - 3 \]
  Για τον προσδιορισμό των σημείων ακροτάτου, λύνουμε την εξίσωση $f'(x) = 0$:
  \[ 3x^2 - 3 = 0 \Leftrightarrow 3(x^2 - 1) = 0 \Leftrightarrow x = \pm 1 \]
  Άρα τα σημεία των τοπικών ακροτάτων είναι τα $x_1 = -1$ και $x_2 = 1$.
  
  Για τη μελέτη της μονοτονίας, εξετάζουμε το πρόσημο της $f'(x)$:
  \begin{itemize}
    \item $f'(x) > 0 \Leftrightarrow 3(x^2 - 1) > 0 \Leftrightarrow x \in (-\infty, -1) \cup (1, +\infty)$
    \item $f'(x) < 0 \Leftrightarrow 3(x^2 - 1) < 0 \Leftrightarrow x \in (-1, 1)$
    \item $f'(x) = 0 \Leftrightarrow x = \pm 1$
  \end{itemize}
  Συνεπώς, η συνάρτηση $f$ είναι \textbf{γνησίως αύξουσα} στο $(-\infty, -1)$ και στο $(1, +\infty)$ και \textbf{γνησίως φθίνουσα} στο $(-1, 1)$.

  \item 
  Από τον πίνακα παραγωγίσιμης και τα όρια της συνάρτησης:
  \[ \lim_{x \to -\infty} f(x) = -\infty, \quad f(-1) = 3, \quad f(1) = -1, \quad \lim_{x \to +\infty} f(x) = +\infty \]
  
  \begin{itemize}
    \item Στο διάστημα $(-\infty, -1)$, η $f$ είναι συνεχής και αλλάζει πρόσημο από το $-\infty$ στο $3$. Επομένως, από το θεώρημα \eng{Bolzano}, υπάρχει τουλάχιστον μία ρίζα $\rho_1 \in (-\infty, -1)$. Επειδή η $f$ είναι \textbf{γνησίως αύξουσα} στο διάστημα αυτό, η $\rho_1$ είναι μοναδική.
    \item Στο διάστημα $(-1, 1)$, η $f$ είναι συνεχής και αλλάζει πρόσημο από το $3$ στο $-1$. Επομένως, από το θεώρημα \eng{Bolzano}, υπάρχει τουλάχιστον μία ρίζα $\rho_2 \in (-1, 1)$. Επειδή η $f$ είναι \textbf{γνησίως φθίνουσα} στο διάστημα αυτό, η $\rho_2$ είναι μοναδική.
    \item Στο διάστημα $(1, +\infty)$, η $f$ είναι συνεχής και αλλάζει πρόσημο από το $-1$ στο $+\infty$. Επομένως, από το θεώρημα \eng{Bolzano}, υπάρχει τουλάχιστον μία ρίζα $\rho_3 \in (1, +\infty)$. Επειδή η $f$ είναι \textbf{γνησίως αύξουσα} στο διάστημα αυτό, η $\rho_3$ είναι μοναδική.
  \end{itemize}
  Άρα η εξίσωση $f(x) = 0$ έχει ακριβώς τρεις πραγματικές ρίζες $\rho_1 \in (-\infty, x_1), \rho_2 \in (x_1, x_2)$ και $\rho_3 \in (x_2, +\infty)$.

  \item 
  Υπολογίζουμε τη δεύτερη παράγωγο της $f$:
  \[ f''(x) = (3x^2 - 3)' = 6x \]
  Το σημείο καμπής προκύπτει όταν $f''(x) = 0$:
  \[ 6x = 0 \Leftrightarrow x = 0 \]
  Για $x=0$, έχουμε $f(0) = 0^3 - 3(0) + 1 = 1$. Άρα το σημείο καμπής είναι το $K(0, 1)$.
  
  Η κλίση της εφαπτομένης στο σημείο $K$ είναι:
  \[ f'(0) = 3(0)^2 - 3 = -3 \]
  Η εξίσωση της εφαπτομένης είναι:
  \[ y - 1 = -3(x - 0) \Leftrightarrow y = -3x + 1 \]

  \item 
  Υπολογίζουμε το ορισμένο ολοκλήρωμα:
  \begin{align*}
  \int_{-1}^1 f(x) \d x &= \int_{-1}^1 (x^3 - 3x + 1) \d x \\
  &= \left[ \frac{x^4}{4} - \frac{3x^2}{2} + x \right]_{-1}^1 \\
  &= \left( \frac{1}{4} - \frac{3}{2} + 1 \right) - \left( \frac{(-1)^4}{4} - \frac{3(-1)^2}{2} + (-1) \right) \\
  &= \left( \frac{1-6+4}{4} \right) - \left( \frac{1-6-4}{4} \right) \\
  &= \left( -\frac{1}{4} \right) - \left( -\frac{9}{4} \right) \\
  &= \frac{8}{4} = 2
  \end{align*}
\end{erwthma}
\end{thema}
