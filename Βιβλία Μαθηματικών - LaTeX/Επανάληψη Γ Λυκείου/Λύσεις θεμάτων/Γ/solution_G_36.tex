\begin{thema}{Γ}
\begin{erwthma}
\item Η συνάρτηση $f(x) = \dfrac{e^x}{x^2+1}$ είναι παραγωγίσιμη στο $\mathbb{R}$ ως πηλίκο παραγωγίσιμων (παρανομαστής πάντα θετικός $x^2+1 \ge 1 > 0$). Η παράγωγός της είναι:
\[ f'(x) = \frac{e^x(x^2+1) - e^x \cdot 2x}{(x^2+1)^2} = \frac{e^x(x^2 - 2x + 1)}{(x^2+1)^2} = \frac{e^x(x-1)^2}{(x^2+1)^2} \]
Εφόσον $e^x > 0$, $(x-1)^2 \ge 0$ και $(x^2+1)^2 > 0$, ισχύει $f'(x) \ge 0$ για κάθε $x \in \mathbb{R}$, με $f'(x) = 0$ μόνο για $x = 1$.
Επομένως, η $f$ είναι \textbf{γνησίως αύξουσα} σε ολόκληρο το $\mathbb{R}$ (μηδένισμα μόνο σε μεμονωμένο σημείο).

Για το σύνολο τιμών, υπολογίζουμε τα όρια:
\[ \lim_{x \to -\infty} \frac{e^x}{x^2+1} = \frac{0}{+\infty} = 0^+ \]
\[ \lim_{x \to +\infty} \frac{e^x}{x^2+1} \xlongequal[\text{\eng{DLH}}]{\frac{+\infty}{+\infty}} \lim_{x \to +\infty} \frac{e^x}{2x} \xlongequal[\text{\eng{DLH}}]{\frac{+\infty}{+\infty}} \lim_{x \to +\infty} \frac{e^x}{2} = +\infty \]
Άρα το σύνολο τιμών είναι το $\boldsymbol{(0, +\infty)}$.

\item Η εξίσωση $e^x = \lambda(x^2+1)$ για $\lambda > 0$ γράφεται ισοδύναμα:
\[ \frac{e^x}{x^2+1} = \lambda \iff f(x) = \lambda \]
Από το ερώτημα (α), η $f$ είναι γνησίως αύξουσα με σύνολο τιμών $(0, +\infty)$.
Εφόσον $\lambda > 0$, η τιμή $\lambda$ ανήκει στο σύνολο τιμών της $f$.
Επειδή η $f$ είναι \textbf{γνησίως αύξουσα} (άρα 1-1), η εξίσωση $f(x) = \lambda$ έχει \textbf{ακριβώς μία} πραγματική ρίζα στο $\mathbb{R}$.

\item Θα αποδείξουμε ότι $1 < \int_0^1 f(x)\d x < \dfrac{e}{2}$.
Για $x \in [0, 1]$, ισχύει:
\begin{itemize}
    \item $x^2 + 1 \le 1 + 1 = 2$ (αφού $x^2 \le 1$), άρα $\dfrac{1}{x^2+1} \ge \dfrac{1}{2}$, οπότε $f(x) = \dfrac{e^x}{x^2+1} \ge \dfrac{e^x}{2}$.
    \item $x^2 + 1 \ge 1$ (αφού $x^2 \ge 0$), άρα $f(x) = \dfrac{e^x}{x^2+1} \le e^x$.
\end{itemize}
Ολοκληρώνουμε τις ανισότητες στο $[0,1]$:
\[ \int_0^1 \frac{e^x}{2} \d x \le \int_0^1 f(x) \d x \le \int_0^1 e^x \d x \]
\[ \frac{1}{2}[e^x]_0^1 \le \int_0^1 f(x) \d x \le [e^x]_0^1 \]
\[ \frac{e-1}{2} \le \int_0^1 f(x) \d x \le e - 1 \]
Αυτές οι ανισότητες δεν είναι αρκετά ισχυρές. Χρησιμοποιούμε καλύτερα φράγματα:
Για $x \in [0,1]$: $e^0 = 1 \le e^x \le e^1 = e$ και $x^2+1 \le 2$.
\begin{itemize}
    \item Κάτω φράγμα: $f(x) = \dfrac{e^x}{x^2+1} \ge \dfrac{e^x}{2} \ge \dfrac{1}{2}$. Άρα $\int_0^1 f(x)\d x \ge \int_0^1 \frac{1}{2}\d x = \frac{1}{2}$.
\end{itemize}
Χρησιμοποιούμε πιο ισχυρό κάτω φράγμα: για $x \in [0,1]$, $e^x \ge 1 + x \ge 1$ και $x^2 + 1 \le 2$, άρα:
\[ f(x) = \frac{e^x}{x^2+1} > \frac{e^0}{1^2+1} \cdot \frac{?}{} \]
Εναλλακτικά, αφού $f$ γνησίως αύξουσα, χρησιμοποιούμε:
\[ \int_0^1 f(x)\d x > f(0) \cdot 1 = \frac{e^0}{0^2+1} = 1 \]
*(Αυτό ισχύει επειδή η $f$ αυξάνεται, οπότε $f(x) > f(0) = 1$ για κάθε $x \in (0,1]$).*

Για το άνω φράγμα, αφού $f$ αύξουσα:
\[ \int_0^1 f(x)\d x < f(1) \cdot 1 = \frac{e^1}{1^2+1} = \frac{e}{2} \]
Άρα αποδείχθηκε:
\[ \boldsymbol{1 < \int_0^1 f(x)\d x < \frac{e}{2}} \]

\item Ορίζουμε τη συνάρτηση $h: [0,1] \to \mathbb{R}$ με:
\[ h(x) = F(x) + f(x) \]
Η $h$ είναι συνεχής στο $[0,1]$ (ως άθροισμα συνεχών) και παραγωγίσιμη στο $(0,1)$.
Υπολογίζουμε τις τιμές στα άκρα:
\[ h(0) = F(0) + f(0) = F(0) + 1 \]
\[ h(1) = F(1) + f(1) = F(1) + \frac{e}{2} \]
Η παράγωγος της $h$ είναι:
\[ h'(x) = F'(x) + f'(x) = f(x) + f'(x) \]
Η ζητούμενη συνθήκη $h(x_0) = F(1) + 1$ γράφεται:
\[ F(x_0) + f(x_0) = F(1) + 1 = F(1) + f(0) \]
Αυτό σημαίνει ότι ψάχνουμε $x_0 \in (0,1)$ τέτοιο ώστε $h(x_0) = h(1) + f(0) - f(1) + f(0)$...

Ορίζουμε αντί αυτού τη βοηθητική συνάρτηση $\phi(x) = F(x) + f(x) - F(1) - 1$.
Θέλουμε να αποδείξουμε ότι η $\phi$ μηδενίζεται σε κάποιο $x_0 \in (0,1)$.
\[ \phi(0) = F(0) + f(0) - F(1) - 1 = F(0) + 1 - F(1) - 1 = F(0) - F(1) \]
\[ \phi(1) = F(1) + f(1) - F(1) - 1 = f(1) - 1 = \frac{e}{2} - 1 > 0 \]
*(αφού $e > 2$)*

Από το Θεώρημα Μέσης Τιμής: $F(1) - F(0) = \int_0^1 f(x)\d x$.
Από το (γ), γνωρίζουμε ότι $\int_0^1 f(x)\d x > 1$, άρα $F(1) - F(0) > 1$, δηλαδή $F(0) - F(1) < -1 < 0$.
Άρα:
\[ \phi(0) = F(0) - F(1) < 0 \quad \text{και} \quad \phi(1) = \frac{e}{2} - 1 > 0 \]
Εφόσον η $\phi$ είναι συνεχής στο $[0,1]$ και $\phi(0) \cdot \phi(1) < 0$, από το \textbf{Θεώρημα Bolzano} υπάρχει τουλάχιστον ένα $x_0 \in (0, 1)$ τέτοιο ώστε:
\[ \phi(x_0) = 0 \implies F(x_0) + f(x_0) = F(1) + 1 \]
\end{erwthma}
\end{thema}
