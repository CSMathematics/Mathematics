\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = (x-a)e^x + \beta$.
\begin{erwthma}
\item Η συνάρτηση παράγεται με κανόνα γινομένου:
\[ f'(x) = (x-a)'e^x + (x-a)(e^x)' = 1\cdot e^x + (x-a)e^x = e^x(1 + x - a) \]
Εφόσον στο $x_0 = 1$ παρουσιάζει τοπικό ακρότατο (και είναι παραγωγίσιμη), ισχύει από θεώρημα Fermat: $f'(1) = 0$.
\[ e^1(1 + 1 - a) = 0 \Leftrightarrow e(2-a) = 0 \]
Καθώς $e \ne 0$, προκύπτει υποχρεωτικά $2-a = 0 \Leftrightarrow a = 2$.
Επίσης, η τιμή του ακροτάτου είναι $2$, δηλαδή $f(1) = 2$. Αντικαθιστώντας (και με $a=2$):
\[ (1-2)e^1 + \beta = 2 \Leftrightarrow -e + \beta = 2 \Leftrightarrow \beta = e + 2 \]

\item Αντικαθιστούμε τα $a, \beta$: $f(x) = (x-2)e^x + e+2$.
Η παράγωγος είναι $f'(x) = e^x(x-1)$.
Το πρόσημο της παραγώγου εξαρτάται μόνο από το $x-1$:
- $f'(x) > 0 \Leftrightarrow x > 1$.
- $f'(x) < 0 \Leftrightarrow x < 1$.

Η συνάρτηση είναι:
- \textbf{Γνησίως φθίνουσα} στο $(-\infty, 1]$.
- \textbf{Γνησίως αύξουσα} στο $[1, +\infty)$.
- Παρουσιάζει \textbf{ολικό ελάχιστο} στο $x=1$ με τιμή $f(1) = 2$.

\item Αφού σύμφωνα με το προηγούμενο ερώτημα ο αριθμός 2 είναι το \textbf{ολικό ελάχιστο} της $f$, ισχύει για κάθε $x \in \mathbb{R}$:
\[ f(x) \ge f(1) \Leftrightarrow f(x) \ge 2 \]
Αντικαθιστώντας τον τύπο της $f(x)$:
\[ (x-2)e^x + e + 2 \ge 2 \Leftrightarrow (x-2)e^x + e \ge 0 \Leftrightarrow e^x(x-2) + e \ge 0 \]
Η σχέση ισχύει για κάθε πραγματικό αριθμό $x$.

\item Υπολογίζουμε τα όρια στα $\pm\infty$ για τον εντοπισμό οριζόντιων ασύμπτωτων:
- Στο $+\infty$:
\[ \lim_{x\to+\infty} f(x) = \lim_{x\to+\infty} [(x-2)e^x + e + 2] = (+\infty)(+\infty) + e+2 = +\infty \]
Άρα δεν έχει οριζόντια ασύμπτωτη στο $+\infty$.
- Στο $-\infty$:
\[ \lim_{x\to-\infty} f(x) = \lim_{x\to-\infty} [(x-2)e^x + e + 2] = \lim_{x\to-\infty} [x e^x - 2e^x + e + 2] \]
Γνωρίζουμε ότι $\lim_{x\to-\infty} e^x = 0$.
Για το όριο του  $\lim_{x\to-\infty} (x e^x)$:
\[ \lim_{x\to-\infty} (x e^x) = \lim_{x\to-\infty} \frac{x}{e^{-x}} \xlongequal[\text{DLH}]{\frac{-\infty}{+\infty}} \lim_{x\to-\infty} \frac{1}{-e^{-x}} = 0 \]
Άρα:
\[ \lim_{x\to-\infty} f(x) = 0 - 2(0) + e + 2 = e + 2 \]
Συμπεραίνουμε πως η ευθεία $y = e+2$ αποτελεί \textbf{οριζόντια ασύμπτωτη} στο $-\infty$.
\end{erwthma}
\end{thema}
