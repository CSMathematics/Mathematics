\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \ln(x-a) + x - 1$, η οποία διέρχεται από το σημείο $A(2, 1)$.

\begin{erwthma}
\item Αφού η $C_f$ διέρχεται από το $A(2, 1)$, ισχύει ότι $f(2) = 1$.
Αντικαθιστούμε $x = 2$ στον τύπο της συνάρτησης:
\[ f(2) = \ln(2-a) + 2 - 1 = \ln(2-a) + 1 \]
Άρα $\ln(2-a) + 1 = 1 \Leftrightarrow \ln(2-a) = 0 \Leftrightarrow 2-a = 1 \Leftrightarrow a = 1$.
Οπότε ο τύπος της είναι $f(x) = \ln(x-1) + x - 1$.
Η $f$ ορίζεται όταν $x-1 > 0 \Leftrightarrow x > 1$.
Επομένως το πεδίο ορισμού της είναι $D_f = (1, +\infty)$.

\item Η κατακόρυφη ασύμπτωτη της $f$ αναζητείται στο άκρο του πεδίου ορισμού $x_0 = 1$.
Υπολογίζουμε το όριο:
\[ \lim_{x\to1^+} f(x) = \lim_{x\to1^+} (\ln(x-1) + x - 1) =-\infty + 0 = -\infty\]
Αφού το πλευρικό όριο στο $x_0 = 1$ δίνει άπειρο, η ευθεία $x = 1$ είναι κατακόρυφη ασύμπτωτη της γραφικής της παράστασης.

\item Η $f$ είναι παραγωγίσιμη στο $(1, +\infty)$ με παράγωγο:
\[ f'(x) = (\ln(x-1) + x - 1)' = \dfrac{1}{x-1} + 1>0 \]
για κάθε $x \in (1, +\infty)$. Άρα η συνάρτηση $f$ είναι γνησίως αύξουσα, δηλαδή είναι συνάρτηση $1-1$, και επομένως αντιστρέφεται. Για την εξίσωση $f(e^x+1) = 1$:
Από τα δεδομένα γνωρίζουμε ήδη ότι $f(2) = 1$. Οπότε:
\[ f(e^x+1) = f(2)\xLeftrightarrow{1-1}e^x+1 = 2 \Leftrightarrow e^x = 1 \Leftrightarrow e^x = e^0 \Leftrightarrow x = 0 \]
Άρα η μοναδική λύση είναι $x = 0$.

\item Η $f$ είναι συνεχής και γνησίως αύξουσα στο $\Delta = (1, 2)$, με εικόνα:
\[ f((1, 2)) = \left( \lim_{x\to1^+} f(x), \lim_{x\to2^-} f(x) \right) \]
\begin{itemize}
\item $\displaystyle\lim_{x\to1^+} f(x)=-\infty$.
\item $\displaystyle\lim_{x\to2^-} f(x) = f(2) = 1$
\end{itemize}
Επομένως, $f((1, 2))=(-\infty, 1)$. Επειδή το $0\in(-\infty, 1) = f((1, 2))$, η εξίσωση $f(x) = 0$ έχει τουλάχιστον μία ρίζα στο $(1, 2)$. Και επειδή η $f$ είναι γνησίως αύξουσα, η ρίζα αυτή είναι μοναδική. Άρα η εξίσωση $f(x) = 0$ έχει ακριβώς μία ρίζα στο διάστημα $(1, 2)$.
\end{erwthma}
\end{thema}
