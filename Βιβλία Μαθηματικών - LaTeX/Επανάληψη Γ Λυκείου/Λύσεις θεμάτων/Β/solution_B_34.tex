\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = x^2e^{-x+1}$.

\begin{erwthma}
\item Το πεδίο ορισμού είναι $D_f = \mathbb{R}$. Η $f$ είναι παραγωγίσιμη με:
\[ f'(x) = 2x e^{-x+1} + x^2(-e^{-x+1}) = x(2- x)e^{-x+1} \]
Οι ρίζες είναι $x=0$ και $x=2$. Επειδή $e^{-x+1} > 0$, το πρόσημο καθορίζεται από το $x(2-x) = -x^2+2x$.
Στον παρακάτω πίνακα φαίνεται το πρόσημο της $f'$ και η μονοτονία της $f$:

\end{tikzpicture}
\end{center}
Η συνάρτηση παρουσιάζει:
- ολικό ελάχιστο στο $x=0$ ίσο με $0$, 
- τοπικό μέγιστο στο $x=2$ ίσο με $\frac{4}{e}$.

\item Η $f'$ είναι παραγωγίσιμη με:
\[ f''(x) = (2x-x^2)'e^{-x+1} + (2x-x^2)(e^{-x+1})' = (2-2x)e^{-x+1} - (2x-x^2)e^{-x+1} = (x^2-4x+2)e^{-x+1} \]
Οι ρίζες του $x^2-4x+2=0$ είναι $x_1 = 2-\sqrt{2}$ και $x_2 = 2+\sqrt{2}$.
Στον παρακάτω πίνακα φαίνεται το πρόσημο της $f''$ και η κυρτότητα της $f$:

Η $C_f$ αλλάζει κυρτότητα στα σημεία αυτά τα οποία αποτελούν σημεία καμπής.

\item Υπολογίζουμε $f(1) = 1^2e^0 = 1$ και $f'(1) = 1(2-1)e^0 = 1$.
Η εξίσωση της εφαπτομένης στο $(1, 1)$ είναι:
\[ y - 1 = 1(x - 1) \Leftrightarrow y = x \]
Για την ανισότητα $x^2e^{-x+1} \le x$ για $x \ge 0$:
Για $x=0$, ισχύει ως $0 \le 0$.
Για $x > 0$, απαιτείται $x e^{-x+1} \le 1$. Επειδή και τα δύο μέλη είναι θετικά, λογαριθμίζουμε:
\[ \ln(xe^{-x+1}) \le \ln 1 \Leftrightarrow \ln x + \ln(e^{-x+1}) \le 0 \Leftrightarrow \ln x - x + 1 \le 0 \Leftrightarrow \ln x \le x - 1 \]
Η τελευταία ανισότητα είναι η γνωστή βασική $\ln x \le x-1$ που ισχύει για κάθε $x>0$.

\item Το όριο είναι:
\[ \lim_{x\to0^+} (f(x) \ln x) = \lim_{x\to0^+} (x^2 e^{-x+1} \ln x) = \lim_{x\to0^+} ( e^{-x+1} \cdot x \cdot (x \ln x) ) \]
Επειδή $\lim_{x\to0^+} e^{-x+1} = e$, $\lim_{x\to0^+} x = 0$ και $\lim_{x\to0^+} (x \ln x) = 0$ (αποδεδειγμένο όριο), το συνολικό γινόμενο τείνει στο $e \cdot 0 \cdot 0 = 0$.
\end{erwthma}
\end{thema}
