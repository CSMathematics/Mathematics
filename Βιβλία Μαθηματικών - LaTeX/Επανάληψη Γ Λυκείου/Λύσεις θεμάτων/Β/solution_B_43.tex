\begin{thema}{Β}
Δίνονται οι συναρτήσεις $f(x) = x+1$ και $g(x) = \dfrac{1}{x+1}$.
\begin{erwthma}
\item Το πεδίο ορισμού της $f$ είναι $\mathbb{R}$. Το πεδίο ορισμού της $g$ είναι το σύνολο $\mathbb{R} \setminus \{-1\}$.
Το πεδίο ορισμού του αθροίσματος $h = f + g$ είναι η τομή των πεδίων ορισμού, άρα $A_h = \mathbb{R} \setminus \{-1\}$.
Ο τύπος της είναι:
\[ h(x) = f(x) + g(x) = x + 1 + \frac{1}{x+1} \]

\item Εξετάζουμε την εξίσωση $h(x) = 0$ στο $[-2, 0]$ (και φυσικά $x \ne -1$):
\[ x + 1 + \frac{1}{x+1} = 0 \Leftrightarrow \frac{(x+1)^2 + 1}{x+1} = 0 \Leftrightarrow (x+1)^2 + 1 = 0 \Leftrightarrow (x+1)^2 = -1 \]
H παραπάνω εξίσωση είναι προφανώς αδύνατη στο $\mathbb{R}$. Επομένως, \textbf{δεν έχει καμία λύση} ούτε στο διάστημα $[-2, 0]$.
Δεύτερο σκέλος: ελέγχουμε αν υπάρχει $x_0 \in [0, 1]$ τέτοιο ώστε $h(x_0)=2$.
Βλέπουμε ότι με δοκιμή στα άκρα:
$h(0) = 0 + 1 + 1/1 = 2$.
Άρα \textbf{υπάρχει} τέτοιο σημείο (το $x_0=0$) το οποίο ανήκει στο $[0, 1]$.

\item Η $h$ είναι παραγωγίσιμη στο πεδίο ορισμού της με:
\[ h'(x) = 1 - \frac{1}{(x+1)^2} = \frac{(x+1)^2 - 1}{(x+1)^2} = \frac{x^2+2x+1-1}{(x+1)^2} = \frac{x^2+2x}{(x+1)^2} = \frac{x(x+2)}{(x+1)^2} \]
Οι ρίζες της $h'(x)$ είναι το $0$ και το $-2$. 
Επειδή ο παρονομαστής $(x+1)^2 > 0$ για $x \ne -1$, το πρόσημο εξαρτάται μόνο από τον αριθμητή:
- $h'(x) > 0 \Leftrightarrow x \in (-\infty, -2) \cup (0, +\infty)$.
- $h'(x) < 0 \Leftrightarrow x \in (-2, -1) \cup (-1, 0)$.
Στον παρακάτω πίνακα φαίνεται το πρόσημο της $h'$ και η μονοτονία της $h$:

Η συνάρτηση $h$ παρουσιάζει:
- τοπικό μέγιστο στο $x = -2$, με τιμή $h(-2) = -2 + 1 + \frac{1}{-2+1} = -2$.
- τοπικό ελάχιστο στο $x = 0$, με τιμή $h(0) = 2$.
(Αξίζει να σημειωθεί ότι το τοπικό ελάχιστο είναι μεγαλύτερο από το τοπικό μέγιστο).

\item \textbf{Κατακόρυφες:} Αναζητούμε κατακόρυφη ασύμπτωτη στο σημείο μη ορισμού $x = -1$.
\[ \lim_{x\to-1^+} h(x) = \lim_{x\to-1^+} \left( (x+1) + \frac{1}{x+1} \right) = 0 + \frac{1}{0^+} = +\infty \]
Ομοίως $\lim_{x\to-1^-} h(x) = -\infty$. Άρα η ευθεία $x = -1$ είναι κατακόρυφη ασύμπτωτη.
\textbf{Πλάγιες/Οριζόντιες:} Γράφουμε την $h(x)$ σε μορφή $h(x) = \lambda x + \beta + \Phi(x)$.
Συγκεκριμένα $h(x) = (x+1) + \frac{1}{x+1}$.
Επειδή $\lim_{x\to\pm\infty} \frac{1}{x+1} = 0$, προκύπτει άμεσα ότι η ευθεία $y = x+1$ είναι ασύμπτωτη της γραφικής παράστασης τόσο στο $+\infty$ όσο και στο $-\infty$.
\end{erwthma}
\end{thema}
