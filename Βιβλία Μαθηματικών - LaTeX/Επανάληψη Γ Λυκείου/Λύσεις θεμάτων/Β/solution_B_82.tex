\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = x^3 - 3x^2 + 1$ με πεδίο ορισμού το $\mathbb{R}$.

\begin{erwthma}

\item Η $f(x)$ είναι παραγωγίσιμη στο $\mathbb{R}$ (ως πολυωνυμική συνάρτηση) με παράγωγο:
\[ f'(x) = (x^3 - 3x^2 + 1)' = 3x^2 - 6x = 3x(x - 2) \]

Βρίσκουμε τις ρίζες και το πρόσημο της παραγώγου:
\begin{itemize}
    \item $f'(x) = 0 \Leftrightarrow 3x(x - 2) = 0 \Leftrightarrow x = 0$ ή $x = 2$
    \item Το τριώνυμο $3x^2 - 6x$ έχει θετικό πρόσημο εκτός του διαστήματος των ριζών, δηλαδή για $x < 0$ ή $x > 2$, και αρνητικό εντός, δηλαδή για $0 < x < 2$.
\end{itemize}

Στον παρακάτω πίνακα φαίνεται το πρόσημο της $f'$ και η μονοτονία της $f$:
\begin{center}

\end{center}
Συνεπώς η $f$ είναι γνησίως αύξουσα στα διαστήματα $(-\infty, 0]$ και $[2, +\infty)$, και γνησίως φθίνουσα στο $[0, 2]$. 
Παρουσιάζει:
\begin{itemize}
    \item \textbf{Τοπικό μέγιστο} στο $x = 0$ με τιμή $f(0) = 0^3 - 3 \cdot 0^2 + 1 = 1$.
    \item \textbf{Τοπικό ελάχιστο} στο $x = 2$ με τιμή $f(2) = 2^3 - 3 \cdot 2^2 + 1 = 8 - 12 + 1 = -3$.
\end{itemize}

\item Η συνάρτηση είναι συνεχής σε όλο το $\mathbb{R}$. Υπολογίζουμε τα όρια στα άκρα του πεδίου ορισμού:
\begin{itemize}
    \item $\lim\limits_{x \to -\infty} f(x) = \lim\limits_{x \to -\infty} (x^3 - 3x^2 + 1) = \lim\limits_{x \to -\infty} x^3 = -\infty$
    \item $\lim\limits_{x \to +\infty} f(x) = \lim\limits_{x \to +\infty} (x^3 - 3x^2 + 1) = \lim\limits_{x \to +\infty} x^3 = +\infty$
\end{itemize}
Εφόσον $f$ συνεχής και τα όριά της στο $-\infty$ και $+\infty$ είναι $-\infty$ και $+\infty$ αντίστοιχα, το \textbf{σύνολο τιμών της είναι όλο το} $\mathbb{R}$. 
Επειδή το σύνολο τιμών δεν έχει άνω ή κάτω φράγμα (είναι το $(-\infty, +\infty)$), η $f$ \textbf{δεν παρουσιάζει ολικά ακρότατα}.

\item Η δοσμένη εξίσωση γράφεται ισοδύναμα:
\[ x^3 - 3x^2 + \lambda = 0 \Leftrightarrow (x^3 - 3x^2 + 1) - 1 + \lambda = 0 \Leftrightarrow f(x) = 1 - \lambda \]
Το πλήθος των ριζών αντιστοιχεί στο πλήθος των σημείων τομής της γραφικής παράστασης της $f$ με την οριζόντια ευθεία $y = 1 - \lambda$. 

Με βάση τα τοπικά ακρότατα της συνάρτησης, $f(0) = 1$ και $f(2) = -3$, θεωρούμε τα υποδιαστήματα μονοτονίας $\Delta_1 = (-\infty, 0], \Delta_2 = (0, 2)$ και $\Delta_3 = [2, +\infty)$. Τα αντίστοιχα υποσύνολα τιμών είναι $f(\Delta_1) = (-\infty, 1]$, $f(\Delta_2) = (-3, 1)$ και $f(\Delta_3) = [-3, +\infty)$. Διακρίνουμε τις περιπτώσεις για την τιμή του $1 - \lambda$:
\begin{itemize}
    \item Αν $1 - \lambda > 1 \Leftrightarrow \lambda < 0$: Η ευθεία τέμνει την καμπύλη μόνο στον κλάδο του $\Delta_3$, άρα \textbf{1 ρίζα}.
    \item Αν $1 - \lambda = 1 \Leftrightarrow \lambda = 0$: Η ευθεία τέμνει την καμπύλη στο τοπικό μέγιστο (διπλή/σημείο επαφής στο $\Delta_1,\Delta_2$) και σε 1 σημείο στο $\Delta_3$, συνολικά \textbf{2 ρίζες}.
    \item Αν $-3 < 1 - \lambda < 1 \Leftrightarrow 0 < \lambda < 4$: Η ευθεία τέμνει την καμπύλη τρεις φορές, μία σε κάθε διάστημα $\Delta_1, \Delta_2, \Delta_3$, άρα \textbf{3 ρίζες}.
    \item Αν $1 - \lambda = -3 \Leftrightarrow \lambda = 4$: Η ευθεία τέμνει την καμπύλη στο τοπικό ελάχιστο (διπλή/σημείο επαφής στο $\Delta_2,\Delta_3$) και σε 1 σημείο στο $\Delta_1$, συνολικά \textbf{2 ρίζες}.
    \item Αν $1 - \lambda < -3 \Leftrightarrow \lambda > 4$: Η ευθεία τέμνει την καμπύλη μόνο στον κλάδο του $\Delta_1$, άρα \textbf{1 ρίζα}.
\end{itemize}

\item Η εφαπτομένη της γραφικής παράστασης $C_f$ είναι οριζόντια στα σημεία όπου ο συντελεστής διεύθυνσης, δηλαδή η παράγωγος, μηδενίζεται. 
Έχουμε ήδη υπολογίσει ότι $f'(x) = 0$ για $x = 0$ και $x = 2$.
Τα αντίστοιχα σημεία της $C_f$ είναι ακριβώς εκείνα των τοπικών ακροτάτων:
\begin{itemize}
    \item Για $x=0$,  η τεταγμένη είναι $f(0) = 1$, άρα το σημείο είναι $A(0, 1)$.
    \item Για $x=2$, η τεταγμένη είναι $f(2) = -3$, άρα το σημείο είναι $B(2, -3)$.
\end{itemize}
Συνεπώς, τα ζητούμενα σημεία είναι το $A(0, 1)$ και το $B(2, -3)$.

\end{erwthma}
\end{thema}
