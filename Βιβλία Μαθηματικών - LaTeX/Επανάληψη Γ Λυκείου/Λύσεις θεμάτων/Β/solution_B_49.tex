\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \dfrac{x - \hm x}{x + \hm x}$ με $x \neq 0$. (Η εκφώνηση υπονοεί $x>0$ ή ανοικτό διάστημα γύρω από το 0 αποκλείοντας το 0 και άλλα σημεία μηδενισμού, πχ $x=-\hm x$. Στην περιοχή του $0$ ισχύει.)
\begin{erwthma}
\item Για το όριο στο 0 διαιρούμε αριθμητή και παρονομαστή με $x \neq 0$:
\[ \lim_{x\to0} f(x) = \lim_{x\to0} \frac{x - \hm x}{x + \hm x} = \lim_{x\to0} \frac{\frac{x}{x} - \frac{\hm x}{x}}{\frac{x}{x} + \frac{\hm x}{x}} = \lim_{x\to0} \frac{1 - \frac{\hm x}{x}}{1 + \frac{\hm x}{x}} \]
Γνωρίζοντας το βασικό όριο $\lim_{x\to0} \frac{\hm x}{x} = 1$, έχουμε:
\[ \lim_{x\to0} f(x) = \frac{1 - 1}{1 + 1} = \frac{0}{2} = 0 \]

\item Για το όριο στο $+\infty$, ακολουθούμε παρόμοια τεχνική βγάζοντας κοινό παράγοντα το $x$:
\[ \lim_{x\to+\infty} f(x) = \lim_{x\to+\infty} \frac{x\left(1 - \frac{\hm x}{x}\right)}{x\left(1 + \frac{\hm x}{x}\right)} = \lim_{x\to+\infty} \frac{1 - \frac{\hm x}{x}}{1 + \frac{\hm x}{x}} \]
Από την ιδιότητα $|\hm x| \le 1 \Rightarrow -1 \le \hm x \le 1$. Διαιρώντας με $x > 0$:
\[ -\frac{1}{x} \le \frac{\hm x}{x} \le \frac{1}{x} \]
Επειδή $\lim_{x\to+\infty} \left(-\frac{1}{x}\right) = 0$ και $\lim_{x\to+\infty} \frac{1}{x} = 0$, σύμφωνα με το Κριτήριο Παρεμβολής ισχύει $\lim_{x\to+\infty} \frac{\hm x}{x} = 0$.
Επομένως το ζητούμενο όριο είναι:
\[ \lim_{x\to+\infty} f(x) = \frac{1 - 0}{1 + 0} = 1 \]

\item Η συνάρτηση $h(x) = x - \hm x$ είναι παραγωγίσιμη στο $\mathbb{R} $ με:
\[ h'(x) = 1 - \syn x \]
Γνωρίζουμε ότι $\syn x \le 1 \Rightarrow 1 - \syn x \ge 0$.
Άρα $h'(x) \ge 0$ για κάθε $x \in \mathbb{R}$. Το $h'(x)$ μηδενίζεται μόνο στα απομονωμένα σημεία $x = 2\kappa\pi$ ($\kappa \in \mathbb{Z}$). 
Δεδομένου ότι η παράγωγος δεν είναι μηδέν σε κανένα διάστημα (μη πεπερασμένου πλάτους), η $h$ είναι γνησίως αύξουσα στο $\mathbb{R}$.

\item Ζητείται η μοναδικότητα της ρίζας για την εξίσωση $x = \hm x \Leftrightarrow x - \hm x = 0 \Leftrightarrow h(x) = 0$.
Παρατηρούμε ότι για $x = 0$, ισχύει $h(0) = 0 - \hm 0 = 0$. Οπότε το $x=0$ είναι προφανής ρίζα της εξίσωσης.
Επιπροσθέτως, όπως αποδείχθηκε στο (Β3), η συνάρτηση $h(x)$ είναι γνησίως αύξουσα σε όλο το $\mathbb{R}$. 
Επομένως, η $h(x)$ τέμνει τον άξονα $x'x$ το πολύ σε ένα σημείο. 
Άρα το $x=0$ αποτελεί τη μοναδική ρίζα της εξίσωσης στο $\mathbb{R}$.
\end{erwthma}
\end{thema}
