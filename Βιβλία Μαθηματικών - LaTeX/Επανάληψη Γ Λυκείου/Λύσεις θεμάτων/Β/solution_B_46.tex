\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \dfrac{\sqrt{x+1}-1}{x}$ για $x \ge -1$ και $x \ne 0$.
\begin{erwthma}
\item Για τον υπολογισμό του ορίου στο 0, πολλαπλασιάζουμε με τη συζυγή παράσταση:
\[ \lim_{x\to0} f(x) = \lim_{x\to0} \frac{\sqrt{x+1}-1}{x} = \lim_{x\to0} \frac{(\sqrt{x+1}-1)(\sqrt{x+1}+1)}{x(\sqrt{x+1}+1)} = \lim_{x\to0} \frac{x+1-1}{x(\sqrt{x+1}+1)} \]
\[ = \lim_{x\to0} \frac{x}{x(\sqrt{x+1}+1)} = \lim_{x\to0} \frac{1}{\sqrt{x+1}+1} = \frac{1}{\sqrt{1}+1} = \frac{1}{2} \]

\item Αφού η $g$ αποτελεί συνεχή επέκταση της $f$ στο $[-1, +\infty)$, πρέπει η τιμή της στο $x_0 = 0$ να ισούται με το όριό της. Δηλαδή $g(0) = \lim\limits_{x\to0} f(x) = \frac{1}{2}$.
Ο τύπος της $g$ είναι:
\[ g(x) = \begin{cases} \frac{\sqrt{x+1}-1}{x}, & x \in [-1, 0) \cup (0, +\infty) \\ \frac{1}{2}, & x = 0 \end{cases} \]

\item Εξετάζουμε τη συνεχή(ως επέκταση) συνάρτηση $g$ στο κλειστό διάστημα $[0, 3]$.
Υπολογίζουμε τις τιμές στα άκρα:
- $g(0) = \frac{1}{2} = 0,5$.
- $g(3) = \frac{\sqrt{3+1}-1}{3} = \frac{2-1}{3} = \frac{1}{3} \approx 0,33$.
Παρατηρούμε ότι το $\frac{2}{5} = 0,4$ βρίσκεται ακριβώς ανάμεσα στις τιμές $g(3)$ και $g(0)$, αφού $0,33 < 0,4 < 0,5$. 
Συγκεκριμένα: $g(3) < \frac{2}{5} < g(0)$.
Αφού η $g$ είναι συνεχής στο $[0, 3]$, το Θεώρημα Ενδιάμεσων Τιμών εξασφαλίζει ότι υπάρχει τουλάχιστον ένα $\xi \in (0, 3)$ τέτοιο ώστε $g(\xi) = \frac{2}{5}$.

\item Η συνάρτηση $g$ (που ταυτίζεται με την $f$) είναι παραγωγίσιμη στο $(-1, 0) \cup (0, +\infty)$. Υπολογίζουμε την $g'$:
\[ g'(x) = \frac{ \frac{1}{2\sqrt{x+1}}\cdot x - (\sqrt{x+1}-1)\cdot 1 }{x^2} = \frac{ x - 2\sqrt{x+1}(\sqrt{x+1}-1) }{2x^2\sqrt{x+1}} = \frac{ x - 2(x+1) + 2\sqrt{x+1} }{2x^2\sqrt{x+1}} \]
\[ g'(x) = \frac{ -x - 2 + 2\sqrt{x+1} }{2x^2\sqrt{x+1}} \]
Για τον αριθμητή, ισχύει από βασική ταυτότητα: $(\sqrt{x+1}-1)^2 > 0 \Rightarrow x+1 - 2\sqrt{x+1} + 1 > 0 \Rightarrow x+2 > 2\sqrt{x+1}$.
Οπότε $-x-2+2\sqrt{x+1} < 0$. Αφού ο παρονομαστής είναι θετικός, $g'(x) < 0$ για κάθε $x \neq 0$.
Επειδή η $g$ είναι συνεχής και στο 0, συνάγεται ότι είναι γνησίως φθίνουσα σε όλο το $[-1, +\infty)$. Επειδή είναι γνησίως μονότονη, είναι "1-1" κι επομένως αντιστρέφεται στο πεδίο ορισμού της.
\end{erwthma}
\end{thema}
