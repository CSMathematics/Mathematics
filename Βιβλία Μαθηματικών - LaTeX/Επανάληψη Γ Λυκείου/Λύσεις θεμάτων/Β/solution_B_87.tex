\begin{thema}{Β}
Δίνεται μια συνάρτηση $f$ με πεδίο ορισμού το $\mathbb{R}$ η οποία ικανοποιεί τη συναρτησιακή σχέση $2f(x) + f(-x) = 3x^2 + x$ για κάθε $x \in \mathbb{R}$.

\begin{erwthma}

\item Στη δοσμένη σχέση, θέτουμε όπου $x$ το $-x$. Επειδή το πεδίο ορισμού είναι όλο το $\mathbb{R}$, αυτό είναι επιτρεπτό. Λαμβάνουμε:
\[ 2f(-x) + f(-(-x)) = 3(-x)^2 + (-x) \Leftrightarrow 2f(-x) + f(x) = 3x^2 - x \]
Σχηματίζεται έτσι το ακόλουθο γραμμικό σύστημα των $f(x)$ και $f(-x)$:
\[ \begin{cases}
2f(x) + f(-x) = 3x^2 + x \quad (1) \\
f(x) + 2f(-x) = 3x^2 - x \quad (2)
\end{cases} \]
Πολλαπλασιάζουμε την εξίσωση (1) επί 2:
\[ 4f(x) + 2f(-x) = 6x^2 + 2x \quad (3) \]
Αφαιρούμε την εξίσωση (2) από την (3) κατά μέλη:
\[ (4f(x) + 2f(-x)) - (f(x) + 2f(-x)) = (6x^2 + 2x) - (3x^2 - x) \]
\[ 3f(x) = 3x^2 + 3x \xlongequal{:3} f(x) = x^2 + x \]
Επομένως, δείξαμε ότι ο τύπος της συνάρτησης είναι πράγματι $f(x) = x^2 + x$.

\item Η συνάρτηση $f(x) = x^2 + x$ είναι ένα παραβολικό πολυώνυμο 2ου βαθμού, δύο φορές παραγωγίσιμη στο $\mathbb{R}$.
\begin{itemize}
    \item \textbf{Μονοτονία:}
    Η πρώτη παράγωγος είναι $f'(x) = 2x + 1$.
    \[ f'(x) = 0 \Leftrightarrow 2x + 1 = 0 \Leftrightarrow x = -\frac{1}{2} \]
    Το πρόσημο της $f'(x)$ είναι αρνητικό για $x < -1/2$ και θετικό για $x > -1/2$. Άρα, η συνάρτηση είναι:
    \begin{itemize}
        \item Γνησίως φθίνουσα στο $\left(-\infty, -\frac{1}{2}\right]$.
        \item Γνησίως αύξουσα στο $\left[-\frac{1}{2}, +\infty\right)$.
    \end{itemize}
    (και κατά συνέπεια παρουσιάζει ολικό ελάχιστο στο $x = -1/2$).
    
    \item \textbf{Κυρτότητα:}
    Η δεύτερη παράγωγος είναι $f''(x) = (2x + 1)' = 2 > 0$ για κάθε $x \in \mathbb{R}$.
    Καθώς η $f''(x)$ είναι σταθερά θετική, συναπάγεται ότι η συνάρτηση $f$ είναι κυρτή (στρέφει τα κοίλα άνω) σε όλο το $\mathbb{R}$.
\end{itemize}

\item Εξετάζουμε αν το σημείο $Α(-1, 0)$ ανήκει στη γραφική παράσταση $C_f$:
\[ f(-1) = (-1)^2 + (-1) = 1 - 1 = 0 \]
Καθώς $f(-1) = 0$, το σημείο όντως ανήκει στην $C_f$.

Για την εφαπτομένη της συνάρτησης στο σημείο αυτό, βρίσκουμε πρώτα την κλίση της:
\[ \lambda = f'(-1) = 2(-1) + 1 = -1 \]
Οπότε η εξίσωση της εφαπτομένης $(\varepsilon)$ στο $A(-1, 0)$ διαμορφώνεται ως εξής:
\[ y - f(-1) = f'(-1) (x - (-1)) \Leftrightarrow y - 0 = -1 (x + 1) \Leftrightarrow y = -x - 1 \]
Ζητείται να δειχθεί ότι η εφαπτομένη $\varepsilon: y = -x - 1$ διέρχεται από το $Β(0, -1)$.
Αντικαθιστώντας $x = 0$ στην εξίσωση της εφαπτομένης προκύπτει:
\[ y = -0 - 1 = -1 \]
Άρα η εξίσωση επαληθεύεται, πράγμα που σημαίνει ότι η ευθεία διέρχεται από το σημείο $Β(0, -1)$.

\item \textit{Σημείωση επί της εκφώνησης:} Η εκφώνηση ζητά το εμβαδόν του χωρίου μεταξύ $C_f$, της εφαπτομένης και του άξονα $x'x$. Όμως η $C_f$, η $(\varepsilon)$ και ο $x'x$ ταυτίζονται ως προς σημεία τομής αποκλειστικά στο κοινό τους σημείο $A(-1, 0)$ δίχως να περικλείουν κάποιο κλειστό χωρίο. Είναι πρόδηλο γεωμετρικά ότι οι τρεις κορυφές του καμπυλόγραμμου τριγώνου, για να σχηματίσει εμβαδόν πεπερασμένης έκτασης, είναι το $A(-1,0)$, το $O(0,0)$ (ρίζα της $C_f$) και το $B(0,-1)$ (σημείο τομής εφαπτομένης με άξονα $y'y$). Συνεπώς, εννοείται η τομή με τον άξονα $y'y$ ($x=0$) αντί του $x'x$. Προχωράμε τον υπολογισμό με βάση αυτό το δεδομένο, καθώς είναι η ορθή προσέγγιση σε αυτό το κλασικό θέμα.

Το ζητούμενο εμβαδόν οριοθετείται κατακόρυφα από το $x=-1$ έως το $x=0$. Σε αυτό το διάστημα, η κυρτότητα της $f(x)$ εξασφαλίζει ότι η γραφική παράσταση (που σχηματίζει κοίλανση) βρίσκεται συνεχώς "πάνω" από την εφαπτομένη της. Αυτό επιβεβαιώνεται και αλγεβρικά:
\[ f(x) - y_{\varepsilon} = x^2 + x - (-x - 1) = x^2 + 2x + 1 = (x + 1)^2 \ge 0 \]
Συνεπώς, το εμβαδόν αντιστοιχεί στο ολοκλήρωμα της διαφοράς των δύο συναρτήσεων:
\[ E = \int_{-1}^{0} | f(x) - y_{\varepsilon} | \, \mathrm{d}x = \int_{-1}^{0} (x + 1)^2 \, \mathrm{d}x \]
Υπολογίζοντας το ολοκλήρωμα καταλήγουμε:
\[ E = \left[ \frac{(x + 1)^3}{3} \right]_{-1}^{0} = \frac{(0 + 1)^3}{3} - \frac{(-1 + 1)^3}{3} = \frac{1}{3} - 0 = \frac{1}{3} \ \text{τ.μ.} \]

\end{erwthma}
\end{thema}
