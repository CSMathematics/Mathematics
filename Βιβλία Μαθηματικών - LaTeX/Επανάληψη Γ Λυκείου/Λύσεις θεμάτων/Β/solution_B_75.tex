\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \dfrac{ax^2+1}{x}$ με $x \ne 0$.
\begin{erwthma}
\item Η παραγωγήσιμη συνάρτηση είναι (ως πηλίκο):
\[ f'(x) = \left(ax + \frac{1}{x}\right)' = a - \frac{1}{x^2} \]
Γνωρίζουμε ότι η $f$ παρουσιάζει τοπικό ακρότατο στο εσωτερικό σημείο $x_0=1$. Από το Θεώρημα Fermat έπεται ότι:
\[ f'(1) = 0 \Leftrightarrow a - \frac{1}{1^2} = 0 \Leftrightarrow a = 1 \]

\item Αντικαθιστούμε το $a=1$: $f(x) = \frac{x^2+1}{x} = x + \frac{1}{x}$.
Η παράγωγος είναι $f'(x) = 1 - \frac{1}{x^2} = \frac{x^2-1}{x^2}$.
Μηδενίζουμε την παράγωγο για να βρούμε τα κρίσιμα σημεία:
$x^2 - 1 = 0 \Leftrightarrow x = 1$ ή $x = -1$.
- Για $x \in (-\infty, -1) \cup (1, +\infty)$, $x^2-1 > 0 \Rightarrow f'(x) > 0$.
- Για $x \in (-1, 0) \cup (0, 1)$, $x^2-1 < 0 \Rightarrow f'(x) < 0$.

- Παρουσιάζει \textbf{τοπικό μέγιστο} στο $x = -1$ με τιμή $f(-1) = -1 - 1 = -2$.
- Παρουσιάζει \textbf{τοπικό ελάχιστο} στο $x = 1$ με τιμή $f(1) = 1 + 1 = 2$.
Επειδή $\lim_{x\to0^+} f(x) = +\infty$ και $\lim_{x\to0^-} f(x) = -\infty$, η συνάρτηση \textbf{δεν έχει ολικά} ακρότατα.

\item Εφαρμόζουμε το Θεώρημα Μέσης Τιμής (Θ.Μ.Τ.) για την $f$ στο διάστημα $[1, 2]$:
- Η $f$ είναι συνεχής στο $[1, 2]$.
- Η $f$ είναι παραγωγίσιμη στο $(1, 2)$.
Άρα υπάρχει $\xi \in (1, 2)$ τέτοιο ώστε:
\[ f'(\xi) = \frac{f(2) - f(1)}{2 - 1} \]
Υπολογίζουμε τις τιμές: $f(2) = 2 + \frac{1}{2} = 2,5 = \frac{5}{2}$ και $f(1) = 2$.
Αντικαθιστώντας λαμβάνουμε:
\[ f'(\xi) = \frac{\frac{5}{2} - 2}{1} = \frac{5-4}{2} = \frac{1}{2} \]
Το ζητούμενο αποδείχθηκε.

\item Αναζητούμε κατακόρυφες και πλάγιες/οριζόντιες ασύμπτωτες:
- **Κατακόρυφες**: Ελέγχουμε στο σημείο εκτός πεδίου ορισμού, το $0$.
$\lim_{x\to0^+} f(x) = \lim_{x\to0^+} \left( \frac{x^2+1}{x} \right) = \frac{1}{0^+} = +\infty$.
$\lim_{x\to0^-} f(x) = \lim_{x\to0^-} \left( \frac{x^2+1}{x} \right) = \frac{1}{0^-} = -\infty$.
Άρα η ευθεία $x = 0$ (ορθότερα ο άξονας $y'y$) αποτελεί \textbf{κατακόρυφη ασύμπτωτη}.
- **Πλάγιες**: Καθώς ο βαθμός του αριθμητή (2) ξεπερνά αυτόν του παρονομαστή κατά 1, έχουμε πλάγια.
Από τη διαίρεση πολυωνύμων προκύπτει η μορφή: $f(x) = x + \frac{1}{x}$.
Επειδή $\lim_{x\to\pm\infty} \frac{1}{x} = 0$, συμπεραίνουμε πως η ευθεία $y = x$ αποτελεί \textbf{πλάγια ασύμπτωτη} στο $+\infty$ και στο $-\infty$.
\end{erwthma}
\end{thema}
