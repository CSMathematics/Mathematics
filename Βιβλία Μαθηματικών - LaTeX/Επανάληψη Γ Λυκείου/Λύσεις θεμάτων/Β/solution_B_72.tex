\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = x^3 + a x + \beta$.
\begin{erwthma}
\item Η ευθεία $(\epsilon): y = 3x - 4$ εφάπτεται στην $C_f$ στο σημείο με $x_0=1$.
Από αυτό εξάγουμε δύο πληροφορίες:
1. Το σημείο επαφής ανήκει και στις δύο γραμμές. Άρα $f(1) = y(\text{για } x=1) = 3(1)-4 = -1$.
2. Ο συντελεστής διεύθυνσης της εφαπτομένης (που είναι η παράγωγος στο σημείο επαφής) ισούται με την κλίση $\lambda$ της ευθείας. Άρα $f'(1) = \lambda = 3$.
Από τις δύο αυτές συνθήκες θα υπολογίσουμε τα $a, \beta$.
Η παράγωγος είναι $f'(x) = 3x^2 + a$.
Από $f'(1) = 3 \Rightarrow 3(1)^2 + a = 3 \Leftrightarrow 3 + a = 3 \Leftrightarrow a = 0$.
Από $f(1) = -1 \Rightarrow 1^3 + a(1) + \beta = -1 \Leftrightarrow 1 + 0 + \beta = -1 \Leftrightarrow \beta = -2$.

\item Με $a=0$ και $\beta=-2$, η συνάρτηση είναι $f(x) = x^3 - 2$.
Θέλουμε να βρούμε (να δείξουμε ότι υπάρχει) σημείο $\xi \in (0, 2)$ όπου η εφαπτομένη να είναι παράλληλη στη $\zeta: y = 4x+1$, που έχει κλίση $\lambda = 4$. Άρα ζητάμε $f'(\xi) = 4$.
Μπορούμε να εφαρμόσουμε το Θεώρημα Μέσης Τιμής (Θ.Μ.Τ.) για την $f$ στο $[0, 2]$:
- Η $f$ είναι συνεχής στο $[0, 2]$ (πολυωνυμική).
- Η $f$ είναι παραγωγίσιμη στο $(0, 2)$.
Υπάρχει λοιπόν τουλάχιστον ένα $\xi \in (0, 2)$ τέτοιο ώστε:
\[ f'(\xi) = \frac{f(2) - f(0)}{2 - 0} \]
Υπολογίζουμε τις τιμές: $f(2) = 2^3 - 2 = 8 - 2 = 6$ και $f(0) = 0^3 - 2 = -2$.
Άρα $f'(\xi) = \frac{6 - (-2)}{2} = \frac{8}{2} = 4$. Το ζητούμενο αποδείχθηκε κομψά.

\item Υπολογίζουμε το όριο:
\[ \lim_{x\to2} \frac{f(x)-6}{x-2} = \lim_{x\to2} \frac{(x^3-2)-6}{x-2} = \lim_{x\to2} \frac{x^3-8}{x-2} \]
Με χρήση της διαφοράς κύβων $a^3-b^3 = (a-b)(a^2+ab+b^2)$:
\[ \lim_{x\to2} \frac{(x-2)(x^2+2x+4)}{x-2} = \lim_{x\to2} (x^2+2x+4) = 2^2 + 2(2) + 4 = 12 \]
*(Αξίζει να σημειωθεί ότι αφού $f(2) = 6$, το όριο αυτό ταυτίζεται με τον ορισμό της παραγώγου στο $2$, άρα με την τιμή $f'(2) = 3(2)^2 = 12$).*

\item Η παράγωγος είναι $f'(x) = 3x^2 \ge 0$ για κάθε $x \in \mathbb{R}$. Το $f'(x)$ μηδενίζεται μόνο στο μεμονωμένο σημείο $x=0$, οπότε η $f$ είναι \textbf{γνησίως αύξουσα} σε όλο το $\mathbb{R}$.
Ως γνησίως μονότονη είναι συνάρτηση «$1-1$», επομένως είναι \textbf{αντιστρέψιμη}.
Εφόσον η $f$ είναι γνησίως αύξουσα, η ανισότητα διατηρεί τη φορά της αν παραλείψουμε το (εξωτερικό) $f$:
\[ f(f(x)) > f(6) \Leftrightarrow f(x) > 6 \]
Γνωρίζουμε ήδη ότι $f(2) = 6$. Έτσι γράφουμε:
\[ f(x) > f(2) \]
Εφαρμόζοντας ξανά την ιδιότητα της γνησίως αύξουσας, παίρνουμε τελικά:
\[ x > 2 \]
\end{erwthma}
\end{thema}
