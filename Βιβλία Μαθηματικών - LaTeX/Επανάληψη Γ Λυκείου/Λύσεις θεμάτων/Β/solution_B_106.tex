\begin{erwthma}

\item Η $f$ δίνεται ότι είναι \textbf{περιττή}, δηλαδή $f(-x) = -f(x)$ για κάθε $x$ στο πεδίο ορισμού.
\begin{itemize}
    \item $f(-2) = -f(2) = -3$.
    \item $f(0)$: Θέτοντας $x = 0$ στο $f(-x) = -f(x)$, παίρνουμε $f(0) = -f(0) \Rightarrow 2f(0) = 0 \Rightarrow f(0) = 0$.
\end{itemize}
Η συμπλήρωση γίνεται σχεδιάζοντας τον αριστερό κλάδο ως αντίστροφη εικόνα μέσω της αρχής $O$ (κεντρική συμμετρία), δηλαδή αντικατοπτρίζοντας κάθε σημείο $(x, y)$ στο $(-x, -y)$.

\item Ναι! Αν η $f$ περιττή και γνησίως αύξουσα στο $[0, 4]$, τότε η $f$ είναι \textbf{γνησίως αύξουσα και στο $[-4, 0]$}.

Απόδειξη: Έστω $x_1, x_2 \in [-4, 0]$ με $x_1 < x_2$. Τότε $-x_1 > -x_2$ και $-x_1, -x_2 \in [0, 4]$. Εφόσον η $f$ αύξουσα στο $[0, 4]$:
\[ -x_1 > -x_2 \Rightarrow f(-x_1) > f(-x_2) \]
Χρησιμοποιώντας την ιδιότητα $f(-t) = -f(t)$:
\[ -f(x_1) > -f(x_2) \Rightarrow f(x_1) < f(x_2) \]
Αφού $x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$, η $f$ είναι γνησίως αύξουσα στο $[-4, 0]$.

\item Ζητείται $\int_{-2}^{2} f(x)\,\mathrm{d}x$.
Η $f$ είναι \textbf{περιττή} και συνεχής στο $[-2, 2]$. Γνωρίζουμε τη θεμελιώδη ιδιότητα:
\[ \int_{-a}^{a} f(x)\,\mathrm{d}x = 0 \quad \text{αν η } f \text{ περιττή} \]
Αιτιολόγηση: Με την αντικατάσταση $u = -x$:
\[ \int_{-2}^{0} f(x)\,\mathrm{d}x = -\int_2^0 f(-u)\,\mathrm{d}u = \int_0^2 f(-u)\,\mathrm{d}u = \int_0^2 (-f(u))\,\mathrm{d}u = -\int_0^2 f(u)\,\mathrm{d}u \]
Άρα: $\int_{-2}^{2} f(x)\,\mathrm{d}x = \int_{-2}^{0} f(x)\,\mathrm{d}x + \int_0^2 f(x)\,\mathrm{d}x = -\int_0^2 f(x)\,\mathrm{d}x + \int_0^2 f(x)\,\mathrm{d}x = \mathbf{0}$.

\end{erwthma}
\end{thema}
