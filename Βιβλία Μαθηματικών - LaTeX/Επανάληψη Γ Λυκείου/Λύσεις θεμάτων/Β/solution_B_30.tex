\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = x^2 - 2\ln x$.

\begin{erwthma}
\item Πρέπει $x > 0$. Άρα $D_f = (0, +\infty)$. Η $f$ είναι παραγωγίσιμη με \[f'(x) =\left(x^2-2\ln{x}\right)'= 2x - \frac{2}{x} = \frac{2x^2-2}{x}.\]
Επειδή $x>0$, έχουμε 
\begin{itemize}
\item $f'(x) = 0 \Leftrightarrow 2x^2-2 = 0 \Leftrightarrow x^2 = 1 \Leftrightarrow x = 1$.
\item $f'(x) > 0 \Leftrightarrow 2x^2-2 > 0 \Leftrightarrow x > 1$.
\item $f'(x) < 0 \Leftrightarrow 0 < x < 1$.
\end{itemize}

Στον παρακάτω πίνακα φαίνεται το πρόσημο της $f'$ και η μονοτονία της $f$:

Παρουσιάζει ολικό ελάχιστο στο $x_0 = 1$ με τιμή $f(1) = 1^2 - 2\ln 1 = 1$. Η $f'$ επίσης είναι παραγωγίσιμη με \[f''(x) =\left(2x-\frac{2}{x}\right)'= 2 + \frac{2}{x^2}>0\]
για κάθε $x > 0$. Άρα η $f$ είναι κυρτή στο $(0, +\infty)$.

\item Αφού το ολικό ελάχιστο της $f$ είναι $1$, ισχύει $f(x) \ge 1$ για κάθε $x > 0$.
Οπότε:
\[ x^2 - 2\ln x \ge 1 \Leftrightarrow x^2 \ge 2\ln x + 1 \]

\item Αναζητούμε σημείο $M(x_0, f(x_0))$ της $C_f$ στο οποίο ο συντελεστής διεύθυνσης της εφαπτομένης να ισούται με τον συντελεστή διεύθυνσης της ευθείας $\varepsilon: y=2x-3$, δηλαδή $\lambda_\varepsilon = 2$.
Πρέπει 
\[f'(x_0) = 2 \Leftrightarrow \frac{2x_0^2-2}{x_0} = 2 \Leftrightarrow 2x_0^2 - 2 = 2x_0 \Leftrightarrow x_0^2 - x_0 - 1 = 0\]
Το τριώνυμο έχει διακρίνουσα $\Delta = 1 - 4\cdot1\cdot(-1) = 5$. Άρα οι ρίζες είναι $x = \frac{1 \pm \sqrt{5}}{2}$.
Επειδή $D_f = (0, +\infty)$, δεκτή γίνεται μόνο η ρίζα $x_0 = \frac{1+\sqrt{5}}{2}$ αφού η άλλη είναι αρνητική. Επομένως υπάρχει μοναδικό σημείο.
Η εξίσωση της εφαπτομένης είναι \[y - f(x_0) = 2(x - x_0) \Leftrightarrow y = 2x - 2x_0 + f(x_0)\]
Είναι $f(x_0) = x_0^2 - 2\ln x_0$. Όμως $x_0^2 = x_0 + 1$, άρα $f(x_0) = x_0 + 1 - 2\ln x_0$.
Τελικά $y = 2x - 2x_0 + x_0 + 1 - 2\ln x_0 = 2x - x_0 + 1 - 2\ln x_0$, οπότε:
\[ y = 2x + \frac{1-\sqrt{5}}{2} - 2\ln\left( \frac{1+\sqrt{5}}{2} \right) \]

\item Θεωρούμε τη συνάρτηση $g(x) = f(x) - 2$ στο $[1, e]$.
\begin{itemize}
\item Η $g$ είναι συνεχής στο $[1, e]$.
\item $g(1) = f(1) - 2 = 1 - 2 = -1 < 0$.
\item $g(e) = f(e) - 2 = e^2 - 2\ln e - 2 = e^2 - 4 > 0$ (αφού $e > 2 \Rightarrow e^2 > 4$).
Άρα $g(1)g(e) < 0$.
\end{itemize}
Σύμφωνα με το Θεώρημα \eng{Bolzano}, υπάρχει τουλάχιστον ένα $x_0 \in (1, e)$ τέτοιο ώστε $g(x_0) = 0 \Leftrightarrow f(x_0) = 2$.
\end{erwthma}
\end{thema}
