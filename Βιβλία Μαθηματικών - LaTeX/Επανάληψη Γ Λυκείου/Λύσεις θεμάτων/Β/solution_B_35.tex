\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \dfrac{1+\ln x}{x}$.

\begin{erwthma}
\item Το πεδίο ορισμού είναι το $D_f = (0, +\infty)$.
\textbf{Κατακόρυφη Ασύμπτωτη:} στο $x=0$:
\[ \lim_{x\to0^+} f(x) = \lim_{x\to0^+} \left[ (1+\ln x)\frac{1}{x} \right] \]
Είναι $\lim_{x\to0^+} (1+\ln x) = -\infty$ και $\lim_{x\to0^+} \frac{1}{x} = +\infty$, άρα το γινόμενό τους είναι $-\infty$.
Άρα η κατακόρυφη ευθεία $x = 0$ είναι ασύμπτωτη.
\textbf{Οριζόντια Ασύμπτωτη:} στο $+\infty$:
\[ \lim_{x\to+\infty} f(x) = \lim_{x\to+\infty} \frac{1+\ln x}{x} \xlongequal[\text{DLH}]{\frac{+\infty}{+\infty}} \lim_{x\to+\infty} \frac{1/x}{1} = 0 \]
Άρα ο άξονας $y=0$ είναι οριζόντια ασύμπτωτη στο $+\infty$.

\item Η $f$ είναι παραγωγίσιμη με:
\[ f'(x) = \frac{\frac{1}{x}x - (1+\ln x)\cdot 1}{x^2} = \frac{-\ln x}{x^2} \]
Το πρόσημο εξαρτάται μόνο από τον αριθμητή, αφού $x^2 > 0$. Η ρίζα είναι προφανώς το $\ln x = 0 \Leftrightarrow x = 1$.
Είναι $f'(x) > 0 \Leftrightarrow \ln x < 0 \Leftrightarrow 0 < x < 1$.
Ομοίως $f'(x) < 0 \Leftrightarrow \ln x > 0 \Leftrightarrow x > 1$.
Στον παρακάτω πίνακα φαίνεται το πρόσημο της $f'$ και η μονοτονία της $f$:

Επομένως παρουσιάζει ολικό μέγιστο στο $x_0 = 1$ με $f(1) = 1$.

\item Θεωρούμε την εφαπτομένη της βασικής συνάρτησης $g(x) = \ln x$ στο $x_0 = e$:
Η κλίση είναι $g'(e) = \frac{1}{e}$. Έτσι η εξίσωση της εφαπτομένης είναι:
\[ y - g(e) = \frac{1}{e}(x - e) \Leftrightarrow y - 1 = \frac{x}{e} - 1 \Leftrightarrow y = \frac{x}{e} \]
Επειδή η $g(x) = \ln x$ είναι κοίλη ($g''(x) = -\frac{1}{x^2} < 0$), η γραφική της παράσταση βρίσκεται πάντα κάτω ή πάνω ακριβώς στην εφαπτομένη. 
Οπότε για κάθε $x > 0$:
\[ \ln x \le y_{\text{εφ}} \Leftrightarrow \ln x \le \frac{x}{e} \]
Γνωρίζουμε ότι η ζητούμενη προς απόδειξη $1+\ln x \le \frac{x}{e}$ φαίνεται να είναι τυπογραφικό λάθος στην εκφώνηση του αντίστοιχου διαγωνίσματος (π.χ. για $x=e$ δίνει $2 \le 1$ που είναι άτοπο). Εδώ αποδείξαμε την ορθή μαθηματική σχέση $\ln x \le \frac{x}{e}$.

\item Θέλουμε το πλήθος ριζών του $\frac{1+\ln x}{x} = \kappa \Leftrightarrow f(x) = \kappa$. 
Μελετάμε τα σύνολα τιμών στα διαστήματα μονοτονίας:
- $\Delta_1 = (0, 1]$ με $\lim_{x\to0^+} f(x) = -\infty$ και $f(1) = 1$. Άρα $f(\Delta_1) = (-\infty, 1]$.
- $\Delta_2 = (1, +\infty)$ με $\lim_{x\to+\infty} f(x) = 0$ και $f(1) = 1$. Άρα $f(\Delta_2) = (0, 1)$. (Η τιμή 1 στο 1 είναι ανοιχτό άκρο εδώ, εξαιρείται).
Επομένως:
- Για $\kappa \le 0$: μία ρίζα (ανήκει στο $\Delta_1$).
- Για $0 < \kappa < 1$: δύο ρίζες (μία στο $\Delta_1$ και μία στο $\Delta_2$).
- Για $\kappa = 1$: μία ρίζα, η $x=1$.
- Για $\kappa > 1$: ουδεμία ρίζα.
\end{erwthma}
\end{thema}
