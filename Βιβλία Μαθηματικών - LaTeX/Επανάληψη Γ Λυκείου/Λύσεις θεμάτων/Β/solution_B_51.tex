\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = e^{-x^2}$.
\begin{erwthma}
\item Εφαρμόζουμε το Θεώρημα Rolle για την $f$ στο διάστημα $[-1, 1]$:
- Η $f$ είναι συνεχής στο $[-1, 1]$.
- Η $f$ είναι παραγωγίσιμη στο $(-1, 1)$.
- Ισχύει $f(-1) = e^{-(-1)^2} = e^{-1}$ και $f(1) = e^{-1^2} = e^{-1}$, δηλαδή $f(-1) = f(1)$.
Επομένως υπάρχει τουλάχιστον ένα $\xi \in (-1, 1)$ τέτοιο ώστε $f'(\xi) = 0$. Η εφαπτομένη σε τέτοιο σημείο είναι οριζόντια.
Πράγματι, $f'(x) = -2x e^{-x^2}$. Η ρίζα είναι προφανώς το $\xi = 0$, το οποίο ανήκει στο $(-1, 1)$. Το σημείο επαφής είναι το $(0, 1)$.

\item Το πρόσημο της παραγώγου $f'(x) = -2x e^{-x^2}$ εξαρτάται μόνο από το $-2x$, αφού $e^{-x^2} > 0$.
- $f'(x) > 0 \Leftrightarrow -2x > 0 \Leftrightarrow x < 0$.
- $f'(x) < 0 \Leftrightarrow -2x < 0 \Leftrightarrow x > 0$.

Η $f$ είναι γνησίως αύξουσα στο $(-\infty, 0]$ και γνησίως φθίνουσα στο $[0, +\infty)$.
Επομένως, παρουσιάζει στο $x_0 = 0$ \textbf{ολικό μέγιστο}, ίσο με $f(0) = e^0 = 1$.

\item Υπολογίζουμε τη δεύτερη παράγωγο:
\[ f''(x) = (-2x)' e^{-x^2} - 2x(e^{-x^2})' = -2 e^{-x^2} - 2x(-2x e^{-x^2}) = -2 e^{-x^2} + 4x^2 e^{-x^2} = 2e^{-x^2}(2x^2 - 1) \]
Η δεύτερη παράγωγο μηδενίζεται:
\[ f''(x) = 0 \Leftrightarrow 2x^2 - 1 = 0 \Leftrightarrow x^2 = \frac{1}{2} \Leftrightarrow x = \pm \frac{1}{\sqrt{2}} = \pm \frac{\sqrt{2}}{2} \]
Στον παρακάτω πίνακα φαίνεται το πρόσημο της $f''$ και η κυρτότητα της $f$:

Άρα παρουσιάζει σημεία καμπής για $x = -\frac{\sqrt{2}}{2}$ και $x = \frac{\sqrt{2}}{2}$, δηλαδή τα σημεία:
$\Sigma_1\left(-\frac{\sqrt{2}}{2}, \frac{1}{\sqrt{e}}\right)$ και $\Sigma_2\left(\frac{\sqrt{2}}{2}, \frac{1}{\sqrt{e}}\right)$, αφού $f\left(\pm \frac{\sqrt{2}}{2} \right) = e^{-1/2} = \frac{1}{\sqrt{e}}$.

\item Το όριο στο $+\infty$ είναι:
\[ \lim_{x\to+\infty} f(x) = \lim_{x\to+\infty} e^{-x^2} = \lim_{x\to+\infty} \frac{1}{e^{x^2}} \]
Αφού $x^2 \to +\infty \Rightarrow e^{x^2} \to +\infty$, το όριο ισούται με 0.
Επομένως, η ευθεία $y = 0$ (άξονας $x'x$) αποτελεί \textbf{οριζόντια ασύμπτωτη} της $C_f$ στο $+\infty$ (και ομοίως στο $-\infty$).
\end{erwthma}
\end{thema}
