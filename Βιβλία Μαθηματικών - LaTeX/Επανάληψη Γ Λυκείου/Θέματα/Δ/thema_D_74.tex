\begin{thema}{Δ}
Στο σχήμα δίνεται η $C_f$ μιας παραγωγίσιμης $f:[0, 5]\to\mathbb{R}$ μαζί με τη χορδή $AB$ ($A(0,1)$, $B(5,6)$). Η $f$ είναι κοίλη (κυρτή προς τα πάνω) και $f(x) \geq \frac{x}{5}\cdot5 + 1 = x + 1$ (βρίσκεται πάνω από τη χορδή).

\begin{erwthma}
  \item Δείξτε ότι η ανίσωση $f(x) \geq x + 1$ ισχύει $\forall x \in [0, 5]$, χρησιμοποιώντας την κοιλότητα.
  \item Λύστε την εξίσωση $f(x) = x + 1$ στο $[0, 5]$. Πόσες λύσεις έχει; (Ισότητα μόνο στα άκρα.)
  \item Εφαρμόστε ΘΜΤ στη $f$ στο $[0, 5]$: $f'(\xi) = 1$. Δείξτε ότι η εξίσωση $f'(x) = 1$ έχει λύση. Πόσες ακόμα λύσεις μπορεί να έχει;
  \item Αποδείξτε ότι $\dint_0^5 f(x)\,dx > \dint_0^5 (x+1)\,dx = \frac{35}{2}$.
\end{erwthma}
\end{thema}
