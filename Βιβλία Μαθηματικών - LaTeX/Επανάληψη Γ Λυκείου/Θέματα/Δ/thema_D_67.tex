\begin{thema}{Δ}
Στο σχήμα δίνεται η $C_{f'}$ μιας δύο φορές παραγωγίσιμης $f:[0, 8]\to\mathbb{R}$. Η $f'$ είναι συνεχής, $f'(0) = 0$, $f'(4) = 0$, $f'(8) = 0$. Η $f'$ είναι θετική στο $(0, 4)$ και αρνητική στο $(4, 8)$ (συμμετρικά γύρω από $x=4$). Δίνεται $f(0) = 0$.

\begin{erwthma}
  \item Μονοτονία και ακρότατα $f$. Αποδείξτε ότι $f(4)$ τοπ. μέγιστο, $f(8) = f(0) = 0$ (χρησιμοποιήστε ισότητα εμβαδών $E_+ = E_-$).
  \item Εφαρμόστε Θ. Rolle στη $f$ στο $[0, 8]$ (αφού $f(0)=f(8)=0$): υπάρχει $\xi$ με $f'(\xi)=0$. Ήδη ξέρετε ότι $\xi = 4$. Τώρα εφαρμόστε Rolle στη $f'$ στο $[0, 4]$ και στο $[4, 8]$: πόσες ρίζες παρουσιάζει η $f''$;
  \item Αποδείξτε ότι η εξίσωση $f(x) = c$ για $0 < c < f(4)$ έχει ακριβώς δύο λύσεις στο $(0, 8)$.
  \item Σημείο $M(x, f(x))$ κινείται στην $C_f$ με $x'(t) = 1$. Τη στιγμή $t_0$ που $x = 2$, να βρείτε $y'(t_0)$ και τη γωνία $\omega$ που σχηματίζει η εφαπτομένη με τον $x'x$.
\end{erwthma}
\end{thema}
