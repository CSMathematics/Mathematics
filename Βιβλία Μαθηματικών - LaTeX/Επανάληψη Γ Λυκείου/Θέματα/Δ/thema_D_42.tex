\begin{thema}{Δ}
Έστω η συνάρτηση $\displaystyle f(x) = e^{x-1} + \ln x + x - 2$ με $x>0$.
\begin{erwthma}
    \item Να μελετήσετε την $f$ ως προς τη μονοτονία και να βρείτε το σύνολο τιμών της. Στη συνέχεια, να λύσετε την εξίσωση $f(x) = 0$.
    \item Να μελετήσετε την $f$ ως προς την κυρτότητα, να αποδείξετε ότι παρουσιάζει ακριβώς ένα σημείο καμπής και να βρείτε την εξίσωση της εφαπτομένης της $C_f$ σε αυτό.
    \item Να υπολογίσετε το εμβαδόν του χωρίου που περικλείεται από τη γραφική παράσταση της $f$, την εφαπτομένη της στο σημείο καμπής της και την ευθεία $x=e$.
    \item Να λύσετε την εξίσωση $e^{\ln x - 1} + \ln(\ln x) + \ln x = 2$ και να αποδείξετε ότι η εξίσωση $x f(x) = e^2 - 1$ έχει ακριβώς μία ρίζα στο διάστημα $(1, e)$.
\end{erwthma}
\end{thema}
