\begin{thema}{Δ}
Δίνεται η συνεχώς παραγωγίσιμη συνάρτηση $f: \mathbb{R} \to \mathbb{R}$ τέτοια ώστε να επαληθεύονται απολύτως δύο ιδιότητες: $f(1)=e$, και $f'(x) < f(x)$ για κάθε $x \in \mathbb{R}$.
\begin{erwthma}
    \item Να αποδείξετε ότι ισχύει $f(x) < e^x$ για όλες ανεξαιρέτως τις μεταβλητές $x > 1$. \monades{6}
    \item Να αποδείξετε ότι η συνάρτηση $K(x) = e^x - f(x)$ είναι γνησίως αύξουσα στο διάστημα $(1, +\infty)$. \monades{6}
    \item Να αποδείξετε ότι η εξίσωση $f(x) = e^x - 1$ έχει το πολύ μία ρίζα στο διάστημα $(1, +\infty)$. \monades{6}
    \item Αν επιπροσθέτως καταστεί γνωστό ότι $\displaystyle\lim_{x\to+\infty} f(x) = 0$, να αποδείξετε ότι η εξίσωση $f(x) = e^x - 2026$ έχει ακριβώς μία ρίζα στο $(1, +\infty)$. \monades{7}
\end{erwthma}
\end{thema}
