\begin{thema}{Δ}
Δίνεται η συνάρτηση $f(x) = (x-1)e^x + 1, \ x \in \mathbb{R}$.
\begin{erwthma}
    \item Να μελετήσετε τη συνάρτηση $f$ ως προς τη μονοτονία, τα ακρότατα και να αποδείξετε ότι $e^x \le \dfrac{1}{1-x}$ για κάθε $x < 1$.
    \item Να βρείτε το πλήθος των ριζών της εξίσωσης $(x-1)e^x + 1 = \lambda$ για τις διάφορες τιμές του $\lambda \in \mathbb{R}$.
    \item Να αποδείξετε ότι υπάρχουν ακριβώς δύο εφαπτόμενες της $C_f$ που διέρχονται από την αρχή των αξόνων $O(0,0)$, εκ των οποίων η μία εφάπτεται σε σημείο με αρνητική τετμημένη $a \in (-2, -1)$.
    \item Να αποδείξετε ότι $f(x) \le x^2$ για κάθε $x \in [0, 1]$ και στη συνέχεια, να αποδείξετε ότι:
    \[ \dint_0^1 f(x^2) dx < \frac{1}{5} \]
\end{erwthma}
\end{thema}
