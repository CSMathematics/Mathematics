\begin{thema}{Δ}
Στο παρακάτω σχήμα δίνεται η γραφική παράσταση $C_f$ μιας δύο φορές παραγωγίσιμης συνάρτησης $f:[0, 6]\to\mathbb{R}$ με τα ακόλουθα γνωστά: $f(0) = 2$, $f(2) = 5$, $f(4) = 1$, $f(6) = 3$. Η $C_f$ παρουσιάζει τοπικό μέγιστο στο $x = 2$ και τοπικό ελάχιστο στο $x = 4$.

\begin{erwthma}
  \item Να αιτιολογήσετε ότι $f'(2) = 0$ και $f'(4) = 0$.
  \item Να εξηγήσετε γιατί δεν εφαρμόζεται το Θεώρημα \eng{Rolle} για την $f$ στο $[0, 6]$. Στη συνέχεια, με τη βοήθεια του Θεωρήματος \eng{Bolzano}, να αποδείξετε ότι η εξίσωση $f(x) = 2$ έχει τουλάχιστον δύο ρίζες $\rho_1, \rho_2$ στο $(0, 6)$.
  \item Να εφαρμόσετε το Θ.Μ.Τ. για την $f$ στα διαστήματα $[0, 2]$ και $[4, 6]$ και να αποδείξετε ότι υπάρχει $\xi_1 \in (0,2)$ με $f'(\xi_1) = \frac{3}{2}$ και $\xi_2 \in (4,6)$ με $f'(\xi_2) = 1$. Στη συνέχεια, να αποδείξετε ότι η εξίσωση $f'(x) = 1$ έχει τουλάχιστον μία λύση $x_1$ στο $(0, 2)$.
  \item Αξιοποιώντας τα συμπεράσματα του ερωτήματος Δ3, να αποδείξετε ότι υπάρχει τουλάχιστον ένα $x_0 \in (0, 6)$ τέτοιο ώστε $f''(x_0) = 0$. Ποια είναι η γεωμετρική ερμηνεία αυτού του σημείου για τη $C_f$;
\end{erwthma}
\end{thema}
