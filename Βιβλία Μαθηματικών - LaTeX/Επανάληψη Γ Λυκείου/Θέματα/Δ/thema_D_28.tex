\begin{thema}{Δ}
Έστω μια συνάρτηση $f: \mathbb{R} \to \mathbb{R}$, δύο φορές παραγωγίσιμη, για την οποία ισχύει:
\[ f''(x) - 2f'(x) + f(x) = 0 \quad \text{για κάθε } x \in \mathbb{R} \]
με $f(0) = 0$ και $f'(0) = 1$.
\begin{erwthma}
    \item Να αποδείξετε ότι η συνάρτηση $g(x) = (f'(x) - f(x))e^{-x}$ είναι σταθερή στο $\mathbb{R}$ και στη συνέχεια να αποδείξετε ότι $f(x) = x e^x$.
    \item Να μελετήσετε την $f$ ως προς τη μονοτονία, τα ακρότατα, την κυρτότητα και τα σημεία καμπής.
    \item Να αποδείξετε ότι από το σημείο $A(2, 0)$ άγονται ακριβώς δύο εφαπτομένες προς τη γραφική παράσταση της $f$. Αν $x_1, x_2$ είναι οι τετμημένες των σημείων επαφής, να αποδείξετε ότι το γινόμενο των κλίσεων των δύο εφαπτομένων είναι ίσο με $e^2$.
    \item Να αποδείξετε ότι η εξίσωση $f(x) = x^2 + 1$ έχει μοναδική ρίζα στο $\mathbb{R}$, η οποία ανήκει στο διάστημα $(0, 1)$.
\end{erwthma}
\end{thema}
