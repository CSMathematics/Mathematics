\begin{thema}{Δ}
Θεωρούμε μια δύο φορές παραγωγίσιμη συνάρτηση $f: (0, +\infty) \to \mathbb{R}$ που ικανοποιεί τις συνθήκες:
\[ x f''(x) + f'(x) = -2 \quad \text{για κάθε } x > 0, \quad f(1)=1 \text{ και } f'(1)=-1 \]
\begin{erwthma}
    \item Να προσδιορίσετε τον τύπο της συνάρτησης, αποδεικνύοντας ότι $f(x) = \ln x - 2x + 3$.
    \item Να μελετήσετε την $f$ ως προς τη μονοτονία και τα ακρότατα, και να αποδείξετε ότι η εξίσωση $f(x) = 0$ έχει ακριβώς δύο ρίζες $\rho_1, \rho_2$, τέτοιες ώστε $\displaystyle \rho_1 < \frac{1}{2} < \rho_2$.
    \item Να αποδείξετε ότι η $f$ είναι κοίλη, να βρείτε την εξίσωση της εφαπτομένης της στο σημείο με τετμημένη $x_0 = 1$ και να αποδείξετε ότι $\ln x \le x - 1$ για κάθε $x > 0$.
    \item Αν $\rho_1, \rho_2$ είναι οι ρίζες του ερωτήματος $\Delta 2$, να αποδείξετε την παρακάτω ανισότητα για το ορισμένο ολοκλήρωμα:
    \[ 0 < \dint_{\rho_1}^{\rho_2} f(x) dx < \frac{1}{2}(\rho_2 - \rho_1)(4 - \rho_1 - \rho_2) \]
\end{erwthma}
\end{thema}
