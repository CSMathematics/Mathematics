# Templates

Αρχεία LaTeX-βάση ανά τύπο εγγράφου.

Τα templates είναι ελάχιστα αλλά compilable και αντιστοιχούν στα document-type conventions του `wiki/latex/είδος-αρχείου/`.

| Αρχείο | Περιγραφή |
|--------|-----------|
| `exercises.tex` | Ασκήσεις με λύσεις |
| `notes.tex` | Θεωρητικές σημειώσεις |
| `book.tex` | Βιβλίο / σύγγραμμα |
| `exam.tex` | Εξέταση / διαγώνισμα |
