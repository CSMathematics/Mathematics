# Σημειογραφία Μιγαδικών

## Βασική Σημειογραφία

- **Μιγαδικός αριθμός**: `z = x + yi` ή `z = \alpha + \beta i`
- **Συζυγής**: `\bar{z}`
- **Μέτρο**: `|z|`
- **Τριγωνομετρική μορφή**: `z = \rho (\cos \theta + i \sin \theta)`
- **Σύνολο Μιγαδικών**: `\mathbb{C}`
