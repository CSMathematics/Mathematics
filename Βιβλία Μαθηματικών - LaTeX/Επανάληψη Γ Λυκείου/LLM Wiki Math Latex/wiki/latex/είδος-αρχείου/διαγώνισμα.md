# Δομή Εξετάσεων

## Header εξέτασης

```latex
\begin{center}
  {\large\textbf{ΕΞΕΤΑΣΗ --- ΜΑΘΗΜΑ}}\\[0.3em]
  Ημερομηνία: \quad Διάρκεια: \quad Μόρια: 100
\end{center}
\rule{\textwidth}{0.4pt}
```

## Θέματα με μόρια

```latex
\begin{enumerate}[label=\textbf{Θέμα \Alph*.} (\arabic{enumi}0 μόρια)]
  \item Πρώτο θέμα...
  \item Δεύτερο θέμα...
\end{enumerate}
```

## Κανόνας

Τα αρχεία exam **δεν** περιέχουν `\begin{solution}`.
