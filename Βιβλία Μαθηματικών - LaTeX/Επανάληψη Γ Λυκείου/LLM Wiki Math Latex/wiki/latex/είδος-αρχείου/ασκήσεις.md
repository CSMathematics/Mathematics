# Δομή Ασκήσεων

## Δομή αρχείου ασκήσεων

```latex
\begin{exercise}
Διατύπωση άσκησης...
\end{exercise}

\begin{solution}
Λύση...
\end{solution}
```

## Για σειρά ασκήσεων χωρίς λύσεις

```latex
\begin{enumerate}[label=\textbf{Άσκηση \arabic*.}]
  \item Πρώτη άσκηση
  \item Δεύτερη άσκηση
\end{enumerate}
```

## Για λύσεις Γ Λυκείου (Επανάληψη)

Χρησιμοποιούνται custom περιβάλλοντα `thema` / `erwthma`:

```latex
\begin{thema}{Β}
\begin{erwthma}
\item Λύση πρώτου ερωτήματος...
\item Λύση δεύτερου ερωτήματος...
\end{erwthma}
\end{thema}
```

Δες: [[formatting-guide-lykeio]] για πλήρεις προδιαγραφές.
