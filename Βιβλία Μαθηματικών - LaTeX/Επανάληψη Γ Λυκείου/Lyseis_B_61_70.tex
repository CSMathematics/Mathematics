\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = a x e^x + \beta$.
\begin{erwthma}
\item Το όριο στο $-\infty$ είναι:
\[ \lim_{x\to-\infty} f(x) = \lim_{x\to-\infty} (a x e^x + \beta) = a \lim_{x\to-\infty} (x e^x) + \beta \]
Γνωρίζουμε το βασικό όριο:
\[ \lim_{x\to-\infty} (x e^x) = \lim_{x\to-\infty} \frac{x}{e^{-x}} \xlongequal[\text{DLH}]{\frac{-\infty}{+\infty}} \lim_{x\to-\infty} \frac{1}{-e^{-x}} = 0 \]
Συνεπώς: $\lim_{x\to-\infty} f(x) = a (0) + \beta = \beta$. 
Αφού το όριο δίνεται ίσο με 2, προκύπτει άμεσα $\beta = 2$.
Επιπρόσθετα, η γραφική παράσταση διέρχεται από το $A(1, e+2)$, άρα:
\[ f(1) = e+2 \Leftrightarrow a(1)e^1 + 2 = e + 2 \Leftrightarrow ae = e \Leftrightarrow a = 1 \]

\item Ο τύπος της συνάρτησης είναι $f(x) = x e^x + 2$. Παραγωγίζουμε δύο φορές:
\[ f'(x) = 1\cdot e^x + x \cdot e^x = e^x(x+1) \]
\[ f''(x) = e^x \cdot (x+1) + e^x \cdot 1 = e^x(x+2) \]
Βρίσκουμε τη ρίζα της $f''$: $f''(x) = 0 \Leftrightarrow x+2 = 0 \Leftrightarrow x = -2$.
Το πρόσημο εξαρτάται μόνο από το $x+2$:
- Για $x > -2 \Rightarrow f''(x) > 0$. Η $f$ είναι \textbf{κυρτή} (στρέφει τα κοίλα άνω) στο $[-2, +\infty)$.
- Για $x < -2 \Rightarrow f''(x) < 0$. Η $f$ είναι \textbf{κοίλη} (στρέφει τα κοίλα κάτω) στο $(-\infty, -2]$.
Το σημείο στο οποίο αλλάζει η κυρτότητα είναι το $M(-2, f(-2))$, δηλαδή το:
$M\left(-2, -2e^{-2}+2\right) = M\left(-2, 2-\frac{2}{e^2}\right)$, το οποίο αποτελεί το μοναδικό \textbf{σημείο καμπής} της $C_f$.

\item Θεωρούμε τη συνάρτηση $h(x) = f(x) - 3 = x e^x - 1$ στο διάστημα $[0, 1]$.
Η $h$ είναι συνεχής στο $[0, 1]$ ως πράξεις συνεχών παραγωγίσιμων συναρτήσεων.
Ελέγχουμε τις τιμές στα άκρα του διαστήματος:
- $h(0) = f(0) - 3 = (0\cdot e^0 + 2) - 3 = 2 - 3 = -1 < 0$.
- $h(1) = f(1) - 3 = (1\cdot e^1 + 2) - 3 = e - 1 > 0$ (διότι $e \approx 2,71 > 1$).
Δεδομένου ότι $h(0)h(1) < 0$, το Θεώρημα Bolzano εξασφαλίζει ότι υπάρχει τουλάχιστον ένα $x_0 \in (0, 1)$ τέτοιο ώστε $h(x_0)=0 \Leftrightarrow f(x_0)=3$.

\item Αναζητούμε το εμβαδόν μεταξύ της $C_f$, του $x'x$ ($y=0$), του $y'y$ ($x=0$) και της ευθείας $x=1$.
Για $x \in [0, 1]$ ισχύει $x \ge 0$ και $e^x > 0$, επομένως $x e^x \ge 0 \Rightarrow x e^x + 2 > 0 \Rightarrow f(x) > 0$.
Συνεπώς το ζητούμενο εμβαδόν είναι:
\[ E = \int_0^1 f(x) dx = \int_0^1 (x e^x + 2) dx = \int_0^1 x (e^x)' dx + \int_0^1 2 dx \]
Κάνουμε παραγοντική ολοκλήρωση στο πρώτο:
\[ \int_0^1 x(e^x)' dx = \Big[ x e^x \Big]_0^1 - \int_0^1 (x)' e^x dx = (1\cdot e^1 - 0) - \int_0^1 e^x dx = e - \Big[ e^x \Big]_0^1 = e - (e^1 - e^0) = e - e + 1 = 1 \]
Για το δεύτερο ολοκλήρωμα:
\[ \int_0^1 2 dx = \Big[ 2x \Big]_0^1 = 2(1 - 0) = 2 \]
Αθροίζουμε τα αποτελέσματα: $E = 1 + 2 = 3$ τ.μ.
\end{erwthma}
\end{thema}

\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = x^3 + a x + \beta$.
\begin{erwthma}
\item Η ευθεία $(\epsilon): y = 3x - 4$ εφάπτεται στην $C_f$ στο σημείο με $x_0=1$.
Από αυτό εξάγουμε δύο πληροφορίες:
1. Το σημείο επαφής ανήκει και στις δύο γραμμές. Άρα $f(1) = y(\text{για } x=1) = 3(1)-4 = -1$.
2. Ο συντελεστής διεύθυνσης της εφαπτομένης (που είναι η παράγωγος στο σημείο επαφής) ισούται με την κλίση $\lambda$ της ευθείας. Άρα $f'(1) = \lambda = 3$.
Από τις δύο αυτές συνθήκες θα υπολογίσουμε τα $a, \beta$.
Η παράγωγος είναι $f'(x) = 3x^2 + a$.
Από $f'(1) = 3 \Rightarrow 3(1)^2 + a = 3 \Leftrightarrow 3 + a = 3 \Leftrightarrow a = 0$.
Από $f(1) = -1 \Rightarrow 1^3 + a(1) + \beta = -1 \Leftrightarrow 1 + 0 + \beta = -1 \Leftrightarrow \beta = -2$.

\item Με $a=0$ και $\beta=-2$, η συνάρτηση είναι $f(x) = x^3 - 2$.
Θέλουμε να βρούμε (να δείξουμε ότι υπάρχει) σημείο $\xi \in (0, 2)$ όπου η εφαπτομένη να είναι παράλληλη στη $\zeta: y = 4x+1$, που έχει κλίση $\lambda = 4$. Άρα ζητάμε $f'(\xi) = 4$.
Μπορούμε να εφαρμόσουμε το Θεώρημα Μέσης Τιμής (Θ.Μ.Τ.) για την $f$ στο $[0, 2]$:
- Η $f$ είναι συνεχής στο $[0, 2]$ (πολυωνυμική).
- Η $f$ είναι παραγωγίσιμη στο $(0, 2)$.
Υπάρχει λοιπόν τουλάχιστον ένα $\xi \in (0, 2)$ τέτοιο ώστε:
\[ f'(\xi) = \frac{f(2) - f(0)}{2 - 0} \]
Υπολογίζουμε τις τιμές: $f(2) = 2^3 - 2 = 8 - 2 = 6$ και $f(0) = 0^3 - 2 = -2$.
Άρα $f'(\xi) = \frac{6 - (-2)}{2} = \frac{8}{2} = 4$. Το ζητούμενο αποδείχθηκε κομψά.

\item Υπολογίζουμε το όριο:
\[ \lim_{x\to2} \frac{f(x)-6}{x-2} = \lim_{x\to2} \frac{(x^3-2)-6}{x-2} = \lim_{x\to2} \frac{x^3-8}{x-2} \]
Με χρήση της διαφοράς κύβων $a^3-b^3 = (a-b)(a^2+ab+b^2)$:
\[ \lim_{x\to2} \frac{(x-2)(x^2+2x+4)}{x-2} = \lim_{x\to2} (x^2+2x+4) = 2^2 + 2(2) + 4 = 12 \]
*(Αξίζει να σημειωθεί ότι αφού $f(2) = 6$, το όριο αυτό ταυτίζεται με τον ορισμό της παραγώγου στο $2$, άρα με την τιμή $f'(2) = 3(2)^2 = 12$).*

\item Η παράγωγος είναι $f'(x) = 3x^2 \ge 0$ για κάθε $x \in \mathbb{R}$. Το $f'(x)$ μηδενίζεται μόνο στο μεμονωμένο σημείο $x=0$, οπότε η $f$ είναι \textbf{γνησίως αύξουσα} σε όλο το $\mathbb{R}$.
Ως γνησίως μονότονη είναι συνάρτηση «$1-1$», επομένως είναι \textbf{αντιστρέψιμη}.
Εφόσον η $f$ είναι γνησίως αύξουσα, η ανισότητα διατηρεί τη φορά της αν παραλείψουμε το (εξωτερικό) $f$:
\[ f(f(x)) > f(6) \Leftrightarrow f(x) > 6 \]
Γνωρίζουμε ήδη ότι $f(2) = 6$. Έτσι γράφουμε:
\[ f(x) > f(2) \]
Εφαρμόζοντας ξανά την ιδιότητα της γνησίως αύξουσας, παίρνουμε τελικά:
\[ x > 2 \]
\end{erwthma}
\end{thema}

\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \begin{cases} \dfrac{\ln x}{x-1}, & x \ne 1 \\ a, & x=1 \end{cases}$.
\begin{erwthma}
\item Το πεδίο ορισμού είναι οι θετικοί πραγματικοί $(0, +\infty)$. 
Είναι δεδομένο ότι η $f$ είναι συνεχής στο $x_0=1$, επομένως $\lim_{x\to1} f(x) = f(1) = a$.
Υπολογίζουμε το όριο:
\[ \lim_{x\to1} f(x) = \lim_{x\to1} \frac{\ln x}{x-1} \]
Πρόκειται για μορφή $\frac{0}{0}$. Εφαρμόζοντας τον κανόνα De L' Hospital:
\[ \lim_{x\to1} \frac{(\ln x)'}{(x-1)'} = \lim_{x\to1} \frac{\frac{1}{x}}{1} = \lim_{x\to1} \frac{1}{x} = 1 \]
Άρα αναγκαστικά καταλήγουμε ότι $a=1$.

\item Εξετάζουμε τα ανοικτά άκρα του πεδίου ορισμού για \textbf{κατακόρυφη ασύμπτωτη}, κυρίως το $x=0$ (από δεξιά):
\[ \lim_{x\to0^+} f(x) = \lim_{x\to0^+} \frac{\ln x}{x-1} = \lim_{x\to0^+} \left( \ln x \cdot \frac{1}{x-1} \right) \]
Όταν $x\to0^+$, $\ln x \to -\infty$ και $\frac{1}{x-1} \to \frac{1}{-1} = -1$.
Άρα το γινόμενο είναι $(-\infty)(-1) = +\infty$.
Συμπεραίνουμε ότι ο άξονας $y'y$ (δηλαδή η ευθεία $x=0$) αποτελεί την κατακόρυφη ασύμπτωτη της συνάρτησης.

\item Για την παραγωγισιμότητα στο $x_0=1$, ελέγχουμε αν υπάρχει στο $\mathbb{R} $ το όριο του ορισμού:
\[ \lim_{x\to1} \frac{f(x)-f(1)}{x-1} = \lim_{x\to1} \frac{\frac{\ln x}{x-1} - 1}{x-1} = \lim_{x\to1} \frac{\ln x - (x-1)}{(x-1)^2} = \lim_{x\to1} \frac{\ln x - x + 1}{(x-1)^2} \]
Μορφή $\frac{0}{0}$. Με κανόνα De L' Hospital (1η φορά):
\[ \lim_{x\to1} \frac{\frac{1}{x} - 1}{2(x-1)} = \lim_{x\to1} \frac{\frac{1-x}{x}}{2(x-1)} = \lim_{x\to1} \frac{-(x-1)}{2x(x-1)} = \lim_{x\to1} \frac{-1}{2x} = -\frac{1}{2} \]
Το όριο ανήκει στο $\mathbb{R}$, άρα η $f$ είναι παραγωγίσιμη στο $x_0=1$ με $f'(1) = -1/2$.

\item Υπολογίζουμε την παράγωγο για $x \ne 1$:
\[ f'(x) = \frac{(\ln x)'(x-1) - \ln x(x-1)'}{(x-1)^2} = \frac{\frac{1}{x}(x-1) - \ln x}{(x-1)^2} = \frac{x - 1 - x\ln x}{x(x-1)^2} \]
Θεωρούμε τη βοηθητική συνάρτηση $K(x) = x - 1 - x\ln x$ για $x>0$.
Η παράγωγος της είναι: $K'(x) = 1 - (1\cdot\ln x + x\frac{1}{x}) = 1 - \ln x - 1 = -\ln x$.
Για κάθε $x \in (0, 1)$ ισχύει $\ln x < 0 \Rightarrow -\ln x > 0 \Rightarrow K'(x) > 0$.
Η $K$ είναι γνησίως αύξουσα στο $(0, 1]$. Συνεπώς για $x < 1 \Rightarrow K(x) < K(1)$.
Και επειδή $K(1) = 1-1-\ln 1 = 0$, συνάγουμε $K(x) < 0$ για το διάστημα $(0, 1)$.
Με επιστροφή στην παράγωγο $f'$:
Στο $(0, 1)$ ο παρονομαστής $x(x-1)^2$ είναι γινόμενο δύο θετικών, άρα θετικός.
Ο αριθμητής $K(x)$ αποδείχθηκε αρνητικός.
Άρα $f'(x) < 0$ για κάθε $x \in (0, 1)$, αποδεικνύοντας ότι \textbf{η $f$ είναι γνησίως φθίνουσα στο $(0, 1)$}.
\end{erwthma}
\end{thema}

\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \dfrac{x+a}{\beta x-2}$.
\begin{erwthma}
\item Η $C_f$ διαθέτει κατακόρυφη ασύμπτωτη την ευθεία $x=2$. 
Αυτό σημαίνει ότι ο παρονομαστής μηδενίζεται για $x=2$:
\[ \beta(2) - 2 = 0 \Leftrightarrow 2\beta = 2 \Leftrightarrow \beta = 1 \]
Για $\beta=1$ ο τύπος γίνεται $f(x) = \dfrac{x+a}{x-2}$. 
(Ορίζεται στο $\mathbb{R} \setminus \{2\}$. Επαληθεύουμε ότι $\lim_{x\to\pm\infty} f(x) = 1$, άρα το δεδομένο για οριζόντια ασύμπτωτη $y=1$ ισχύει).
Επιπλέον το σημείο $M(-2, 0)$ ανήκει στην $C_f$, άρα $f(-2) = 0$:
\[ \frac{-2+a}{-2-2} = 0 \Leftrightarrow \frac{-2+a}{-4} = 0 \Leftrightarrow -2+a = 0 \Leftrightarrow a = 2 \]
Συνεπώς η συνάρτηση είναι $f(x) = \dfrac{x+2}{x-2}$.

\item Υπολογίζουμε την παράγωγο της $f$:
\[ f'(x) = \frac{(x+2)'(x-2) - (x+2)(x-2)'}{(x-2)^2} = \frac{1(x-2) - (x+2)1}{(x-2)^2} = \frac{x-2-x-2}{(x-2)^2} = \frac{-4}{(x-2)^2} \]
Εφόσον $f'(x) < 0$ για κάθε $x \neq 2$, η συνάρτηση είναι γνησίως φθίνουσα στο $(-\infty, 2)$ και γνησίως φθίνουσα στο $(2, +\infty)$.
Για να αποδείξουμε την αντιστρεψιμότητα, δείχνουμε ότι είναι "1-1":
Έστω $x_1, x_2 \ne 2$ με $f(x_1) = f(x_2)$. 
\[ \frac{x_1+2}{x_1-2} = \frac{x_2+2}{x_2-2} \Leftrightarrow (x_1+2)(x_2-2) = (x_2+2)(x_1-2) \]
\[ x_1 x_2 - 2x_1 + 2x_2 - 4 = x_1 x_2 - 2x_2 + 2x_1 - 4 \]
\[ -2x_1 + 2x_2 = 2x_1 - 2x_2 \Leftrightarrow 4x_2 = 4x_1 \Leftrightarrow x_1 = x_2 \]
Άρα η $f$ είναι "1-1" σε όλο το πεδίο ορισμού της και άρα **αντιστρέφεται**.
Για να βρούμε την αντίστροφη, λύνουμε $y = f(x)$ ως προς $x$:
\[ y = \frac{x+2}{x-2} \Leftrightarrow y(x-2) = x+2 \Leftrightarrow yx - 2y = x + 2 \Leftrightarrow yx - x = 2y + 2 \Leftrightarrow x(y-1) = 2y + 2 \]
Πρέπει $y \ne 1$ (που επιβεβαιώνει την ασύμπτωτη $y=1$).
Οπότε $x = \frac{2y+2}{y-1}$.
Άρα $f^{-1}(x) = \frac{2x+2}{x-1}$ για $x \in \mathbb{R} \setminus \{1\}$.

\item Λύνουμε την εξίσωση $f(x) = 2x$:
\[ \frac{x+2}{x-2} = 2x \Rightarrow x+2 = 2x(x-2) \Leftrightarrow x+2 = 2x^2 - 4x \Leftrightarrow 2x^2 - 5x - 2 = 0 \]
(Ο περιορισμός $x \ne 2$ τηρείται αφού για $x=2$ η εξίσωση δίνει $2(2)^2 - 5(2) - 2 = -4 \ne 0$).
Η διακρίνουσα είναι $\Delta = (-5)^2 - 4(2)(-2) = 25 + 16 = 41 > 0$.
Εφόσον η διακρίνουσα της δευτεροβάθμιας είναι αυστηρά θετική, η εξίσωση κατέχει \textbf{ακριβώς δύο} πραγματικές και άνισες λύσεις (ρίζες).

\item Το εμβαδόν μεταξύ της $C_f$, των αξόνων $x=0$, $y=0$ και της $x=1$ δίνεται από το $\int_0^1 |f(x)|dx$.
Στο διάστημα $x \in [0, 1]$, ο αριθμητής $x+2 > 0$ και ο παρονομαστής $x-2 < 0$. 
Άρα $f(x) \le 0$. Επομένως $|f(x)| = -f(x)$.
\[ E = - \int_0^1 \frac{x+2}{x-2} dx = - \int_0^1 \frac{x-2+4}{x-2} dx = - \int_0^1 \left( 1 + \frac{4}{x-2} \right) dx \]
\[ E = - \Big[ x + 4\ln|x-2| \Big]_0^1 = - \big( (1 + 4\ln|-1|) - (0 + 4\ln|-2|) \big) = - (1 + 0 - 4\ln 2) = 4\ln 2 - 1 \text{ τ.μ.} \]
\end{erwthma}
\end{thema}

\begin{thema}{Β}
Δίνεται η συνάρτηση $f(x) = \dfrac{ax^2+1}{x}$ με $x \ne 0$.
\begin{erwthma}
\item Η παραγωγήσιμη συνάρτηση είναι (ως πηλίκο):
\[ f'(x) = \left(ax + \frac{1}{x}\right)' = a - \frac{1}{x^2} \]
Γνωρίζουμε ότι η $f$ παρουσιάζει τοπικό ακρότατο στο εσωτερικό σημείο $x_0=1$. Από το Θεώρημα Fermat έπεται ότι:
\[ f'(1) = 0 \Leftrightarrow a - \frac{1}{1^2} = 0 \Leftrightarrow a = 1 \]

\item Αντικαθιστούμε το $a=1$: $f(x) = \frac{x^2+1}{x} = x + \frac{1}{x}$.
Η παράγωγος είναι $f'(x) = 1 - \frac{1}{x^2} = \frac{x^2-1}{x^2}$.
Μηδενίζουμε την παράγωγο για να βρούμε τα κρίσιμα σημεία:
$x^2 - 1 = 0 \Leftrightarrow x = 1$ ή $x = -1$.
- Για $x \in (-\infty, -1) \cup (1, +\infty)$, $x^2-1 > 0 \Rightarrow f'(x) > 0$.
- Για $x \in (-1, 0) \cup (0, 1)$, $x^2-1 < 0 \Rightarrow f'(x) < 0$.

- Παρουσιάζει \textbf{τοπικό μέγιστο} στο $x = -1$ με τιμή $f(-1) = -1 - 1 = -2$.
- Παρουσιάζει \textbf{τοπικό ελάχιστο} στο $x = 1$ με τιμή $f(1) = 1 + 1 = 2$.
Επειδή $\lim_{x\to0^+} f(x) = +\infty$ και $\lim_{x\to0^-} f(x) = -\infty$, η συνάρτηση \textbf{δεν έχει ολικά} ακρότατα.

\item Εφαρμόζουμε το Θεώρημα Μέσης Τιμής (Θ.Μ.Τ.) για την $f$ στο διάστημα $[1, 2]$:
- Η $f$ είναι συνεχής στο $[1, 2]$.
- Η $f$ είναι παραγωγίσιμη στο $(1, 2)$.
Άρα υπάρχει $\xi \in (1, 2)$ τέτοιο ώστε:
\[ f'(\xi) = \frac{f(2) - f(1)}{2 - 1} \]
Υπολογίζουμε τις τιμές: $f(2) = 2 + \frac{1}{2} = 2,5 = \frac{5}{2}$ και $f(1) = 2$.
Αντικαθιστώντας λαμβάνουμε:
\[ f'(\xi) = \frac{\frac{5}{2} - 2}{1} = \frac{5-4}{2} = \frac{1}{2} \]
Το ζητούμενο αποδείχθηκε.

\item Αναζητούμε κατακόρυφες και πλάγιες/οριζόντιες ασύμπτωτες:
- **Κατακόρυφες**: Ελέγχουμε στο σημείο εκτός πεδίου ορισμού, το $0$.
$\lim_{x\to0^+} f(x) = \lim_{x\to0^+} \left( \frac{x^2+1}{x} \right) = \frac{1}{0^+} = +\infty$.
$\lim_{x\to0^-} f(x) = \lim_{x\to0^-} \left( \frac{x^2+1}{x} \right) = \frac{1}{0^-} = -\infty$.
Άρα η ευθεία $x = 0$ (ορθότερα ο άξονας $y'y$) αποτελεί \textbf{κατακόρυφη ασύμπτωτη}.
- **Πλάγιες**: Καθώς ο βαθμός του αριθμητή (2) ξεπερνά αυτόν του παρονομαστή κατά 1, έχουμε πλάγια.
Από τη διαίρεση πολυωνύμων προκύπτει η μορφή: $f(x) = x + \frac{1}{x}$.
Επειδή $\lim_{x\to\pm\infty} \frac{1}{x} = 0$, συμπεραίνουμε πως η ευθεία $y = x$ αποτελεί \textbf{πλάγια ασύμπτωτη} στο $+\infty$ και στο $-\infty$.
\end{erwthma}
\end{thema}
