# TeX Curation Guide

## Προτεινόμενη δομή

```latex
\begin{thema}{Γ}
Δίνεται ...
\begin{erwthma}
\item ...
\item ...
\item ...
\item ...
\end{erwthma}
\end{thema}
```

## Conventions

- Κράτα το εισαγωγικό κείμενο πριν από το `\begin{erwthma}`.
- Κάθε υποερώτημα να είναι ένα `\item`.
- Απόφυγε nested `enumerate` μέσα σε υποερώτημα για το MVP.
- Μη βάζεις λύση στο ίδιο αρχείο με την εκφώνηση.
- Χρησιμοποίησε σταθερά σύμβολα για την ίδια συνάρτηση, παράμετρο ή σημείο.

## Parser-friendly πρακτικές

- Μην αλλάζεις το `\begin{thema}{Γ}`.
- Μην γράφεις χειροκίνητη αρίθμηση τύπου `(α)` μέσα στο `\item`.
- Αν υπάρχει σχήμα, κράτησέ το μέσα στο ίδιο υποερώτημα που το χρειάζεται.
- Αν ένα θέμα έχει λιγότερα ή περισσότερα από 4 υποερωτήματα, σημείωσέ το στο evaluation notes.
