# /neo-arxeio

Χρησιμοποίησε αυτή την εντολή όταν ο χρήστης θέλει να δημιουργήσει νέο αρχείο χωρίς να έχει ορίσει πλήρως τη δομή.

## Υποχρεωτικό context
1. [[LLM_WIKI/INDEX|INDEX]]
2. [[LLM_WIKI/TYPES/README|TYPES]]
3. το σχετικό chapter index ή type index

## Ροή
1. Κατάλαβε αν το νέο αρχείο είναι θεωρία, θέμα, λύση ή διαγώνισμα.
2. Διάλεξε σωστό φάκελο και naming.
3. Αν είναι λύση, άνοιξε επίσης [[FORMATTING_GUIDE]] και [[LLM_WIKI/WRITING_SPECS|WRITING_SPECS]].
4. Δημιούργησε το αρχείο με ελάχιστο αλλά σωστό αρχικό περιεχόμενο.
