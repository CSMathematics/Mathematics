% Λύση του 64ου προβλήματος της ενότητας «Άλυτα Προβλήματα».
\subsection*{Λύση Προβλήματος 64 --- Πολωτικό φίλτρο και νόμος του Malus}

\begin{alist}
  \item Έχουμε
        \[
          I(\theta)=100\syn^2\theta.
        \]
        Παραγωγίζουμε:
        \[
          I'(\theta)
          =
          100\cdot2\syn\theta\cdot(-\hm\theta).
        \]
        Άρα
        \[
          {
          I'(\theta)=-200\hm\theta\syn\theta
          }.
        \]
        Ισοδύναμα, επειδή
        \[
          \hm(2\theta)=2\hm\theta\syn\theta,
        \]
        έχουμε
        \[
          {
          I'(\theta)=-100\hm(2\theta)
          }.
        \]

  \item Για
        \[
          0<\theta<\frac{\pi}{2}
        \]
        ισχύει
        \[
          \hm\theta>0
          \quad\text{και}\quad
          \syn\theta>0.
        \]
        Άρα
        \[
          I'(\theta)=-200\hm\theta\syn\theta<0.
        \]
        Επομένως η \(I\) είναι γνησίως φθίνουσα στο
        \[
          \left[0,\frac{\pi}{2}\right].
        \]

  \item Αφού η \(I\) είναι φθίνουσα στο διάστημα
        \(\left[0,\frac{\pi}{2}\right]\), η μέγιστη τιμή της
        επιτυγχάνεται στο αριστερό άκρο:
        \[
          I(0)=100\syn^2 0=100.
        \]
        Άρα
        \[
          {I_{\max}=100\% \quad\text{για}\quad \theta=0}.
        \]

        Η ελάχιστη τιμή της επιτυγχάνεται στο δεξί άκρο:
        \[
          I\!\left(\frac{\pi}{2}\right)
          =
          100\syn^2\!\left(\frac{\pi}{2}\right)
          =
          0.
        \]
        Άρα
        \[
          {
          I_{\min}=0\% \quad\text{για}\quad
          \theta=\frac{\pi}{2}
          }.
        \]

  \item Για \(\theta=\frac{\pi}{4}\), έχουμε
        \[
          I\!\left(\frac{\pi}{4}\right)
          =
          100\syn^2\!\left(\frac{\pi}{4}\right).
        \]
        Επειδή
        \[
          \syn\!\left(\frac{\pi}{4}\right)=\frac{\sqrt2}{2},
        \]
        παίρνουμε
        \[
          I\!\left(\frac{\pi}{4}\right)
          =
          100\cdot\frac12
          =
          50.
        \]
        Άρα
        \[
          {
          I\!\left(\frac{\pi}{4}\right)=50\%
          }.
        \]
        Δηλαδή, όταν ο άξονας του φίλτρου σχηματίζει γωνία
        \(45^\circ\) με τη διεύθυνση πόλωσης, περνά η μισή ένταση του
        πολωμένου φωτός.
\end{alist}

\paragraph{Πηγές και έλεγχος ρεαλιστικότητας}
Ο νόμος του Malus είναι πραγματικός νόμος της οπτικής και δίνει
\[
  I=I_0\syn^2\theta
\]
για ιδανικό πολωτικό φίλτρο \cite{malusLawPolarizer}. Έχει επίσης
επαληθευτεί σε απλά εκπαιδευτικά πειράματα με οθόνη υπολογιστή και
αισθητήρα φωτός κινητού τηλεφώνου
\cite{monteiro2016malusSmartphone}.

Το μοντέλο είναι ρεαλιστικό για καλό πολωτή και γραμμικά πολωμένο φως.
Ο έλεγχος \(I(0)=100\%\), \(I(45^\circ)=50\%\),
\(I(90^\circ)=0\%\) συμφωνεί με τη φυσική ερμηνεία: όταν οι διευθύνσεις
είναι παράλληλες περνά η μέγιστη ένταση, ενώ όταν είναι κάθετες το
ιδανικό φίλτρο δεν αφήνει φως να περάσει. Στην πράξη, πραγματικά
φίλτρα δεν είναι τέλεια, άρα στο \(90^\circ\) μπορεί να περνά πολύ
μικρή, αλλά όχι μηδενική, ένταση.
