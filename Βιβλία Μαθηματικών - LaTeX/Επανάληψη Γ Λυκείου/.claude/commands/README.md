# Slash commands για το project

Αυτός ο φάκελος λειτουργεί ως βιβλιοθήκη εντολών τύπου Claude Code για το αποθετήριο.

## Διαθέσιμες εντολές
- `/lysh`: γράφει ή διορθώνει λύση άσκησης
- `/theory`: γράφει ή οργανώνει θεωρία / σημειώσεις
- `/nea-askisi`: δημιουργεί νέα άσκηση
- `/neo-arxeio`: δημιουργεί νέο αρχείο με σωστό context
- `/organosi`: οργανώνει αρχεία, notes ή indexes
- `/elegxos-style`: ελέγχει αν ένα `.tex` ακολουθεί τις προδιαγραφές
- `/paradeigma`: βρίσκει σχετικό παράδειγμα ή παρόμοια λύση

## Πώς χρησιμοποιούνται
Παραδείγματα:
- `/lysh solution_G_101.tex για όρια και μονοτονία`
- `/theory φτιάξε σημείωση για Bolzano`
- `/nea-askisi νέα άσκηση στο κεφάλαιο 2 για ακρότατα`
- `/neo-arxeio αρχείο θεωρίας για ολοκληρώματα`
- `/elegxos-style solution_B_12.tex`
