Visualizing Functions — A Short Article

Author

Spyros

Abstract

This short article visualizes three elementary functions and discusses key features: a quadratic, a scaled sine, and the reciprocal function. Interactive plots are generated with Plotly.

Functions

We study the following functions:

  1. Quadratic: \(f(x)=x^{2}-4x+3\)
  2. Scaled sine: \(g(x)=2\\sin(x)\)
  3. Reciprocal: \(h(x)=1/x\)

Plots

Below are interactive Plotly code blocks. Quarto will execute the Python and embed the results.

Quadratic and Sine (combined)

import numpy as np
import plotly.graph_objects as go

# x values
x = np.linspace(-6, 6, 400)

# compute
y_q = x**2 - 4*x + 7
y_s = 2 * np.sin(x)

fig = go.Figure()
fig.add_trace(go.Scatter(x=x, y=y_q, mode='lines', name='f(x) = x^2 - 4x + 3'))
fig.add_trace(go.Scatter(x=x, y=y_s, mode='lines', name='g(x) = 2 sin(x)'))

fig.update_layout(title='Quadratic and Sine', xaxis_title='x', yaxis_title='y')
fig.show()

Reciprocal (two branches)

import numpy as np
import plotly.graph_objects as go

# avoid zero: plot left and right branches separately
x_left = np.linspace(-6, -0.1, 250)
x_right = np.linspace(0.1, 6, 250)

y_left = 1.0 / x_left
y_right = 1.0 / x_right

fig = go.Figure()
fig.add_trace(go.Scatter(x=x_left, y=y_left, mode='lines', name='h(x)=1/x (left)'))
fig.add_trace(go.Scatter(x=x_right, y=y_right, mode='lines', name='h(x)=1/x (right)'))

fig.update_layout(title='Reciprocal Function (Two Branches)', xaxis_title='x', yaxis_title='y')
fig.show()

Short Analysis

  • The quadratic has a vertex and grows parabolically; its roots are at \(x=1\) and \(x=3\).
  • The sine is periodic with amplitude 2.
  • The reciprocal has a vertical asymptote at \(x=0\) and two disconnected branches.
