# 📋 Unified Prompt Template

Αυτό είναι το ενιαίο template που ακολουθούν **όλοι οι agents**.

---

## 1. Ρόλος & Στόχος

```markdown
Είσαι [ρόλος του agent].

Ο στόχος σου είναι [περιγραφή στόχου].

[Τι ΔΕΝ κάνεις - αρνητικοί ορισμοί]
```

---

## 2. Ειδικές Οδηγίες

Το κύριο σώμα του prompt με τις ειδικές οδηγίες για κάθε agent.

Χωρίζεται σε υποενότητες με `###` headers.

---

## 3. Διαχείριση Ύλης

```markdown
Για να διασφαλίσεις ότι οι ασκήσεις είναι επιλύσιμες:

Ανατρέχεις στο αρχείο: `@syllabus/[τάξη].md`

Κανόνες:

- Αν η άσκηση είναι **επαναληπτική**: οποιοδήποτε σημείο της ύλης
- Αν **δεν είναι επαναληπτική**: μόνο έννοιες μέχρι το τρέχον μάθημα
```

---

## 4. LaTeX & Τυπογραφία

```markdown
## LaTeX & Τυπογραφία

Ισχύουν **όλοι οι κανόνες** του `@latex_style_guide.md`:

- Ελληνική υποδιαστολή `{,}`
- `\hm`, `\syn`, `\ef`
- `\cdot` για πολλαπλασιασμό
- `\displaystyle` όπου χρειάζεται
- Χωρίς νέα πακέτα
```

---

## 5. Κανόνες Εξόδου

```markdown
## Κανόνες Εξόδου

- Παράγεις **μόνο LaTeX**
- Καμία εξήγηση εκτός LaTeX
- [Ειδικοί κανόνες ανά agent]
```

---

## 6. Παραδείγματα (ΝΕΟ)

```markdown
## Παραδείγματα

### Παράδειγμα 1: [Τίτλος]

**Input:** [περιγραφή αιτήματος]

**Output:**
\`\`\`latex
[LaTeX code]
\`\`\`

### Παράδειγμα 2: [Τίτλος]

...
```

---

## 7. Πρωτόκολλο Εκκίνησης

```markdown
## Πρωτόκολλο Εκκίνησης

Περίμενε να σου δοθούν:

1. [Input 1]
2. [Input 2]
3. ...

Αν κατανοήσεις, απάντησε μόνο:

> _"[Ready message]"_
```

---

## Σημειώσεις

- Χρήση `##` για κύριες ενότητες
- Χρήση `###` για υποενότητες
- Tables για structured data
- Emoji sparingly για visual cues
