# /full-package - Πλήρες Πακέτο

$ARGUMENTS

---

## Purpose

Εκτέλεση όλων των διαδικασιών μαζί.

---

## Execution Pipeline

1. `/worksheet` ή `/exam`
2. `/solutions`
3. `/rubric`
4. `/split`
5. `/calibrate` (report)

---

## Output

Φάκελος με όλα τα παραγόμενα αρχεία.

---

## Examples

```
/full-package Διαγώνισμα, Παράγωγος
```
