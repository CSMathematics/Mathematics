# /mindmap - Εννοιολογικός Χάρτης

$ARGUMENTS

---

## Purpose

Δημιουργία mind map για κεφάλαιο.

---

## Output

TikZ mindmap με:

- Κεντρική έννοια
- Υποέννοιες
- Συνδέσεις

---

## Examples

```
/mindmap Παράγωγος
/mindmap Όρια και Συνέχεια
```
