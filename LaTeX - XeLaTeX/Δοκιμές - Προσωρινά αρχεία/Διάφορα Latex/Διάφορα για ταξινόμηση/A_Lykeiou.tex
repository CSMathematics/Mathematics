\begin{center}
{\Large \textbf{Εξισώσεις 2ου βαθμού με παραμέτρους}}
\end{center}
Αν σε μια εξίσωση 2ου βαθμού οι συντελεστές περιέχουν παραμέτρους, τότε οι δύο πιο συχνές ασκήσεις που συναντάμε είναι:
\begin{enumerate}
\item Επίλυση εξίσωσης για τις διάφορες τιμές των παραμέτρων.
\item Εύρεση παραμέτρου ώστε να ισχύει μια συνθήκη.
\end{enumerate}
\paragraph{Παράδειγμα 1 - Επίλυση εξίσωσης}
Δίνεται η εξίσωση $ \lambda x^2+(2\lambda+1)x+\lambda-1=0 $ με $ \lambda\in\mathbb{R} $. Να λυθεί η εξίσωση για τις διάφορες τιμές του $ \lambda\in\mathbb{R} $.\\\\
\textbf{Λύση}\\
Στην εξίσωση βλέπουμε ότι ο συντελεστής του $ x^2 $ είναι άγνωστος δηλαδή $ a=\lambda $. Αυτό σημαίνει ότι η εξίσωση είναι είτε 2ου βαθμού, αν $ \lambda\neq 0 $ είτε 1ου βαθμού αν $ \lambda=0 $. Θα ξεχωρίσουμε λοιπόν αυτές τις δύο περιπτώσεις ώστε σε καθεμία να λύσουμε την εξίσωση με τον κατάλληλο τρόπο.
\begin{Alist}
\item Αν υποθέσουμε ότι $ \lambda\neq 0 $ τότε η εξίσωση είναι 2ου βαθμού άρα έχουμε τους συντελεστές $ a=\lambda.\beta=2\lambda+1 $ και $ \gamma=\lambda-1 $. Είναι λοιπόν
\[ \Delta=\beta^2-4a\gamma=(2\lambda-1)^2-4\cdot\lambda\cdot(\lambda-1)=4\lambda^2-4\lambda+1-4\lambda^2+4\lambda=8\lambda+1 \]
Παρατηρούμε ότι η διακρίνουσα δεν είναι σταθερός αριθμός αλλά εξαρτάται από την παράμετρο $ \lambda $. Συνεπώς, κάποιες τιμές του $ \lambda $ βγάζουν τη διακρίνουσα θετική, κάποιες αρνητική και άλλες μηδέν.
\begin{rlist}
\item Η εξίσωση έχει $ 2 $ λύσεις αν $ \Delta>0\Rightarrow 8\lambda+1>0\Rightarrow \lambda>-\frac{1}{8} $. Αν λάβουμε υπ' όψιν και τον περιορισμό $ \lambda\neq 0 $ τότε $ \lambda\in\left(\frac{1}{8},0\right)\cup(0,+\infty) $. Οι λύσεις θα είναι
\[ x_{1,2}=\frac{-\beta\pm\sqrt{\Delta}}{2a}=\frac{-(2\lambda+1)\pm\sqrt{8\lambda+1}}{2\cdot\lambda}=\frac{-2\lambda-1\pm\sqrt{8\lambda+1}}{2\lambda} \]
(Οι λύσεις που πήραμε έχουν δύσκολη μορφή και δεν απλοποιούνται περαιτέρω. Ο κύριος σκοπός όμως του παραδείγματος είναι να παρουσιάσουμε τον τρόπο επίλυσης.)
\item Η εξίσωση έχει μία διπλή λύση αν $ \Delta=0\Rightarrow 8\lambda+1=0\Rightarrow \lambda=-\frac{1}{8} $. Η λύση θα είναι 
\[ x=\frac{-\beta}{2a}=-\frac{2\lambda+1}{2\lambda}=-\frac{2\cdot\left(-\frac{1}{8}\right)+1}{2\cdot\left(-\frac{1}{8}\right)}=-\frac{-\frac{1}{4}+1}{-\frac{1}{4}}=3 \]
\item Τέλος η εξίσωση είναι αδύνατη αν $ \Delta<0\Rightarrow 8\lambda+1<0\Rightarrow \lambda<-\frac{1}{8} $.
\end{rlist}
\item Αν υποθέσουμε ότι $ \lambda=0 $ τότε η εξίσωση γίνεται
\[ 0\cdot x^2+(2\cdot 0+1)x+0-1=0\Rightarrow x-1=0\Rightarrow x=1 \]
άρα όπως είδαμε η εξίσωση έγινε 1ου βαθμού και μας έδωσε μοναδική λύση $ x=1 $.
\end{Alist}
\paragraph{Παράδειγμα 2 - Εύρεση παραμέτρου}
Δίνεται η εξίσωση $ x^2+\lambda x+1=0 $. Να βρεθεί η τιμή της παραμέτρου $ \lambda\in\mathbb{R} $ ώστε η εξίσωση να έχει μια διπλή λύση.\\\\
\textbf{Λύση}\\
Εδώ βλέπουμε ότι ο συντελεστής του $ x^2 $ είναι σταθερός αριθμός $ a=1\neq 0 $ οπότε η εξίσωση είναι 2ου βαθμού για οποιοδήποτε $ \lambda\in\mathbb{R} $. Έχουμε λοιπόν $ a=1,\beta=\lambda $ και $ \gamma=1 $. Οπότε
\[ \Delta=\beta^2-4a\gamma=\lambda^2-4\cdot1\cdot1=\lambda^2-4 \]
Και εδώ βλέπουμε ότι η διακρίνουσα εξαρτάται από την παράμετρο άρα αλλάζει τιμές. Προκειμένου η εξίσωση να έχει μία διπλή λύση θα πρέπει $ \Delta=0 $ άρα
\[ \Delta=0\Rightarrow \lambda^2-4=0\Rightarrow\lambda^2=4\Rightarrow\lambda=\pm 2 \]
