\paragraph{Α. Υπολογιστικές Ασκήσεις}

\askhsh
Σε ένα ορθογώνιο τρίγωνο $AB\varGamma$ ($\hat{A}=90^\circ$) δίνονται οι κάθετες πλευρές $b=3\text{ \eng{cm}}$ και $c=4\text{ \eng{cm}}$. Να υπολογίσετε:
\begin{alist}
    \item Την υποτείνουσα $\alpha$ του τριγώνου.
    \item Τους τριγωνομετρικούς αριθμούς $\eta\mu B, \sigma\upsilon\nu B, \eta\mu \Gamma$ και $\sigma\upsilon\nu \Gamma$.
\end{alist}
\begin{center}
    \begin{tikzpicture}[scale=0.6]
        \tkzDefPoint(0,0){A}
        \tkzDefPoint(4,0){B}
        \tkzDefPoint(0,3){C}
        \tkzDrawPolygon[plm](A,B,C)
        \tkzMarkRightAngle[size=0.4](B,A,C)
        \tkzLabelPoint[below left](A){$A$}
        \tkzLabelPoint[below right](B){$B$}
        \tkzLabelPoint[above left](C){$\varGamma$}
        \tkzLabelSegment[below](A,B){$4\text{ \eng{cm}}$}
        \tkzLabelSegment[left](A,C){$3\text{ \eng{cm}}$}
    \end{tikzpicture}
\end{center}

\askhsh
Σε ορθογώνιο τρίγωνο $AB\varGamma$ ($\hat{A}=90^\circ$) έχουμε $\alpha=13\text{ \eng{cm}}$ και $b=5\text{ \eng{cm}}$. Να υπολογίσετε:
\begin{alist}
    \item Την πλευρά $c$.
    \item Τους τριγωνομετρικούς αριθμούς της γωνίας $\hat{B}$ και της γωνίας $\hat{\Gamma}$.
\end{alist}

\askhsh
Αν για μια οξεία γωνία $\omega$ γνωρίζουμε ότι $\eta\mu \omega = \frac{3}{5}$, να υπολογίσετε το $\sigma\upsilon\nu \omega$ χρησιμοποιώντας τον ορισμό των τριγωνομετρικών αριθμών σε κατάλληλο ορθογώνιο τρίγωνο.

\askhsh
Να υπολογίσετε την τιμή των παρακάτω παραστάσεων:
\begin{alist}
    \item $A = 2\eta\mu 30^\circ + 4\sigma\upsilon\nu 60^\circ$
    \item $B = \sigma\upsilon\nu^2 45^\circ + \eta\mu^2 45^\circ$
\end{alist}

\askhsh
Μια σκάλα μήκους $5\text{ m}$ ακουμπά σε έναν κατακόρυφο τοίχο. Η γωνία $\omega$ που σχηματίζει η σκάλα με το έδαφος έχει ημίτονο $\eta\mu \omega = 0,8$. Σε τι ύψος από το έδαφος φτάνει η σκάλα στον τοίχο;

\paragraph{Γ. Ιδιότητες και Θεωρία}

\askhsh
Αν για μια οξεία γωνία $x$ ισχύει $\eta\mu x = \sigma\upsilon\nu 20^\circ$, να βρείτε την τιμή της γωνίας $x$.

\askhsh
Να αποδείξετε ότι για οποιαδήποτε οξεία γωνία $\omega$ ισχύει η σχέση:
\[ (\eta\mu \omega + \sigma\upsilon\nu \omega)^2 = 1 + 2 \eta\mu \omega \sigma\upsilon\nu \omega \]

\askhsh
Αν δύο γωνίες $\alpha$ και $\beta$ είναι συμπληρωματικές ($\alpha + \beta = 90^\circ$), να υπολογίσετε την τιμή της παράστασης:
\[ \Pi = \eta\mu^2 \alpha + \eta\mu^2 \beta \]
