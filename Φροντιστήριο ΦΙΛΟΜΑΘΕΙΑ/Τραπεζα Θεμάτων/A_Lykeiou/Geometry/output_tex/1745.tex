Δίνεται κυρτό τετράπλευρο $\mathrm{A}\mathrm{B}\Gamma\Delta$ με $\mathrm{B}\mathrm{A} = \mathrm{B}\Gamma$ και $\hat{\mathrm{A}} = \hat{\Gamma}$.
Να αποδείξετε ότι:
\begin{alist}
    \item Το τρίγωνο $\mathrm{A}\Delta\Gamma$ είναι ισοσκελές. \monades{9}
    \item Οι διαγώνιοι του τετραπλεύρου $\mathrm{A}\mathrm{B}\Gamma\Delta$ τέμνονται κάθετα. \monades{6}
    \item Το τετράπλευρο που έχει για κορυφές τα μέσα των πλευρών του $\mathrm{A}\mathrm{B}\Gamma\Delta$ είναι ορθογώνιο. \monades{10}
\end{alist}
