Στο ισοσκελές τρίγωνο $\mathrm{A}\mathrm{B}\Gamma$ ($\mathrm{A}\mathrm{B} = \mathrm{A}\Gamma$) φέρνουμε τις διαμέσους $\mathrm{B}\Delta$ και $\Gamma\mathrm{E}$. Μία ευθεία $\varepsilon$ παράλληλη στη βάση $\mathrm{B}\Gamma$ τέμνει τις πλευρές $\mathrm{A}\mathrm{B}$ και $\mathrm{A}\Gamma$ στα $\mathrm{Z}$ και $\mathrm{H}$ αντίστοιχα και τις διαμέσους $\mathrm{B}\Delta$ και $\Gamma\mathrm{E}$ στα σημεία $\Theta$ και $\mathrm{K}$ αντίστοιχα.
Να αποδείξετε ότι:
\begin{alist}
    \item $\mathrm{B}\mathrm{Z} = \Gamma\mathrm{H}$. \monades{8}
    \item τα τρίγωνα $\mathrm{Z}\mathrm{B}\Theta$ και $\mathrm{H}\mathrm{K}\Gamma$ είναι ίσα. \monades{9}
    \item $\mathrm{Z}\mathrm{K} = \mathrm{H}\Theta$. \monades{8}
\end{alist}
