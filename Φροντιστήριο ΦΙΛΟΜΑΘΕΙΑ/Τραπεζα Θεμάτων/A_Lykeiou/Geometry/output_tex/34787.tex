ΘΕΜΑ 2

Θεωρούμε ισοσκελές τρίγωνο ΑΒΓ (ΑΒ=ΑΓ) με γωνία κορυφής $\widehat{Α} = 40^{0}$. Στην προέκταση της ΓΒ (προς το Β ) παίρνουμε τμήμα ΒΔ τέτοιο ώστε $Β\Delta = ΑΒ$.

Να υπολογίσετε:

\begin{alist}
\item τις γωνίες του τριγώνου ΑΒΓ, \monades{10}

\item τη γωνία $\Delta\widehat{Α}\Gamma$. \monades{15}
\end{alist}
