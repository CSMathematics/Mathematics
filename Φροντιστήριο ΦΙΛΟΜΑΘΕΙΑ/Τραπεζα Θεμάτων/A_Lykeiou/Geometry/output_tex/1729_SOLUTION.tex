\begin{alist}
    \item Στο ορθογώνιο τρίγωνο $\mathrm{A}\Delta\Gamma$ οι οξείες γωνίες του $\Delta\hat{\mathrm{A}}\Gamma$ και $\Delta\hat{\Gamma}\mathrm{A}$ είναι συμπληρωματικές, οπότε αφού $\Delta\hat{\Gamma}\mathrm{A} = 30^\circ$, τότε $\Delta\hat{\mathrm{A}}\Gamma = 60^\circ \quad (1)$. Στο ορθογώνιο τρίγωνο $\Delta\mathrm{A}\mathrm{E}$ οι οξείες γωνίες του $\Delta\hat{\mathrm{A}}\Gamma$ (ή $\Delta\hat{\mathrm{A}}\mathrm{E}$) και $\mathrm{A}\hat{\Delta}\mathrm{E}$ είναι συμπληρωματικές, οπότε αφού $\Delta\hat{\mathrm{A}}\Gamma = 60^\circ$, τότε $\mathrm{A}\hat{\Delta}\mathrm{E} = 30^\circ \quad (2)$.
    
    Οι διαγώνιοι $\mathrm{A}\Gamma$ και $\mathrm{B}\Delta$ του ορθογωνίου $\mathrm{A}\mathrm{B}\Gamma\Delta$ είναι ίσες και διχοτομούνται, άρα
    \[ \mathrm{O}\Gamma = \frac{\mathrm{A}\Gamma}{2} = \frac{\mathrm{B}\Delta}{2} = \mathrm{O}\Delta \]
    Επομένως το τρίγωνο $\mathrm{O}\Gamma\Delta$ είναι ισοσκελές με βάση $\Delta\Gamma$, οπότε $\mathrm{O}\hat{\Delta}\Gamma = \mathrm{O}\hat{\Gamma}\Delta = 30^\circ \quad (3)$.
    
    Ισχύει ακόμη ότι: $\mathrm{A}\hat{\Delta}\mathrm{E} + \mathrm{E}\hat{\Delta}\mathrm{O} + \mathrm{O}\hat{\Delta}\Gamma = 90^\circ$. Δηλαδή, $30^\circ + \mathrm{E}\hat{\Delta}\mathrm{O} + 30^\circ = 90^\circ$. Άρα $\mathrm{E}\hat{\Delta}\mathrm{O} = 30^\circ \quad (4)$.
    
    Από τις $(2), (3)$ και $(4)$ έχουμε ότι $\mathrm{A}\hat{\Delta}\mathrm{E} = \mathrm{E}\hat{\Delta}\mathrm{O} = \mathrm{O}\hat{\Delta}\Gamma = 30^\circ$. Άρα η γωνία $\mathrm{A}\hat{\Delta}\Gamma$ χωρίζεται από τις $\Delta\mathrm{E}$ και $\Delta\mathrm{B}$ σε τρείς ίσες γωνίες.
    
    \item Το τρίγωνο $\mathrm{O}\mathrm{A}\Delta$ είναι ισοσκελές με $\mathrm{O}\mathrm{A} = \mathrm{O}\Delta$ ως μισά των ίσων διαγωνίων $\mathrm{A}\Gamma, \mathrm{B}\Delta$ του ορθογωνίου $\mathrm{A}\mathrm{B}\Gamma\Delta$. Αφού $\Delta\hat{\mathrm{A}}\Gamma = 60^\circ$ από τη $(1)$ θα είναι $\mathrm{A}\hat{\Delta}\mathrm{O} = 60^\circ$ (εφόσον το τρίγωνο είναι ισοσκελές, $\mathrm{O}\hat{\mathrm{A}}\Delta = \mathrm{O}\hat{\Delta}\mathrm{A} = 60^\circ$). Άρα το ισοσκελές τρίγωνο $\mathrm{O}\mathrm{A}\Delta$ είναι ισόπλευρο με $\mathrm{O}\mathrm{A} = \mathrm{O}\Delta = \mathrm{A}\Delta$. Όμως $\mathrm{A}\Delta = \mathrm{B}\Gamma$ ως απέναντι πλευρές του ορθογωνίου. Άρα τα τρίγωνα $\mathrm{A}\mathrm{Z}\mathrm{O}$ και $\mathrm{A}\mathrm{B}\Gamma$ έχουν:
    \begin{itemize}
        \item $\hat{\mathrm{O}} = \hat{\mathrm{B}} = 90^\circ$ ($\mathrm{Z}\mathrm{O} \perp \mathrm{A}\Gamma$ στο σημείο $\mathrm{O}$)
        \item $\mathrm{O}\mathrm{A} = \mathrm{B}\Gamma$
        \item $\mathrm{A}\hat{\Gamma}\mathrm{B} = 90^\circ - 30^\circ = 60^\circ = \mathrm{Z}\hat{\mathrm{A}}\mathrm{O}$
    \end{itemize}
    Άρα τα τρίγωνα είναι ίσα, γιατί είναι ορθογώνια με μία κάθετη πλευρά ίση και την προσκείμενη οξεία γωνία ίση.
\end{alist}
