Δίνεται ισοσκελές τραπέζιο ΑΒΓΔ (ΑΒ $\slash \slash$ ΓΔ και ΑΔ = ΒΓ), με ΑΒ \textgreater{} ΓΔ και ΜΝ η διάμεσός του.

\begin{alist}
\item Αν τα μήκη των βάσεων είναι ΑΒ = 3x + 2, ΓΔ = x + 2 και το μήκος της διαμέσου του τραπεζίου είναι ΜΝ = x + 4, τότε να δείξετε ότι x = 2. \monades{10}

\item Αν η γωνία $\widehat{\Gamma}$ είναι διπλάσια της γωνίας $\widehat{Β}$, να υπολογίσετε τις γωνίες του τραπεζίου. \monades{15}
