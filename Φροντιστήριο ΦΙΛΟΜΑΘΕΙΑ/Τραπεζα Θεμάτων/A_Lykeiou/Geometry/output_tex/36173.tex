ΘΕΜΑ 2

Δίνεται ισόπλευρο τρίγωνο $AB\Gamma$ και εκτός αυτού κατασκευάζουμε τετράγωνο $B\Gamma\Delta E$.

\begin{alist}
\item Να υπολογίσετε τις γωνίες:
\begin{alist}
\item $A\widehat{B}E$, \monades{8}
\item $B\widehat{E}A$. \monades{9}
\end{alist}
\item Να αποδείξετε ότι το τρίγωνο $AE\Delta$ είναι ισοσκελές. \monades{8}

\begin{center}
\begin{tikzpicture}[scale=1]
\tkzDefPoint(0,0){B}
\tkzDefPoint(3,0){C}
\tkzDefTriangle[equilateral](B,C) \tkzGetPoint{A}
\tkzDefSquare(B,C) \tkzGetPoints{Delta}{E}

\draw[l3] (A)--(B)--(C)--cycle;
\draw[l3] (B)--(E)--(Delta)--(C);
\draw[l3] (A)--(E)--(Delta)--cycle;

\tkzDrawPoints(A,B,C,Delta,E)
\tkzLabelPoint[above](A){$A$}
\tkzLabelPoint[left](B){$B$}
\tkzLabelPoint[right](C){$\Gamma$}
\tkzLabelPoint[below right](Delta){$\Delta$}
\tkzLabelPoint[below left](E){$E$}

\tkzMarkSegments[mark=s|](A,B B,C A,C B,E E,Delta Delta,C)
\end{tikzpicture}
\end{center}
\end{alist}
