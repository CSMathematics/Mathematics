ΘΕΜΑ 2

Δίνεται ορθογώνιο τρίγωνο $AB\Gamma$ με τη γωνία $A$ ορθή, $2\widehat{\Gamma} = \widehat{B}$ και το ύψος του $A\Delta$.

\begin{alist}
\item Να υπολογιστούν οι οξείες γωνίες του τριγώνου $AB\Gamma$. \monades{9}
\item Να υπολογιστεί η γωνία $B\widehat{A}\Delta$. \monades{7}
\item Να αποδείξετε ότι $B\Delta = \frac{AB}{2}$. \monades{9}

\begin{center}
\begin{tikzpicture}[scale=1.2]
\tkzDefPoint(0,0){A}
\tkzDefPoint(0,2.6){B}
\tkzDefPoint(4.5,0){C} % tan(30) = 2.6/AC -> AC = 4.5
\tkzDefPointBy[projection=onto B--C](A) \tkzGetPoint{Delta}

\draw[l3] (A)--(B)--(C)--cycle;
\draw[l3] (A)--(Delta);

\tkzDrawPoints(A,B,C,Delta)
\tkzLabelPoint[below left](A){$A$}
\tkzLabelPoint[above](B){$B$}
\tkzLabelPoint[right](C){$\Gamma$}
\tkzLabelPoint[above right](Delta){$\Delta$}

\tkzMarkRightAngle(B,A,C)
\tkzMarkRightAngle(A,Delta,B)
\tkzMarkAngle[size=0.6,mark=none](A,B,C)
\tkzLabelAngle[pos=0.9](A,B,C){$60^\circ$}
\tkzMarkAngle[size=0.8,mark=none](A,C,B)
\tkzLabelAngle[pos=1.2](A,C,B){$30^\circ$}
\end{tikzpicture}
\end{center}
\end{alist}
