ΘΕΜΑ 4

Σε οξυγώνιο τρίγωνο ΑΒΓ ($\widehat{\text{Β}} < \widehat{\text{Γ}}$) θεωρούμε τα μέσα Δ, Ε, Ζ των πλευρών ΑΒ, ΑΓ, ΒΓ αντίστοιχα. Έστω Η η προβολή της κορυφής Γ πάνω στην πλευρά ΑΒ.

Να αποδείξετε ότι:

\begin{alist}
\item ΗΕ$\  = \ $ΕΓ και ΗΖ$\  = \ $ΖΓ, \monades{8}

\item το τετράπλευρο ΔΕΓΖ είναι παραλληλόγραμμο, \monades{8}

\item Ζ$\widehat{\text{Δ}}$Ε$\  = \ $Ζ$\widehat{\text{Η}}$Ε. \monades{9}
\end{alist}
