ΘΕΜΑ 2

Δίνεται τρίγωνο $AB\Gamma$ με $AB = A\Gamma$ και η διάμεσός του $A\Delta$ τέτοια ώστε $B\widehat{A}\Delta = 30^{\circ}$. Θεωρούμε σημείο $E$ στην $A\Gamma$ τέτοιο ώστε $A\Delta = AE$.

\begin{alist}
\item Να αποδείξετε ότι το τρίγωνο $AB\Gamma$ είναι ισόπλευρο. \monades{8}
\item Να υπολογίσετε τις γωνίες του τριγώνου $A\Delta E$. \monades{9}
\item Να υπολογίσετε τη γωνία $E\widehat{\Delta}\Gamma$. \monades{8}

\begin{center}
\begin{tikzpicture}[scale=1.2]
\tkzDefPoint(0,0){B}
\tkzDefPoint(4,0){C}
\tkzDefTriangle[equilateral](B,C) \tkzGetPoint{A}
\tkzDefMidPoint(B,C) \tkzGetPoint{Delta}
\tkzDefPointBy[homothety=center A ratio 0.866](C) \tkzGetPoint{E} % AD = 2*sqrt(3) = 3.46. AC=4. 3.46/4 = 0.866.

\draw[l3] (A)--(B)--(C)--cycle;
\draw[l3] (A)--(Delta);
\draw[l3] (Delta)--(E);

\tkzDrawPoints(A,B,C,Delta,E)
\tkzLabelPoint[above](A){$A$}
\tkzLabelPoint[below](B){$B$}
\tkzLabelPoint[below](C){$\Gamma$}
\tkzLabelPoint[below](Delta){$\Delta$}
\tkzLabelPoint[right](E){$E$}

\tkzMarkRightAngle(A,Delta,B)
\tkzMarkAngle[size=0.6,mark=none](B,A,Delta)
\tkzLabelAngle[pos=0.9](B,A,Delta){$30^\circ$}
\tkzMarkSegments[mark=s|](A,Delta A,E)
\end{tikzpicture}
\end{center}
\end{alist}
