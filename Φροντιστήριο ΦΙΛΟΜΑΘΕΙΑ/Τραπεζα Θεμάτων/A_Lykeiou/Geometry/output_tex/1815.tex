    \item 5.10. Τραπέζιο.

Δίνεται τραπέζιο $\mathrm{A}\mathrm{B}\Gamma\Delta$ με $\mathrm{A}\mathrm{B} \parallel \Gamma\Delta$ και $\mathrm{A}\mathrm{B} = \mathrm{A}\Delta + \mathrm{B}\Gamma$. Αν η διχοτόμος της γωνίας $\hat{\Delta}$ τέμνει την $\mathrm{A}\mathrm{B}$ στο σημείο $\mathrm{M}$, να αποδείξετε ότι:
\begin{alist}
    \item Το τρίγωνο $\mathrm{A}\Delta\mathrm{M}$ είναι ισοσκελές. \monades{8}
    \item Το τρίγωνο $\mathrm{M}\mathrm{B}\Gamma$ είναι ισοσκελές. \monades{9}
    \item Η $\Gamma\mathrm{M}$ είναι διχοτόμος της γωνίας $\hat{\Gamma}$ του τραπεζίου. \monades{8}
\end{alist}
