\begin{ylh}{1}
    \item 3.2. 1ο Κριτήριο ισότητας τριγώνων
    \item 4.6. Άθροισμα γωνιών τριγώνου.
\end{ylh}
Δίνεται τρίγωνο $\mathrm{A}\mathrm{B}\Gamma$ με $\mathrm{A}\mathrm{B} < \mathrm{A}\Gamma$. Φέρνουμε τη διχοτόμο του $\mathrm{A}\mathrm{K}$ και σε τυχαίο σημείο της $\mathrm{E}$ φέρνουμε ευθεία κάθετη στη διχοτόμο $\mathrm{A}\mathrm{K}$, η οποία τέμνει τις $\mathrm{A}\mathrm{B}$ και $\mathrm{A}\Gamma$ στα σημεία $\mathrm{Z}$ και $\Delta$ αντίστοιχα και την προέκταση της $\Gamma\mathrm{B}$ στο σημείο $\mathrm{H}$.
Να αποδείξετε ότι:
\begin{alist}
    \item $\mathrm{Z}\hat{\Delta}\Gamma = 90^\circ + \frac{\hat{\mathrm{A}}}{2}$. \monades{7}
    \item $\mathrm{Z}\mathrm{K} = \mathrm{K}\Delta$. \monades{8}
    \item $\mathrm{Z}\hat{\mathrm{H}}\Gamma = \frac{\hat{\mathrm{B}} - \hat{\Gamma}}{2}$. \monades{10}
\end{alist}
