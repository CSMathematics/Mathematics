Δίνεται τραπέζιο $\mathrm{A}\mathrm{B}\Gamma\Delta$ ($\mathrm{A}\mathrm{B} \parallel \Gamma\Delta$) με $\hat{\mathrm{A}} = \hat{\Delta} = 90^\circ$, $\Delta\Gamma = 2\mathrm{A}\mathrm{B}$ και $\hat{\mathrm{B}} = 3\hat{\Gamma}$. Φέρνουμε $\mathrm{B}\mathrm{E} \perp \Delta\Gamma$ που τέμνει τη διαγώνιο $\mathrm{A}\Gamma$ στο $\mathrm{M}$. Φέρνουμε την $\mathrm{A}\mathrm{E}$ που τέμνει τη διαγώνιο $\mathrm{B}\Delta$ στο $\mathrm{N}$.
Να αποδείξετε ότι:
\begin{alist}
    \item $\hat{\Gamma} = 45^\circ$. \monades{7}
    \item Το τετράπλευρο $\mathrm{A}\mathrm{B}\Gamma\mathrm{E}$ είναι παραλληλόγραμμο. \monades{9}
    \item $\mathrm{A}\mathrm{E} \perp \mathrm{B}\Delta$. \monades{9}
\end{alist}
