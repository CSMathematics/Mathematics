ΘΕΜΑ 2

Θεωρούμε ορθογώνιο τρίγωνο ΑΒΓ ($\widehat{Α} = 90^{0}$) με $\widehat{\Gamma} = 40^{0}$. Έστω Δ τυχαίο σημείο της πλευράς ΑΓ και $\Delta Ε\bot Β\Gamma$.

Να υπολογίσετε:

\begin{alist}
\item τις γωνίες του τριγώνου ΔΕΓ, \monades{10}

\item τις γωνίες του τετραπλεύρου ΑΔΕΒ. \monades{15}


\begin{center}
\begin{tikzpicture}[scale=1.2]
\tkzDefPoint(0,0){A}
\tkzDefPoint(4,0){C}
\tkzDefPoint(0,3.35){B} % Using tan(40) ~ 0.839. AC*tan(40) = 4 * 0.839 = 3.356

\tkzDefPoint(2,0){D}
\tkzDefPointBy[projection=onto B--C](D) \tkzGetPoint{E}

\draw[l3] (A)--(B)--(C)--cycle;
\draw[l3] (D)--(E);

\tkzDrawPoints(A,B,C,D,E)
\tkzLabelPoint[below left](A){$A$}
\tkzLabelPoint[above](B){$B$}
\tkzLabelPoint[below](C){$\Gamma$}
\tkzLabelPoint[below](D){$\Delta$}
\tkzLabelPoint[above right](E){$E$}

\tkzMarkRightAngle(B,A,C)
\tkzMarkRightAngle(D,E,C)
\tkzMarkAngle[size=0.6,mark=none](B,C,A)
\tkzLabelAngle[pos=0.9](B,C,A){$40^\circ$}
\end{tikzpicture}
\end{center}
\end{alist}
