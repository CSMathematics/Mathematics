ΘΕΜΑ 2

Δίνεται ισοσκελές τρίγωνο ΑΒΓ (ΑΒ = ΑΓ) και το ύψος του ΑΜ. Φέρουμε ημιευθεία Γx κάθετη στη ΒΓ, προς το ημιεπίπεδο που δεν ανήκει το Α, και παίρνουμε σε αυτήν τμήμα ΓΔ = ΑΒ.

Να αποδείξετε ότι:

\begin{alist}
\item η γωνία Δ$\widehat{Α}$Γ είναι ίση με τη γωνία Γ$\widehat{\Delta}$Α, \monades{12}

\item ΓΔ // ΑΜ, \monades{6}

\item η ΑΔ είναι διχοτόμος της γωνίας Μ$\widehat{Α}$Γ. \monades{7}

\begin{tikzpicture}[scale=1]
\tkzDefPoint(0,0){B}
\tkzDefPoint(4,0){C}

\tkzDefMidPoint(B,C) \tkzGetPoint{M}

\tkzDefPointBy[homothety=center C ratio 1](B) \tkzGetPoint{temp}

\draw[l3] (A)--(M);
