\lysh{34153}{2}

\begin{alist}
\item Οι αριθμοί $x + 6, 5x + 2, 11x - 6$ είναι διαδοχικοί όροι αριθμητικής προόδου αν
και μόνο αν:

\[\dfrac{x + 6 + 11x - 6}{2} = 5x + 2 \Leftrightarrow \dfrac{12x}{2} = 5x + 2 \Leftrightarrow 6x = 5x + 2 \Leftrightarrow x = 2.\]

Είναι:

\[\omega = 5x + 2 - (x + 6) = 5x + 2 - x - 6 = 4x - 4 = 4 \cdot 2 - 4 = 4.\]

\item Ισχύει ότι:

\[\alpha_8 = \alpha_1 + (8 - 1)\omega = 0 + 7 \cdot 4 = 28.\]

Τότε είναι:

\[S_8 = \dfrac{8}{2}(\alpha_1 + \alpha_8) = 4(0 + 28) = 4 \cdot 28 = 112.\]
\end{alist}
