\begin{alist}
\item
\begin{rlist}
\item Το τριώνυμο $x^2 + 9x + 18$ έχει $\alpha = 1, \beta = 9, \gamma = 18$ και διακρίνουσα:
\[\Delta = \beta^2 - 4\alpha\gamma = 9^2 - 4 \cdot 1 \cdot 18 = 81 - 72 = 9 > 0.\]
Οι ρίζες του τριωνύμου είναι οι:
\[x_{1,2} = \dfrac{-\beta \pm \sqrt{\Delta}}{2\alpha} = \dfrac{-9 \pm \sqrt{9}}{2 \cdot 1} = \dfrac{-9 \pm 3}{2} = \begin{cases} -3 \\ -6 \end{cases}.\]

\item Επειδή $|x + 3| \ge 0$ και $|x^2 + 9x + 18| \ge 0$, ισοδύναμα βρίσκουμε:
\begin{align*}
|x + 3| = 0 \text{ και } |x^2 + 9x + 18| = 0 \ &\Leftrightarrow \\
x + 3 = 0 \text{ και } x^2 + 9x + 18 = 0 \ &\Leftrightarrow \\
x &= -3 \text{ και } \{x = -3 \text{ ή } x = -6\}.
\end{align*}
Άρα, τελικά $x = -3$.
\end{rlist}

\begin{rlist}
\item Το πρόσημο του τριωνύμου φαίνεται στον παρακάτω πίνακα:

\[x^2 + 9x + 18 < 0 \Leftrightarrow x \in (-6, -3)\]
και
\[x^2 + 9x + 18 > 0 \Leftrightarrow x \in (-\infty, -6) \cup (-3, +\infty).\]

\item Η εξίσωση γράφεται:
$|x^2 + 9x + 18| = -(x^2 + 9x + 18)$,
που ισχύει αν και μόνο αν:
$x^2 + 9x + 18 \le 0$.
Άρα, από το ερώτημα $(\beta)$i. συμπεραίνουμε ότι $x \in [-6, -3]$.
