\lysh{36778}{2}

\begin{alist}
\item Ισχύει ότι:
\[K = \dfrac{\sqrt{x^2 + 4x + 4}}{x + 2} - \dfrac{\sqrt{x^2 - 6x + 9}}{x - 3} = \dfrac{\sqrt{(x + 2)^2}}{x + 2} - \dfrac{\sqrt{(x - 3)^2}}{x - 3} = \dfrac{|x + 2|}{x + 2} - \dfrac{|x - 3|}{x - 3}.\]

Η παράσταση $K$ έχει νόημα πραγματικού αριθμού αν και μόνο αν:
\[\begin{cases} x + 2 \ne 0 \\ x - 3 \ne 0 \end{cases} \Leftrightarrow \begin{cases} x \ne -2 \\ x \ne 3 \end{cases}\]

Οπότε πρέπει $x \ne -2, 3$.

\item Ισχύει ότι: $-2 < x < 3$, οπότε $x + 2 > 0$ και $x - 3 < 0$.
Άρα $|x + 2| = x + 2$ και $|x - 3| = -(x - 3)$.
Οπότε $K = \dfrac{x + 2}{x + 2} - \dfrac{-(x - 3)}{x - 3} = 1 - (-1) = 1 + 1 = 2$, που είναι ανεξάρτητη του $x$.
\end{alist}
