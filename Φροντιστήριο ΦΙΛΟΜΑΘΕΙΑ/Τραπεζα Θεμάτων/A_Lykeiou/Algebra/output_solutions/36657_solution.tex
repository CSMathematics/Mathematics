\lysh{36657}{4}

\begin{alist}
\item Οι τετμημένες των κοινών σημείων των $C_f, C_g$ είναι οι λύσεις της εξίσωσης $f(x) = g(x)$. Είναι:
$f(x) = g(x) \Leftrightarrow x^2 = \lambda x + 1 - \lambda \Leftrightarrow x^2 - \lambda x + \lambda - 1 = 0$ (1)
Η εξίσωση έχει διακρίνουσα
\[\Delta = \beta^2 - 4\alpha\gamma = (-\lambda)^2 - 4 \cdot 1 \cdot (\lambda - 1) = \lambda^2 - 4\lambda + 4 = (\lambda - 2)^2 \ge 0\]
για κάθε $\lambda \in \mathbb{R}$.
Επομένως η (1) έχει δυο πραγματικές ρίζες για κάθε τιμή της παραμέτρου $\lambda$, οπότε οι $C_f, C_g$ έχουν, για κάθε τιμή του $\lambda$, ένα τουλάχιστον κοινό σημείο.

\item Η (1) έχει μια διπλή ρίζα, δηλαδή οι $C_f, C_g$ έχουν ένα μόνο κοινό σημείο, αν και μόνο αν:
\[\Delta = 0 \Leftrightarrow (\lambda - 2)^2 = 0 \Leftrightarrow \lambda = 2.\]
Για $\lambda = 2$, η εξίσωση γίνεται:
$x^2 - 2x + 1 = 0$
η οποία έχει μοναδική λύση $x = 1$.
Τότε $f(1) = 1$, άρα το κοινό σημείο των δύο γραφικών παραστάσεων είναι το $(1, 1)$.

\item Από τους τύπους Vieta έχουμε:
\[S = x_1 + x_2 = -\dfrac{\beta}{\alpha} = \lambda\]
οπότε με $\lambda \ne 2$ είναι:
\[(x_1 + x_2)^2 = |x_1 + x_2| + 2 \Leftrightarrow \lambda^2 - |\lambda| - 2 = 0 \Leftrightarrow |\lambda|^2 - |\lambda| - 2 = 0.\]

Θέτουμε $|\lambda| = \kappa, \kappa > 0$ και η εξίσωση γράφεται
\[\kappa^2 - \kappa - 2 = 0 \Leftrightarrow \kappa = 2 \text{ ή } \kappa = -1 \text{ (απορρίπτεται)}.\]

Άρα, $|\lambda| = 2 \Leftrightarrow \lambda = -2 \text{ ή } \lambda = 2$, που απορρίπτεται, οπότε τελικά $\lambda = -2$.
\end{alist}
