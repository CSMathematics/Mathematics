\lysh{35415}{2}

\begin{alist}
\item Ισχύει ότι:
\[1 < x < 2 \Leftrightarrow (1 < x \text{ και } x < 2) \Leftrightarrow (0 < x - 1 \text{ και } x - 2 < 0)\]

Τότε:
$|x - 1| = x - 1$ και $|x - 2| = -(x - 2) = 2 - x$

Άρα:
\[A = |x - 1| - |x - 2| = x - 1 - (2 - x) = x - 1 - 2 + x = 2x - 3.\]

\item Για $x < 1$ είναι:
$|x - 1| = -(x - 1) = 1 - x$ και $|x - 2| = -(x - 2) = 2 - x$

Επομένως:
$A = |x - 1| - |x - 2| = 1 - x - (2 - x) = 1 - x - 2 + x = -1$, σταθερή.
\end{alist}
