\begin{alist}
\item Είναι:
\[A = x^3 - x^2 + 3x - 3 = x^2(x - 1) + 3(x - 1) = (x - 1)(x^2 + 3).\]

\item Η συνάρτηση $f$ έχει πεδίο ορισμού το σύνολο $A = \mathbb{R}^* = \mathbb{R} - \{0\}$ και η συνάρτηση $g$ το σύνολο $B = \mathbb{R}$.
Τα σημεία τομής τους προκύπτουν από τη λύση του συστήματος:
\[\begin{cases} y = f(x) \\ y = g(x) \end{cases}\]

Έχουμε:
\begin{align*}
f(x) = g(x) &\Leftrightarrow \dfrac{3}{x} = x^2 - x + 3 \Leftrightarrow 3 = x(x^2 - x + 3) \Leftrightarrow 3 = x^3 - x^2 + 3x \ \Leftrightarrow \\
x^3 - x^2 + 3x - 3 &= 0 \overset{(\alpha)}{\Leftrightarrow} \\
(x - 1)(x^2 + 3) = 0 \ &\Leftrightarrow \\
x - 1 &= 0 \text{ ή } x^2 + 3 = 0 \text{ (αδύνατη)} \Leftrightarrow x = 1.
\end{align*}

Για $x = 1$ είναι $f(1) = 3$.
Άρα το σημείο τομής των γραφικών παραστάσεων των συναρτήσεων $f, g$ είναι το $A(1, 3)$.
\end{alist}
