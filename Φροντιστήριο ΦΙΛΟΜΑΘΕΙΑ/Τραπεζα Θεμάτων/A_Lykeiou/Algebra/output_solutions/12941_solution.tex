\lysh{12941}{4}

\begin{alist}
\item Για να ορίζεται η συνάρτηση $f$ πρέπει και αρκεί να ισχύει: $3 - |x| \ne 0$
Επειδή ισχύει
\[3 - |x| = 0 \Leftrightarrow -|x| = -3 \Leftrightarrow |x| = 3 \Leftrightarrow x = \pm 3\]
για να ορίζεται η συνάρτηση $f$ πρέπει και αρκεί $x \ne \pm 3$.
Επομένως η συνάρτηση $f$ ορίζεται για $x \in (-\infty, -3) \cup (-3, 3) \cup (3, +\infty)$.

\item Για $x \in (-\infty, -3) \cup (-3, 3) \cup (3, +\infty)$ η συνάρτηση $f$ παίρνει τη μορφή
\[f(x) = \dfrac{9 - x^2}{3 - |x|} = \dfrac{3^2 - |x|^2}{3 - |x|} = \dfrac{(3 + |x|)(3 - |x|)}{3 - |x|} = 3 + |x|\]

\item Για να βρούμε το σημείο τομής της γραφικής παράστασης $C_f$ με τον άξονα $x'x$ λύνουμε την εξίσωση $f(x) = 0 \Leftrightarrow 3 + |x| = 0 \Leftrightarrow |x| = -3$ η οποία είναι αδύνατη. Άρα η γραφική παράσταση $C_f$ δεν τέμνει τον άξονα $x'x$.
Για να βρούμε το σημείο τομής της $C_f$ με τον άξονα $y'y$ πρέπει να βρούμε το $f(0)$.
Ισχύει $f(0) = 3 + |0| = 3$. Άρα το σημείο τομής της γραφικής παράστασης $C_f$ με τον άξονα $y'y$ είναι το $A(0,3)$.

\item Για να βρούμε τα κοινά σημεία των γραφικών παραστάσεων $C_f$ και $C_g$ λύνουμε την εξίσωση:
Η εξίσωση $g(x) = f(x)$ γίνεται
\begin{gather*}
-x^2 + 3 = 3 + |x|\text{ δηλαδή} \\
-|x|^2 + 3 - 3 - |x| = 0\text{ και τελικά} \\
|x|^2 + |x| = 0
\end{gather*}
Επειδή $|x^2| \ge 0$ και $|x| \ge 0$ ισχύει $|x|^2 + |x| = 0$ αν και μόνο αν $x=0$.
Άρα το κοινό σημείο των γραφικών παραστάσεων $C_f$ και $C_g$ είναι το $(0, 3)$.
\end{alist}
