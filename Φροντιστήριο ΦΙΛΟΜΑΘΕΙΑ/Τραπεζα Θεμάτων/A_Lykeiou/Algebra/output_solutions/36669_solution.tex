\item Είναι:
\[2 \le |x| \le 3 \Leftrightarrow (2 \le |x| \text{ (1) και } |x| \le 3 \text{ (2)})\]

Από την ανίσωση (1) βρίσκουμε:
\[2 \le |x| \Leftrightarrow x \ge 2 \text{ ή } x \le -2 \text{ (3)}\]

Από την ανίσωση (2) βρίσκουμε:
\[|x| \le 3 \Leftrightarrow -3 \le x \le 3 \text{ (4)}\]

Οι κοινές λύσεις των ανισώσεων (3) και (4) είναι: $x \in [-3, -2] \cup [2, 3] \text{ (5)}$

Το τριώνυμο $x^2 - 4x$ έχει ρίζες τις $0$ και $4$ αφού:
\[x^2 - 4x = 0 \Leftrightarrow x(x - 4) = 0 \Leftrightarrow x = 0 \text{ ή } x = 4\]

\item Οι κοινές λύσεις των ανισώσεων (5) και (6), με χρήση του άξονα των αριθμών, είναι: $x \in [2, 3]$.

\item Επειδή $\rho_1, \rho_2 \in [2, 3]$ ισχύει ότι:
\[2 \le \rho_1 \le 3 \text{ (7) και } 2 \le \rho_2 \le 3 \text{ (8)}\]

Προσθέτουμε κατά μέλη τις ανισώσεις (7) και (8) και βρίσκουμε:
\begin{align*}
2 + 2 \le \rho_1 + \rho_2 \le 3 + 3 \ &\Leftrightarrow \\
4 \le \rho_1 + \rho_2 \le 6 \ &\Leftrightarrow \\
\dfrac{4}{2} \le \dfrac{\rho_1 + \rho_2}{2} \le \dfrac{6}{2} \ &\Leftrightarrow \\
2 &\le \dfrac{\rho_1 + \rho_2}{2} \le 3
\end{align*}

Άρα $\dfrac{\rho_1 + \rho_2}{2} \in [2, 3]$, οπότε και ο αριθμός $\dfrac{\rho_1 + \rho_2}{2}$ είναι κοινή τους λύση.
\end{alist}
