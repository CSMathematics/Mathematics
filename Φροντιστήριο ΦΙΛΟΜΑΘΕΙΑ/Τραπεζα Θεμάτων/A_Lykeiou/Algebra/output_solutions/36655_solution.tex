\lysh{36655}{4}

\begin{alist}
\item H συνάρτηση ορίζεται μόνο όταν:
\[9 - x^2 > 0 \Leftrightarrow x^2 < 9 \Leftrightarrow |x| < 3 \Leftrightarrow -3 < x < 3\]
Άρα, $A_f = (-3, 3)$.

\item Η $C_f$ τέμνει τον άξονα $x'x$ μόνο όταν για κάποιο $x \in A_f$ ισχύει $f(x) = 0$. Είναι:
\[f(x) = 0 \Leftrightarrow \dfrac{x + 2}{\sqrt{9 - x^2}} = 0 \Leftrightarrow x + 2 = 0 \Leftrightarrow x = -2.\]
Επομένως η $C_f$ τέμνει τον άξονα $x'x$ στο σημείο $A(-2, 0)$.

Επίσης έχουμε:
\[f(0) = \dfrac{0 + 2}{\sqrt{9 - 0}} = \dfrac{2}{3}.\]
Άρα η $C_f$ τέμνει τον άξονα $y'y$ στο σημείο $B\left(0, \dfrac{2}{3}\right)$.

\item Έστω $(\varepsilon): y = \alpha x + \beta$ η εξίσωση της ζητούμενης ευθείας. Ο συντελεστής διεύθυνσης της ευθείας που διέρχεται από τα σημεία $A, B$ είναι:
\[\alpha = \dfrac{y_B - y_A}{x_B - x_A} = \dfrac{\dfrac{2}{3} - 0}{0 - (-2)} = \dfrac{\dfrac{2}{3}}{2} = \dfrac{2}{6} = \dfrac{1}{3}.\]

Άρα η εξίσωση της ευθείας γράφεται
$(\varepsilon): y = \dfrac{1}{3}x + \beta$.
Επιπλέον η ευθεία διέρχεται από το σημείο $A(-2, 0)$, οπότε οι συντεταγμένες του $A$ την επαληθεύουν. Έτσι, έχουμε:
\[0 = \dfrac{1}{3}(-2) + \beta \Leftrightarrow \beta - \dfrac{2}{3} = 0 \Leftrightarrow \beta = \dfrac{2}{3}.\]
Επομένως η εξίσωση της ευθείας είναι $(\varepsilon): y = \dfrac{1}{3}x + \dfrac{2}{3}$.
\end{alist}
