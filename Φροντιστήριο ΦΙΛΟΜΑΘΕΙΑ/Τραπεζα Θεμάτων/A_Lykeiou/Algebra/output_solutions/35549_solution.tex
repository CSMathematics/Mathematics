\begin{alist}
\item Η περίμετρος του $E \text{Z} B A \Gamma \Delta$ είναι:
\begin{gather*}
\Pi = AB + BZ + ZE + E\Delta + \Delta\Gamma + \Gamma A = \\
= x + 2y + x - y + y + y + y = 2x + 4y
\end{gather*}

\item Είναι:
$5 < x < 8 \Leftrightarrow 2 \cdot 5 < 2x < 2 \cdot 8 \Leftrightarrow 10 < 2x < 16$ (1)
$1 < y < 2 \Leftrightarrow 4 \cdot 1 < 4y < 4 \cdot 2 \Leftrightarrow 4 < 4y < 8$ (2)

Προσθέτουμε κατά μέλη τις ανισώσεις (1) και (2) και βρίσκουμε:
\[10 + 4 < 2x + 4y < 16 + 8 \Leftrightarrow 14 < \Pi < 24\]
\end{alist}
