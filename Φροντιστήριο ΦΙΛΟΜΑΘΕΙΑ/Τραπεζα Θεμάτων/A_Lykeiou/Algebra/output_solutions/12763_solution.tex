\lysh{12763}{2}

\begin{alist}
\item Για να αποτελούν οι $\alpha_1, \alpha_2, \alpha_3, \dots$ διαδοχικούς όρους αριθμητικής προόδου θα έπρεπε να έχουν την ιδιότητα $\alpha_2 = \dfrac{\alpha_1 + \alpha_3}{2}$.
Δηλαδή ισοδύναμα $2\sqrt{2} = \dfrac{2 + 4}{2} \Leftrightarrow 2\sqrt{2} = 3 \Leftrightarrow \sqrt{2} = \dfrac{3}{2}$, το οποίο δεν ισχύει, διότι ο $\sqrt{2}$ δεν είναι ρητός, ενώ ο $\dfrac{3}{2}$ είναι ρητός.

\item Για την πρόοδο $(\alpha_\nu)$ ισχύει ότι $\dfrac{\alpha_2}{\alpha_1} = \dfrac{2\sqrt{2}}{2} = \sqrt{2}$ και $\dfrac{\alpha_3}{\alpha_2} = \dfrac{4}{2\sqrt{2}} = \dfrac{2}{\sqrt{2}} = \dfrac{2\sqrt{2}}{2} = \sqrt{2}$, οπότε
αποτελεί γεωμετρική πρόοδο με λόγο $\lambda = \sqrt{2}$.

Εφόσον η $(\alpha_\nu)$ αποτελεί γεωμετρική πρόοδο, o $\nu$-οστός της όρος θα έχει τη μορφή
$\alpha_\nu = \alpha_1 \cdot \lambda^{\nu-1}$, όπου $\alpha_1, \lambda$, ο πρώτος όρος και ο λόγος της προόδου αντίστοιχα.
Επειδή $\alpha_1 = 2, \lambda = \sqrt{2}$ o $\nu$-οστός όρος είναι: $\alpha_\nu = 2 \cdot (\sqrt{2})^{\nu-1}$.
\end{alist}
