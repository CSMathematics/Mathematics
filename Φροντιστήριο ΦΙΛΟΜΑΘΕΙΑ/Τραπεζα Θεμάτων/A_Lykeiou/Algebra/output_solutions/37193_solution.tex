\lysh{37193}{2}

\begin{alist}
\item Πρέπει να ισχύει:
\[x - 4 \ge 0 \text{ και } x + 1 \ge 0 \Leftrightarrow x \ge 4 \text{ και } x \ge -1 \Leftrightarrow x \ge 4 \Leftrightarrow x \in [4, +\infty).\]

\item Είναι:
\[A = (\sqrt{x - 4} + \sqrt{x + 1}) \cdot (\sqrt{x - 4} - \sqrt{x + 1}) = (\sqrt{x - 4})^2 - (\sqrt{x + 1})^2 = x - 4 - (x + 1) = x - 4 - x - 1 = -5.\]

Επομένως πράγματι η παράσταση $A$ είναι σταθερή, ανεξάρτητη του $x$.
\end{alist}
