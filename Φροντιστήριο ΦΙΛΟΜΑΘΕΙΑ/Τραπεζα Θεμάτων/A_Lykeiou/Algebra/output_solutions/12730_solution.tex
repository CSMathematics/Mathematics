\lysh{12730}{2}

\begin{alist}
\item Αφού η ευθεία $y = \alpha x + \beta$ σχηματίζει με τον άξονα $x'x$ γωνία $45^\circ$, η κλίση της ευθείας θα είναι $\alpha = \varepsilon\phi 45^\circ = 1$. Άρα η ευθεία παίρνει τη μορφή $y = x + \beta$.
Αφού η ευθεία διέρχεται από το σημείο $A(0,3)$, θα ισχύει $3 = 0 + \beta \Leftrightarrow \beta = 3$.
Άρα η ευθεία είναι η $y = x + 3$.

\item Αφού οι ευθείες $y = x + 3$ και $y = \lambda x + \kappa$ είναι παράλληλες, θα έχουν την ίδια κλίση, άρα $\lambda = 1$. Οπότε η ευθεία παίρνει τη μορφή $y = x + \kappa$.
Αφού η ευθεία διέρχεται από το σημείο $B(2,0)$, θα ισχύει $0 = 2 + \kappa \Leftrightarrow \kappa = -2$.
Άρα η ζητούμενη ευθεία είναι η $y = x - 2$.
\end{alist}
