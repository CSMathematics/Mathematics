\item Είναι $x^2 < x \Leftrightarrow x^2 - x < 0$.
Το πολυώνυμο $x^2 - x$ έχει ρίζες τις $0$ και $1$ αφού:
\[x^2 - x = 0 \Leftrightarrow x(x - 1) = 0 \Leftrightarrow x = 0 \text{ ή } x = 1.\]

Το πρόσημο του $x^2 - x$ φαίνεται στον παρακάτω πίνακα.

\begin{rlist}
\item Αφού $0 < \alpha < 1$ με βάση το $\alpha)$ έχουμε ότι $\alpha^2 < \alpha$.
Επίσης $\alpha \ne 0$ οπότε $\alpha^2 > 0$.

Τέλος, αφού $0 < \alpha < 1$ είναι και $0 < \sqrt{\alpha} < 1$, οπότε με βάση το $\alpha)$ για $x = \sqrt{\alpha}$ έχουμε ότι
\[(\sqrt{\alpha})^2 < \sqrt{\alpha} \Rightarrow \alpha < \sqrt{\alpha}.\]
Συνεπώς $0 < \alpha^2 < \alpha < \sqrt{\alpha} < 1$.

\item Ισοδύναμα βρίσκουμε:
\begin{align*}
\sqrt{1 + \alpha} < 1 + \dfrac{\alpha}{2} \Leftrightarrow (\sqrt{1 + \alpha})^2 < \left(1 + \dfrac{\alpha}{2}\right)^2 \ &\Leftrightarrow \\
\Leftrightarrow 1 + \alpha < 1 + 2\dfrac{\alpha}{2} + \dfrac{\alpha^2}{4} \ &\Leftrightarrow \\
\Leftrightarrow 1 + \alpha &< 1 + \alpha + \dfrac{\alpha^2}{4} \Leftrightarrow 0 < \dfrac{\alpha^2}{4}
\end{align*}
που ισχύει για κάθε $\alpha > 0$.
\end{rlist}
