\lysh{13474}{4}

\begin{alist}
\item Είναι:
\[|x - 1| \le \sqrt{3} \Leftrightarrow -\sqrt{3} \le x - 1 \le \sqrt{3} \Leftrightarrow 1 - \sqrt{3} \le x \le 1 + \sqrt{3}.\]

\item Η μικρότερη λύση της $(1)$ είναι ο αριθμός $x_1 = 1 - \sqrt{3}$ και η μεγαλύτερη είναι $x_2 = 1 + \sqrt{3}$.
Για το άθροισμα $S$ και το γινόμενο $P$ των αριθμών αυτών ισχύει:
$S = x_1 + x_2 = (1 - \sqrt{3}) + (1 + \sqrt{3}) = 2$ και $P = x_1x_2 = (1 - \sqrt{3})(1 + \sqrt{3}) = 1^2 - (\sqrt{3})^2 = 1 - 3 = -2$.

Με τη βοήθεια του τύπου $x^2 - Sx + P = 0$ βρίσκουμε ότι η εξίσωση με ρίζες τη μικρότερη και
τη μεγαλύτερη λύση της $(1)$, είναι η $x^2 - 2x - 2 = 0$.

\item Για την ανίσωση $(2)$ έχουμε:
\[3 - \dfrac{x+4}{2} < 0 \Leftrightarrow 6 - (x + 4) < 0 \Leftrightarrow 6 - x - 4 < 0 \Leftrightarrow -x < -2 \Leftrightarrow x > 2.\]
Όπως φαίνεται στο επόμενο σχήμα, οι κοινές λύσεις των δυο ανισώσεων είναι όλοι οι αριθμοί $x$ με: $2 < x \le 1 + \sqrt{3}$.

\item Οι αριθμοί $\alpha, \beta$ που είναι κοινές λύσεις των $(1)$ και $(2)$ περιέχονται στο διάστημα $(2, 1 + \sqrt{3}]$.
Έτσι έχουμε: $2 < \alpha \le 1 + \sqrt{3}$, οπότε $6 < 3\alpha \le 3(1 + \sqrt{3})$, $(3)$.
Ανάλογα, $2 < \beta \le 1 + \sqrt{3}$, οπότε $8 < 4\beta \le 4(1 + \sqrt{3})$, $(4)$.
Με πρόσθεση των ανισοτήτων $(3), (4)$ παίρνουμε $14 < 3\alpha + 4\beta \le 7(1 + \sqrt{3})$ απ' όπου
συνεπάγεται ότι:
\[2 < \dfrac{3\alpha + 4\beta}{7} \le 1 + \sqrt{3}.\]
Από την τελευταία συμπεραίνουμε ότι ο αριθμός $\dfrac{3\alpha + 4\beta}{7}$ είναι επίσης κοινή λύση των $(1)$
και $(2)$, που είναι το ζητούμενο.
\end{alist}
