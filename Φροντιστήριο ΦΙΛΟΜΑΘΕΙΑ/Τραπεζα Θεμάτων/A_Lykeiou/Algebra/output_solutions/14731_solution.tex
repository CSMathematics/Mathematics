\item \textbf{ΛΑΘΟΣ}. Για $\alpha=9$ και $\beta=16$ έχουμε $\sqrt{9} + \sqrt{16} = 3 + 4 = 7$, ενώ $\sqrt{9 + 16} = \sqrt{25} = 5$. Άρα δεν ισχύει η ισότητα για οποιουσδήποτε μη αρνητικούς αριθμούς $\alpha,\beta$.
\item \textbf{ΣΩΣΤΟ}. Ισχύει ότι $|\alpha| = |-\alpha|$, για κάθε $\alpha$ πραγματικό αριθμό. Οπότε από την τριγωνική ανισότητα $|\alpha + \beta| \le |\alpha| + |\beta|$, προκύπτει το ζητούμενο, αφού $|\alpha-\beta|=|\alpha + (-\beta)| \le |\alpha| + |-\beta| = |\alpha| + |\beta|$. 
\item \textbf{ΣΩΣΤΟ}. Η κλίση μίας ευθείας είναι ίση με την εφαπτομένη της γωνίας που σχηματίζει η ευθεία με τον άξονα $x'x$. Οι οξείες γωνίες έχουν θετική εφαπτομένη, ενώ οι αμβλείες έχουν αρνητική εφαπτομένη.
\item \textbf{ΛΑΘΟΣ}. Για $x=-2$ η εξίσωση $x^2 - x - 6 = 0$ επαληθεύεται ($4 - (-2) - 6 = 0$).
\item \textbf{ΛΑΘΟΣ}. Αν $\alpha=-1, \beta=-2$, δηλαδή $\alpha < 1 \text{ και } \beta < 1$, τότε $\alpha\beta=2>1$.
\end{alist}
