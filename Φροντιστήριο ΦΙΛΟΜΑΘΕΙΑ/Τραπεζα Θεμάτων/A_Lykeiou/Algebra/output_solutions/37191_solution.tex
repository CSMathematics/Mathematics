\begin{alist}
\item 
\begin{rlist}
\item Είναι:
\begin{align*}
|1 - 2x| < 5 &\Leftrightarrow -5 < 1 - 2x < 5 \Leftrightarrow -5 - 1 < 1 - 2x - 1 < 5 - 1 \ \Leftrightarrow \\
&\Leftrightarrow -6 < -2x < 4 \Leftrightarrow \dfrac{-6}{-2} > \dfrac{-2x}{-2} > \dfrac{4}{-2} \Leftrightarrow 3 > x > -2 \Leftrightarrow -2 < x < 3.
\end{align*}

\item Ισχύει ότι:
\begin{align*}
|1 - 2x| \ge 1 &\Leftrightarrow 1 - 2x \le -1 \text{ ή } 1 - 2x \ge 1 \Leftrightarrow -2x \le -2 \text{ ή } -2x \ge 0 \ \Leftrightarrow \\
&\Leftrightarrow \dfrac{-2x}{-2} \ge \dfrac{-2}{-2} \text{ ή } \dfrac{-2x}{-2} \le \dfrac{0}{-2} \Leftrightarrow x \ge 1 \text{ ή } x \le 0.
\end{align*}

Οι λύσεις των παραπάνω ανισώσεων παριστάνονται στον άξονα των πραγματικών αριθμών με το παρακάτω σχήμα:
\end{rlist}

\item Από τις λύσεις των δύο ανισώσεων και από τον παραπάνω άξονα προκύπτει ότι οι κοινές τους λύσεις είναι:
\[-2 < x \le 0 \text{ ή } 1 \le x < 3 \Leftrightarrow x \in (-2, 0] \cup [1, 3).\]

Επομένως οι ακέραιες αντίστοιχα κοινές λύσεις είναι: $x = -1, x = 0, x = 1, x = 2$.
\end{alist}
