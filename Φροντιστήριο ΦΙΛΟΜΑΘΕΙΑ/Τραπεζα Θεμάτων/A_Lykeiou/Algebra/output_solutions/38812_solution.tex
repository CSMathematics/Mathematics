\lysh{38812}{4}

\begin{alist}
\item Έχουμε $\pi\rho^2 = 1,5$ ή $\rho^2 = \dfrac{1,5}{\pi}$ ή $\rho^2 = \dfrac{\dfrac{3}{2}}{\pi}$ ή $\rho^2 = \dfrac{3}{2\pi}$.
Άρα $\rho = \sqrt{\dfrac{3}{2\pi}}$.

\item Η ακτίνα είναι $\rho = \sqrt{\dfrac{3}{2\pi}}$.
Είναι $\pi > 3$ άρα $2\pi > 6$ ή $\dfrac{3}{2\pi} < \dfrac{3}{6}$ ή $\dfrac{3}{2\pi} < \dfrac{1}{2}$ ή $\dfrac{3}{2\pi} < 0,5$ ή $\sqrt{\dfrac{3}{2\pi}} < \sqrt{0,5}$.
Άρα $\rho < \sqrt{0,5}$.
Όμως $\sqrt{0,5} < 0,75$ αφού $0,5 < 0,5625 = 0,75^2$.
Άρα $\rho < 0,75$.

\textit{Άλλος τρόπος:}
Επειδή $0,75 = \dfrac{3}{4}$, η ζητούμενη ανισότητα $\rho < 0,75$ γράφεται ισοδύναμα:
$\sqrt{\dfrac{3}{2\pi}} < \dfrac{3}{4}$ ή $\dfrac{3}{2\pi} < \dfrac{9}{16}$ ή $48 < 18\pi$ ή $8 < 3\pi$, γιατί τα μέλη της ανίσωσης είναι θετικά.
Που είναι αληθές, γιατί $3\pi \simeq 3 \cdot 3,14 > 9 > 8$.

\item Για να είναι κατάλληλο το τετράγωνο, χρειάζεται η πλευρά του να είναι μεγαλύτερη από ή ίση με τη διάμετρο της επιφάνειας του τραπεζιού.
Η πλευρά του τετραγώνου είναι ίση με $\sqrt{2,5}$.
Επειδή η $\sqrt{2,5}$ είναι άρρητος αριθμός θα βρούμε έναν «βολικό» ρητό που είναι «κοντινός» της αλλά μικρότερος από αυτή. Σκεφτόμαστε ότι η $\sqrt{2,25} = 1,5$, δηλαδή είναι ρητός:
Εφόσον $2,5 > 2,25$ ισχύει ότι $\sqrt{2,5} > \sqrt{2,25}$ ή $\sqrt{2,5} > 1,5$.

Η διάμετρος της επιφάνειας του τραπεζιού είναι $2\rho$.
Όμως $\rho < 0,75$ ή $2\rho < 1,5$.

Επομένως $2\rho < \sqrt{2,5}$.
Άρα το τετράγωνο επαρκεί για την κατασκευή της επιφάνειας του τραπεζιού.

\textit{Άλλος τρόπος:}
Αρκεί να αποδείξουμε ότι $2\rho < \sqrt{2,5}$ ή $\rho < \dfrac{\sqrt{2,5}}{2}$ ή $\rho^2 < \dfrac{2,5}{4}$ ή $\rho^2 < \dfrac{5}{8}$.
Η σχέση αυτή της ακτίνας δίνει $\dfrac{3}{2\pi} < \dfrac{5}{8}$ ή $24 < 10\pi$, που είναι αληθές, γιατί $10\pi \simeq 10 \cdot 3,14 = 31,4 > 24$.
\end{alist}
