\lysh{14306}{2}

\begin{alist}
\item Είναι: $|y - 3| < 1 \Leftrightarrow -1 < y - 3 < 1 \Leftrightarrow 2 < y < 4$.

\item Το εμβαδόν ενός ορθογωνίου με διαστάσεις $x, y$ είναι: $E = xy$.
Έχουμε:
$\begin{cases} 1 < x < 3 \\ 2 < y < 4 \end{cases} \Rightarrow 2 < xy < 12$. Άρα $2 < E < 12$.
\end{alist}
