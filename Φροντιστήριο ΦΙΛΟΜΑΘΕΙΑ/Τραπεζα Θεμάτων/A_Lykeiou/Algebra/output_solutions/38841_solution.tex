\lysh{38841}{4}

\begin{alist}
\item Για να βρούμε πόσα ολόκληρα τετραγωνάκια χωράνε οριζόντια στη σελίδα του τετραδίου, κάνουμε τον υπολογισμό $210 : 8 = 26,25$.
Άρα σε κάθε γραμμή της σελίδας χωράνε $26$ ολόκληρα τετραγωνάκια.

\item
\begin{rlist}
\item Εφόσον χωράνε $37$ ολόκληρα τετράγωνα και όχι $38$ σε κάθε στήλη και η στήλη έχει μήκος $297\text{mm}$, το συνολικό μήκος μιας στήλης $38$ τετραγώνων πρέπει να είναι μεγαλύτερο από $297$, άρα $38x > 297$.
\item Εφόσον χωράνε $37$ ολόκληρα τετράγωνα σε κάθε στήλη και η στήλη έχει μήκος $297$, το συνολικό μήκος μιας στήλης τετραγώνων είναι το πολύ ίσο με $297$, άρα ισχύει ότι:
$37x \le 297$ ή $x \le \dfrac{297}{37}$.
Επομένως, η πλευρά του κάθε τετραγώνου έχει μήκος το πολύ ίσο με $\dfrac{297}{37}\text{ mm}$.
\item Γράφοντας τις δύο ανισώσεις σε μία έχουμε:
$\dfrac{297}{38} < x \le \dfrac{297}{37}$.
\end{rlist}

\item Σκεφτόμαστε όπως στην απάντηση του ερωτήματος $\beta$.
Εφόσον η κάθε γραμμή του τετραδίου έχει $23$ ολόκληρα τετραγωνάκια, τότε:
$\dfrac{210}{24} < x \le \dfrac{210}{23}$.

Εφόσον η κάθε στήλη του τετραδίου έχει $33$ ολόκληρα τετραγωνάκια, τότε:
$\dfrac{297}{34} < x \le \dfrac{297}{33}$.

Κάνοντας τις διαιρέσεις και χρησιμοποιώντας τα πηλίκα που δίνονται έχουμε:
$\dfrac{210}{24} = 8,75$, $\dfrac{210}{23} \simeq 9,23$, $\dfrac{297}{34} \simeq 8,74$, $\dfrac{297}{33} = 9$.

Άρα:
\[\dfrac{297}{34} < \dfrac{210}{24} < \dfrac{297}{33} < \dfrac{210}{23}.\]

Επομένως, συναληθεύοντας τις παραπάνω ανισώσεις έχουμε:
$\dfrac{210}{24} < x \le \dfrac{297}{33}$.
Επομένως, η πλευρά κάθε τετραγώνου έχει μήκος μεγαλύτερο από $\dfrac{210}{24} = 8,75\text{mm}$ και το πολύ ίσο με $\dfrac{297}{33} = 9\text{mm}$.
\end{alist}
