\lysh{35041}{2}

\begin{alist}
\item Είναι:
$d(2x, 3) = |2x - 3|$.

Γνωρίζουμε ότι:
$|2x - 3| \ge 0$.

Τότε από τη σχέση της υπόθεσης $|2x - 3| = 3 - 2x$ ισοδύναμα βρίσκουμε:
\[3 - 2x \ge 0 \Leftrightarrow 2x \le 3 \Leftrightarrow x \le \dfrac{3}{2}.\]

\item Επειδή ισχύει $x \le \dfrac{3}{2}$ είναι $2x \le 3$ και προφανώς $x < 3$. Τότε:
\begin{gather*}
2x - 3 \le 0 \Rightarrow |2x - 3| = 3 - 2x\text{, και} \\
3 - x > 0 \Rightarrow |3 - x| = 3 - x.
\end{gather*}

Επομένως η παράσταση γράφεται:
\[K = |2x - 3| - 2|3 - x| = 3 - 2x - 2(3 - x) = 3 - 2x - 6 + 2x = -3.\]
Άρα η παράσταση είναι ανεξάρτητη του $x$.
\end{alist}
