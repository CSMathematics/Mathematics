\item Είναι $A = |2x + 2| + |x - 5| = 2|x + 1| + |x - 5|$.
Επειδή $x \in (-1, 4)$ τότε $x > -1$ και $x + 1 > 0$. Άρα $|x + 1| = x + 1$.
Επειδή $x \in (-1, 4)$ τότε $x < 4 < 5$ και $x - 5 < 0$. Άρα $|x - 5| = 5 - x$.
Επομένως η παράσταση $A = 2(x + 1) + 5 - x = 2x + 2 + 5 - x = x + 7$.
