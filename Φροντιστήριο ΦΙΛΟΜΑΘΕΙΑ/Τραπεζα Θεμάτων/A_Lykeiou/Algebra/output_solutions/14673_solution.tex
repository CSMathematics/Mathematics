\begin{alist}
\item Οι γραφικές παραστάσεις των συναρτήσεων $f$ και $g$ τέμνονται στα σημεία $A$ και $B$, άρα οι
τετμημένες των σημείων $A$ και $B$ θα είναι οι λύσεις της εξίσωσης $f(x) = g(x)$ δηλαδή της
εξίσωσης $x^2 - 2 = x \Leftrightarrow x^2 - x - 2 = 0$, η διακρίνουσα της οποίας είναι
$\Delta = (-1)^2 - 4 \cdot 1 \cdot (-2) = 9$, άρα $x = \dfrac{-(-1) \pm \sqrt{9}}{2 \cdot 1} = \dfrac{1 \pm 3}{2}$. Ώστε $x = 2 \text{ ή } x = -1$.

Τότε $f(2) = g(2) = 2$ και $f(-1) = g(-1) = -1$.

\item Για το τριώνυμο $x^2 - x - 2$ έχουμε βρει ότι οι ρίζες του είναι οι αριθμοί
$x = 2 \text{ ή } x = -1$.
Στον παρακάτω πίνακα φαίνεται το πρόσημο του παραπάνω τριωνύμου.

Άρα οι λύσεις της δοθείσας ανίσωσης είναι $-1 < x < 2$.

\item Έχουμε $\omega^2 - |\omega| - 2 < 0 \Leftrightarrow |\omega|^2 - |\omega| - 2 < 0$ η οποία γράφεται στη μορφή
$x^2 - x - 2 < 0$, αν θέσουμε $|\omega| = x$.
Με βάση το $\beta)$ ερώτημα παίρνουμε $-1 < |\omega| < 2$.
Αλλά η σχέση $-1 < |\omega|$ ισχύει για κάθε πραγματικό αριθμό $\omega$.
Έτσι, πρέπει να ισχύει $|\omega| < 2$, η οποία γράφεται $-2 < \omega < 2$.
Ώστε οι λύσεις της ανίσωσης $\omega^2 - |\omega| - 2 < 0$ είναι οι αριθμοί $\omega \in (-2, 2)$.
\end{alist}
