\lysh{14629}{4}

\begin{alist}
\item Αν το πλήθος των σωστών απαντήσεων είναι $x$, τότε το πλήθος των λανθασμένων 
απαντήσεων είναι $100 - x$. Σύμφωνα με τα δεδομένα του προβλήματος, ο φοιτητής θα πάρει
$x$ βαθμούς για τις σωστές απαντήσεις και θα του αφαιρεθούν (αρνητική βαθμολογία)
$\dfrac{1}{3}(100 - x)$ βαθμοί για τις λανθασμένες απαντήσεις. Έτσι, η τελική βαθμολογία του θα είναι
\[E(x) = x - \dfrac{1}{3}(100 - x) = \dfrac{3x - (100 - x)}{3} = \dfrac{4x - 100}{3} = \dfrac{4}{3}(x - 25)\]
όπου $x$ είναι το πλήθος των σωστών απαντήσεων.

\item Είναι:
\[E(x) = 88 \Leftrightarrow \dfrac{4}{3}(x - 25) = 88 \Leftrightarrow x - 25 = 66 \Leftrightarrow x = 91\]
Άρα ο φοιτητής που βαθμολογήθηκε με $88$, απάντησε σωστά σε $91$ ερωτήσεις και
λανθασμένα σε $9$ ερωτήσεις.

\item Έστω ότι η βαθμολογία ενός φοιτητή που απάντησε σωστά σε $x$ ερωτήσεις είναι ίση με $50$.
Τότε έχουμε:
\[E(x) = 50 \Leftrightarrow \dfrac{4}{3}(x - 25) = 50 \Leftrightarrow 4x - 100 = 150 \Leftrightarrow 4x = 250 \Leftrightarrow x = \dfrac{125}{2}\]
που είναι άτοπο, αφού ο αριθμός $x$ που παριστάνει το πλήθος των σωστών απαντήσεων,
είναι ακέραιος. Επομένως η βαθμολογία ενός φοιτητή δεν μπορεί να είναι ίση με $50$.
Ένας φοιτητής θα πάρει βαθμολογία μεγαλύτερη από τη βάση, μόνο όταν $E(x) > 50$. Είναι:
\[E(x) > 50 \Leftrightarrow \dfrac{4}{3}(x - 25) > 50 \Leftrightarrow 4x - 100 > 150 \Leftrightarrow 4x > 250 \Leftrightarrow x > \dfrac{125}{2} = 62.5\]
Επομένως η βαθμολογία ενός φοιτητή είναι μεγαλύτερη του $50$ μόνο όταν απαντήσει σωστά
σε $63$ τουλάχιστον ερωτήσεις.

\item Έστω ότι το πλήθος των σωστών απαντήσεων των φοιτητών είναι $x_1$, $x_2$ αντίστοιχα. Τότε
έχουμε:
\[E(x_1) + E(x_2) = 140 \Leftrightarrow \dfrac{4}{3}(x_1 - 25) + \dfrac{4}{3}(x_2 - 25) = 140 \Leftrightarrow 4x_1 - 100 + 4x_2 - 100 = 420 \Leftrightarrow 4(x_1 + x_2) = 620 \Leftrightarrow x_1 + x_2 = 155\]
Επομένως οι δυο φοιτητές απάντησαν σωστά σε $155$ από τις $200$ ερωτήσεις τους και
λανθασμένα στις υπόλοιπες $200 - 155 = 45$ ερωτήσεις.
\end{alist}
