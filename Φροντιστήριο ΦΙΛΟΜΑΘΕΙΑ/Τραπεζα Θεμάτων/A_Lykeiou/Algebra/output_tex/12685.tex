\begin{ylh}{2}
    \item 2.1. Οι Πράξεις και οι Ιδιότητές τους
\end{ylh}
Αν για τους πραγματικούς αριθμούς $a,\beta \neq 0,$ ισχύει ότι:
\[(a + \beta)\left( \dfrac{1}{a} + \dfrac{1}{\beta} \right) = 4,\] τότε να αποδείξετε ότι:
\begin{alist}
\item $\dfrac{a}{\beta} + \dfrac{\beta}{a} = 2.$
\monades{12}
\item $a = \beta.$
\monades{13}
\end{alist}
