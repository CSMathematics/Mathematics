Στο παρακάτω σχήμα δίνεται η γραφική παράσταση της συνάρτησης $f(x) = x^{2} + 2\lambda x + \gamma$ με $x\mathbb{\in R}$ και παράμετρο $\lambda\mathbb{\in R}$, η οποία τέμνει τον άξονα $y'y$ στο $(0, - 1)$ για κάθε $\lambda\mathbb{\in R}$.

\begin{alist}
\item Να αποδείξετε ότι:
\begin{rlist}
\item $\gamma = - 1$. \monades{5}
\item
  η γραφική παράσταση της $f$ δεν είναι κάτω από την ευθεία $y = - \lambda^{2} - 1$ για κάθε $\lambda\mathbb{\in R}$. \monades{7}
\end{rlist}
\item Να αποδείξετε ότι για κάθε $\lambda\mathbb{\in R}$ η γραφική παράσταση της $f$ τέμνει τον άξονα $x'x$ σε δύο σημεία $A$ και $B$ με συντεταγμένες $A\left( - \lambda - \sqrt{\lambda^{2} + 1},0 \right)$ και $B\left( - \lambda + \sqrt{\lambda^{2} + 1},0 \right)\ $.
\monades{7}
\item Να αποδείξετε ότι η απόσταση των $A$ και $B$ είναι μεγαλύτερη ή ίση του 2 για κάθε $\lambda\mathbb{\in R}$.
\monades{6}
\end{alist}
