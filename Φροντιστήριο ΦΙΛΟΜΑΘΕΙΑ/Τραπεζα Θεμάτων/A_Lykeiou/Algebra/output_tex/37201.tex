\begin{ylh}{2}
    \item 2.2. Διάταξη Πραγματικών Αριθμών
    \item 2.3. Απόλυτη Τιμή Πραγματικού Αριθμού
\end{ylh}
Δίνεται η παράσταση $A = |x - 1| + |y - 3|$ με x, y πραγματικούς αριθμούς για τους οποίους ισχύει: $1 < x < 4$ και $2 < y < 3$. Να αποδείξετε ότι:
\begin{multicols}{2}
\begin{alist}
\item $A = x - y + 2$.
\monades{12}
\item $0 < A < 4$.
\monades{13}
\end{alist}
\end{multicols}
