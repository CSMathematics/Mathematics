Το άθροισμα των $\nu$ πρώτων διαδοχικών όρων μιας ακολουθίας $(a_{\nu})$ είναι $a_{1} + a_{2} + \ldots + a_{\nu} = S_{\nu}\  = \ 2v^{2}\  + \ 3\nu$ , $\nu \in N$ με $\nu \geq 1$.
\begin{alist}
\item Να βρείτε τον πρώτο όρο $a_{1}$.
\monades{5}
\item Να αποδείξετε ότι $S_{\nu - 1}\  = \ 2\nu^{2} - \nu - 1$, $\nu \geq 2$
\monades{6}
\item Να αποδείξετε ότι $a_{\nu} = 4\nu + 1$, $\nu \geq 1$
\monades{7}
\item Να αποδείξετε ότι αυτή η ακολουθία είναι αριθμητική πρόοδος, της οποίας να βρείτε τη διαφορά $\omega$.

\monades{7}
\end{alist}
