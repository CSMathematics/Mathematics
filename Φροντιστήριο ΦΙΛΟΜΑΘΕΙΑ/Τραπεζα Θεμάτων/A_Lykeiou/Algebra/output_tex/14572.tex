    \item 2.2. Διάταξη Πραγματικών Αριθμών
    \item 2.3. Απόλυτη Τιμή Πραγματικού Αριθμού
\end{ylh}
Δίνεται πραγματικός αριθμός $x$, για τον οποίο ισχύει: $|x+2| < 1$. Να δείξετε ότι:
\begin{alist}
\item $-3 < x < -1$.\monades{10}
\item $|2x+4| < 2$.\monades{15}
\end{alist}
