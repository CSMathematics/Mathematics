ΛΥΣΗ
\begin{alist}
    \item [α)] Για τη συνάρτηση $f$ είναι $9 - x^2 \ge 0 \Leftrightarrow -3 \le x \le 3$, οπότε $D_f = [-3,3]$.
    Για τη συνάρτηση $g$ είναι $4 - x^2 \ge 0$ και $x \ne 0 \Leftrightarrow -2 \le x \le 2$ και $x \ne 0$, οπότε $D_g = [-2,0) \cup (0,2]$.
    \item [β)]
    \begin{rlist}
        \item Γνωρίζουμε ότι το γινόμενο δύο συναρτήσεων ορίζεται στην τομή των πεδίων ορισμού τους, οπότε: $D_f \cap D_g = [-3,3] \cap ([-2,0) \cup (0,2]) = [-2,0) \cup (0,2]$.
        Για $x \in [-2,0) \cup (0,2]$ είναι:
        \[ f(x) \cdot g(x) = \sqrt{9-x^2} \cdot \frac{\sqrt{4-x^2}}{x} = \frac{\sqrt{9-x^2} \cdot \sqrt{4-x^2}}{x}. \]
        \item Γνωρίζουμε ότι το πηλίκο δύο συναρτήσεων $\frac{f}{g}$ ορίζεται στην τομή των πεδίων ορισμού τους, εξαιρουμένων των τιμών του $x$ που μηδενίζουν τον παρονομαστή $g(x)$. Λόγω του ερωτήματος (β, i) το $D_f \cap D_g = [-2,0) \cup (0,2]$ και $g(x) = 0 \Leftrightarrow \frac{\sqrt{4-x^2}}{x} = 0 \Leftrightarrow 4-x^2 = 0 \Leftrightarrow x=-2 \text{ ή } x=2$.
        Επομένως η συνάρτηση $\frac{f}{g}$ ορίζεται στο $(-2,0) \cup (0,2)$.
        Για $x \in (-2,0) \cup (0,2)$ είναι:
        \[ \frac{f(x)}{g(x)} = \frac{\sqrt{9-x^2}}{\frac{\sqrt{4-x^2}}{x}} = \frac{x\sqrt{9-x^2}}{\sqrt{4-x^2}}. \]
    \end{rlist}
\end{alist}
