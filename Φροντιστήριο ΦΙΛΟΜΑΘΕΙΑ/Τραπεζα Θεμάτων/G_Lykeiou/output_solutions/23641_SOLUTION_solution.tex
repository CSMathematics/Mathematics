ΛΥΣΗ
\begin{alist}
\item α) Επειδή η συνάρτηση $f$ είναι γνησίως αύξουσα, έχουμε:
\[ f(x^2) < f(x) \overset{f \uparrow}{\iff} x^2 < x \iff x^2 - x < 0 \iff 0 < x < 1. \]
\item β) Είναι $a^2 < a \Rightarrow a^2 - a < 0 \overset{f \uparrow}{\Rightarrow} f(a^2 - a) < f(0) \Rightarrow f(a^2 - a) - f(0) < 0$.

Επιπλέον ισχύει ότι
\[ \lim_{x \to +\infty} x = +\infty \]
Επομένως, είναι:
\[ \lim_{x \to +\infty} ([f(a^2 - a) - f(0)] x) = -\infty \]
\item γ) Αφού η συνάρτηση $f$ είναι γνησίως αύξουσα, τότε είναι και ``1-1''. Επομένως, έχουμε
\[ f(e^x - 1) = f(0) \iff e^x - 1 = 0 \iff e^x = 1 \iff x = 0. \]
\end{alist}
