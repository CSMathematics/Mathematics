ΛΥΣΗ
\begin{alist}
\item Η κλίση της συνάρτησης $f$ στο $x_o = 2$ ισούται με $f'(2)$. Από τη γραφική παράσταση της συνάρτησης $f'$ παρατηρούμε ότι $f'(2) = 1$.
\item Η γραφική παράσταση της συνάρτησης $f'$ βρίσκεται πάνω από τον άξονα $x'x$ για $x \in [0,3]$. Έτσι έχουμε:
\[ f'(x) > 0 \Leftrightarrow x \in [0,3] \]
Συνεπώς, η συνάρτηση $f$ είναι γνησίως αύξουσα στο διάστημα $[0,3]$, αφού είναι συνεχής σε αυτό ως πολυωνυμική.
\item Η συνάρτηση $f$ είναι γνησίως αύξουσα στο διάστημα $[0,3]$. Αφού $1 < 2$, τότε $f(1) < f(2)$.
\item Είναι:
\[ \int_{0}^{3} f''(x)dx = [f'(x)]_{0}^{3} = f'(3) - f'(0) = 0 - 2 = -2 \]
\end{alist}
