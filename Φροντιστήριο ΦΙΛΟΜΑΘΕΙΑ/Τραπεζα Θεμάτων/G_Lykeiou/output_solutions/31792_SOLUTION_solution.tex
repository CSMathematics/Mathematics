Παρατηρούμε ότι $\lim_{x \to 1} f(x) = \lim_{x \to 1} (-x^2+x+1) = 1$, ενώ
\[ \lim_{x \to 1} f(x) = 1 + \lim_{x \to 1} \frac{(\ln x)^2}{x-1} = 1+0=1. \]
Οπότε $\lim_{x \to 1} f(x) = f(1) = 1$, άρα $f$ συνεχής στο $1$.
\[ \lim_{x \to 1^-} \frac{f(x)-f(1)}{x-1} = \lim_{x \to 1^-} \frac{-x^2+x+1-1}{x-1} = \lim_{x \to 1^-} \frac{-x(x-1)}{x-1} = \lim_{x \to 1^-} (-x) = -1, \text{ ενώ} \]
\[ \lim_{x \to 1^+} \frac{f(x)-f(1)}{x-1} = \lim_{x \to 1^+} \frac{\frac{(\ln x)^2}{x-1}}{x-1} = \lim_{x \to 1^+} \frac{(\ln x)^2}{(x-1)^2} \text{ (απροσδ. } \frac{0}{0}\text{)}. \]
Ελέγχουμε αν υπάρχει το $\lim_{x \to 1^+} \frac{(\ln x)^2}{(x-1)^2} = \lim_{x \to 1^+} \frac{2\ln x \cdot \frac{1}{x}}{2(x-1)} = \lim_{x \to 1^+} \frac{2\ln x}{2x(x-1)} = 0$.
\[ \text{Άρα } \lim_{x \to 1^+} \frac{f(x)-f(1)}{x-1} = 0. \]
Οπότε η $f$ δεν είναι παραγωγίσιμη στο $1$.

β) Από α) ερώτημα, προκύπτει ότι ένα κρίσιμο σημείο είναι το $x_0 = 1$.
Εξετάζουμε αν υπάρχουν εσωτερικά σημεία του διαστήματος $[1, +\infty)$ στα οποία η παράγωγος μηδενίζεται.
\[ f'(x) = \begin{cases} -2x+1, & -1 \leq x < 1 \\ \frac{\ln(2-\ln x)}{x^2}, & x > 1 \end{cases} \]
\[ \text{διότι } \left[\frac{(\ln x)^2}{x}\right]' = \frac{(\ln x)^2 x' - (\ln x)^2 x}{x^2} = \frac{2\ln x \cdot \frac{1}{x} \cdot x - (\ln x)^2}{x^2} = \frac{2\ln x - (\ln x)^2}{x^2} \text{ και} \]
\[ -2x+1 = 0 \Leftrightarrow x = \frac{1}{2}. \]
Παρατηρούμε ότι για $-1 < x < 1$, έχουμε $f'(x) = 0 \Leftrightarrow -2x+1 = 0 \Leftrightarrow x = \frac{1}{2}$ δεκτό, ενώ
για $x > 1$, έχουμε $\ln x > 0$, άρα $f'(x) = 0 \Leftrightarrow 2-\ln x = 0 \Leftrightarrow x = e^2 > 1$, δεκτό.
Οπότε υπάρχουν τρία κρίσιμα σημεία, τα $x_1 = \frac{1}{2}$, $x_0 = 1$ και $x_2 = e^2$.

γ) Παρατηρούμε ότι για $x \in [1, e]$, έχουμε:
\[ x \geq 1 \Rightarrow -x \leq -1. \text{ Άρα } e^{-x} \leq e^{-1} = \frac{1}{e} \leq 1 + \frac{(\ln x)^2}{x}. \]
\[ \text{Ώστε } e^{-x} < 1 + \frac{(\ln x)^2}{x} = f(x), \text{ για κάθε } x \in [1, e]. \]
Οπότε το ζητούμενο εμβαδόν είναι:
\[ E = \int_1^e \left[ \left(1+\frac{(\ln x)^2}{x}\right) - e^{-x} \right] dx = \int_1^e 1 dx + \int_1^e \frac{(\ln x)^2}{x} dx - \int_1^e e^{-x} dx \]
\[ E = [x]_1^e + \left(e - \frac{e^{-e} + e^{-1}}{3} \right) = e-1 + \frac{1}{e} - \frac{e^{-e}+e^{-1}}{3}, \text{ διότι για τον υπολογισμό του} \]
\[ I_1 = \int_1^e \frac{(\ln x)^2}{x} dx, \text{ θέτουμε } u = \ln x, \text{ άρα } du = (\ln x)' dx = \frac{1}{x} dx, \text{ οπότε } I_1 = \int_{\ln 1}^{\ln e} u^2 du = \int_0^1 u^2 du = \left[\frac{u^3}{3}\right]_0^1 = \frac{1}{3}, \text{ ενώ } \int_1^e e^{-x} dx = [-e^{-x}]_1^e = -e^{-e}+e^{-1}. \]
