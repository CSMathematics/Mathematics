ΛΥΣΗ
\begin{alist}
\item Όταν $x \in [0,1)$, η $f(x)=(1-x)\sin^2\PARENS{\frac{1}{1-x}}$ είναι συνεχής ως πράξεις συνεχών.
Ακόμη, είναι $0 \le \sin^2\PARENS{\frac{1}{1-x}} \le 1 \Rightarrow 0 \le (1-x)\sin^2\PARENS{\frac{1}{1-x}} \le 1-x$ κοντά στο $x_0=1$.
Από αριστερά και $\lim_{x\to 1^-} 0 = \lim_{x\to 1^-} (1-x) = 0$. Από την εφαρμογή του κριτηρίου παρεμβολής έχουμε ότι:
\[ \lim_{x\to 1^-} \PARENS{ (1-x)\sin^2\PARENS{\frac{1}{1-x}} } = 0 \Rightarrow \lim_{x\to 1^-} f(x)=0 \Rightarrow \lim_{x\to 1^-} f(x) = f(1). \]
Συνεπώς η συνάρτηση $f$ είναι συνεχής. \monades{1}

\item Για κάθε $x \in [0,1]$, ισχύει:
\[ 0 \le \sin^2\PARENS{\frac{1}{1-x}} \le 1 \Rightarrow 0 \le (1-x)\sin^2\PARENS{\frac{1}{1-x}} \le 1-x \Rightarrow 0 \le f(x) \le 1-x. \]
Επιπλέον το $1$ επαληθεύει την ανισότητα $0 \le f(x) \le 1-x$, αφού ισχύει $0 \le f(1) \le 1-1$, όπου $f(1)=0$.
Συνεπώς για κάθε $x \in [0,1]$ ισχύει $0 \le f(x) \le 1-x$. \monades{1}

\item Είναι $E=\int_0^1 |f(x)|dx$ όμως η $f$ είναι μη αρνητική στο διάστημα $[0,1]$, άρα
\[ E=\int_0^1 f(x)dx. \]
Για τις συνεχείς συναρτήσεις $f(x)$ και $g(x)=1-x$ στο διάστημα $[0,1]$, ισχύουν:
\begin{itemize}
    \item $g(x) \ge f(x)$ για κάθε $x \in [0,1]$ και
    \item $f(0) = \sin^2 1 \ne 1 = g(0)$.
\end{itemize}
Οπότε είναι:
\[ \int_0^1 g(x)dx > \int_0^1 f(x)dx \Rightarrow \int_0^1 (1-x)dx > E \Rightarrow E < \left[ x - \frac{x^2}{2} \right]_0^1 \Rightarrow \]
\[ E < \PARENS{1-\frac{1^2}{2}} - \PARENS{0-\frac{0^2}{2}} \Rightarrow E < \frac{1}{2} \text{ τ.μ.}. \monades{1} \]
\end{alist}
