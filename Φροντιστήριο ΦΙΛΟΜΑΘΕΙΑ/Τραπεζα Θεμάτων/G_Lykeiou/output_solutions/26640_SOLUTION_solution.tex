\textbf{ΛΥΣΗ}
\begin{enumerate}[label=\alph*)]
    \item Για τη συνάρτηση f είναι $A = \mathbb{R}$.

    Έστω $x_1, x_2 \in \mathbb{R}$ με $x_1 < x_2$, τότε ισχύουν:
    \[ x_1 < x_2 \Rightarrow 2x_1 < 2x_2 \Rightarrow e^{2x_1} < e^{2x_2} \]
    \[ x_1 < x_2 \Rightarrow x_1^3 < x_2^3 \]
    \[ x_1 < x_2 \Rightarrow 2x_1 < 2x_2 \]
    και με πρόσθεση κατά μέλη των τριών ανισώσεων παίρνουμε:
    \[ e^{2x_1} + x_1^3 + 2x_1 < e^{2x_2} + x_2^3 + 2x_2 \Rightarrow f(x_1) < f(x_2) \]
    συνεπώς η συνάρτηση f είναι γνησίως αύξουσα στο $\mathbb{R}$.

    \textbf{2η Λύση με χρήση της παραγώγου συνάρτησης}

    Είναι $f'(x) = (e^{2x} + x^3 + 2x)' = 2e^{2x} + 3x^2 + 2 > 0$, για κάθε $x \in \mathbb{R}$, συνεπώς η f είναι γνησίως αύξουσα στο $\mathbb{R}$.

    \item Αφού η συνάρτηση f είναι γνησίως αύξουσα στο $\mathbb{R}$ είναι 1-1, συνεπώς αντιστρέφεται.
    επιπλέον είναι:
    \[ \lim_{x \to -\infty} f(x) = \lim_{x \to -\infty} (e^{2x} + x^3 + 2x) = -\infty \]
    \[ \lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} (e^{2x} + x^3 + 2x) = +\infty \]
    Εφόσον η συνάρτηση f είναι συνεχής και γνησίως αύξουσα στο $\mathbb{R}$ στο το σύνολο τιμών $f(A)$ της συνάρτησης f είναι:
    \[ f(A) = f(\mathbb{R}) = \left( \lim_{x \to -\infty} f(x), \lim_{x \to +\infty} f(x) \right) = (-\infty, +\infty) = \mathbb{R} \]

    \item Λόγω του ερωτήματος (β), το πεδίο ορισμού της συνάρτησης $f^{-1}$ είναι το $\mathbb{R}$. Έστω ότι η συνάρτηση $f^{-1}$ δεν είναι γνησίως αύξουσα στο $\mathbb{R}$, τότε θα υπάρχουν $\alpha, \beta \in \mathbb{R}$ με $\alpha < \beta$ τέτοια ώστε $f^{-1}(\alpha) \geq f^{-1}(\beta)$.

    Επειδή η συνάρτηση f είναι γνησίως αύξουσα στο $\mathbb{R}$ έχουμε:
    \[ f^{-1}(\alpha) \geq f^{-1}(\beta) \xrightarrow{\text{f γνησ. αύξ.}} f(f^{-1}(\alpha)) \geq f(f^{-1}(\beta)) \Rightarrow \alpha \geq \beta \text{ άτοπο.} \]
    άρα $f^{-1}(\alpha) < f^{-1}(\beta)$ συνεπώς η $f^{-1}$ είναι γνησίως αύξουσα στο $\mathbb{R}$.

    \item Η συνάρτηση $f^{-1}$ ως γνησίως αύξουσα στο $\mathbb{R}$ είναι 1-1. Παρατηρούμε ότι:
    $f(0) = e^{2 \cdot 0} + 0^3 + 2 \cdot 0 = 1$ άρα $f^{-1}(1) = 0$

    τότε η εξίσωση γράφεται:
    \[ f^{-1}(x) = 0 \Leftrightarrow f^{-1}(x) = f^{-1}(1) \Leftrightarrow x = 1. \]
\end{enumerate}
