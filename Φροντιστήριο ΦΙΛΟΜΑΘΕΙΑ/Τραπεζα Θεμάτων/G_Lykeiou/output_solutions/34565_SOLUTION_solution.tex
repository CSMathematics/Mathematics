Σημείωση: Παράδειγμα τέτοιας συνάρτησης είναι η $f(x) = e^{-x}$ στο διάστημα $[2, 4]$.

\begin{alist}
    \item [α.] Αν αποδείξουμε ότι η συνάρτηση $g$ ικανοποιεί τις υποθέσεις του θεωρήματος Rolle στο διάστημα $[\alpha, \beta]$.
    Από την εκφώνηση, έχουμε ότι $\lambda = \frac{f(\beta) - f(\alpha)}{\beta - \alpha}$, οπότε $f'(\beta) - f'(\alpha) = \lambda(\beta - \alpha)$.
    Η συνάρτηση $g$ είναι παραγωγίσιμη στο διάστημα $[\alpha, \beta]$, άρα και συνεχής, ενώ
    \[g(\alpha) = f(\alpha) + \frac{\lambda + f'(\alpha)}{2}\alpha - \frac{\lambda + f'(\alpha)}{2}\alpha = f(\alpha)\]
    και
    \[g(\beta) = f(\beta) + \frac{\lambda + f'(\beta)}{2}\beta - \frac{\lambda + f'(\beta)}{2}\beta = f(\beta).\]
    Δηλαδή $g(\alpha) = g(\beta)$.

    \item [β)] Από το ερώτημα α) προκύπτει ότι υπάρχει $c \in (\alpha, \beta)$ ώστε $g'(c) = 0$.
    Παρατηρούμε ότι
    \[g'(x) = \frac{\left[f(x)+\lambda+f'(x)\right]' \cdot x - \left(f(x)+\lambda+f'(x)\right) \cdot x'}{x^2} - \frac{\lambda+f'(x)}{x^2} = \frac{xf'(x) - f(x) - \lambda - f'(x)}{x^2}.\]
    Επομένως, $g'(c) = 0 \Rightarrow cf'(c) - f(c) - \lambda + f'(c) = 0$. (1)

    \item [γ)] Γνωρίζουμε ότι η εφαπτομένη ευθεία $(\varepsilon)$ της γραφικής παράστασης της $f$ στο $M$ έχει εξίσωση $y - f(c) = f'(c)(x - c)$ δηλαδή $y = f'(c)x + (f(c) - cf'(c))$.
    Η ευθεία $AB$ έχει εξίσωση $y - f(\alpha) = \lambda(x - \alpha)$ δηλαδή $y = \lambda x + (f(\alpha) - \lambda \alpha)$.
    Αρκεί να δείξουμε ότι το σημείο τομής αυτών των δύο ευθειών $(\varepsilon)$ και $AB$ βρίσκεται πάνω στον άξονα $y'$.
    Για να βρούμε την τετμημένη του σημείου τομής των δύο ευθειών, λύνουμε την εξίσωση
    \[f'(c)x + (f(c) - cf'(c)) = \lambda x + (f(\alpha) - \lambda \alpha),\]
    άρα
    \[(f'(c) - \lambda)x = cf'(c) - f(c) + f(\alpha) - \lambda \alpha = 0,\]
    λόγω της σχέσης (1).
    Θα αποδείξουμε τώρα ότι $f'(c) \ne \lambda$.
    Αν είναι $f'(c) = \lambda$ τότε η σχέση (1) γίνεται $\lambda = \frac{f(c) - f(\alpha)}{c - \alpha}$, που σημαίνει ότι η ευθεία $AM$ είναι παράλληλη προς την $AB$, κάτι που θα σήμαινε ότι το $M$ θα ανήκει στην ευθεία $AB$.
    Αντίφαση.
    Ώστε $x = 0$, άρα το σημείο τομής των ευθειών $(\varepsilon)$ και $AB$ έχει τετμημένη μηδέν και επομένως βρίσκεται πάνω στον άξονα $y'$.

    \item [δ)] Θέτουμε $u = x^2 + 1$, οπότε $du = 2xdx$, άρα $\frac{1}{2} du = xdx$.
    Για $x = \sqrt{\alpha - 1}$, παίρνουμε $u = (\sqrt{\alpha - 1})^2 + 1 = \alpha$ και ανάλογα
    για $x = \sqrt{\beta - 1}$, παίρνουμε $u = (\sqrt{\beta - 1})^2 + 1 = \beta$.
    Ώστε
    \[I = \frac{1}{2}\int_{\alpha}^{\beta} \frac{f'(u)}{u} du = \frac{1}{2}\left[\ln(f(u))\right]_{\alpha}^{\beta} = \frac{1}{2}(\ln(f(\beta)) - \ln(f(\alpha))) = \frac{1}{2}\ln\left(\frac{f(\beta)}{f(\alpha)}\right).\]
    \[\implies I = \frac{1}{2}\ln\left(\frac{1}{2}\right) = \frac{1}{2}(-\ln 2).\]
\end{alist}
