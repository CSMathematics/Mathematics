\textbf{ΛΥΣΗ}
\begin{alist}
\item Η συνάρτηση είναι συνεχής για $x<0$ ως πολυωνυμική. Επίσης είναι συνεχής για $x>0$ ως σύνθεση συνεχών συναρτήσεων. Απομένει η συνέχεια της $f$ στο $x_0 = 0$.
Είναι:
\[ \lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} x^3 = 0 \]
και
\[ \lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} \ln(x+1) = 0 = f(0) \]
Επειδή ισχύει $\lim_{x \to 0} f(x) = f(0) = 0$, η $f$ είναι συνεχής και στο $x_0 = 0$. Επομένως η $f$ είναι συνεχής στο πεδίο ορισμού της που είναι το $\mathbb{R}$.

\item Η $f$ είναι παραγωγίσιμη σε καθένα από τα διαστήματα $(-\infty, 0)$ και $(0, +\infty)$ με
\[ f'(x) = 3x^2 > 0, \quad \text{αν } x<0 \]
και
\[ f'(x) = \frac{1}{x+1} > 0, \quad \text{αν } x>0 \]
Επομένως η $f$ έχει θετική παράγωγο σε καθένα από τα διαστήματα $(-\infty, 0)$, $(0, +\infty)$ και είναι συνεχής στο $x_0 = 0$, οπότε είναι γνησίως αύξουσα στο $\mathbb{R}$.
\end{alist}
