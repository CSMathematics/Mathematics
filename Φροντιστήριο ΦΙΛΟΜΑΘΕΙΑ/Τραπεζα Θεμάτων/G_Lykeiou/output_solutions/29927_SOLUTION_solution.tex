\item \label{item:alpha} α)
\[ \lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} \left( \frac{x}{\ln x} \right) = \lim_{x \to 0^+} \left( \frac{1}{\frac{\ln x}{x}} \right) = 0 \cdot 0 = 0, \]
Διότι, $\lim_{x \to 0^+} \ln x = -\infty$, άρα $\lim_{x \to 0^+} \frac{1}{\ln x} = 0$.
\[ \lim_{x \to 1^-} f(x) = \lim_{x \to 1^-} \left( \frac{x}{\ln x} \right) = 1 \cdot (-\infty) = -\infty. \]
Διότι, $\ln x = 0$ και $\ln x < 0$ για $x \in (0,1)$ οπότε $\lim_{x \to 1^-} \left( \frac{1}{\ln x} \right) = -\infty$.
\[ \lim_{x \to 1^+} f(x) = \lim_{x \to 1^+} \left( \frac{x}{\ln x} \right) = 1 \cdot (+\infty) = +\infty. \]
Διότι, $\ln x = 0$ και $\ln x > 0$ για $x > 1$ οπότε $\lim_{x \to 1^+} \left( \frac{1}{\ln x} \right) = +\infty$.
\[ \lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} \left( \frac{x}{\ln x} \right) = \lim_{x \to +\infty} \left( \frac{(x)'}{(\ln x)'} \right) = \lim_{x \to +\infty} \left( \frac{1}{\frac{1}{x}} \right) = \lim_{x \to +\infty} x = +\infty. \]

\item \label{item:beta} β)
\begin{rlist}
\item \label{item:beta:i} i. Η συνάρτηση $f$ ορίζεται για κάθε $x \in (0,1) \cup (1, +\infty)$ και είναι συνεχής στο πεδίο ορισμού της ως πηλίκο συνεχών συναρτήσεων.
\[ f'(x) = \left( \frac{x}{\ln x} \right)' = \frac{(\ln x)' x - (\ln x) (x)'}{(\ln x)^2} = \frac{\ln x - 1}{\ln^2 x}. \]
$f'(x) = 0 \Leftrightarrow \ln x - 1 = 0 \Leftrightarrow x = e$.

Για κάθε $x \in (0,1)$ $\ln x < 0$ και $\ln x - 1 < -1 < 0$, ενώ $\ln^2 x > 0$, οπότε $f'(x) < 0$ και η $f$ είναι συνεχής στο $(0,1)$, άρα η συνάρτηση $f$ είναι γνησίως φθίνουσα στο διάστημα $(0,1)$.

Στο διάστημα $(1, +\infty)$ είναι $f'(x) = \frac{\ln x - 1}{\ln^2 x}$, με $f'(x) > 0 \Leftrightarrow \ln x - 1 > 0 \Leftrightarrow x > e$.
Οπότε, για κάθε $x \in [e, +\infty)$ και $f$ συνεχής με $f'(x) > 0$ για κάθε $x \in (e, +\infty)$, οπότε $f$ γνησίως αύξουσα στο $[e, +\infty)$. Αντίστοιχα, $f'(x) < 0$ για κάθε $x \in (1, e)$ και $f$ συνεχής στο $(1, e]$, οπότε $f$ γνησίως φθίνουσα στο $(1, e]$.

\item \label{item:beta:ii} ii. Στο $\Delta_1 = (0,1)$ η $f$ είναι συνεχής και γνησίως φθίνουσα σε αυτό, οπότε $f(\Delta_1) = (\lim_{x \to 1^-} f(x), \lim_{x \to 0^+} f(x)) = (-\infty, 0)$, διότι
$\lim_{x \to 1^-} f(x) = -\infty$ και $\lim_{x \to 0^+} f(x) = 0$ (από α ερώτημα).
Στο $\Delta_2 = (1, e]$ η $f$ είναι συνεχής και γνησίως φθίνουσα σε αυτό, οπότε $f(\Delta_2) = [f(e), \lim_{x \to 1^+} f(x)) = [e, +\infty)$, διότι
$f(e) = \frac{e}{\ln e} = e$ και $\lim_{x \to 1^+} f(x) = +\infty$ (από α ερώτημα).
Στο $\Delta_3 = [e, +\infty)$ η $f$ είναι συνεχής και γνησίως αύξουσα σε αυτό, οπότε $f(\Delta_3) = [f(e), \lim_{x \to +\infty} f(x)) = [e, +\infty)$, διότι
$f(e) = \frac{e}{\ln e} = e$ και $\lim_{x \to +\infty} f(x) = +\infty$ (από α ερώτημα).
Άρα το σύνολο τιμών της $f$ είναι το $f(\Delta_1) \cup f(\Delta_2) \cup f(\Delta_3) = (-\infty, 0) \cup [e, +\infty)$.
\end{rlist}

\item \label{item:gamma} γ) Για κάθε $x > 0$ η εξίσωση $e^x = x^\alpha$ γράφεται ισοδύναμα $\ln e^x = \ln x^\alpha \Leftrightarrow x = \alpha \ln x$.
Αν $\ln x \ne 0 \Leftrightarrow x \ne 1$ η εξίσωση γράφεται ισοδύναμα $\frac{x}{\ln x} = \alpha \Leftrightarrow f(x) = \alpha$, με την $f$ ορισμένη για κάθε $x \in (0,1) \cup (1, +\infty)$.
Η τιμή $x = 1$ δεν αποτελεί λύση της εξίσωσης $e^x = x^\alpha$, αφού για $x=1$ προκύπτει $e=1$ (άτοπο).
Οι λύσεις της εξίσωσης $e^x = x^\alpha$ είναι τελικά οι λύσεις της εξίσωσης $f(x) = \alpha$.
Η $f$ ορίζεται για κάθε $x \in (0,1) \cup (1, +\infty)$ και το σύνολο τιμών της είναι το $(-\infty, 0) \cup [e, +\infty)$.
\begin{itemize}
    \item Για κάθε $\alpha \in [0, e)$ η εξίσωση $f(x) = \alpha$ είναι αδύνατη, αφού το $\alpha$ δεν ανήκει στο σύνολο τιμών της $f$.
    \item Αν το $\alpha \in (-\infty, 0)$ η $f(\Delta_1)$, τότε η εξίσωση $f(x) = \alpha$ έχει μία τουλάχιστον λύση στο $\Delta_1 = (0,1)$ και επειδή η $f$ είναι γνησίως φθίνουσα στο $\Delta_1$, έχει ακριβώς μία λύση στο $\Delta_1$.
    \item Αν το $\alpha \in (e, +\infty) \subseteq f(\Delta_2) = f(\Delta_3)$, τότε η εξίσωση $f(x) = \alpha$ έχει μία τουλάχιστον λύση στο $(1, e)$ και μία τουλάχιστον λύση στο $(e, +\infty)$. Επειδή η $f$ είναι γνησίως φθίνουσα $\Delta_2 = (1, e]$ ακριβώς μία λύση στο $(1, e]$. Επίσης είναι γνησίως αύξουσα στο $(e, +\infty)$, οπότε έχει μία ακριβώς λύση στο $(e, +\infty)$.
    \item Για $\alpha = e$ η εξίσωση $f(x) = \alpha$ έχει μία λύση, την τιμή $x = e$.
\end{itemize}
Συμπερασματικά για το πλήθος των λύσεων της εξίσωσης $e^x = x^\alpha$, για τις διάφορες τιμές του $\alpha$ έχουμε :
\begin{itemize}
    \item καμία λύση για κάθε $0 \le \alpha < e$,
    \item μία λύση που ανήκει στο $(0,1)$, για κάθε $\alpha < 0$,
    \item δύο λύσεις, μία στο $(1, e)$ και μία στο $(e, +\infty)$ για κάθε $\alpha > e$,
    \item μία λύση την $x = e$ για $\alpha = e$.
\end{itemize}
\end{alist}
