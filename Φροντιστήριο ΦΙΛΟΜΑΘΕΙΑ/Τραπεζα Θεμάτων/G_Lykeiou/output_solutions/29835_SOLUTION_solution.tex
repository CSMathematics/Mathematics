ΛΥΣΗ

\begin{alist}
\item Για την $f: x+1 \ge 0 \iff x \ge -1$, άρα $D_f = [-1, +\infty)$.
Επίσης το $D_g = \mathbb{R}$ γιατί η $g$ είναι πολυωνυμική συνάρτηση. \monades{X}

\item Είναι $A_1 = \{x \in D_g : g(x) \in D_f\} = \{x \in \mathbb{R}: 2-x \in [-1, +\infty)\} = \{x \in \mathbb{R}: 2-x \ge -1\} = \{x \in \mathbb{R}: x \le 3\} = (-\infty, 3] \ne \emptyset$, επομένως ορίζεται η $f \circ g$ και έχει τύπο:
\[
(f \circ g)(x) = f(g(x)) = \sqrt{g(x)+1}-1 = \sqrt{2-x+1}-1 = \sqrt{3-x}-1.
\] \monades{X}

\item Λόγω του ερωτήματος (β) είναι $\varphi(x)=\sqrt{3-x}-1$ με $A=(-\infty,3]$.
Η $\varphi$ είναι συνεχής στο $A$ ως αποτέλεσμα πράξεων συνεχών συναρτήσεων. Επίσης η $\varphi$ είναι παραγωγίσιμη στο $(-\infty,3)$ με
\[
\varphi'(x) = (\sqrt{3-x}-1)' = \frac{1}{2\sqrt{3-x}} \cdot (3-x)' = -\frac{1}{2\sqrt{3-x}} < 0,
\]
άρα η $\varphi$ είναι γνησίως φθίνουσα στο $A=(-\infty,3]$, επομένως «1-1», οπότε αντιστρέψιμη.

Επίσης το $\varphi(A)=[\varphi(3), \lim_{x \to -\infty} \varphi(x)) = [-1, +\infty)$
γιατί $\varphi(3) = \sqrt{3-3}-1 = -1$ και $\lim_{x \to -\infty} \varphi(x) = \lim_{x \to -\infty} (\sqrt{3-x}-1) = +\infty$.

Επομένως ορίζεται $\varphi^{-1} : \varphi(A) \to A$ ή $\varphi^{-1} : [-1, +\infty) \to (-\infty,3]$.
Για την εύρεση του τύπου της αντίστροφου της $\varphi$ θέτουμε
\[
\varphi(x)=y \iff \sqrt{3-x}-1=y \iff \sqrt{3-x}=y+1 \iff 3-x=(y+1)^2 \iff x=3-(y+1)^2,
\]
επομένως $\varphi^{-1}(x)=3-(x+1)^2$. \monades{X}
\end{alist}
