    \item % This is (α)i
    Για να εφάπτεται της $C_f$ η ευθεία $y=x$ στο σημείο $A\left(\frac{\pi}{2}, f\left(\frac{\pi}{2}\right)\right)$, αρκεί να αποδείξουμε ότι η εξίσωση της εφαπτομένης της $C_f$ στο $A$, είναι η $y=x$.
    Για κάθε $x \in \mathbb{R}$ είναι $f'(x) = (\eta\mu x)' = (x)' \eta\mu x + x (\eta\mu x)' = \eta\mu x + x\sigma\upsilon\nu x$.
    Η εξίσωση εφαπτομένης $(\varepsilon)$ της $C_f$ στο $A$, είναι η $y - f\left(\frac{\pi}{2}\right) = f'\left(\frac{\pi}{2}\right) \left(x - \frac{\pi}{2}\right)$.
    Είναι $f\left(\frac{\pi}{2}\right) = \eta\mu \frac{\pi}{2} + \frac{\pi}{2} \sigma\upsilon\nu \frac{\pi}{2} = 1 + \frac{\pi}{2} \cdot 0 = 1$ και $f'\left(\frac{\pi}{2}\right) = \eta\mu \frac{\pi}{2} = 1$ άρα η εξίσωση της εφαπτομένης $(\varepsilon)$ γράφεται
    \[ y - 1 = 1 \left(x - \frac{\pi}{2}\right) \Leftrightarrow y - 1 = x - \frac{\pi}{2} \Leftrightarrow y = x \]
    και έπεται το ζητούμενο.
    \item % This is (α)ii
    Για να βρούμε τα κοινά σημεία της $C_f$ με την $y=x$ επιλύουμε το σύστημα
    \[ \left\{ \begin{array}{l} y=x \\ y=x\eta\mu x \end{array} \right., x \in \mathbb{R}. \]
    Με $x \in \mathbb{R}$ έχουμε:
    \[ \left\{ \begin{array}{l} y=x \\ x=x\eta\mu x \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} y=x \\ x-x\eta\mu x=0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} y=x \\ x(1-\eta\mu x)=0 \end{array} \right. \]
    \[ \Leftrightarrow \left\{ \begin{array}{l} y=x \\ x=0 \text{ ή } \eta\mu x=1 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} y=x \\ x=0 \text{ ή } x=2k\pi+\frac{\pi}{2}, \kappa \in \mathbb{Z} \end{array} \right. \]
    Για $x=0$ είναι $y=0$.
    Για $x=2k\pi+\frac{\pi}{2}$ είναι $y=2k\pi+\frac{\pi}{2}$ με $\kappa \in \mathbb{Z}$.
    Οπότε η $C_f$ έχει άπειρα κοινά σημεία με την εφαπτομένη της $y=x$ τα οποία είναι η αρχή των αξόνων $(0,0)$ και τα σημεία $\left(2k\pi+\frac{\pi}{2}, 2k\pi+\frac{\pi}{2}\right)$ με $\kappa \in \mathbb{Z}$.
    \end{rlist}

    \item % This is (β)i
    Είναι
    \[ \lim_{x \to +\infty} (g(x)-x) = \lim_{x \to +\infty} \left(\ln\left(1+\frac{1}{e^x}\right)\right) \]
    Θέτουμε $u=\frac{1}{e^x}$. Όταν $x \to +\infty$, τότε $u \to 0$. Άρα
    \[ \lim_{x \to +\infty} \left(\ln\left(1+\frac{1}{e^x}\right)\right) = \lim_{u \to 0} (\ln(1+u)) \]
    Επειδή $\lim_{u \to 0} \frac{\ln(1+u)}{u} = 1$, έχουμε $\lim_{u \to 0} (\ln(1+u)) = \lim_{u \to 0} \left(u \frac{\ln(1+u)}{u}\right) = 0 \cdot 1 = 0$.
    Οπότε η $y=x$ είναι ασύμπτωτη της $C_g$ στο $+\infty$.
    \item % This is (β)ii
    Η $C_g$ βρίσκεται πάνω από την $y=x$ στο διάστημα $(0,+\infty)$ αν και μόνο αν $g(x) > x$, για κάθε $x \in (0,+\infty)$.
    Για $x \in (0,+\infty)$ έχουμε: $g(x) > x \Leftrightarrow g(x) - x > 0 \Leftrightarrow \ln\left(1+\frac{1}{e^x}\right) > \ln 1 \Leftrightarrow 1+\frac{1}{e^x} > 1$ που ισχύει.
    \end{rlist}

\item % This is part (γ)
    Στο $(0,+\infty)$ ισχύουν:
    \[ g(x)>x \text{ και } 1 \ge \eta\mu x \Rightarrow x \ge x\eta\mu x \Rightarrow x \ge f(x). \]
    Άρα είναι $g(x) \ge x \ge f(x)$ ή $g(x) \ge f(x)$, για κάθε $x \in (0,+\infty)$ και έπεται το ζητούμενο.
    \textbf{Σχόλιο:} Ακολουθεί μια αλγεβρική επίλυση του ερωτήματος (γ).
    Με $x \in (0,+\infty)$ είναι $g(x)=\ln(e^x+1)$ και έτσι έχουμε:
    \begin{align*}
        g(x) > f(x) & \Leftrightarrow \ln(e^x+1) - x\eta\mu x > 0 \\
        & \Leftrightarrow \ln(e^x+1) - x - x\eta\mu x + x > 0 \\
        & \Leftrightarrow \ln(e^x+1) - \ln e^x + x(1-\eta\mu x) > 0 \\
        & \Leftrightarrow \ln\left(\frac{e^x+1}{e^x}\right) + x(1-\eta\mu x) > 0 \\
        & \Leftrightarrow \underbrace{\ln\left(1+\frac{1}{e^x}\right)}_{>0 \text{ (από βii)}} + \underbrace{x(1-\eta\mu x)}_{\ge 0 \text{ (από } 0<x, \eta\mu x \le 1 \text{)}} > 0
    \end{align*}
    που ισχύει.
