Ένας αγρότης θέλει να περιφράξει σε ένα χωράφι μια περιοχή σχήματος ορθογωνίου με μεταβλητές διαστάσεις $x, y$ ώστε να έχει εμβαδόν $800 \, m^2$. Η μία πλευρά της περιοχής, μήκους $x$, θα είναι πέτρινη, ενώ για τις υπόλοιπες πλευρές θα χρησιμοποιήσει συρμάτινο φράχτη. Αν το κόστος περίφραξης για την πέτρινη πλευρά είναι $6$ ευρώ ανά $m$ και για τον συρμάτινο φράχτη είναι $2$ ευρώ ανά $m$, τότε:
\begin{alist}
\item Να αποδείξετε ότι το συνολικό κόστος της περίφραξης, συναρτήσει του $x$, είναι:
\[ K(x) = 8x + \frac{3200}{x}, x > 0 \] \monades{08}
\item Να βρείτε ποιες θα πρέπει να είναι οι διαστάσεις του κτήματος ώστε το συνολικό κόστος περίφραξης να είναι ελάχιστο, και να προσδιορίσετε την ελάχιστη τιμή του. \monades{10}
\item Να αποδείξετε ότι ο ρυθμός μεταβολής του κόστους αυξάνεται για κάθε $x > 0$. \monades{07}
\end{alist}
