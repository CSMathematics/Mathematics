\begin{ylh}{1}
    \item 3.4 Ορισμένο ολοκλήρωμα
\end{ylh}
Αν $f$ μια συνεχής συνάρτηση στο $\mathbb{R}$ με $\int_{2}^{3} f(x)dx = 2$, $\int_{1}^{3} f(x)dx = 4$ και $\int_{1}^{7} f(x)dx = 10$ να βρείτε τα παρακάτω ολοκληρώματα:
\begin{alist}
    \item $\int_{3}^{2} f(x)dx$. \monades{5}
    \item $\int_{3}^{7} f(x)dx$. \monades{6}
    \item $\int_{7}^{2} f(x)dx$. \monades{6}
    \item $\int_{1}^{3} (f(x)-x)dx$. \monades{8}
\end{alist}
