Έστω $I = \frac{\pi}{2} \int_0^{\frac{\pi}{2}} \sin^2 x dx$ και $J = \frac{\pi}{2} \int_0^{\frac{\pi}{2}} \cos^2 x dx$.

\begin{alist}
    \item Να αποδείξετε ότι $I+J = \frac{\pi^2}{4}$. \monades{6}
    \item Με χρήση της αντικατάστασης $u = \frac{\pi}{2} - x$ να αποδείξετε ότι $I=J$ και κατόπιν ότι $I=J=\frac{\pi^2}{8}$. \monades{7}
    \item Στο παρακάτω σχήμα δίνεται η γραφική παράσταση $C_f$ της συνάρτησης $f(x) = \frac{\pi}{2} \sin^2 x$ στο διάστημα $\left[0, \frac{\pi}{2}\right]$. Η ευθεία $OA$ τέμνει τη $C_f$ στα σημεία $O(0,0)$, $A\left(\frac{\pi}{2}, \frac{\pi}{2}\right)$, $K(x_o, f(x_o))$ και ορίζει με τη $C_f$ τα χωρία $\Omega_1, \Omega_2$. Να αποδείξετε ότι :
    \begin{rlist}
        \item το εμβαδόν που περικλείεται μεταξύ της $C_f$, του άξονα $yy'$ και της ευθείας $y=\frac{\pi}{2}$ είναι το $J$. \monades{6}
        \item τα εμβαδά των χωρίων $\Omega_1, \Omega_2$ είναι ίσα. \monades{6}
    \end{rlist}
\end{alist}
