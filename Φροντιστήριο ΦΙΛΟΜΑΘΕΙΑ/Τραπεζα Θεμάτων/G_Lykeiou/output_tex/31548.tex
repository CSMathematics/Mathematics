\begin{ylh}{1}
    \item 1.4 Όριο συνάρτησης στο $x_0$
    \item 1.8 Συνέχεια συνάρτησης.
\end{ylh}
Έστω $f : \mathbb{R} \rightarrow \mathbb{R}$ μία συνάρτηση για την οποία ισχύει $|f(x)-2x| \leq (x-1)^2$ για κάθε $x \in \mathbb{R}$.
Να αποδείξετε ότι :
\begin{alist}
    \item $f(1)=2$. \monades{10}
    \item $\lim_{x \to 1} f(x)=2$. \monades{10}
    \item η $f$ είναι συνεχής στο $1$. \monades{5}
\end{alist}
