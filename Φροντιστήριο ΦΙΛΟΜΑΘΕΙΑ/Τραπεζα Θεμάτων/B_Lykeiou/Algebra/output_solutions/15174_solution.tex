\begin{alist}
\item Η διαίρεση του πολυωνύμου $P(x)$ με το πολυώνυμο $\delta(x)$ :
\begin{center}
\begin{tabular}{r|l}
$x^4 + x^3 \phantom{{} - 2x^2} + \alpha x - 4$ & $x^2 - 3x + 2$ \\ \cline{2-2}
$-x^4 + 3x^3 - 2x^2 \phantom{{} + \alpha x - 4}$ & $x^2 + 4x + 10$ \\ \cline{1-1}
$4x^3 - 2x^2 \phantom{{} + 0x} + \alpha x - 4$ & \\
$-4x^3 + 12x^2 \phantom{{} + 0x} - 8x \phantom{{} - 4}$ & \\ \cline{1-1}
$10x^2 + (\alpha - 8)x - 4$ & \\
$-10x^2 + 30x - 20$ & \\ \cline{1-1}
$(\alpha + 22)x - 24$ &
\end{tabular}
\end{center}
Η ταυτότητα της διαίρεσης είναι:
\[P(x) = \delta(x) \cdot (x^2 + 4x + 10) + (\alpha + 22)x - 24\]
Επομένως πρέπει να ισχύει $(\alpha + 22)x - 24 = 24x - 24$ για κάθε $x \in \mathbb{R}$. \\
Είναι:
\[(\alpha + 22)x - 24 = 24x - 24 \Leftrightarrow \alpha + 22 = 24 \Leftrightarrow \alpha = 2.\]
\item Για $\alpha = 2$, είναι $P(x) = x^4 + x^3 + 2x - 4$.
\begin{rlist}
\item Το υπόλοιπο της διαίρεσης του $P(x)$ με το $x - 1$ είναι το $P(1) = 0$.
\item Ζητείται η επίλυση της εξίσωσης $P(x) = 0$. \\
Είναι: $P(1) = 0 \Leftrightarrow 1 \text{ ρίζα του } P(x) \Leftrightarrow x - 1 \text{ παράγοντας του } P(x)$. \\
Εφαρμογή του σχήματος Horner:
\begin{center}
\Horner{1,1,0,2,-4}{1}
\end{center}
Επομένως ισχύει: $P(x) = (x - 1)(x^3 + 2x^2 + 2x + 4)$ \\
Αλλά $x^3 + 2x^2 + 2x + 4 = x^2(x + 2) + 2(x + 2) = (x + 2)(x^2 + 2)$. \\
Τελικά ισχύει $P(x) = (x - 1)(x + 2)(x^2 + 2)$. \\
Είναι λοιπόν
\[P(x) = 0 \Leftrightarrow (x - 1)(x + 2)(x^2 + 2) = 0 \xLeftrightarrow{x^2+2\ne0} x = 1 \text{ ή } x = -2.\]
\end{rlist}
\end{alist}
