\lysh{20867}{2}
\begin{alist}
\item Η τιμή της παράστασης για $x = 0$ είναι: $A = \syn ^2 0 - \hm ^2 0 = 1 - 0 = 1$.
\item Γνωρίζουμε ότι: $\hm ^2 x + \syn ^2 x = 1 \Leftrightarrow \syn ^2 x = 1 - \hm ^2 x$. Οπότε έχουμε:
\[A = \syn ^2 x - \hm ^2 x = (1 - \hm ^2 x) - \hm ^2 x = 1 - 2\hm ^2 x.\]
\item Έχουμε ισοδύναμα: $A = 1 \overset{(\beta)}{\Longleftrightarrow} 1 - 2\hm ^2 x = 1$. Με χρήση της γραφικής παράστασης της συνάρτησης με τύπο $1 - 2\hm ^2 x$,

\end{center}
παρατηρούμε ότι $1 - 2\hm ^2 x = 1$ για $x = \pi$, αφού $0 < x < 2\pi$. Άρα η λύση της εξίσωσης $A = 1$, για $0 < x < 2\pi$, είναι $x = \pi$.
\end{alist}
