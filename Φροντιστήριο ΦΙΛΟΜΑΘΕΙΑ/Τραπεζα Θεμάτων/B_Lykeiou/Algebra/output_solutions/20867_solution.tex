\begin{alist}
\item Η τιμή της παράστασης για $x = 0$ είναι: $A = \sigma\upsilon\nu^2 0 - \eta\mu^2 0 = 1 - 0 = 1$.

\item Γνωρίζουμε ότι: $\eta\mu^2 x + \sigma\upsilon\nu^2 x = 1 \Leftrightarrow \sigma\upsilon\nu^2 x = 1 - \eta\mu^2 x$. Οπότε έχουμε:
\[A = \sigma\upsilon\nu^2 x - \eta\mu^2 x = (1 - \eta\mu^2 x) - \eta\mu^2 x = 1 - 2\eta\mu^2 x.\]

\item Έχουμε ισοδύναμα: $A = 1 \overset{(\beta)}{\Longleftrightarrow} 1 - 2\eta\mu^2 x = 1$. Με χρήση της γραφικής παράστασης της συνάρτησης με τύπο $1 - 2\eta\mu^2 x$,
