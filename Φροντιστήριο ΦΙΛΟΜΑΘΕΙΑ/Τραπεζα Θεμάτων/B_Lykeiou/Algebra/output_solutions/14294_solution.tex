\begin{alist}
\item Αφού η παραβολή διέρχεται από το σημείο $\varGamma(0, -2)$, ισχύει ότι
\[f(0) = -2 \Leftrightarrow \alpha \cdot 0^2 + \beta \cdot 0 + \gamma = -2 \Leftrightarrow \gamma = -2.\]
Άρα, $f(x) = \alpha x^2 + \beta x - 2$. Επίσης, τα σημεία $A(2,0)$ και $B(-2,0)$, είναι σημεία της παραβολής, οπότε:
\[\begin{cases} f(2) = 0 \\ f(-2) = 0 \end{cases} \Leftrightarrow \begin{cases} \alpha \cdot 2^2 + \beta \cdot 2 - 2 = 0 \\ \alpha \cdot (-2)^2 + \beta \cdot (-2) - 2 = 0 \end{cases} \Leftrightarrow\]
\[\begin{cases} 4\alpha + 2\beta - 2 = 0 \\ 4\alpha - 2\beta - 2 = 0 \end{cases} \Leftrightarrow \begin{cases} \beta = -2\alpha + 1 \\ 2\alpha - (-2\alpha + 1) = 1 \end{cases} \Leftrightarrow\]
\[\begin{cases} \beta = -2\alpha + 1 \\ 4\alpha - 1 = 1 \end{cases} \Leftrightarrow \begin{cases} \beta = -2 \cdot \dfrac{1}{2} + 1 \\ \alpha = \dfrac{1}{2} \end{cases} \Leftrightarrow \begin{cases} \beta = 0 \\ \alpha = \dfrac{1}{2} \end{cases}\]
Άρα, $f(x) = \dfrac{1}{2}x^2 - 2$.

\item Για να βρούμε τις τετμημένες των κοινών σημείων της παραβολής και της ευθείας, λύνουμε την εξίσωση:
\[f(x) = g(x) \Leftrightarrow \dfrac{1}{2}x^2 - 2 = -x + 2 \Leftrightarrow x^2 + 2x - 8 = 0.\]
Το τριώνυμο έχει διακρίνουσα $\varDelta = 2^2 - 4(-8) = 36$ και ρίζες:
\[x_1 = \dfrac{-2 + 6}{2} = 2 \quad \text{και} \quad x_2 = \dfrac{-2 - 6}{2} = -4.\]
Είναι $g(2) = 0$ και $g(-4) = 6$. Άρα, τα σημεία είναι τα $A(2,0)$ και $\varDelta(-4,6)$.

\item Με μετατόπιση της παραβολής κατά $4{,}5$ μονάδες προς τα πάνω προκύπτει η συνάρτηση
\[h(x) = \dfrac{1}{2}x^2 - 2 + 4{,}5 \Leftrightarrow h(x) = \dfrac{1}{2}x^2 + 2{,}5.\]
Για να βρούμε τις τετμημένες των κοινών σημείων της γραφικής παράστασης της συνάρτησης $h$ με την ευθεία $g$ λύνουμε την εξίσωση:
\[h(x) = g(x) \Leftrightarrow \dfrac{1}{2}x^2 + 2{,}5 = -x + 2 \Leftrightarrow\]
\[x^2 + 2x + 1 = 0 \Leftrightarrow (x + 1)^2 = 0 \Leftrightarrow x = -1.\]
Επίσης, $g(-1) = 3$. Άρα, η γραφική παράσταση της συνάρτησης $h$ και η ευθεία $g$ έχουν ένα μόνο κοινό σημείο το $(-1, 3)$.
\end{alist}
