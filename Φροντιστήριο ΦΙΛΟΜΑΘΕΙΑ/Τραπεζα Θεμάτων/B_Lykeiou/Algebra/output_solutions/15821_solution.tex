\begin{alist}
\item Αν υπήρχε γωνία $x$ τέτοια ώστε $\hm  x = \syn  x = 0$, τότε από τη βασική τριγωνομετρική ταυτότητα $\hm ^2x + \syn ^2x = 1$ θα είχαμε $0 + 0 = 1$, το οποίο είναι άτοπο. Συνεπώς δεν υπάρχει γωνία $x$ τέτοια ώστε $\hm  x = \syn  x = 0$.
\item Αν $\syn  x = 0$ τότε από την εξίσωση $\sqrt{3}\cdot\hm  x = 3\cdot\syn  x$ θα είχαμε και $\hm  x = 0$, το οποίο όμως όπως δείξαμε στο α) είναι άτοπο. Συνεπώς $\syn  x \neq 0$. \\
Με $\syn  x \neq 0$ έχουμε ισοδύναμα
\[\sqrt{3}\cdot\hm  x = 3\cdot\syn  x \Leftrightarrow \frac{\hm  x}{\syn  x} = \frac{3}{\sqrt{3}} \Leftrightarrow \ef  x = \sqrt{3} \Leftrightarrow \ef  x = \ef \frac{\pi}{3}\]
η οποία στο διάστημα $[0, 2\pi]$ έχει λύσεις τις $x = \dfrac{\pi}{3}$ και $x = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}$.
\item Με βάση τον παρακάτω πίνακα τιμών
