\lysh{15014}{4}
\begin{alist}
\item Για την συνάρτηση $f(x) = \alpha \cdot \hm \beta x$ με $\alpha$ θετικό ακέραιο μέγιστη τιμή είναι το $\alpha$, άρα $\alpha = 2$.
Εναλλακτικά έχουμε ότι η μέγιστη τιμή του $\hm \beta x$ είναι $1$, άρα αν $\alpha \cdot \hm \beta x = 2$, πρέπει $\alpha = 2$.
\item Η συνάρτηση από το α) ερώτημα είναι $f(x) = 2 \cdot \hm \beta x$, άρα
\[f\left(\dfrac{\pi}{16}\right) = 2 \Leftrightarrow 2\hm \dfrac{\beta\pi}{16} = 2 \Leftrightarrow \hm \dfrac{\beta\pi}{16} = 1.\]
Λύνουμε την εξίσωση
\[\hm \dfrac{\beta\pi}{16} = 1 \Leftrightarrow \hm \dfrac{\beta\pi}{16} = \hm \dfrac{\pi}{2} \Leftrightarrow \dfrac{\beta\pi}{16} = 2\kappa\pi + \dfrac{\pi}{2}, \quad \mu\varepsilon \quad \kappa \in \mathbb{Z}\]
(η λύση $\dfrac{\beta\pi}{16} = 2\kappa\pi + \pi - \dfrac{\pi}{2}$ ταυτίζεται με την προηγούμενη).
Απλοποιώντας το $\pi$ έχουμε $\dfrac{\beta}{16} = 2\kappa + \dfrac{1}{2}$, η μικρότερη θετική τιμή του $\beta$ που ζητάμε θα είναι όταν ο $\kappa$, ως ακέραιος, γίνει ίσος με $0$ (για αρνητικές τιμές του $\kappa$ το $\beta$ γίνεται αρνητικό). Οπότε $\dfrac{\beta}{16} = 2\kappa + \dfrac{1}{2} \overset{\kappa=0}{\iff} \dfrac{\beta}{16} = \dfrac{1}{2} \Leftrightarrow \beta = 8$.
\item Η εξίσωση $f(x) = 1$ από τα προηγούμενα ερωτήματα είναι:
\[2 \cdot \hm  8x = 1 \Leftrightarrow \hm  8x = \dfrac{1}{2} \Leftrightarrow \hm  8x = \hm \dfrac{\pi}{6} \Leftrightarrow\]
\[\begin{cases} 8x = 2\kappa\pi + \dfrac{\pi}{6} \\ \\ 8x = 2\kappa\pi + \pi - \dfrac{\pi}{6} \end{cases} \Leftrightarrow \begin{cases} x = \dfrac{\kappa\pi}{4} + \dfrac{\pi}{48} \\ \\ x = \dfrac{\kappa\pi}{4} + \dfrac{5\pi}{48} \end{cases}, \quad \mu\varepsilon \quad \kappa \in \mathbb{Z}\]
Αφού πρέπει $x \in \left[0, \dfrac{\pi}{2}\right]$ λύνουμε τις παρακάτω δύο ανισώσεις:
i) $0 \le \dfrac{\kappa\pi}{4} + \dfrac{\pi}{48} \le \dfrac{\pi}{2} \Leftrightarrow 0 \le \left(\dfrac{\kappa}{4} + \dfrac{1}{48}\right)\pi \le \dfrac{\pi}{2} \Leftrightarrow 0 \le \dfrac{\kappa}{4} + \dfrac{1}{48} \le \dfrac{1}{2} \Leftrightarrow$
$-\dfrac{1}{48} \le \dfrac{\kappa}{4} \le \dfrac{1}{2} - \dfrac{1}{48} \Leftrightarrow -\dfrac{1}{48} \le \dfrac{\kappa}{4} \le \dfrac{23}{48} \Leftrightarrow -\dfrac{4}{48} \le \kappa \le \dfrac{4 \cdot 23}{48} \Leftrightarrow -\dfrac{1}{12} \le \kappa \le \dfrac{23}{12}.$
Αφού $\kappa \in \mathbb{Z}$, είναι $\kappa = 0$ ή $\kappa = 1$ δηλαδή δεκτές είναι οι γωνίες $x = \dfrac{\pi}{48}\,\text{rad}$ ή $x = \dfrac{\pi}{4} + \dfrac{\pi}{48} = \dfrac{13\pi}{48}\,\text{rad}$.
\end{alist}
