\lysh{15049}{4}
\begin{alist}
\item Επειδή $\hm \left(\dfrac{\pi}{2} - x\right) = \syn  x$ και $\hm (\pi + x) = -\hm  x$, έχουμε: $f(x) = \syn  x - \hm  x,\: x \in \mathbb{R}$.
\item Για κάθε $x \in \mathbb{R}$, έχουμε:
\[-1 \le \syn  x \le 1, \, (1) \text{ και } -1 \le \hm  x \le 1 \Leftrightarrow -1 \le -\hm  x \le 1, \, (2)\]
Με πρόσθεση των (1) και (2) προκύπτει ότι: $-2 \le \syn  x - \hm  x \le 2$, δηλαδή $-2 \le f(x) \le 2$, που είναι το ζητούμενο.
Αν υποθέσουμε ότι ο αριθμός $2$ είναι η μέγιστη τιμή της $f$, τότε για κάποιο $x_o \in \mathbb{R}$ ισχύει $\syn  x_o = 1$ και $\hm  x_o = -1$, οπότε $\hm ^2 x_o + \syn ^2 x_o = 1 + 1 = 2$, που είναι άτοπο. Άρα ο αριθμός 2 δεν είναι η μέγιστη τιμή της $f$.
\item 
\begin{rlist}
\item Με $x = 0$ έχουμε: $f(0) = \syn  0 - \hm  0 = 1 - 0 = 1$, οπότε η $C_f$ τέμνει τον άξονα $y'y$ στο σημείο $(0, 1)$.
\item Με $y = 0$ δηλαδή $f(x) = 0$ έχουμε: $\syn  x - \hm  x = 0 \Leftrightarrow \syn  x = \hm  x$. Μια προφανής λύση της εξίσωσης είναι ο αριθμός $\dfrac{\pi}{4}$ και επειδή $\syn \left(\pi + \dfrac{\pi}{4}\right) = -\syn \dfrac{\pi}{4} = -\hm \dfrac{\pi}{4} = \hm \left(\pi + \dfrac{\pi}{4}\right)$, μια άλλη λύση της είναι ο αριθμός $\pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}$.
Άρα δυο κοινά σημεία της $C_f$ με τον $x'x$ είναι τα $\left(\dfrac{\pi}{4}, 0\right)$ και $\left(\dfrac{5\pi}{4}, 0\right)$.
\end{rlist}
\end{alist}
