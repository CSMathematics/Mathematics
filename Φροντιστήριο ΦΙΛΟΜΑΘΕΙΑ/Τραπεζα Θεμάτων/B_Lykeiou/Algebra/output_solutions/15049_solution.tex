\begin{alist}
\item Επειδή $\eta\mu\left(\dfrac{\pi}{2} - x\right) = \sigma\upsilon\nu x$ και $\eta\mu(\pi + x) = -\eta\mu x$, έχουμε: $f(x) = \sigma\upsilon\nu x - \eta\mu x,\: x \in \mathbb{R}$.

\item Για κάθε $x \in \mathbb{R}$, έχουμε:
\[-1 \le \sigma\upsilon\nu x \le 1, \, (1) \text{ και } -1 \le \eta\mu x \le 1 \Leftrightarrow -1 \le -\eta\mu x \le 1, \, (2)\]
Με πρόσθεση των (1) και (2) προκύπτει ότι: $-2 \le \sigma\upsilon\nu x - \eta\mu x \le 2$, δηλαδή $-2 \le f(x) \le 2$, που είναι το ζητούμενο.
Αν υποθέσουμε ότι ο αριθμός $2$ είναι η μέγιστη τιμή της $f$, τότε για κάποιο $x_o \in \mathbb{R}$ ισχύει $\sigma\upsilon\nu x_o = 1$ και $\eta\mu x_o = -1$, οπότε $\eta\mu^2 x_o + \sigma\upsilon\nu^2 x_o = 1 + 1 = 2$, που είναι άτοπο. Άρα ο αριθμός 2 δεν είναι η μέγιστη τιμή της $f$.

\item 
\begin{rlist}
\item Με $x = 0$ έχουμε: $f(0) = \sigma\upsilon\nu 0 - \eta\mu 0 = 1 - 0 = 1$, οπότε η $C_f$ τέμνει τον άξονα $y'y$ στο σημείο $(0, 1)$.
\item Με $y = 0$ δηλαδή $f(x) = 0$ έχουμε: $\sigma\upsilon\nu x - \eta\mu x = 0 \Leftrightarrow \sigma\upsilon\nu x = \eta\mu x$. Μια προφανής λύση της εξίσωσης είναι ο αριθμός $\dfrac{\pi}{4}$ και επειδή $\sigma\upsilon\nu\left(\pi + \dfrac{\pi}{4}\right) = -\sigma\upsilon\nu\dfrac{\pi}{4} = -\eta\mu\dfrac{\pi}{4} = \eta\mu\left(\pi + \dfrac{\pi}{4}\right)$, μια άλλη λύση της είναι ο αριθμός $\pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}$.
Άρα δυο κοινά σημεία της $C_f$ με τον $x'x$ είναι τα $\left(\dfrac{\pi}{4}, 0\right)$ και $\left(\dfrac{5\pi}{4}, 0\right)$.
\end{rlist}
\end{alist}
