\lysh{20943}{4}
\begin{alist}
\item Έχουμε: $\hm (\pi - x) = \hm  x$, $\hm (\pi + x) = -\hm  x$, $\syn (-x) = \syn  x$, επομένως:
\[A = \hm ^2 x + (-\hm  x)^2 + \syn ^2 x = \hm ^2 x + \hm ^2 x + \syn ^2 x = 1 + \hm ^2 x.\]
\item 
\begin{align*}
B &= \frac{\hm  x}{1 + \syn  x} + \frac{1 + \syn  x}{\hm  x} = \frac{\hm ^2 x + (1 + \syn  x)^2}{(1 + \syn  x)\hm  x} = \frac{\hm ^2 x + 1 + 2\syn  x + \syn ^2 x}{(1 + \syn  x)\hm  x} \\
&= \frac{2(1 + \syn  x)}{(1 + \syn  x)\hm  x} = \frac{2}{\hm  x}.
\end{align*}
\item Θα εξετάσουμε αν η εξίσωση $A = B$ δηλαδή $\hm ^2 x + 1 = \dfrac{2}{\hm  x} \quad (1)$ έχει λύση. \\
Θέτουμε $\hm  x = \omega$ και η εξίσωση $(1)$ μετασχηματίζεται στην $\omega^2 + 1 = \dfrac{2}{\omega} \quad (2)$. \\
Επειδή $\dfrac{3\pi}{2} < x < 2\pi$ είναι $-1 < \hm  x < 0$ δηλαδή $-1 < \omega < 0$. \\
Τότε: 
\begin{align*}
(2) &\Leftrightarrow \omega^3 + \omega = 2 \Leftrightarrow \omega^3 + \omega - 2 = 0 \Leftrightarrow \omega^3 - \omega + 2\omega - 2 = 0 \Leftrightarrow \\
&\omega(\omega^2 - 1) + 2(\omega - 1) = 0 \Leftrightarrow \omega(\omega - 1)(\omega + 1) + 2(\omega - 1) = 0 \Leftrightarrow \\
&(\omega - 1)[\omega(\omega + 1) + 2] = 0 \Leftrightarrow (\omega - 1)(\omega^2 + \omega + 2) = 0 \Leftrightarrow \\
&\omega - 1 = 0 \text{ ή } \omega^2 + \omega + 2 = 0 \Leftrightarrow \omega = 1 \text{ ή } \omega^2 + \omega + 2 = 0
\end{align*}
Η $\omega = 1$ απορρίπτεται λόγω του περιορισμού ενώ η εξίσωση $\omega^2 + \omega + 2 = 0$ έχει διακρίνουσα $\Delta = -7$, οπότε είναι αδύνατη. \\
Επομένως, δεν υπάρχουν τιμές του $x$ τέτοιες, ώστε $A = B$.
\end{alist}
