\item Η διαίρεση $P(x) : (x^2 - 4)$ φαίνεται παρακάτω
\begin{center}
\begin{tabular}{r|l}
$x^5 - 4x^3 - x^2 + \alpha x + \beta$ & $x^2 - 4$ \\ \cline{2-2}
$-x^5 + 4x^3 \phantom{{} - x^2 + \alpha x + \beta}$ & $x^3 - 1$ \\ \cline{1-1}
$-x^2 + \alpha x + \beta$ & \\
$x^2 \phantom{{} + \alpha x} - 4$ & \\ \cline{1-1}
$\alpha x + \beta - 4$ &
\end{tabular}
\end{center}

\item Από το α) ερώτημα έχουμε ότι το υπόλοιπο της διαίρεσης $P(x) : (x^2 - 4)$ είναι το πολυώνυμο $\alpha x + \beta - 4$. Όμως από την εκφώνηση δίνεται ότι είναι το πολυώνυμο $4x + 1$. Συνεπώς τα πολυώνυμα $\alpha x + \beta - 4$ και $4x + 1$ πρέπει να είναι ίσα, δηλαδή $\alpha = 4$ και $\beta = 5$.

\item Για $\alpha = 4$ και $\beta = 5$ έχουμε $P(x) = x^5 - 4x^3 - x^2 + 4x + 5$.
\begin{rlist}
\item Η ταυτότητα της διαίρεσης $P(x) : (x^2 - 4)$ είναι $P(x) = (x^2 - 4)(x^3 - 1) + 4x + 1$.
\item Αξιοποιώντας την ταυτότητα της διαίρεσης που βρήκαμε παραπάνω έχουμε
\[P(x) < 4x + 1 \Leftrightarrow (x^2 - 4)(x^3 - 1) + 4x + 1 < 4x + 1 \Leftrightarrow (x^2 - 4)(x - 1)(x^2 + x + 1) < 0.\]
Το πρόσημο του πολυωνύμου $\Pi(x) = (x^2 - 4)(x - 1)(x^2 + x + 1)$ φαίνεται στον παρακάτω πίνακα.
