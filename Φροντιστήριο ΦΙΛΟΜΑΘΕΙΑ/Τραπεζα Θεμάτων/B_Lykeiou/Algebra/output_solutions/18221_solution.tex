\begin{rlist}
\item Είναι $\text{AB} = \alpha - (-\alpha) = 2\alpha$. \\
Επειδή το $\Delta$ ανήκει στην παραβολή $y = 3 - x^2$ ισχύει $y_\Delta = 3 - x_\Delta^2 = 3 - \alpha^2$. Οπότε $\text{A}\Delta = y_\Delta - y_\text{A} = 3 - \alpha^2 - 0 = 3 - \alpha^2$. \\
Είναι $\text{E} = \text{AB}\cdot \text{A}\Delta = 2\alpha(3 - \alpha^2) = 6\alpha - 2\alpha^3$. \\
Επομένως για κάθε $\alpha \in (0, \sqrt{3})$ είναι $\text{E} = f(\alpha) = -2\alpha^3 + 6\alpha$.
\item Το ζητούμενο εμβαδό ισούται με $f(1) = -2\cdot 1^3 + 6\cdot 1 = 4$ τετ. μονάδες.
\end{rlist}

\item Για να αποδείξουμε ότι το εμβαδό E δεν μπορεί να ξεπεράσει τις $4$ τετραγωνικές μονάδες αρκεί να αποδείξουμε ότι $\text{E} \le 4$. \\
Έχουμε
\begin{align*}
\text{E} \le 4 &\Leftrightarrow -2\alpha^3 + 6\alpha \le 4 \\
&\Leftrightarrow 2\alpha^3 - 6\alpha + 4 \ge 0 \\
&\Leftrightarrow \alpha^3 - 3\alpha + 2 \ge 0 \quad (1) \\
&\Leftrightarrow (\alpha+2)(\alpha-1)^2 \ge 0 
\end{align*}
που ισχύει για κάθε $\alpha \in (0, \sqrt{3})$.
