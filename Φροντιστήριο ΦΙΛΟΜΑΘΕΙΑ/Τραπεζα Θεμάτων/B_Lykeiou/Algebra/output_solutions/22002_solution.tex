Αναγωγή στο $1^o$ τεταρτημόριο:

\begin{alist}
\item $\sigma\upsilon\nu 72^\circ = \sigma\upsilon\nu(90^\circ - 18^\circ) = \eta\mu 18^\circ = \dfrac{\sqrt{5} - 1}{4}$.

\item $\sigma\upsilon\nu 108^\circ = \sigma\upsilon\nu(90^\circ + 18^\circ) = -\eta\mu 18^\circ = \dfrac{1 - \sqrt{5}}{4}$.

\item $\eta\mu 162^\circ = \eta\mu(180^\circ - 18^\circ) = \eta\mu 18^\circ = \dfrac{\sqrt{5} - 1}{4}$.
\end{alist}
