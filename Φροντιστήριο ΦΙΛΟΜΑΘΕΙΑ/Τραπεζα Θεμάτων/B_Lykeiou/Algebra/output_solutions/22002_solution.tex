Αναγωγή στο $1^o$ τεταρτημόριο:
\begin{alist}
\item $\syn  72^\circ = \syn (90^\circ - 18^\circ) = \hm  18^\circ = \dfrac{\sqrt{5} - 1}{4}$.
\item $\syn  108^\circ = \syn (90^\circ + 18^\circ) = -\hm  18^\circ = \dfrac{1 - \sqrt{5}}{4}$.
\item $\hm  162^\circ = \hm (180^\circ - 18^\circ) = \hm  18^\circ = \dfrac{\sqrt{5} - 1}{4}$.
\end{alist}
