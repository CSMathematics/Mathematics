Άρα, η εξίσωση έχει μοναδική λύση $x = 1$.

\textbf{Εναλλακτική λύση:}
Οι ρίζες της εξίσωσης $f(x) = g(x)$ προκύπτουν από τις λύσεις της παρακάτω εξίσωσης
\[\sqrt{x + 3} = 3x - 1.\]
Η εξίσωση ορίζεται για $x \ge -3$ και $3x - 1 \ge 0 \Leftrightarrow x \ge \dfrac{1}{3}$.
$\sqrt{x + 3} = 3x - 1$ υψώνουμε και τα δυο μέλη στο τετράγωνο
\[\sqrt{x + 3}^2 = (3x - 1)^2 \Leftrightarrow x + 3 = 9x^2 - 6x + 1 \Leftrightarrow 9x^2 - 7x - 2 = 0.\]
Οι ρίζες του τριωνύμου είναι $1$ και $-\dfrac{2}{9}$. Από τις ρίζες αυτές διαπιστώνουμε με επαλήθευση ότι μόνο η $x = 1$ είναι δεκτή.
Άρα, μοναδική λύση της εξίσωσης $f(x) = g(x)$ είναι η $x = 1$.
