\begin{alist}
\item Έχουμε $P(x) = 0 \Leftrightarrow x^3 - x^2 - 2x = 0 \Leftrightarrow x(x^2 - x - 2) = 0$. Οπότε $x = 0$ ή $x^2 - x - 2 = 0$ που έχει $\varDelta = 9$ και ρίζες $x = -1$ και $x = 2$. Τελικά ρίζες της εξίσωσης $P(x) = 0$ είναι οι $x = 0$, $x = -1$ και $x = 2$.
\item Για να ορίζεται η εξίσωση, πρέπει $x > 0$. Θέτουμε $\ln x = \omega$ και η εξίσωση γίνεται $P(\omega) = 0$.
Από το α) ερώτημα έχουμε τις ρίζες $\omega = 0$, $\omega = -1$, $\omega = 2$. Οπότε προκύπτουν τρεις εξισώσεις:
\begin{rlist}
\item $\ln x = 0 \Leftrightarrow \ln x = \ln 1 \Leftrightarrow x = 1$ δεκτή.
\item $\ln x = -1 \Leftrightarrow \ln x = \ln e^{-1} \Leftrightarrow x = e^{-1}$ δεκτή.
\item $\ln x = 2 \Leftrightarrow \ln x = \ln e^2 \Leftrightarrow x = e^2$ δεκτή.
\end{rlist}
\item Η ανίσωση $x^3 - x^2 - 2x > 0 \Leftrightarrow P(x) > 0 \Leftrightarrow x(x^2 - x - 2) > 0$ αληθεύει για $x \in (-1, 0) \cup (2, +\infty)$, όπως φαίνεται στον παρακάτω πίνακα.

Οπότε για την ανίσωση $(\ln x)^3 - (\ln x)^2 - 2(\ln x) > 0 \Leftrightarrow P(\ln x) > 0$, προκύπτει ότι $\ln x \in (-1, 0) \cup (2, +\infty)$. Λύνουμε τις δύο ανισώσεις:
\begin{rlist}
\item $-1 < \ln x < 0 \Leftrightarrow \ln e^{-1} < \ln x < \ln 1 \overset{f\uparrow}{\iff} \dfrac{1}{e} < x < 1$
\item $2 < \ln x \Leftrightarrow \ln e^2 < \ln x \overset{f\uparrow}{\iff} e^2 < x$.
\end{rlist}
Τελικά $x \in \left(\dfrac{1}{e}, 1\right) \cup (e^2, +\infty)$.
\end{alist}
