\item Από το σχήμα παρατηρούμε ότι $\syn \theta = 0,8 = \dfrac{4}{5}$.
Εναλλακτικά, από τη βασική τριγωνομετρική ταυτότητα $\hm ^2\theta + \syn ^2\theta = 1$ παίρνουμε
$\left(\dfrac{3}{5}\right)^2 + \syn ^2\theta = 1$, άρα $\syn ^2\theta = 1 - \dfrac{9}{25} = \dfrac{16}{25}$ και καθώς η γωνία $\theta$ βρίσκεται στο 1ο τεταρτημόριο θα είναι $\syn \theta = \sqrt{\dfrac{16}{25}} = \dfrac{4}{5}$.
Αλλά $\varepsilon\phi\theta = \dfrac{\hm \theta}{\syn \theta} = \dfrac{\dfrac{3}{5}}{\dfrac{4}{5}} = \dfrac{3}{4}$.
