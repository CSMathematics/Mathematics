\begin{alist}
\item Από το σχήμα παρατηρούμε ότι $\sigma\upsilon\nu\theta = 0,8 = \dfrac{4}{5}$.
Εναλλακτικά, από τη βασική τριγωνομετρική ταυτότητα $\eta\mu^2\theta + \sigma\upsilon\nu^2\theta = 1$ παίρνουμε
$\left(\dfrac{3}{5}\right)^2 + \sigma\upsilon\nu^2\theta = 1$, άρα $\sigma\upsilon\nu^2\theta = 1 - \dfrac{9}{25} = \dfrac{16}{25}$ και καθώς η γωνία $\theta$ βρίσκεται στο 1ο τεταρτημόριο θα είναι $\sigma\upsilon\nu\theta = \sqrt{\dfrac{16}{25}} = \dfrac{4}{5}$.
Αλλά $\varepsilon\phi\theta = \dfrac{\eta\mu\theta}{\sigma\upsilon\nu\theta} = \dfrac{\dfrac{3}{5}}{\dfrac{4}{5}} = \dfrac{3}{4}$.

\item Γνωρίζουμε ότι είναι $B(\sigma\upsilon\nu\theta, \eta\mu\theta)$ και $\Gamma(1, \varepsilon\phi\theta)$. Έτσι έχουμε $B\left(\dfrac{4}{5}, \dfrac{3}{5}\right)$, $\Gamma\left(1, \dfrac{3}{4}\right)$.
