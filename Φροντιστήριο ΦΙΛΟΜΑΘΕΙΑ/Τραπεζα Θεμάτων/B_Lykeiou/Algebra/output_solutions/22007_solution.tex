Γνωρίζουμε ότι η γραφική παράσταση της συνάρτησης $\sigma\upsilon\nu x$ έχει ως εξής:

\begin{center}
\begin{tikzpicture}
\begin{axis}[
    axis lines=middle,
    xmin=-1.2*pi, xmax=2.5*pi,
    ymin=-1.2, ymax=1.2,
    xtick={-pi, -0.5*pi, 0, 0.5*pi, pi, 1.5*pi, 2*pi},
    xticklabels={$-\pi$, $-\frac{\pi}{2}$, $0$, $\frac{\pi}{2}$, $\pi$, $\frac{3\pi}{2}$, $2\pi$},
    ytick={-1, 0, 1},
    thick,
    width=10cm, height=5cm,
    samples=100
]
\addplot[domain=-pi:2.2*pi, maincolor, thick] {cos(deg(x))} node[pos=0.3, above right] {\small $y=\sigma\upsilon\nu x$};
\end{axis}
\end{tikzpicture}
\end{center}

Άρα:
\begin{alist}
\item $\alpha = -\dfrac{\pi}{2}$ και $\beta = \dfrac{3\pi}{2}$.

\item Αρκεί να μετατοπιστεί προς τα δεξιά κατά $\dfrac{\pi}{2}$. Το ίδιο αποτέλεσμα θα είχαμε αν πραγματοποιούσαμε μετατόπιση προς τα δεξιά κατά $2\pi + \dfrac{\pi}{2}$ (ή $4\pi + \dfrac{\pi}{2}$ ή $6\pi + \dfrac{\pi}{2}$ κ.λπ.) ή προς τα αριστερά κατά $\dfrac{3\pi}{2}$. Το ερώτημα επιδέχεται πολλές σωστές απαντήσεις, λόγω περιοδικότητας.

\begin{center}

\begin{axis}[
    axis lines=middle,
    xmin=-1.2*pi, xmax=2.5*pi,

    xticklabels={$-\pi$, $-\frac{\pi}{2}$, $0$, $\frac{\pi}{2}$, $\pi$, $\frac{3\pi}{2}$, $2\pi$},
    ytick={-1, 0, 1},
    thick,
    width=10cm, height=5cm,
    samples=100
]
\addplot[domain=-pi:2.2*pi, black, thick] {cos(deg(x))} node[pos=0.6, below] {\small $y=\sigma\upsilon\nu x$};
\addplot[domain=-1.2*pi:2.2*pi, densely dotted, gray, thick] {sin(deg(x))} node[pos=0.6, above right, black] {\small $y=\eta\mu x$};
\end{axis}
\end{tikzpicture}
\end{center}
\end{alist}
