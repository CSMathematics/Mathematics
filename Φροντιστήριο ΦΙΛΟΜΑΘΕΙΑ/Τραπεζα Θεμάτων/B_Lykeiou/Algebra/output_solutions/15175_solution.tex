\lysh{15175}{2}
\begin{alist}
\item Είναι $P(1) = 1^3 - 1^2 + 1 - 1 = 0$, άρα το 1 είναι μία ρίζα του πολυωνύμου.
\item Επιπλέον ισχύει ότι
\[1 \text{ ρίζα του } P(x) \Leftrightarrow x - 1 \text{ παράγοντας του } P(x)\]
Εφαρμογή του σχήματος Horner:
\begin{center}
\Horner[remainder=maincolor]{1,-1,1,-1}{1}
\end{center}
Επομένως ισχύει: $P(x) = (x - 1)(x^2 + 1)$.
Εναλλακτική απάντηση:
\[P(x) = x^3 - x^2 + x - 1 = x^2(x - 1) + (x - 1) = (x - 1)(x^2 + 1)\]
\item Είναι λοιπόν
\[P(x) = 0 \Leftrightarrow (x - 1)(x^2 + 1) = 0 \xLeftrightarrow{x^2+1\ne0} x = 1.\]
\end{alist}
