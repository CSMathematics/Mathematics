\lysh{15248}{2}
\begin{alist}
\item Από την ταυτότητα της διαίρεσης έχουμε
\[P(x) = (2x - 1)(x^2 - 2) + 1 = 2x^3 - 4x - x^2 + 2 + 1 = 2x^3 - x^2 - 4x + 3.\]
\item Με $P(x) = 2x^3 - x^2 - 4x + 3$
\begin{rlist}
\item Το σχήμα Horner για τη διαίρεση $P(x) : (x - 1)$ φαίνεται παρακάτω.
\begin{center}
\Horner[width=3em,remainder=maincolor]{2,-1,-4,3}{1}
\end{center}
Συνεπώς το $P(x)$ έχει ρίζα το $1$ και η ταυτότητα της διαίρεσης $P(x) : (x - 1)$ είναι
\[P(x) = (x - 1)(2x^2 + x - 3).\]
\item Έχουμε λοιπόν: $P(x) = 0 \Leftrightarrow (x - 1)(2x^2 + x - 3) = 0$ οπότε
\[x - 1 = 0 \text{ ή } 2x^2 + x - 3 = 0 \text{ δηλαδή } x = 1 \text{ ή } x = 1 \text{ ή } x = -\frac{3}{2}.\]
Τελικά $x = 1 \text{ (διπλή ρίζα) ή } x = -\dfrac{3}{2}$.
\end{rlist}
\end{alist}
