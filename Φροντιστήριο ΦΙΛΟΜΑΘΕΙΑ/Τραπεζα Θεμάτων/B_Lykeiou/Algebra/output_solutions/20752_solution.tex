\item Επειδή για το σημείο $M$ του τριγωνομετρικού κύκλου οι συντεταγμένες του είναι $M(\sigma\upsilon\nu\omega, \eta\mu\omega)$ για την αντίστοιχη γωνία $\omega$ που έχει τελική πλευρά OM, είναι φανερό ότι έχει άδικο ο Φίλιππος καθώς δεν υπάρχει γωνία $\omega$ με $\eta\mu\omega = 1$ και $\sigma\upsilon\nu\omega = 1$ καθώς τότε θα είχαμε $\eta\mu^2\omega + \sigma\upsilon\nu^2\omega = 1^2 + 1^2 = 1+1 = 2$, που είναι αδύνατο καθώς γνωρίζουμε ότι για κάθε γωνία $\omega$, ισχύει $\eta\mu^2\omega + \sigma\upsilon\nu^2\omega = 1$.

\begin{rlist}
\item Από το πρώτο ερώτημα συμπεραίνουμε ότι οι σωστές συντεταγμένες του σημείου M είναι $M(0,8, 0,6)$, επομένως $\sigma\upsilon\nu\omega = 0,8 = \dfrac{4}{5}$ διότι αποτελεί την τετμημένη του M και $\eta\mu\omega = 0,6 = \dfrac{3}{5}$ διότι αποτελεί την τεταγμένη του M.
\item Επίσης, $\varepsilon\varphi\omega = \dfrac{\eta\mu\omega}{\sigma\upsilon\nu\omega} = \dfrac{0,6}{0,8} = \dfrac{3}{4}$ και $\sigma\varphi\omega = \dfrac{\sigma\upsilon\nu\omega}{\eta\mu\omega} = \dfrac{0,8}{0,6} = \dfrac{4}{3}$. \\
Για την παράσταση A με αναγωγή στο πρώτο τεταρτημόριο έχουμε
\begin{align*}
\text{A} &= \eta\mu(\pi-\omega) - 2\sigma\upsilon\nu\left(\frac{\pi}{2}-\omega\right) + \varepsilon\varphi(-\omega) + \sigma\varphi(\pi+\omega) = \\
&= \eta\mu\omega - 2\eta\mu\omega - \varepsilon\varphi\omega + \sigma\varphi\omega = \\
&= -\eta\mu\omega - \varepsilon\varphi\omega + \sigma\varphi\omega = \\
&= -\frac{3}{5} - \frac{3}{4} + \frac{4}{3} = \\
&= -\frac{36}{60} - \frac{45}{60} + \frac{80}{60} = -\frac{1}{60}
\end{align*}
\end{rlist}

\item Για τις τιμές που βρήκαμε στο προηγούμενο ερώτημα η συνάρτηση $f$ γίνεται $f(x) = 5\cdot 0,8x^3 - 10\cdot 0,6x^2 + 5x - 3 = 4x^3 - 6x^2 + 5x - 3$. Ζητάμε τις λύσεις της ανίσωσης $f(x) < 0 \Leftrightarrow 4x^3 - 6x^2 + 5x - 3 < 0$. Με τη βοήθεια του σχήματος Horner βρίσκουμε ότι $4x^3 - 6x^2 + 5x - 3 = (x-1)(4x^2 - 2x + 3)$. \\
Επομένως, λύνουμε την ανίσωση $(x-1)(4x^2 - 2x + 3) < 0 \Leftrightarrow x-1 < 0 \Leftrightarrow x < 1$, αφού $4x^2 - 2x + 3 > 0$ για κάθε πραγματικό αριθμό $x$ καθώς εύκολα αποδεικνύεται ότι η διακρίνουσά του είναι αρνητική και δεν έχει ρίζες. Επομένως η γραφική παράσταση της συνάρτησης $f$ βρίσκεται κάτω από τον άξονα $x'x$ όταν $x<1$, δηλαδή στο διάστημα $(-\infty, 1)$.
