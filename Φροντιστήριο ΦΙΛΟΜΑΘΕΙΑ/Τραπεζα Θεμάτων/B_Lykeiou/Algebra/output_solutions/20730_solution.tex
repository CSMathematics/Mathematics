\begin{alist}
\item Η συνάρτηση $f$ ως λογαριθμική ορίζεται για $1 - x > 0$ τότε $x < 1$. \\
Επομένως, το πεδίο ορισμού της συνάρτησης $f$ είναι το $D_f = (-\infty, 1)$.

\item Θα χρησιμοποιήσουμε την ιδιότητα των λογαρίθμων για $x < 1$ και θα λύσουμε την λογαριθμική εξίσωση. \\
Άρα,
\begin{align*}
\ln(1 - x) = \ln(x^2 + 1) &\Leftrightarrow 1 - x = x^2 + 1 \\
&\Leftrightarrow -x = x^2 \\
&\Leftrightarrow x^2 + x = 0 \\
&\Leftrightarrow x(x + 1) = 0 \\
&\Leftrightarrow x = 0 \text{ ή } x = -1.
\end{align*}
Οι δύο λύσεις που βρήκαμε είναι δεκτές, διότι $x_1 = -1 < 1$ και $x_2 = 0 < 1$.
\end{alist}
