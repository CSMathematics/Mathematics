\lysh{15591}{4}
\begin{alist}
\item Για να ορίζεται η εκθετική συνάρτηση πρέπει η βάση
\[\frac{\alpha}{\alpha + 5} > 0 \Leftrightarrow \alpha(\alpha + 5) > 0 \Leftrightarrow \alpha \in (-\infty, -5) \cup (0, +\infty).\]
Επιπλέον πρέπει $\dfrac{\alpha}{\alpha + 5} \ne 1$. Όμως, αν $\dfrac{\alpha}{\alpha + 5} = 1 \Leftrightarrow \alpha = \alpha + 5 \Leftrightarrow 0 = 5$, το οποίο δε συμβαίνει για κανέναν πραγματικό αριθμό $\alpha$.
\item Για να είναι η συνάρτηση γνησίως αύξουσα πρέπει
\[\frac{\alpha}{\alpha + 5} > 1 \Leftrightarrow \frac{\alpha}{\alpha + 5} - 1 > 0 \Leftrightarrow \frac{\alpha - \alpha - 5}{\alpha + 5} > 0 \Leftrightarrow -\frac{5}{\alpha + 5} > 0 \Leftrightarrow \alpha + 5 < 0 \Leftrightarrow \alpha < -5.\]
\item Η συνάρτηση $f$ είναι γνησίως αύξουσα όταν $\alpha < -5$. \\
Η μεγαλύτερη ακέραια τιμή του $\alpha = -6$, για την οποία η συνάρτηση $f$ είναι εκθετική και γνησίως αύξουσα και γίνεται $f(x) = \left(\dfrac{-6}{-6 + 5}\right)^x = 6^x$. \\
Η εξίσωση γράφεται ισοδύναμα:
\begin{align*}
f(x) + f(x+1) = 14 &\Leftrightarrow 6^x + 6^{x+1} = 14 \\
&\Leftrightarrow 6^x + 6 \cdot 6^x = 14 \\
&\Leftrightarrow 7 \cdot 6^x = 14 \\
&\Leftrightarrow 6^x = 2 \\
&\Leftrightarrow x = \log_6 2.
\end{align*}
\end{alist}
