\begin{alist}
\item Χρησιμοποιώντας ιδιότητες λογαρίθμων, έχουμε:
\[A = 2\log 6 - \log 12 = \log 6^2 - \log 12 = \log 36 - \log 12 = \log\frac{36}{12} = \log 3\]
\[B = \log 5 + \log 2 = \log(5\cdot 2) = \log 10 = 1\]

\item Είναι:
\[A < B \Leftrightarrow \log 3 < 1 \Leftrightarrow \log 3 < \log 10 \overset{\log x \uparrow}{\Longleftrightarrow} 3 < 10\]
Επομένως, αποδείξαμε την ζητούμενη σχέση.

\item Η ανίσωση αυτή ορίζεται εφόσον $x > 0$. Τότε έχουμε ισοδύναμα:
\[\log x < 1 \Leftrightarrow \log x < \log 10 \overset{\log x \text{ γν.\ αύξουσα}}{\Longleftrightarrow} x < 10.\]
Επομένως, είναι $0 < x < 10$.
\end{alist}
