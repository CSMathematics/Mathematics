# Workflow: Math Docs to LaTeX

Το παρακάτω workflow περιγράφει τη βέλτιστη διαδικασία για τη μετατροπή μαθηματικών ασκήσεων από μορφή Word/PDF σε κώδικα LaTeX (συμπεριλαμβανομένων καθαρών μαθηματικών τύπων και σχεδίων PGFPlots).

### Προαπαιτούμενα
- Βεβαιώσου ότι βρίσκεσαι στον φάκελο του project (π.χ. `1_1_5/`). 
- Όλα τα scripts βρίσκονται πλέον συγκεντρωμένα στον φάκελο `scripts/math_conversion/`. Ενθαρρύνεται να καλείς τα scripts από τον ριζικό φάκελο (π.χ. `python scripts/math_conversion/doc2latex.py`).

---

### Βήμα 1: Λήψη Αρχείων (Προαιρετικό)
1. Αν έχεις λίστα με IDs ασκήσεων, εκτέλεσε το `download_docs.py` (συνδέεται με το Τράπεζα Θεμάτων και κατεβάζει εκφωνήσεις / λύσεις).

### Βήμα 2: Αρχική Μετατροπή .doc σε LaTeX
1. Εκτέλεσε το script `python scripts/math_conversion/doc2latex.py`.
2. Το script θα σαρώσει τον τρέχοντα φάκελο για αρχεία `.doc`, θα τα διαβάσει μέσω `pandoc` και θα τα γράψει στον φάκελο `output_tex/`. 
3. Το απλό κείμενο θα έχει μετατραπεί σωστά. Τα μαθηματικά της μορφής MathType θα αποθηκευτούν ως placeholders εικόνων μέσα στο LaTeX (π.χ., `\includegraphics[height=1.2em]{...image1.pdf}`).

### Βήμα 3: Καθαρισμός Κατάλοιπων Διαμόρφωσης (Λίστες & Μονάδες)
Μετά την αρχική μετατροπή μέσω Pandoc, εκτέλεσε τα εξής scripts για να διορθώσεις δομικά στοιχεία:
1. `python scripts/math_conversion/fix_lists.py`: Επιδιορθώνει αυτόματα τις λίστες `alist`, `rlist` και `itemize` αναδιαμορφώνοντας εσφαλμένα bullets (π.χ. `α)`, `i.`) και ανοίγοντας/κλείνοντας τα σωστά περιβάλλοντα LaTeX.
2. `python scripts/math_conversion/replace_monades.py`: Κανονικοποιεί και μετατρέπει το plain text "Μονάδες X+Y" στη macro μορφή `\monades{X+Y}` για σωστή απεικόνιση μέσα στις ασκήσεις.

### Βήμα 4: Εξαγωγή Καθαρών Μαθηματικών από PDFs
Επειδή δεν κάνουμε OCR τις εικόνες των εξισώσεων:
1. Δημιούργησε ένα φάκελο `extracted/`.
2. Χρησιμοποίησε ένα εργαλείο όπως το `pdftotext` στα αντίστοιχα `.pdf` των ασκήσεων για να δημιουργήσεις αρχεία `.txt` μέσα στον `extracted/` φάκελο (εκεί οι μαθηματικοί τύποι ξεχωρίζουν ως inline κείμενο, πιθανώς με ειδικά σύμβολα Symbol/Unicode).
3. (Προαιρετικά) Τρέξε το `python scripts/math_conversion/transcribe_math.py` για να βοηθήσεις στην χαρτογράφηση ειδικών Symbol font χαρακτήρων (π.χ. `` → `\alpha`).

### Βήμα 5: Μαζική Αντικατάσταση τύπων (Μέσω AI Agent)
Ζήτησε από τον Agent να τρέξει Batch Processing:
- "Πάρε τα 20 επόμενα αρχεία στο `output_tex/`. Συρράφοντας τα `extracted/*.txt` txt αρχεία τους, φρόντισε να μετατρέψεις όλα τα \includegraphics tags σε καθαρό κώδικα `$...$` στο LaTeX."
- Ο Agent θα χρησιμοποιήσει το `multi_replace_file_content` εργαλείο, προσομοιάζοντας τις εξισώσεις και γράφοντας τα σωστά όρια ριζών, κλασμάτων και απολύτων.

### Βήμα 6: Παραγωγή Σχημάτων (TikZ / PGFPlots)
1. Τρέξε το script `python scripts/math_conversion/scan_diagrams.py`.
2. Αυτό θα σου παραγάγει ένα report με το ποια αρχεία περιέχουν ακόμα `TODO: Μετατροπή σχήματος` μαζί με τις συναρτήσεις ($f(x)$, $g(x)$) της καθεμιάς.
3. Ανάθεσε τις ασκήσεις αυτές (μία μία ή σε μικρά γκρουπ) στον PGFPlots Agent, με ένα prompt τύπου: *"Φτιάξε μου το TikZ/PGFPlots σχήμα για την άσκηση ΧΧΧ. Η εκφώνηση δίνει τη συνάρτηση f(x) = ... "*
4. Επικόλλησε τον παραγόμενο κώδικα στη θέση του `TODO` block.

### Βήμα 7: Τελική Σύνθεση Εγγράφου (Building)
1. Μόλις ολοκληρωθούν επιτυχώς οι μετατροπές σε όλα τα αρχεία του `output_tex/`, εκτέλεσε το συγκεντρωτικό script:
   `python scripts/math_conversion/build_trapeza.py`
2. Το εργαλείο θα συλλέξει αυτόματα όλα τα καθαρισμένα αρχεία `.tex` (δίνοντας πάντα προτεραιότητα σε αρχεία τύπου `_tikz.tex` αν περιέχουν παραγόμενα σχήματα).
3. Θα τα ταξινομήσει αριθμητικά, θα αφαιρέσει τα βοηθητικά header, και θα τα ενσωματώσει ως μία ενιαία συλλογή στο τελικό master έγγραφο (`trapeza_BL_algebra.tex`).

---
**Tip:** *Για την καλύτερη δυνατή συνεργασία, χώρισε το Βήμα 4 σε φάσεις (π.χ. Batches των 50 ασκήσεων) και έλεγχε την ευθυγράμμιση κειμένου-μαθηματικών για τα πρώτα αρχεία (Pilot phase).*
