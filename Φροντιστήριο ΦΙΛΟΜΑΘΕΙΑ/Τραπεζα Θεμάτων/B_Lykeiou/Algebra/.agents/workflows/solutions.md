# Workflow: Solutions (PDF) Docs to LaTeX

Το παρακάτω workflow περιγράφει τη διαδικασία για τη μετατροπή των **Λύσεων** από τη μορφή `_SOLUTION.pdf` σε κώδικα LaTeX, εφόσον δεν παρέχεται το αντίστοιχο Word document (`.doc`). 

Αυτή η διαδικασία βασίζεται άμεσα στην τεχνολογία οπτικής αναγνώρισης και ανάγνωσης μέσω AI, εφόσον δεν υπάρχει βασικό κείμενο από το Word για δομή. Τα scripts βρίσκονται στον φάκελο `scripts/solutions_conversion/`.

### Προαπαιτούμενα
- Τα αρχεία `XXXXX_SOLUTION.pdf` πρέπει να βρίσκονται στον αρχικό φάκελο (π.χ. `1_1_5/`). 

---

### Βήμα 1: Εξαγωγή Καθαρού Κειμένου από τα PDF (pdftotext)
Δεδομένου ότι το κείμενο είναι "κλειδωμένο" στα PDF, εξάγουμε ό,τι μπορεί να διαβάσει η γραμμή εντολών.
1. Τρέξε το script `python scripts/solutions_conversion/extract_solutions_txt.py`.
2. Το εργαλείο θα σαρώσει τον φάκελο για αρχεία `*SOLUTION.pdf`.
3. Θα εξαγάγει το κείμενο μέσω `pdftotext` (το οποίο περιέχει τις μαθηματικές εκφράσεις ως "σπασμένα" Symbol fonts) μέσα στον φάκελο `extracted_solutions/` ως `.txt` αρχεία.
4. Θα συμπεριλάβει ένα βασικό parsing που διορθώνει τη χαρτογράφηση Symbol/Unicode ➡️ LaTeX equivalents, καθαρίζοντας τα κενά. 

### Βήμα 2: AI OCR & LaTeX Transcription
Μόλις έχεις τα `.txt` αρχεία λύσεων (τα οποία έχουν τον μαθηματικό σκελετό, αλλά υστερούν ίσως σε ποιότητα format λόγω της pdf εξαγωγής), αναθέτεις στον Agent την τελική μεταγραφή σε LaTeX.

**Εντολή στον Agent:**
- "Διάβασε τα αρχεία κειμένου από τον φάκελο `extracted_solutions/`. Χρησιμοποίησε τα ως οδηγό και βλέποντας τον κώδικα του `XXXXX_SOLUTION.pdf` (Vision), δημιούργησε απευθείας το καθαρό αρχείο `output_solutions/XXXXX_solution.tex` περιέχοντας το text και τους `$...$` τύπους σε τέλεια μορφή LaTeX."
*Σημείωση:* Σε αντίθεση με τις εκφωνήσεις, ο Agent *δεν* θα διορθώνει placeholders, αλλά θα δημιουργεί το νέο αρχείο `.tex` εξ αρχής χρησιμοποιώντας το hint text και την εικόνα του PDF.

### Βήμα 3: Τελική Σύνθεση Εγγράφου ลύσεων (Building)
1. Μόλις το AI έχει δημιουργήσει επιτυχώς τα `output_solutions/*.tex` αρχεία, εκτέλεσε το script:
   `python scripts/solutions_conversion/build_trapeza_solutions.py`
2. Το script θα πάρει κάθε παραγόμενο λυμένο `.tex`, θα ταξινομήσει αριθμητικά τα IDs και θα τα ενσωματώσει σειριακά σε ένα ενιαίο έγγραφο λύσεων (`trapeza_BL_algebra_solutions.tex`).
