Δίνεται το πολυώνυμο $P(x) = \alpha x^3 + \beta x^2 - \beta x + 3, \ \alpha, \beta \in \mathbb{R}$. Αν είναι γνωστό ότι έχει ρίζα τον αριθμό $2$, τότε:
\begin{alist}
\item Να αποδείξετε ότι τουλάχιστον ένας συντελεστής του δεν είναι ακέραιος.
\monades{7}
Αν επιπλέον $P(1) = 0$, τότε:
\item Να αποδείξετε ότι $\alpha = -3$ και $\beta = \frac{21}{2}$.
\monades{6}
\item Να λύσετε την ανίσωση $P(x) \le 0$.
\monades{6}
\item Να λύσετε την εξίσωση $P(\syn  x) = 0$.
\monades{6}
\end{alist}
