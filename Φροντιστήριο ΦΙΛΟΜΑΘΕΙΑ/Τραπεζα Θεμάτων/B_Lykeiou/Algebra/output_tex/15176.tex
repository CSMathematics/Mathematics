ΘΕΜΑ 2

Δίνεται το πολυώνυμο $P(x) = x^{3} - 2x^{2} + 3\ x - 2$.

\begin{alist}
\item Να αποδείξετε ότι το $x - 1\ $ είναι παράγοντας του πολυωνύμου.

\monades{12}

\item Αν $P(x) = (x - 1\ ) \bullet (x^{2} - x + 2)$, να βρείτε για ποιες τιμές του $x$ είναι $P(x) > 0$.

\monades{13}
\end{alist}
