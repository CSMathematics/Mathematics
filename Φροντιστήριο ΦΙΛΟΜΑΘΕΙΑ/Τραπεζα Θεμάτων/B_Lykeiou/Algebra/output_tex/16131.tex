\begin{ylh}{1}
\item 3.4 Οι τριγωνομετρικές συναρτήσεις
\end{ylh}
Θεωρούμε τη συνάρτηση $f(x) = \ef  x$, $x \in R\  - \ \left\{ k\pi + \frac{\pi}{2} \right\}$, όπου $k \in Z$.
\begin{alist}
\item Να λύσετε την εξίσωση $f(x) = 1$ στο διάστημα $(0,\ 2\pi)$.
\monades{15}
\item Να μεταφέρετε στο γραπτό σας το παρακάτω σχήμα, στο οποίο να παραστήσετε τις λύσεις της παραπάνω εξίσωσης.
\monades{10}
