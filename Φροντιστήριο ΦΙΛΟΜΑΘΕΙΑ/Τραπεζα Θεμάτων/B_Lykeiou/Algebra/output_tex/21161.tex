\begin{ylh}{1}
\item 3.1 Τριγωνομετρικοί Αριθμοί Γωνίας
\end{ylh}
Σε έναν κύκλο ακτίνας ρ θεωρούμε ένα τόξο $AB$ με μήκος ίσο με 2ρ.
\begin{alist}
\item Να βρείτε πόσα ακτίνια είναι η αντίστοιχη στο τόξο ΑΒ, επίκεντρη γωνία ω.
\monades{13}
\item Αν ω=2 ακτίνια, να βρείτε πόσες μοίρες είναι η γωνία ω.
\monades{12}
\end{alist}
