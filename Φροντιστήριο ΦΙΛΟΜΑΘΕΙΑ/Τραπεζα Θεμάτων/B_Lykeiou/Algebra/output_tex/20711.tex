\Askhsh{20711}{2}
\begin{ylh}{1}
\item 5.2 Λογάριθμοι
\end{ylh}
Δίνονται οι αριθμοί $\alpha = \log 3$ και $\beta = \log 4$.
\begin{alist}
\item Να αιτιολογήσετε γιατί $0 < \alpha < \beta$.
\monades{12}
\item Να αποδείξετε ότι :
\begin{rlist}
\item $\beta + \alpha > 1$ .
\monades{6}
\item $\ln\frac{\alpha}{\beta} < 0$ .
\monades{7}
\end{rlist}
\end{alist}
