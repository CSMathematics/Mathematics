Δίνεται η παράσταση $A = \sigma\upsilon\nu^2 x - \eta\mu^2 x$.

\begin{alist}
\item Να βρείτε την τιμή της παράστασης $A$ για $x = 0$.

\monades{7}

\item Να δείξετε ότι $A = 1 - 2\eta\mu^2 x$.

\monades{9}

\item Με χρήση της παρακάτω γραφικής παράστασης της συνάρτησης με τύπο $1 - 2\eta\mu^2 x$ και του ερωτήματος β), να λύσετε την εξίσωση $A = 1$, για $0 < x < 2\pi$.

\monades{9}
