\begin{ylh}{1}
\item 4.1 Πολυώνυμα
\end{ylh}
Δίνονται τα πολυώνυμα:
$P(x) = -2x^3 + 4x^2 + 2(x^3 - 1) + 9$ και $Q(x) = \alpha x^2 + 7$, $\alpha \in \mathbb{R}$.
\begin{alist}
\item Είναι το πολυώνυμο $P(x)$ 3ου βαθμού; Να αιτιολογήσετε την απάντησή σας.
\monades{13}
\item Να βρείτε την τιμή του $\alpha$, ώστε τα πολυώνυμα $P(x)$ και $Q(x)$ να είναι ίσα.
\monades{12}
\end{alist}
