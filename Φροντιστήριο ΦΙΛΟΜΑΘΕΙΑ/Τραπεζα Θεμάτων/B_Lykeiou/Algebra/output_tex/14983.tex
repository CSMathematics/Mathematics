ΘΕΜΑ 2

Στο παρακάτω σχήμα δίζεται η γραφική παράσταση της συνάρτησης $g(x) = \frac{1}{3}x^{2}$, $x \in R$ και η γραφική παράσταση της συνάρτησης $f(x)$ η οποία προκύπτει από μία οριζόντια μετατόπιση της $g(x)$ κατά 3 μονάδες προς τα δεξιά και μετά κατά μία μονάδα προς τα πάνω.

\begin{alist}
\item Να επιλέξετε την σωστή απάντηση όσον αφορά τον τύπο της $f(x)$.

(I) $f(x) = g(x\  + \ 3) + 1$. (II) $f(x) = g(x\  + 3) - 1$. (III) $f(x) = g(x\  - \ 3) + 1$.

(IV) $f(x) = g(x\  - \ 3) - 1$.

\monades{9}

\item Να βρείτε την ελάχιστη τιμή της συνάρτησης $f(x)$ και την θέση ελαχίστου.

\monades{8}

\item Να γράψετε τα διαστήματα στα οποία η συνάρτηση $f(x)$ είναι γνησίως αύξουσα ή γνησίως φθίνουσα.

\begin{center}
\begin{tikzpicture}[scale=0.5, >=latex]
    \draw[very thin, color=green!40] (-10.5,-1.5) grid (20.5,13.5);
    \draw[->, thick] (-10.5,0) -- (20.5,0) node[right] {$x$};
    \draw[->, thick] (0,-1.5) -- (0,13.5) node[above] {$y$};

    \node[below left, font=\small] at (0,0) {$0$};
    
    % g(x) = 1/3 * x^2
