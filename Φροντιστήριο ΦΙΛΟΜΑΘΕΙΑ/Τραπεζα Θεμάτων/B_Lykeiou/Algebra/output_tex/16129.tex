\item 2.1 Μονοτονία-Ακρότατα-Συμμετρίες Συνάρτησης
\end{ylh}
Στο παρακάτω σχήμα δίνεται η γραφική παράσταση μιας συνάρτησης $f(x)$.

\begin{center}
\begin{tikzpicture}[scale=0.8, >=latex]
    % Grid
    \draw[very thin, color=gray!30] (-4.5,-1.5) grid (4.5,4.5);
    % Axes
    \draw[->, thick] (-4.7,0) -- (4.7,0) node[right] {$x$};
    \draw[->, thick] (0,-1.7) -- (0,4.7) node[above] {$y$};
    % Ticks
    \foreach \x in {-4,-3,-2,-1,1,2,3,4}
        \draw (\x, 1pt) -- (\x, -1pt) node[below, font=\small] {$\x$};
    \foreach \y in {-1,1,2,3,4}
        \draw (1pt, \y) -- (-1pt, \y) node[left, font=\small] {$\y$};
    \node[below left] at (0,0) {$0$};
    % Function: upper semicircle y = sqrt(9 - x^2)
    \draw[very thick, color=maincolor, samples=100, domain=-3:3] plot (\x, {sqrt(9 - \x^2)});
    % Points
    \filldraw[maincolor] (-3,0) circle (2pt) node[above left, black] {$A$};
    \filldraw[maincolor] (3,0) circle (2pt) node[above right, black] {$B$};
    \filldraw[maincolor] (0,3) circle (2pt) node[above right, black] {$\Gamma$};
\end{tikzpicture}
\end{center}
