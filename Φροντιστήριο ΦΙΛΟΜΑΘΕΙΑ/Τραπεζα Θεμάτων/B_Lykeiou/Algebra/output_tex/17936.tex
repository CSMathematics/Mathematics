\item 3.3 Αναγωγή στο 1o Τεταρτημόριο

Στον παρακάτω τριγωνομετρικό κύκλο δίνεται η γωνία $\widehat{AOZ} = \theta$.
\begin{center}
\begin{tikzpicture}[scale=2, >=latex]

    \draw[->] (0,-1.2) -- (0,1.2) node[above] {$y$};

    \node[below left] at (0,0) {$O$};

    \node[above right] at (A) {$A$};
    % Point Z such that cos(theta) = 0.4 => theta approx 66.42 deg
    \coordinate (Z) at (66.42:1);
    \draw[thick] (0,0) -- (Z);
    \node[above right] at (Z) {$Z$};
    % Angle theta
    \draw (0.3,0) arc (0:66.42:0.3);
    \node at (33.21:0.45) {$\theta$};
    % Coordinate projection for cos(theta)=0.4
    \draw[dashed] (Z) -- (0.4,0) node[below] {$0,4$};
    \filldraw (0.4,0) circle (0.5pt);

\monades{9}
\end{rlist}
