\item 5.3 Λογαριθμική συνάρτηση
\end{ylh}
Δίνεται η συνάρτηση $f(x) = \ln(x + 1)$.
\begin{alist}
\item Να βρείτε το πεδίο ορισμού της.
\monades{7}
\item Να εξετάσετε αν η γραφική της παράσταση διέρχεται από το σημείο $O(0, 0)$.
\monades{8}
\item Να λύσετε την εξίσωση $f(x) = 2$.
\monades{10}
\end{alist}
