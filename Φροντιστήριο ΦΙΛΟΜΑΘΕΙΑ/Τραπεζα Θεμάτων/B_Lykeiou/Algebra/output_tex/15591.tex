\begin{alist}
\item Να βρείτε τις τιμές του $a \in {\mathbb{R}},$ για τις οποίες η συνάρτηση $f$ είναι εκθετική και ορίζεται στους πραγματικούς αριθμούς.

\monades{8}

\item Να βρείτε τις τιμές του $a \in {\mathbb{R}},$ για τις οποίες η συνάρτηση $f$ είναι γνησίως αύξουσα.

\monades{8}

\item Για τη μεγαλύτερη τιμή του $a \in {\mathbb{Z}}$ για την οποία η συνάρτηση $f$ είναι γνησίως αύξουσα εκθετική με βάση ακέραιο αριθμό, να λύσετε την εξίσωση:

$f(x) + f(x + 1) = 14$
