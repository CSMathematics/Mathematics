Το εμβαδόν του τριγώνου ΟΑΜ που βλέπετε στο παρακάτω σχήμα είναι $(\text{OAM}) = \frac{4}{6}$ τετραγωνικές μονάδες. Η ευθεία ε είναι εφαπτόμενη στον κύκλο στο σημείο Α.
\begin{alist}
\item Να αποδείξετε ότι για τη γωνία $\omega = \overset{\hat{}}{\text{ΑΟΜ}}$ ισχύει $\text{εφω} = \frac{4}{3}\ ,\ 0 < \omega < \frac{\pi}{2}$.
\monades{08}
\item Να υπολογίσετε τους τριγωνομετρικούς αριθμούς $\text{ημω}$, $\text{συνω}$, $\text{σφω}$ της γωνίας $\omega = \overset{\hat{}}{\text{ΑΟΜ}}$ αν ισχύει$0 < \omega < \frac{\pi}{2}$.
\monades{08}
\item Να βρείτε τα σημεία τομής της γραφικής παράστασης της συνάρτησης $f(x) = \text{ημ}^{2}x - 5\text{ημω} \cdot \text{ημ}x + 5\text{συνω}$ και του άξονα x΄x, όπου$\omega = \overset{\hat{}}{\text{ΑΟΜ}}$ η γωνία του προηγούμενου ερωτήματος και $x \in R$.
\monades{09}
