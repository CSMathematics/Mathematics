ΘΕΜΑ 3

Έστω μια συνάρτηση $f$ με πεδίο ορισμού το διάστημα $[-1, 1]$, η οποία είναι περιττή και γνησίως φθίνουσα.

\begin{alist}
\item Από τις παρακάτω γραφικές παραστάσεις μόνο μία μπορεί να είναι η γραφική παράσταση της $f$. Να βρείτε ποια είναι αιτιολογώντας την απάντησή σας.

\monades{8}

\item Να σχεδιάσετε τη γραφική παράσταση της συνάρτησης $g(x) = f(x) + 2$

\monades{5}

\item Να σχεδιάσετε τη γραφική παράσταση της συνάρτησης $h(x) = f(x - 1)$

\monades{5}

\item Να σχεδιάσετε τη γραφική παράσταση της συνάρτησης $s(x) = e^x - 1$ και να αποδείξετε (αλγεβρικά ή γραφικά) ότι η εξίσωση $s(x) = f(x)$ έχει μοναδική λύση τη $x = 0$.

\monades{7}
