\item 5.3 Λογαριθμική συνάρτηση
\end{ylh}
Δίνεται η συνάρτηση $f(x) = logx$, $x > 0$.
\begin{alist}
\item Να υπολογίσετε τους αριθμούς $f(100)$, $f\left( \sqrt{10} \right)$
\monades{12}
\item Για $x > 1$, να επιλύσετε την εξίσωση $f(x + 1) + f(x - 1) = log10\  - \ log5$.
\monades{13}
\end{alist}
