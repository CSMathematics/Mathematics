ΘΕΜΑ 4

Δίνεται η συνάρτηση $f(x) = \frac{1}{2} \ln x^2, x \neq 0$.

\begin{alist}
\item Να αποδείξετε ότι η γραφική της παράσταση είναι συμμετρική ως προς τον άξονα $y'y$.

\monades{5}

\item Να αποδείξετε ότι για κάθε $x > 0$ ισχύει $f(x) = \ln x$.

\monades{6}

\item Να σχεδιάσετε τη γραφική παράσταση της $f(x) = \frac{1}{2} \ln x^2, x \neq 0$.

\monades{7}

\item Να βρείτε για ποιες τιμές του x η γραφική της παράσταση είναι κάτω από την ευθεία $y = 2$.

\monades{7}
\end{alist}
