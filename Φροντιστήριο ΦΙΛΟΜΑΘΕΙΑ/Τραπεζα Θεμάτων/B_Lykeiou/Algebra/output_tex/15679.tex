ΘΕΜΑ 4

Δίνεται η παράσταση $A = \ln\left(\frac{e^{2x} - 1}{e^x - 3}\right)$.

\begin{alist}
\item Να λύσετε την ανίσωση $\frac{\omega^2 - 1}{\omega - 3} > 0$.

\monades{8}

\item Να βρείτε για ποιες τιμές του $x$ ορίζεται η παράσταση $A$.

\monades{8}

\item Να λύσετε την εξίσωση $A = -\ln 3$.

\monades{9}
\end{alist}
