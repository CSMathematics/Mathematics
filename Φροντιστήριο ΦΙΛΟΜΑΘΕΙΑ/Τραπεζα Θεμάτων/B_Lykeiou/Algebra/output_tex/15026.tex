ΘΕΜΑ 4

Δίνεται η συνάρτηση $f(x) = 1 + 2\eta\mu\left(\frac{\pi x}{2}\right)$, $x \in \mathbb{R}$.

\begin{alist}
\item Να βρείτε την περίοδο της συνάρτησης $f$.

\monades{5}

\item Να βρείτε τα ακρότατα της συνάρτησης $f$.

\monades{6}

\item Να βρείτε τις τετμημένες των σημείων στα οποία η γραφική παράσταση της $f$ τέμνει τον άξονα $x'x$.

\monades{7}

\item Να αποδείξετε ότι $(f(x) - 1)^2 + (f(1-x) - 1)^2 = 4$, για κάθε $x \in \mathbb{R}$.

\monades{7}
\end{alist}
