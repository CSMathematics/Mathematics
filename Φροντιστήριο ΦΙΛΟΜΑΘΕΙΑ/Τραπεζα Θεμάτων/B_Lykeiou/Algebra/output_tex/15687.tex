\item 5.2 Λογάριθμοι
\end{ylh}
Δίνεται η παράσταση $A = \log_4 3 + \log_4 \alpha - \log_4 \beta$, όπου α, β θετικοί αριθμοί.
\begin{alist}
\item Να αποδείξετε ότι $A = \log_4 \frac{3\alpha}{\beta}$
\monades{13}
\item Αν για τους αριθμούς α, β ισχύει $3\alpha = 16\beta$, να βρείτε την τιμή της παράστασης Α.
\monades{12}
\end{alist}
