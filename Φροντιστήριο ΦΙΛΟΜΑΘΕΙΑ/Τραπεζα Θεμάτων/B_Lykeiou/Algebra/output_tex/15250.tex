\begin{ylh}{1}
\item 4.2 Διαίρεση πολυωνύμων
\item 4.3 Πολυωνυμικές εξισώσεις και ανισώσεις
\end{ylh}
Δίνεται το πολυώνυμο $P(x) = x^5 - 4x^3 - x^2 + \alpha x + \beta$ το οποίο διαιρούμενο με το $x^2 - 4$ δίνει υπόλοιπο $4x + 1$.
\begin{alist}
\item Να κάνετε τη διαίρεση $P(x) : (x^2 - 4)$.
\monades{7}
\item Να βρείτε τις τιμές των $\alpha$ και $\beta$.
\monades{7}
\item Έστω $\alpha = 4$ και $\beta = 5$. Αν το πηλίκο της διαίρεσης $P(x) : (x^2 - 4)$ είναι το $\pi(x) = x^3 - 1$, τότε:
\begin{rlist}
\item να γράψετε την ταυτότητα της διαίρεσης $P(x) : (x^2 - 4)$.
\monades{4}
\item να λύσετε την ανίσωση $P(x) < 4x + 1$.
\monades{7}
\end{rlist}
\end{alist}
