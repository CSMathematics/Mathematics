ΘΕΜΑ 2

Δίνεται το πολυώνυμο $P(x) = 3x^3 - x^2 - x + 2$.

\begin{alist}
\item Να κάνετε τη διαίρεση $P(x) : (x - 1)$ και να γράψετε την ταυτότητα της διαίρεσης.

\monades{10}

\item Αν $P(x) = (x - 1)(3x^2 + 2x + 1) + 3$ να λύσετε την ανίσωση $P(x) < 3$.

\monades{15}
\end{alist}
