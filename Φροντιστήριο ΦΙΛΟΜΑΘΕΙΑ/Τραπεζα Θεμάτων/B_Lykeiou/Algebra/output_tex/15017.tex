\begin{ylh}{1}
\item 2.1 Μονοτονία-Ακρότατα-Συμμετρίες Συνάρτησης
\end{ylh}
Μία συνάρτηση $f$ με πεδίο ορισμού το διάστημα $(\alpha, 3)$ είναι άρτια και η γραφική της παράσταση διέρχεται από το σημείο $(2, 2)$.
\begin{alist}
\item Να βρείτε την τιμή του $\alpha$.
\monades{7}
\item Να βρείτε το $f(-2)$.
\monades{8}
\item Στο παρακάτω σχήμα δίνεται η γραφική παράσταση της συνάρτησης $f$ στο διάστημα $[0, 3)$. Να σχεδιάσετε τη γραφική παράσταση της $f$ στο πεδίο ορισμού της.
\begin{center}
\begin{tikzpicture}
\begin{axis}[
    axis lines = middle,
    xlabel = {$x$},
    ylabel = {$y$},
    xmin = -3.5, xmax = 3.5,
    ymin = -0.5, ymax = 3.5,
    xtick = {-3,-2,-1,1,2,3},
    ytick = {1,2,3},
    grid = both,
    grid style = {gray!30},
    samples = 150,
    width = 10cm, height = 6cm,
    tick label style = {font=\small},
    every axis x label/.style = {at={(current axis.right of origin)}, anchor=north west},
    every axis y label/.style = {at={(current axis.above origin)}, anchor=south east},
]
    \addplot[very thick, maincolor, domain=0:3] {x};
    \addplot[only marks, mark=*, mark size=2pt, maincolor] coordinates {(2,2)} node[below right] {\tiny $(2,2)$};
    \addplot[thick, dashed, secondarycolor, domain=-3:0] {-x};
    \addplot[only marks, mark=*, mark size=2pt, secondarycolor] coordinates {(-2,2)} node[below left] {\tiny $(-2,2)$};
\end{axis}
\end{tikzpicture}
\end{center}
\monades{10}
\end{alist}
