ΘΕΜΑ 4

Δίνονται οι συναρτήσεις $f(x) = \rho\ \eta\mu x$, $g(x) = \eta\mu(\omega x)$, όπου $\rho,\omega > 0.$

\begin{alist}
\item Να βρεθούν οι τιμές των $\rho,\omega$, αν είναι γνωστό ότι η ελάχιστη τιμή της $f$ είναι $- 2$ και η περίοδος της $g$ είναι $\pi$. Να αιτιολογήσετε τις απαντήσεις σας.

\monades{6}

\item

\end{alist}
\begin{alist}
\item
  Να κάνετε, στο ίδιο σύστημα αξόνων, τις γραφικές παραστάσεις των συναρτήσεων $f(x) = 2\eta\mu x,\ x \in \lbrack 0,\pi\rbrack$ και $g(x) = \eta\mu(2x)$, $x \in \lbrack 0,\pi\rbrack.$

\monades{10}


\end{alist}
\begin{alist}
\item
  Χρησιμοποιώντας τις παραπάνω γραφικές παραστάσεις των δύο συναρτήσεων ή με οποιονδήποτε άλλο τρόπο, να αποδείξετε ότι $2\eta\mu\frac{5\pi}{9} > \eta\mu\frac{10\pi}{9}$.

\monades{9}
\end{alist}
