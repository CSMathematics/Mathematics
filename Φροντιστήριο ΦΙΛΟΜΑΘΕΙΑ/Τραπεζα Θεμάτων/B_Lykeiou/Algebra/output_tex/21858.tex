ΘΕΜΑ 2

Δίνεται η παράσταση $A = 2^{\log 5} + 2^{\log 2}$.

\begin{alist}
\item Να αποδείξετε ότι $A = 2$.

\monades{12}

\item Να βρεθεί η τιμή του λ για την οποία ισχύει ότι $e^\lambda = A$.

\monades{6}

\item Για την τιμή του λ που βρήκατε στο ερώτημα β), να αποδείξετε ότι $\ln \lambda < 0$.

\monades{7}
\end{alist}
