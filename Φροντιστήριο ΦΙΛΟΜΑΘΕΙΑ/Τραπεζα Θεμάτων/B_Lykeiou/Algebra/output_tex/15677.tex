ΘΕΜΑ 4

Δίνεται το πολυώνυμο $P(x) = x^4 - 2x^3 - x^2 + \alpha x + \beta$, όπου $\alpha, \beta \in \mathbb{R}$.

\begin{alist}
\item Να βρείτε τις τιμές των $\alpha, \beta$, αν είναι γνωστό ότι το $P(x)$ διαιρείται με το πολυώνυμο $Q(x) = x^2 - 2x + 1$.

\monades{8}

\item Για $\alpha = 4, \beta = -2$

\begin{rlist}
\item Να κάνετε τη διαίρεση $P(x) : (x^2 + 5)$ και να γράψετε την ταυτότητα της διαίρεσης.

\monades{8}

\item Αν $P(x) = (x^2 + 5)(x^2 - 2x - 6) + 14x + 28$ να λύσετε την εξίσωση $P(x) = 14(x + 2)$.

\monades{9}
\end{rlist}
\end{alist}
