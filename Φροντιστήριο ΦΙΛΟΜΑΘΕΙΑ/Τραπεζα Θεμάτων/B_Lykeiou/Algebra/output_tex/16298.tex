ΘΕΜΑ 2

Δίνεται γωνία $\omega$, με $0 \leq \ \omega < 2\pi$ που ικανοποιεί τις σχέσεις: $\sigma\upsilon\nu\omega = - \frac{1}{2}$ και $\eta\mu\omega > \ 0$.

\begin{alist}
\item Να σχεδιάσετε τη γωνία ω πάνω στον τριγωνομετρικό κύκλο και να βρείτε το μέτρο της.

\monades{15}

\item Να βρείτε όλες τις γωνίες $\varphi\ $με $\varphi\epsilon\mathbb{R}$, που ικανοποιούν τη σχέση $\sigma\upsilon\nu\varphi = - \frac{1}{2}$ .

\monades{10}
\end{alist}
