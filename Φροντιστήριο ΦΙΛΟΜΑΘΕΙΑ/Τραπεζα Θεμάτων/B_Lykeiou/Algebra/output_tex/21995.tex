Πόσες και ποιες λύσεις έχει η εξίσωση $\eta\mu x = \alpha$ στο διάστημα $\lbrack - 2\pi,2\pi\rbrack$ όταν:

\begin{alist}
\item $\alpha = 1$.

\monades{13}

\item $\alpha = - 2$.

\monades{12}

Να αιτιολογήσετε γραφικά, ή όπως αλλιώς θέλετε, την απάντησή σας σε κάθε ένα από τα παραπάνω ερωτήματα.
\end{alist}
