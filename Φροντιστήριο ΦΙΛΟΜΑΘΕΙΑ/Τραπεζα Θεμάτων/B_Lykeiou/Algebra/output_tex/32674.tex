\item 2.2 Κατακόρυφη-Οριζόντια Μετατόπιση Καμπύλης
\end{ylh}
Δίνεται η συνάρτηση $f(x) = x^{2} - 4x + 5$, $x\mathbb{\in R}$.
\begin{alist}
\item Να δείξετε ότι η $f$ γράφεται στη μορφή $f(x) = (x - 2)^2 + 1$.
\monades{10}
\item Να αναφέρετε με ποιες μετατοπίσεις της $y(x) = x^{2}$ προκύπτει η γραφική παράσταση της συνάρτησης $f$, την οποία και να χαράξετε στο σύστημα συντεταγμένων που ακολουθεί.
\monades{15}
