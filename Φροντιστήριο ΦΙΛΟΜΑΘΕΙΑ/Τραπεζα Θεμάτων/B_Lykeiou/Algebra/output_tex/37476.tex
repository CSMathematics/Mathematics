ΘΕΜΑ 4

Δίνεται το πολυώνυμο $P(x) = x^3 - 2x^2 - x + 2$. Να αποδείξετε ότι

\begin{alist}
\item το $P(x)$ έχει παράγοντα το $x - 1$ και να γράψετε την ταυτότητα της διαίρεσης $P(x) : (x - 1)$.

\monades{6}

\item $P(x) < 0$ για κάθε $x \in (-\infty, -1) \cup (1, 2)$.

\monades{7}

\item $1 < \log 20 < 2$.

\monades{6}

\item $P(\log 20) < 0$.

\monades{6}
\end{alist}
