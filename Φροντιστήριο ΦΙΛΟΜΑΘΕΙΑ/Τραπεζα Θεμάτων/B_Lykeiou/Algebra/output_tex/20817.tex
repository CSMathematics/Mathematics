ΘΕΜΑ 2

Δίνεται γωνία $\omega$, με $\pi < \omega < \frac{3\pi}{2}$, για την οποία ισχύει $\sigma\upsilon\nu\omega = -\frac{4}{5}$.

\begin{alist}
\item Να δείξετε ότι $\eta\mu\omega = -\frac{3}{5}$.

\monades{12}

\item Να υπολογίστε την τιμή της παράστασης $A = \frac{\eta\mu\omega + \sigma\upsilon\nu\omega}{1 + \varepsilon\varphi\omega}$.

\monades{13}
\end{alist}
