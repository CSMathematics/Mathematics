\item 3.2 Βασικές Τριγωνομετρικές Ταυτότητες
\end{ylh}
Δίνεται γωνία $\omega$, με $\pi < \omega < \frac{3\pi}{2}$, για την οποία ισχύει $\syn \omega = -\frac{4}{5}$.
\begin{alist}
\item Να δείξετε ότι $\hm \omega = -\frac{3}{5}$.
\monades{12}
\item Να υπολογίστε την τιμή της παράστασης $A = \frac{\hm \omega + \syn \omega}{1 + \ef \omega}$.
\monades{13}
\end{alist}
