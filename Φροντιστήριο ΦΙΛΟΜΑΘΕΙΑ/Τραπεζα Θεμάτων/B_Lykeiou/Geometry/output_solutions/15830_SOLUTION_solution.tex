\textbf{ΛΥΣΗ}
\begin{alist}
\item Από τα δεδομένα η $ZE // B\Gamma$, οπότε από το Θ. Θαλή θα είναι: $\frac{ZA}{ZB} = \frac{EA}{E\Gamma}$.
\item Είναι $ME // A\Delta$ (από τα δεδομένα είναι κάθετα στην ίδια ευθεία $B\Gamma$), οπότε από το Θ. Θαλή θα είναι: $\frac{M\Delta}{M\Gamma} = \frac{EA}{E\Gamma}$.
\end{alist}
Από την τελευταία ισότητα και την ισότητα που δείξαμε στο ερώτημα (α) συμπεραίνουμε ότι: $\frac{ZA}{ZB} = \frac{M\Delta}{M\Gamma}$.
