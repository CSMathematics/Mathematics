ΛΥΣΗ
\begin{alist}
    \item Το εμβαδόν του τριγώνου \text{ΒΔΕ} ισούται με: $(\text{ΒΔΕ}) = \frac{1}{2} \cdot \text{ΔΕ} \cdot \text{ΒΓ} = \frac{1}{2} \cdot 2 \cdot \alpha = \alpha$.
    Το εμβαδόν του τετραγώνου \text{ΑΒΓΔ} ισούται με: $(\text{ΑΒΓΔ}) = \alpha^2$.
    Από την υπόθεση έχουμε: $(\text{ΒΕΔ}) = \frac{(\text{ΑΒΓΔ})}{8}$, άρα $\alpha = \frac{\alpha^2}{8} \text{ ή } 8\alpha = \alpha^2 \text{ ή } 8 = \alpha$.
    Άρα η πλευρά του τετραγώνου είναι $\alpha = 8$.
    \item Από το α) ερώτημα έχουμε $\text{ΒΓ} = \alpha = 8$, $\text{ΔΕ} = 2$ οπότε η $\text{ΓΕ} = \text{ΓΔ} - \text{ΔΕ} = 8 - 2 = 6$.
    Στο ορθογώνιο τρίγωνο \text{ΒΓΕ} από πυθαγόρειο θεώρημα έχουμε: $\text{ΒΕ}^2 = \text{ΒΓ}^2 + \text{ΓΕ}^2 \text{ ή } \text{ΒΕ}^2 = 8^2 + 6^2 \text{ ή } \text{ΒΕ}^2 = 64 + 36 = 100 \text{ ή } \text{ΒΕ} = 10$.
\end{alist}
