ΛΥΣΗ
\begin{alist}
\item Από τα δεδομένα έχουμε: $\widehat{A} = \widehat{Δ} = 90^\circ$ και $ΑΔ=4$, $ΑΒ=5$, $ΔΓ=8$. Το ΑΒΕΔ είναι ορθογώνιο (έχει τρείς γωνίες ορθές), οπότε $ΒΕ = ΑΔ = 4$ και $ΔΕ = ΑΒ = 5$. Άρα η $ΕΓ = ΔΓ - ΔΕ = 8 - 5 = 3$.
\item Στο ορθογώνιο τρίγωνο ΒΕΓ από το πυθαγόρειο θεώρημα έχουμε: $ΒΓ^2 = ΒΕ^2 + ΕΓ^2$ ή $ΒΓ^2 = 4^2 + 3^2$ ή $ΒΓ^2 = 25$, άρα $ΒΓ = 5$.
\item 
\end{alist}
Λόγω του ερωτήματος (α) είναι:
\begin{itemize}
    \item $(ΒΔΓ) = \frac{1}{2}\cdot ΔΓ \cdot ΒΕ = \frac{1}{2}\cdot 8 \cdot 4 = 16$
    \item $(ΑΒΓΔ) = \frac{ΑΒ+ΔΓ}{2}\cdot ΑΔ = \frac{5+8}{2}\cdot 4 = 26$
\end{itemize}
οπότε:
\[ \frac{(ΒΔΓ)}{(ΑΒΓΔ)} = \frac{16}{26} = \frac{8}{13}. \]
