ΛΥΣΗ
\begin{alist}
\item Για το εμβαδόν $E$ του κύκλου $(K, \rho)$ ισχύει ότι $E=\pi\rho^2$. Όμως $E=4\pi$, άρα $\pi\rho^2=4\pi$ ή $\rho^2=4$ ή $\rho=2$. \monades{1}
\item Για τη διάμετρο $A\Gamma$ του κύκλου $(K, \rho)$ ισχύει ότι $A\Gamma=2\rho=4$. \monades{1}
\end{alist}
Το τρίγωνο $AB\Gamma$ είναι ορθογώνιο με $\hat{B}=90^\circ$ και ισοσκελές με $AB=B\Gamma$, που είναι ίσες ως πλευρές του τετραγώνου $AB\Gamma\Delta$.

Εφαρμόζοντας το Πυθαγόρειο θεώρημα στο τρίγωνο $AB\Gamma$ έχουμε:
$A\Gamma^2 = AB^2 + B\Gamma^2$ ή $A\Gamma^2 = AB^2 + AB^2$ ή $2AB^2 = 16$ ή $AB^2 = 8$ ή $AB = \sqrt{8}$.

(εναλλακτικά:
Γνωρίζουμε ότι το μήκος της πλευράς $\lambda_4$ του τετραγώνου που είναι εγγεγραμμένο σε κύκλο ακτίνας $\rho$ είναι $\lambda_4 = \rho\sqrt{2}$. Άρα $\lambda_4 = 2\sqrt{2} = \sqrt{4\cdot2} = \sqrt{8}$.)
\begin{alist}
\item Το εμβαδόν του τετραγώνου $AB\Gamma\Delta$ είναι $(AB\Gamma\Delta) = AB^2 = (\sqrt{8})^2 = 8$. \monades{1}
\end{alist}
