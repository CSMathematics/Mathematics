\begin{alist}
\item [α.] Τα τρίγωνα $\text{ΓΑΒ}$ και $\text{ΓΕΔ}$ είναι ισοσκελή με βάσεις $\text{ΑΒ}$ και $\text{ΔΕ}$ αντίστοιχα και έχουν τις γωνίες στην κορυφή τους ίσες αφού, $\widehat{\text{ΑΓΒ}} = \widehat{\text{ΔΓΕ}}$, ως κατακορυφήν. Έτσι $\widehat{\text{Α}} = \widehat{\text{Β}} = \frac{180^\circ - \widehat{\text{ΑΓΒ}}}{2} = \frac{180^\circ - \widehat{\text{ΔΓΕ}}}{2} = \widehat{\text{Ε}} = \widehat{\text{Δ}}$. Οπότε τα τρίγωνα έχουν τις γωνίες τους ίσες μία προς μία, άρα είναι όμοια.
\item [β.]
    \begin{rlist}
    \item [i.] Ομόλογες είναι οι πλευρές που είναι απέναντι από τις ίσες γωνίες στα δύο τρίγωνα. Οπότε οι λόγοι των ομόλογων πλευρών είναι :
    \[ \frac{\text{AB}}{\text{ΔΕ}} \text{, ως απέναντι από τις ίσες γωνίες } \widehat{\text{ΑΓΒ}} \text{ και } \widehat{\text{ΔΓΕ}} \]
    \[ \frac{\text{ΒΓ}}{\text{ΓΔ}} \text{, } \frac{\text{ΑΓ}}{\text{ΓΕ}} \text{, ως απέναντι από τις ίσες γωνίες } \widehat{\text{A}} \text{, } \widehat{\text{E}} \text{ και } \widehat{\text{B}} \text{, } \widehat{\text{Δ}} \text{ αντίστοιχα.} \]
    Αφού τα τρίγωνα $\text{ΓΑΒ}$ και $\text{ΓΕΔ}$ είναι όμοια οι λόγοι των ομόλογων πλευρών του είναι ίσοι δηλαδή, ισχύει $\frac{\text{AB}}{\text{ΔΕ}} = \frac{\text{ΒΓ}}{\text{ΓΔ}} = \frac{\text{ΑΓ}}{\text{ΓΕ}}$.
    \item [ii.] Από το προηγούμενο ερώτημα ισχύει $\frac{\text{ΑΓ}}{\text{ΓΕ}} = \frac{\text{ΑΒ}}{\text{ΔΕ}} = \frac{2 \cdot \text{ΔΕ}}{\text{ΔΕ}} = 2$. Δηλαδή ισχύει $\frac{\text{ΑΓ}}{\text{ΓΕ}} = 2$ ή $\text{ΑΓ} = 2 \cdot \text{ΓΕ}$. Οπότε η πλευρά $\text{ΑΓ}$ του τριγώνου $\text{ΑΒΓ}$ είναι διπλάσια από την πλευρά $\text{ΓΕ}$ του τριγώνου $\text{ΓΔΕ}$.
    \end{rlist}
\end{alist}
