    \item 10.2. Εμβαδόν ευθύγραμμου σχήματος - Ισοδύναμα ευθύγραμμα σχήματα
    \item 10.3. Εμβαδόν βασικών ευθύγραμμων σχημάτων.
\end{ylh}
Σε τρίγωνο $\mathrm{AB}\Gamma$ θεωρούμε σημείο $\Delta$ εσωτερικό της πλευράς του $\mathrm{B}\Gamma$. Έστω $\mathrm{M}$ το μέσο του τμήματος $\mathrm{A}\Delta$.
\begin{alist}
\item Να αποδείξετε ότι:
    \begin{rlist}
    \item $(\mathrm{ABM}) = \frac{1}{2}(\mathrm{AB}\Delta)$ \monades{8}
    \item $(\mathrm{ABM}) + (\mathrm{M}\Delta\Gamma) = \frac{1}{2}(\mathrm{AB}\Gamma)$ \monades{9}
    \end{rlist}
\item Να εξετάσετε αν υπάρχει θέση του σημείου $\Delta$ τέτοια ώστε τα τρίγωνα $\mathrm{ABM}$ και $\mathrm{M}\Delta\Gamma$ να έχουν ίσα εμβαδά. Στην περίπτωση που υπάρχει θέση του σημείου $\Delta$ για την οποία τα εμβαδά των τριγώνων $\mathrm{ABM}$ και $\mathrm{M}\Delta\Gamma$ είναι ίσα, να βρείτε τι μέρος του εμβαδού του τριγώνου $\mathrm{AB}\Gamma$ είναι το εμβαδόν του κάθε τριγώνου $\mathrm{ABM}$ και $\mathrm{M}\Delta\Gamma$. Να αιτιολογήσετε την απάντησή σας. \monades{8}
\end{alist}
