ΘΕΜΑ 2

Στο παρακάτω σχήμα οι ευθείες $\varepsilon_1$, $\varepsilon_2$ και $\varepsilon_3$ είναι παράλληλες. Δίνονται ότι $\Gamma E = 4$, $\mathrm{O}\Delta = 3$, $\mathrm{OA} = 12$, $\mathrm{OB} = 6$.
\begin{alist}
\item Να υπολογίσετε τα τμήματα $\mathrm{O}\Gamma$ και $\Delta \mathrm{Z}$.  \monades{10}
\item Να αποδείξετε ότι τα τρίγωνα $\mathrm{OEZ}$ και $\mathrm{OBA}$ είναι όμοια.  \monades{09}
\item Αν $\mathrm{O}\Gamma = 1.5$ και $\Delta \mathrm{Z} = 8$, να υπολογίσετε τον λόγο $\frac{EZ}{AB}$.  \monades{06}
\end{alist}
