\Askhsh{22130}{2}
\begin{ylh}{1}
    \item 9.2. Το Πυθαγόρειο θεώρημα.
\end{ylh}
Δίνεται ορθογώνιο τρίγωνο ΑΒΓ ($\hat{A} = 90^\circ$) εγγεγραμμένο σε κύκλο ακτίνας $R$.
Αν οι πλευρές του τριγώνου είναι $\text{B}\Gamma = \alpha$, $\text{A}\Gamma = \beta$ και $\text{A}\text{B} = \gamma$, τότε να αποδείξετε ότι:
\begin{alist}
\item $\alpha = 2R$. \monades{12}
\item $\alpha^2 + \beta^2 + \gamma^2 = 8R^2$. \monades{13}
\end{alist}
