    \item 9.4. Γενίκευση του Πυθαγόρειου θεωρήματος
    \item 11.3. Εγγραφή βασικών κανονικών πολυγώνων σε κύκλο και στοιχεία τους
    \item 11.7. Εμβαδόν κυκλικού τομέα και κυκλικού τμήματος.
\end{ylh}
Δίνεται τρίγωνο ΑΒΓ, εγγεγραμμένο σε κύκλο $(O,R)$ με $AB=\gamma$, $A\Gamma= \beta$ και $B\Gamma=\sqrt{\beta^2 + \gamma^2 + \beta\gamma}$. Να αποδείξετε ότι:
\begin{alist}
\item το τρίγωνο ΑΒΓ είναι αμβλυγώνιο με $\widehat{A} > 90^{\circ}$. \monades{8}
\item η γωνία Α του τριγώνου ΑΒΓ ισούται με $120^{\circ}$. Δίνεται $\sigma\upsilon\nu 120^{\circ} = -\frac{1}{2}$. \monades{5}
\item η γωνία ΒΟΓ ισούται με $120^{\circ}$. \monades{5}
\item το εμβαδόν του κυκλικού τμήματος, που ορίζεται από τη χορδή ΒΓ και το κυρτογώνιο τόξο ΒΓ, είναι: $Ε = \frac{(4\pi - 3\sqrt{3})R^2}{12}$. Δίνεται $\eta\mu 120^{\circ} = \frac{\sqrt{3}}{2}$. \monades{7}
\end{alist}
