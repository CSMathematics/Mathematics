Στο τρίγωνο $\mathrm{A}\mathrm{B}\Gamma$ του παρακάτω σχήματος, τα $\Delta$, $\mathrm{E}$, $\mathrm{Z}$, είναι σημεία των πλευρών $\mathrm{A}\mathrm{B}$, $\mathrm{B}\Gamma$, $\mathrm{A}\Gamma$ αντίστοιχα, ώστε: $\mathrm{A}\Delta = \frac{1}{4}\mathrm{A}\mathrm{B}$, $\mathrm{B}\mathrm{E} = \frac{2}{3}\mathrm{B}\Gamma$ και $\Gamma\mathrm{Z} = \frac{1}{2}\mathrm{A}\Gamma$. Να αποδείξετε ότι:
\begin{alist}
\item $\left(\Delta\mathrm{A}\mathrm{Z}\right) = \frac{1}{8} \left(\mathrm{A}\mathrm{B}\Gamma\right)$, $\left(\mathrm{B}\mathrm{E}\Delta\right) = \frac{1}{2} \left(\mathrm{A}\mathrm{B}\Gamma\right)$, $\left(\Gamma\mathrm{E}\mathrm{Z}\right) = \frac{1}{6} \left(\mathrm{A}\mathrm{B}\Gamma\right)$. \monades{15}
\item $\left(\Delta\mathrm{E}\mathrm{Z}\right) = \frac{5}{24} \left(\mathrm{A}\mathrm{B}\Gamma\right)$. \monades{10}
\end{alist}
