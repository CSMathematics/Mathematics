\lysh{21682_SOLUTION}{1}
\textbf{ΛΥΣΗ}

α) Αν προσθέσουμε τις δοσμένες διανυσματικές ισότητες, παίρνουμε
\[ \vec{\alpha} + \vec{\beta} + \vec{\alpha} - \vec{\beta} = (11, 2) + (-5, -10) \]
δηλαδή $2\vec{\alpha} = (6, -8)$, οπότε $\vec{\alpha} = (3, -4)$.
Με $\vec{\alpha} = (3, -4)$ η πρώτη ισότητα δίνει
\[ \vec{\beta} = (11, 2) - (3, -4) = (8, 6) \]

β) Για τα διανύσματα $\vec{\alpha} = (3, -4)$ και $\vec{\beta} = (8, 6)$ έχουμε
\[ \vec{\alpha} \cdot \vec{\beta} = (3)(8) + (-4)(6) = 24 - 24 = 0 \]
οπότε $\vec{\alpha} \perp \vec{\beta}$. Επιπλέον,
\[ |\vec{\alpha}| = \sqrt{3^2+(-4)^2} = \sqrt{9+16} = \sqrt{25} = 5, \quad |\vec{\beta}| = \sqrt{8^2+6^2} = \sqrt{64+36} = \sqrt{100} = 10 \]
οπότε $|\vec{\beta}| = 2|\vec{\alpha}|$.
\end{lysh}
