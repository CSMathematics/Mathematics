\text{α) Ο συντελεστής διεύθυνσης της ευθείας ΑΒ είναι} $\lambda = \frac{5-(-1)}{3-1} = \frac{6}{2} = 3$.

\text{β) Το μέσο Μ του ΑΒ έχει συντεταγμένες } $M\left(\frac{1+3}{2}, \frac{-1+5}{2}\right)$ \text{ δηλαδή } $M(2,2)$.

\text{γ) Αν ($\varepsilon$) η ζητούμενη μεσοκάθετος τότε ($\varepsilon$) $\perp$ ΑΒ οπότε } $\lambda_\varepsilon \cdot \lambda_{\text{AB}} = -1$ \text{ και άρα}
\[
\lambda_\varepsilon \cdot 3 = -1 \Leftrightarrow \lambda_\varepsilon = -\frac{1}{3}.
\]
\text{Η ευθεία ($\varepsilon$) διέρχεται από το σημείο } $M(2,2)$ \text{ και έχει συντελεστή διεύθυνσης } $\lambda_\varepsilon = -\frac{1}{3}$,
\text{οπότε ($\varepsilon$): } $y-2 = -\frac{1}{3}(x-2)$.
