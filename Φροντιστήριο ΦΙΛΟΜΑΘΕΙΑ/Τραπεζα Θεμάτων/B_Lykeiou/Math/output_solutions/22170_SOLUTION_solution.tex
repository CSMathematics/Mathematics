α) $\vec{u} = \vec{a} - 2\vec{b} = (-1,3) - 2(-2, -\frac{1}{2}) = (-1,3) + (4,1) = (-1+4,3+1) = (3,4)$

β) Για να είναι κάθετα τα διανύσματα θα πρέπει το εσωτερικό τους γινόμενο να είναι ίσο με μηδέν, δηλαδή $\vec{u} \cdot \vec{v} = 0$ ή $(3,4)\cdot(x^2, x-1) = 0$ ή $3x^2+4(x-1) = 0$ ή $3x^2+4x-4 = 0$. Η διακρίνουσα είναι $64$ και οι ρίζες $x = \frac{2}{3}$ και $x = -2$.

γ) Για να είναι τα διανύσματα $\vec{v}$ και $\vec{b}$ συγγραμμικά πρέπει η ορίζουσα των συντελεστών τους να είναι μηδέν.
\[
\begin{vmatrix}
x^2 & x-1 \\
-2 & -\frac{1}{2}
\end{vmatrix}
= 0 \text{ ή } -\frac{1}{2}x^2 - (-2)(x-1) = 0 \text{ ή } -\frac{1}{2}x^2 + 2x - 2 = 0 \text{ ή } x^2- 4x + 4 = 0 \text{ ή } x = 2.
\]
