\lysh{20684_SOLUTION}{1}
ΛΥΣΗ
\begin{enumerate}[\normalfont α)]
    \item Από τον ορισμό της παραβολής, έχουμε ότι $AB = AE$. Αλλά η $BE$ είναι διάμεσος ορθογωνίου τριγώνου που αντιστοιχεί στην υποτείνουσα, άρα είναι $BE = \frac{A\Gamma}{2} = EA$.
    Ώστε το τρίγωνο $ABE$ είναι ισόπλευρο.
    \item Γνωρίζουμε ότι η εστία E έχει συντεταγμένες $E\left(\frac{p}{2}, 0\right)$, άρα είναι $E(1,0)$, αφού $2p = 4$, άρα $p=2$. Η διευθετούσα έχει εξίσωση $(\delta): x = -\frac{p}{2} = -1$, άρα η τετμημένη του σημείου $\Gamma$ θα είναι $-1$, δηλαδή $x_{\Gamma} = -1$. Αλλά $x_E = \frac{x_A+x_{\Gamma}}{2} \Leftrightarrow 1 = \frac{x_A+(-1)}{2}$, άρα $x_A = 3$.
    Εναλλακτικά, θα είναι $B(-1, y_A)$, οπότε $AB = |x_A - (-1)| = |x_A + 1|$.
    Ακόμα $BE = \sqrt{[1 - (-1)]^2 + (0 - y_A)^2} = \sqrt{4 + y_A^2}$.
    Όμως $AB^2 = BE^2 \Leftrightarrow (x_A + 1)^2 = 4 + y_A^2 \Leftrightarrow x_A^2 + 2x_A + 1 = 4 + 4x_A \Leftrightarrow x_A^2 - 2x_A - 3 = 0$, εξίσωση που έχει ως ρίζες τους αριθμούς $3$ και $-1$.
    Ώστε $x_A = 3$, αφού $x_A > 0$.
    Τότε $y_A^2 = 12$, άρα $y_A = 2\sqrt{3}$, αφού $y_A > 0$.
    \item Ζητάμε την εξίσωση του περιγεγραμμένου κύκλου του τριγώνου $AB\Gamma$, το οποίο όμως είναι ορθογώνιο. Από το α) ερώτημα έχουμε ότι $EA = EB = E\Gamma$, άρα το E θα είναι το κέντρο του ζητούμενου κύκλου, ενώ η ακτίνα του θα είναι $AE = AB = |3 - (-1)| = 4$.
    Έτσι, ο κύκλος έχει εξίσωση $(x - 1)^2 + y^2 = 16$.
\end{enumerate}
