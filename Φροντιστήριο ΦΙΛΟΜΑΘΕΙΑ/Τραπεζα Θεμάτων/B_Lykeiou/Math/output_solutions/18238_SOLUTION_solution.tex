\noindent \textbf{ΛΥΣΗ}

\noindent \alpha) Είναι $x_K = \frac{x_A + x_B}{2} = \frac{1 + (-3)}{2} = -1$ και $y_K = \frac{y_A + y_B}{2} = \frac{3 + 5}{2} = 4$, οπότε $K(-1,4)$.

\noindent \beta) Είναι $(KA) = \sqrt{(x_K - x_A)^2 + (y_K - y_A)^2} = \sqrt{(-1-1)^2 + (4-3)^2} = \sqrt{5}$.

\noindent \gamma) Ο ζητούμενος κύκλος έχει κέντρο το σημείο $K(-1,4)$ και ακτίνα την απόσταση $(KA)=\sqrt{5}$, οπότε έχει εξίσωση: $(x+1)^2 + (y-4)^2 = 5$.
