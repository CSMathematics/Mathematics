\lysh{16477_SOLUTION}{1}
\textnormal{i.} Οι φωτεινές ακτίνες που παριστάνει η εξίσωση $\varepsilon_{\lambda}$ διέρχονται από το φάρο $\Phi$. Επομένως οι συντεταγμένες του φάρου $\Phi(x_\Phi, y_\Phi)$ επαληθεύουν την εξίσωση της $\varepsilon_{\lambda}$ για κάθε $\lambda \in \mathbb{R}$.

Δηλαδή είναι
\[
\lambda x_\Phi + (1-\lambda) y_\Phi + 2 = 0
\]
\[
\Leftrightarrow \lambda x_\Phi + y_\Phi - \lambda y_\Phi + 2 = 0
\]
\[
\Leftrightarrow \lambda(x_\Phi - y_\Phi) + y_\Phi + 2 = 0
\]
Η τελευταία σχέση πρέπει να ισχύει για κάθε $\lambda \in \mathbb{R}$, συνεπώς οι συντελεστές των δυνάμεων του $\lambda$ πρέπει να είναι μηδέν. Άρα:
\[
\left\{
\begin{array}{l}
x_\Phi - y_\Phi = 0 \\
y_\Phi + 2 = 0
\end{array}
\right.
\Leftrightarrow
\left\{
\begin{array}{l}
x_\Phi = y_\Phi \\
y_\Phi = -2
\end{array}
\right.
\Leftrightarrow
\left\{
\begin{array}{l}
x_\Phi = -2 \\
y_\Phi = -2
\end{array}
\right.
\]
Οπότε οι συντεταγμένες του φάρου είναι $\Phi(-2, -2)$.

\textbf{Δεύτερος τρόπος}
Γνωρίζουμε ότι όλες οι ευθείες διέρχονται από το ίδιο σημείο $\Phi$. Για τον προσδιορισμό των συντεταγμένων του φάρου αρκεί να βρούμε το σημείο τομής δύο ευθειών της οικογένειας $\varepsilon_{\lambda}$.

Μια ευθεία της οικογένειας $\varepsilon_{\lambda}$ προκύπτει για $\lambda=1$ με εξίσωση $1x+(1-1)y+2=0 \Leftrightarrow x+2=0$ και μια άλλη προκύπτει για $\lambda=0$ με εξίσωση $0x+(1-0)y+2=0 \Leftrightarrow y+2=0$.

Για την εύρεση του κοινού σημείου $\Phi$, των ευθειών με εξισώσεις $x+2=0$ και $y+2=0$, επιλύουμε το σύστημα $(\Sigma)$:
\[
\left\{
\begin{array}{l}
x+2=0 \\
y+2=0
\end{array}
\right.
\]
Είναι
\[
\left\{
\begin{array}{l}
y=-2 \\
x=-2
\end{array}
\right.
\]
άρα οι συντεταγμένες του φάρου είναι $\Phi(-2, -2)$.

\textnormal{ii.} Έστω ότι υπάρχει φωτεινή ακτίνα που εκπέμπεται από το φάρο προς το αγκυροβολημένο πλοίο. Άρα υπάρχει πραγματικός αριθμός $\lambda$ ώστε η $\varepsilon_{\lambda}$ να διέρχεται από το $\mathrm{O}(0,0)$. Τότε οι συντεταγμένες του $\mathrm{O}(0,0)$ επαληθεύουν την εξίσωση της $\varepsilon_{\lambda}$.

Έχουμε $\lambda \cdot 0 + (1-\lambda) \cdot 0 + 2 = 0 \Leftrightarrow 2 = 0$, άτοπο.

Οπότε δεν υπάρχει φωτεινή ακτίνα που εκπέμπεται από το φάρο προς το αγκυροβολημένο πλοίο.

\textnormal{β)} Αν είναι $\mathrm{P}(x_\mathrm{P}, y_\mathrm{P})$ τότε ισχύει $y_\mathrm{P} > y_\Phi \Leftrightarrow y_\mathrm{P} > -2$ αφού το ρυμουλκό πλοίο $\mathrm{P}$ βρίσκεται βόρεια του φάρου $\Phi$.
Επειδή το σημείο $\mathrm{P}$ ανήκει στην ευθεία με εξίσωση $x+y+4=0$ ισχύει $x_\mathrm{P}+y_\mathrm{P}+4=0 \Leftrightarrow x_\mathrm{P}=-4-y_\mathrm{P}$. Οπότε $\mathrm{P}(-4-y_\mathrm{P}, y_\mathrm{P})$ με $y_\mathrm{P} > -2$.
Η συντομότερη διαδρομή που πρέπει να διανύσει το ρυμουλκό πλοίο για να πάει προς το αγκυροβολημένο φορτηγό πλοίο είναι το ευθύγραμμο τμήμα $\mathrm{PO}$ με μήκος 4 μονάδες.

Είναι
\[
\mathrm{PO} = 4 \Leftrightarrow \sqrt{(x_\mathrm{O} - x_\mathrm{P})^2 + (y_\mathrm{O} - y_\mathrm{P})^2} = 4
\]
\[
\Leftrightarrow \sqrt{(0 - (-4-y_\mathrm{P}))^2 + (0 - y_\mathrm{P})^2} = 4
\]
\[
\Leftrightarrow \sqrt{(4+y_\mathrm{P})^2 + y_\mathrm{P}^2} = 4
\]
\[
\Leftrightarrow \sqrt{2y_\mathrm{P}^2 + 8y_\mathrm{P} + 16} = 4
\]
\[
\Leftrightarrow \left(\sqrt{2y_\mathrm{P}^2 + 8y_\mathrm{P} + 16}\right)^2 = 4^2
\]
\[
\Leftrightarrow 2y_\mathrm{P}^2 + 8y_\mathrm{P} + 16 = 16
\]
\[
\Leftrightarrow 2y_\mathrm{P}^2 + 8y_\mathrm{P} = 0
\]
\[
\Leftrightarrow 2y_\mathrm{P}(y_\mathrm{P} + 4) = 0
\]
\[
\Leftrightarrow 2y_\mathrm{P} = 0 \text{ ή } y_\mathrm{P} + 4 = 0
\]
\[
\Leftrightarrow y_\mathrm{P} = 0 \text{ ή } y_\mathrm{P} = -4
\]
Δεκτή είναι μόνο η $y_\mathrm{P}=0$ αφού $y_\mathrm{P} > -2$. Ακόμη είναι $x_\mathrm{P}=-4-y_\mathrm{P}=-4-0=-4$.
Τελικά, οι συντεταγμένες του ρυμουλκού πλοίου είναι $\mathrm{P}(-4,0)$.
