α) $\vec{AM} = (x_M - x_A, y_M - y_A) = (x - (-1), y - 0) = (x + 1, y)$.
$|\vec{AM}| = \sqrt{(x + 1)^2 + y^2}$

$\vec{BM} = (x_M - x_B, y_M - y_B) = (x - 1, y - 0) = (x - 1, y)$.
$|\vec{BM}| = \sqrt{(x - 1)^2 + y^2}$

$|\vec{AB}| = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2} = \sqrt{(1 - (-1))^2 + (0 - 0)^2} = \sqrt{2^2 + 0} = 2$.

$\vec{AM}^2 + \vec{BM}^2 = 9|\vec{AB}|$, άρα $|\vec{AM}|^2 + |\vec{BM}|^2 = 9 \cdot 2$ ή

\[ (x + 1)^2 + y^2 + (x - 1)^2 + y^2 = 18 \]

\[ 2x^2 + 2y^2 + 2 = 18 \]

β)
i. Για τα σημεία $\Gamma$ και $\Delta$ του κύκλου ισχύει $\Gamma\Delta^2 = 32$
δηλαδή $\Gamma\Delta = \sqrt{32} = \sqrt{16 \cdot 2} = 4\sqrt{2}$.

Η εξίσωση του κύκλου είναι $x^2 + y^2 = 8$, οπότε η ακτίνα του $\rho$ είναι $\rho = \sqrt{8} = 2\sqrt{2}$ και το κέντρο του το $O(0,0)$.

Παρατηρούμε ότι $\Gamma\Delta = 2\rho$, οπότε τα σημεία $\Gamma$ και $\Delta$ είναι αντιδιαμετρικά και επομένως η διάμετρος $\Gamma\Delta$ θα διέρχεται από το κέντρο $O$ του κύκλου.

ii. Αφού η $\Gamma\Delta$ είναι διάμετρος και το σημείο $M$ είναι σημείο του κύκλου, τότε η γωνία $\widehat{\Gamma M \Delta} = 90^\circ$ γιατί είναι εγγεγραμμένη που βαίνει σε ημικύκλιο. Επειδή τα διανύσματα $\vec{M\Gamma}$ και $\vec{M\Delta}$ είναι κάθετα, το εσωτερικό τους γινόμενο θα ισούται με μηδέν.
