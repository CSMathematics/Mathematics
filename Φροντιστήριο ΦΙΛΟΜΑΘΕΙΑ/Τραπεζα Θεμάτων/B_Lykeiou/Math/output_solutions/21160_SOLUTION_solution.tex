α) Επειδή τα τετράπλευρα $OB\Delta E$ και $O\Gamma ZH$ είναι τετράγωνα, οι συντεταγμένες των κορυφών τους είναι: $\Delta(\kappa, -\kappa)$, $E(0, -\kappa)$, $Z(-2\kappa, 2\kappa)$ και $H(-2\kappa, 0)$.

Η εξίσωση της ευθείας $\Gamma\Delta$ είναι:
\[
\frac{y - 2\kappa}{x - 0} = \frac{\kappa - 2\kappa}{0 - \kappa} \iff \frac{y - 2\kappa}{x} = \frac{-\kappa}{-\kappa} \iff \frac{y - 2\kappa}{x} = 1 \iff y - 2\kappa = x \iff x - y + 2\kappa = 0
\]
Η εξίσωση της ευθείας $BZ$ είναι:
\[
\frac{y - 0}{x - \kappa} = \frac{2\kappa - 0}{-2\kappa - \kappa} \iff \frac{y}{x - \kappa} = \frac{2\kappa}{-3\kappa} \iff \frac{y}{x - \kappa} = -\frac{2}{3} \iff 3y = -2(x - \kappa) \iff 3y = -2x + 2\kappa \iff 2x + 3y - 2\kappa = 0
\]

β) Ο συντελεστής διεύθυνσης της ευθείας που ορίζεται από το ευθύγραμμο τμήμα $B\Gamma$ είναι:
\[
\lambda_{B\Gamma} = \frac{2\kappa - 0}{0 - \kappa} = -2
\]
η ευθεία $(\epsilon)$ που ορίζεται από το ύψος $A\Delta$ του ορθογωνίου τριγώνου $OB\Gamma$, είναι κάθετη της πλευράς $B\Gamma$, επομένως για τους συντελεστές διεύθυνσης τους ισχύει:
\[
\lambda_{\epsilon} \cdot \lambda_{B\Gamma} = -1
\]
Επειδή $\lambda_{B\Gamma} = -2$, έχουμε ότι:
\[
\lambda_{\epsilon} \cdot (-2) = -1 \iff \lambda_{\epsilon} = \frac{1}{2}
\]

γ) Για να αποδείξουμε ότι οι ευθείες που ορίζονται από τα ευθύγραμμο τμήματα $\Gamma\Delta$, $BZ$ και η ευθεία $(\epsilon)$ διέρχονται από το ίδιο σημείο, αρκεί να βρούμε σημείο $M$ του οποίου οι συντεταγμένες του να επαληθεύουν όλες τις εξισώσεις των ευθειών. Επομένως αρκεί να αποδείξουμε ότι η τομή δύο ευθειών από τις τρεις ανήκει στην τρίτη ευθεία.

Οι συντεταγμένες της τομής $M$ των ευθειών $(\epsilon)$ και $\Gamma\Delta$ δίνονται από την λύση του συστήματος:
\[
\begin{cases}
3x + y - 2\kappa = 0 \\
y = \frac{1}{2}x
\end{cases}
\iff
\begin{cases}
3x + \frac{1}{2}x - 2\kappa = 0 \\
y = \frac{1}{2}x
\end{cases}
\iff
\begin{cases}
\frac{7}{2}x = 2\kappa \\
y = \frac{1}{2}x
\end{cases}
\iff
\begin{cases}
x = \frac{4}{7}\kappa \\
y = \frac{1}{2} \cdot \frac{4}{7}\kappa
\end{cases}
\iff
\begin{cases}
x = \frac{4}{7}\kappa \\
y = \frac{2}{7}\kappa
\end{cases}
\]
επομένως $M\left(\frac{4}{7}\kappa, \frac{2}{7}\kappa\right)$.

Το σημείο $M$ ανήκει στην ευθεία που ορίζεται από το ευθύγραμμο τμήμα $BZ$ αφού οι συντεταγμένες του $M$ την επαληθεύουν, πράγματι
\[
2 \cdot \frac{4}{7}\kappa + 3 \cdot \frac{2}{7}\kappa - 2\kappa = \frac{8}{7}\kappa + \frac{6}{7}\kappa - 2\kappa = \frac{14}{7}\kappa - 2\kappa = 2\kappa - 2\kappa = 0.
\]
επομένως οι ευθείες που ορίζονται από τα ευθύγραμμο τμήματα $\Gamma\Delta$, $BZ$ και η ευθεία $(\epsilon)$ διέρχονται από το ίδιο σημείο.
