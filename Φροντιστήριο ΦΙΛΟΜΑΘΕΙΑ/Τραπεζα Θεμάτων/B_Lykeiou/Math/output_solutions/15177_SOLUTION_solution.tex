\lysh{15177_SOLUTION}{1}
\textbf{α)} Θεωρούμε σημείο $N(x, y)$ του επιπέδου. Τότε $\vec{NA} = (1-x, -y)$, $\vec{NB} = (-x-1, -y)$, οπότε ισχύει:
\[
\vec{NA}^2 - \vec{NB}^2 = 4 \Leftrightarrow |\vec{NA}|^2 - |\vec{NB}|^2 = 4 \Leftrightarrow (1-x)^2 + y^2 - ((-x-1)^2 + y^2) = 4 \Leftrightarrow x+y+2=0.
\]
Άρα τα ζητούμενα σημεία $N$ ανήκουν σε ευθεία με εξίσωση ($\varepsilon$): $y = -x-2$.

\textbf{β)} Έστω σημείο $P(x, y)$ του επιπέδου. Τότε, χρησιμοποιώντας τη μέθοδο συμπλήρωσης τετραγώνου, ισχύει:
\[
2x^2 + 2y^2 + 10x + 14y + 21 = 0 \Leftrightarrow x^2 + y^2 + 5x + 7y + \frac{21}{2} = 0 \Leftrightarrow
\]
\[
x^2 + 2x\left(\frac{5}{2}\right) + \left(\frac{5}{2}\right)^2 + y^2 + 2y\left(\frac{7}{2}\right) + \left(\frac{7}{2}\right)^2 = -\frac{21}{2} + \frac{25}{4} + \frac{49}{4} \Leftrightarrow
\]
\[
\left(x+\frac{5}{2}\right)^2 + \left(y+\frac{7}{2}\right)^2 = 8
\]
$c_2$: $\left(x+\frac{5}{2}\right)^2 + \left(y+\frac{7}{2}\right)^2 = 8$.
Άρα τα σημεία $P$ ανήκουν σε κύκλο $c_2$, με κέντρο $\Lambda\left(-\frac{5}{2}, -\frac{7}{2}\right)$ και ακτίνα $R = \sqrt{8} = 2\sqrt{2}$.

\textbf{2\textsuperscript{o} τρόπος:}
\[
2x^2 + 2y^2 + 10x + 14y + 21 = 0 \Leftrightarrow x^2 + y^2 + 5x + 7y + \frac{21}{2} = 0.
\]
Αλλά $5^2 + 7^2 - 4 \cdot \frac{21}{2} = 25 + 49 - 42 = 32 > 0$, επομένως η εξίσωση παραστάνει κύκλο, με κέντρο
$\Lambda\left(-\frac{5}{2}, -\frac{7}{2}\right)$ και ακτίνα $\rho = \frac{\sqrt{32}}{2} = \frac{4\sqrt{2}}{2} = 2\sqrt{2}$.

\textbf{γ)}
\textbf{i.} Οι κύκλοι $c_1$ και $c_2$ εφάπτονται εξωτερικά, διότι έχουν διάκεντρο
\[
\delta = (K\Lambda) = \sqrt{\left(\frac{1}{2}+\frac{5}{2}\right)^2 + \left(-\frac{1}{2}+\frac{7}{2}\right)^2} = \sqrt{3^2 + 3^2} = \sqrt{9+9} = \sqrt{18} = 3\sqrt{2}
\]
και ισχύει $\delta = \rho + R$.
Άρα η ελάχιστη απόσταση των σημείων των δύο κύκλων είναι μηδέν και η μέγιστη απόσταση είναι ίση με $\Sigma T = \Sigma Z + Z T = 2\rho + 2R = 2\sqrt{2} + 2\sqrt{2} = 4\sqrt{2}$.

\textbf{ii.} Είναι $d(K, \varepsilon) = \frac{\left|\frac{1}{2} + \frac{1}{2} + 2\right|}{\sqrt{1^2+1^2}} = \frac{|3|}{\sqrt{2}} = \frac{3}{\sqrt{2}} = \frac{3\sqrt{2}}{2}$ και $d(\Lambda, \varepsilon) = \frac{\left|-\frac{5}{2} - \frac{7}{2} + 2\right|}{\sqrt{1^2+1^2}} = \frac{|-6+2|}{\sqrt{2}} = \frac{|-4|}{\sqrt{2}} = \frac{4}{\sqrt{2}} = 2\sqrt{2} = R$.
Άρα η ευθεία ($\varepsilon$) είναι η ζητούμενη κοινή εφαπτομένη.
