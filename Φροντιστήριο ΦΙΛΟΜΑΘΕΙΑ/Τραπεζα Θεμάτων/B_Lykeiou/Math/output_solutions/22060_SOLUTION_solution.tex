ΛΥΣΗ

α) $\overrightarrow{\text{A}\Delta} = \overrightarrow{\text{O}\Delta} - \overrightarrow{\text{O}\text{A}} = (3,4) - (0,2) = (3-0, 4-2) = (3,2)$.
\[
\overrightarrow{\text{B}\Gamma} = \overrightarrow{\text{O}\Gamma} - \overrightarrow{\text{O}\text{B}} = (6,2) - (3,0) = (6-3, 2-0) = (3,2).
\]
Άρα, $\overrightarrow{\text{A}\Delta} = \overrightarrow{\text{B}\Gamma}$.

Επίσης, $\overrightarrow{\text{B}\text{A}} = \overrightarrow{\text{O}\text{A}} - \overrightarrow{\text{O}\text{B}} = (0,2) - (3,0) = (-3,2)$.

β) Από το α) ερώτημα έχουμε ότι $\overrightarrow{\text{B}\text{A}} = (-3,2)$. Οπότε $|\overrightarrow{\text{B}\text{A}}| = \sqrt{(-3)^2 + 2^2} = \sqrt{13}$.

Επίσης,
\[
\overrightarrow{\text{B}\Gamma} = \overrightarrow{\text{O}\Gamma} - \overrightarrow{\text{O}\text{B}} = (6,2) - (3,0) = (3,2), \text{ οπότε } |\overrightarrow{\text{B}\Gamma}| = \sqrt{3^2 + 2^2} = \sqrt{13}.
\]
Άρα, $|\overrightarrow{\text{B}\text{A}}| = |\overrightarrow{\text{B}\Gamma}|$.

Το τετράπλευρο \text{ABΓΔ} είναι ρόμβος καθώς η συνθήκη $\overrightarrow{\text{A}\Delta} = \overrightarrow{\text{B}\Gamma}$ συνεπάγεται ότι το τετράπλευρο \text{ABΓΔ} είναι παραλληλόγραμμο, ενώ η συνθήκη $|\overrightarrow{\text{B}\text{A}}| = |\overrightarrow{\text{B}\Gamma}|$ βεβαιώνει ότι το \text{ABΓΔ} είναι ρόμβος (τα μήκη δύο διαδοχικών πλευρών είναι ίσα).
