α)
i. Οι συντεταγμένες του μέσου $\Delta$ του B$\Gamma$ δίνονται από τους τύπους
\[
x_{\Delta} = \frac{x_{\Gamma} + x_B}{2} = \frac{4+4}{2} = 4 \text{ και } y_{\Delta} = \frac{y_B + y_{\Gamma}}{2} = \frac{4+0}{2} = 2.
\]
Επομένως, είναι $\Delta(4,2)$.

ii. Έστω $Z(x,y)$. Τότε $\vec{AZ} = (x_Z - x_A, y_Z - y_A) = (x-0, y-4) = (x, y-4)$ και
$\vec{A\Gamma} = (x_{\Gamma} - x_A, y_{\Gamma} - y_A) = (4-0, 0-4) = (4,-4)$.
Όμως $\vec{AZ} = \frac{3}{4}\vec{A\Gamma}$, άρα $(x, y-4) = \frac{3}{4}(4,-4) = (3,-3)$.
Επομένως $x=3$ και $y-4 = -3$, δηλαδή $y=1$. Άρα, είναι $Z(3,1)$.

β) Από το ερώτημα β) έχουμε ότι $\vec{AZ}=(3,3)$.
$\vec{Z\Delta} = (x_{\Delta} - x_Z, y_{\Delta} - y_Z) = (4-3, 2-1) = (1,1)$.
$\vec{AZ} \cdot \vec{Z\Delta} = (3,3)\cdot(1,-1) = 3 - 3 = 0$.
Επομένως τα διανύσματα είναι κάθετα. Το ίδιο θα ισχύει και για τους φορείς τους, δηλαδή Α$\Gamma$ κάθετη στην Z$\Delta$.

Εναλλακτική λύση:
Ο συντελεστής διεύθυνσης της ευθείας ΑΖ είναι $\lambda_{AZ} = \frac{y_Z - y_A}{x_Z - x_A} = \frac{1-4}{3-0} = \frac{-3}{3} = -1$.
Ο συντελεστής διεύθυνσης της ευθείας Z$\Delta$ είναι $\lambda_{Z\Delta} = \frac{y_{\Delta} - y_Z}{x_{\Delta} - x_Z} = \frac{2-1}{4-3} = \frac{1}{1} = 1$.
Επειδή $\lambda_{AZ} \cdot \lambda_{Z\Delta} = -1 \cdot 1 = -1$, οι ευθείες ΑΖ και Z$\Delta$ είναι κάθετες.
