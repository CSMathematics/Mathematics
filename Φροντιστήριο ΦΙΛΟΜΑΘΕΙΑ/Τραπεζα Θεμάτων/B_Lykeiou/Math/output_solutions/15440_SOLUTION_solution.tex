\lysh{15440_SOLUTION}{1}
\textbf{ΛΥΣΗ}

α) Οι συντεταγμένες των διανυσμάτων είναι:
$\vec{AB} = (3 - 0, 0 - 2) = (3, -2)$ και $\vec{A\Gamma} = (1 - 0, 1 - 2) = (1, -1)$.

β)
i. Η ορίζουσα των διανυσμάτων είναι:
\[ \det(\vec{AB}, \vec{A\Gamma}) = \begin{vmatrix} 3 & -2 \\ 1 & -1 \end{vmatrix} = -3 + 2 = -1 \neq 0. \]
Για να σχηματίζεται τρίγωνο πρέπει τα διανύσματα να μην είναι παράλληλα, διαφορετικά τα τρία σημεία θα είναι συνευθειακά.
Αφού λοιπόν $\det(\vec{AB}, \vec{A\Gamma}) \neq 0$ τότε τα σημεία $A, B$ και $\Gamma$ ορίζουν τρίγωνο.

ii. Αφού είναι $\det(\vec{AB}, \vec{A\Gamma}) = -1$, το εμβαδόν του τριγώνου $AB\Gamma$ είναι:
\[ (AB\Gamma) = \frac{1}{2} |\det(\vec{AB}, \vec{A\Gamma})| = \frac{1}{2} |-1| = \frac{1}{2} \text{ τ.μ.} \]
\end{lysh}
