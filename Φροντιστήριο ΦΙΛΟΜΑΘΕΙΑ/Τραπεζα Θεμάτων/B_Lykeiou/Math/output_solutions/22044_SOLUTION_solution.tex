Όμως,
\[ \vec{BA} = (0 - 4, 0 - 0) = (-4, 0) \]
και
\[ \vec{B\Gamma} = (5 - 4, 1 - 0) = (1, 1), \]
Άρα,
\[ \vec{B\Delta} = \vec{BA} + \vec{B\Gamma} = (-4, 0) + (1, 1) = (-3, 1). \]
Συνεπώς,
\[ \vec{A\Delta} = \vec{AB} + \vec{B\Delta} = (4, 0) + (-3, 1) = (1, 1). \]
Επομένως, το ζητούμενο σημείο είναι το σημείο \(\Delta(1, 1)\).
