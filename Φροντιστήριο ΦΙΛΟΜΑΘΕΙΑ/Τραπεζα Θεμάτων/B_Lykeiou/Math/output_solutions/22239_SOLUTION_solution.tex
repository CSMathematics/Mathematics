\lysh{22239_SOLUTION}{1}
{\large \Alpha)}
\begin{enumerate}
    \item Ο κύκλος έχει κέντρο το $O(0,0)$ και ακτίνα $\rho=2$. Η εξίσωση κύκλου με κέντρο το $O(0,0)$ είναι της μορφής $x^2 + y^2 = \rho^2$. Επομένως η εξίσωση γίνεται $x^2 + y^2 = 4$.
    \item Για να διέρχεται ο αγωγός από το κέντρο $O$ θα πρέπει οι συντεταγμένες του να επαληθεύουν την εξίσωση $3x+4y=25$, δηλαδή $3 \cdot 0 + 4 \cdot 0 = 0$, που δεν είναι ίσο με $25$. Επομένως, ο αγωγός δεν διέρχεται από το κέντρο του συντριβανιού.
    \item Για να έχουμε την ελάχιστη δυνατή απόσταση θα πρέπει να φέρουμε την κάθετη $OA$ από το κέντρο $O$ προς την ευθεία του αγωγού. Ο συντελεστής διεύθυνσης της ευθείας του αγωγού είναι $\lambda_1 = -\frac{A}{B} = -\frac{3}{4}$. Για να είναι η $AO$ κάθετη στον αγωγό πρέπει $\lambda_{1} \lambda_{AO} = -1$ ή $-\frac{3}{4} \lambda_{AO} = -1$ ή $\lambda_{AO} = \frac{4}{3}$. Η εξίσωση της $AO$ θα είναι:
    \[ y-y_O = \lambda_{AO}(x-x_O) \text{ ή } y-0 = \frac{4}{3}(x-0) \text{ ή } y = \frac{4}{3}x. \]
    Το σημείο $A$ είναι το σημείο τομής της $AO$ και της ευθείας του αγωγού. Για να βρεθεί λύνουμε το σύστημά τους.
    \[ \begin{cases} 3x+4y=25 \quad (1) \\ y=\frac{4}{3}x \quad (2) \end{cases} \]
    Η (1) γίνεται $3x+4\left(\frac{4}{3}x\right) = 25$ ή $9x+16x=75$ ή $25x=75$, δηλαδή $x=3$. Η (2) γίνεται $y=\frac{4}{3} \cdot 3 = 4$. Επομένως το σημείο $A$ είναι το $(3,4)$.
\end{enumerate}

{\large \Beta)}
Για να εφάπτεται ο δρόμος του κυκλικού συντριβανιού πρέπει η απόσταση του κέντρου $O$ από την ευθεία του δρόμου να ισούται με την ακτίνα του κύκλου, δηλαδή $d(O,\varepsilon)=\rho$.
\[ d(O,\rho) = \frac{|Ax_o + By_o + \Gamma|}{\sqrt{A^2+B^2}} = \frac{|\lambda \cdot 0 + 0 + \lambda-2|}{\sqrt{\lambda^2+1^2}} = 2 \text{ ή } \frac{|\lambda-2|}{\sqrt{\lambda^2+1}} = 2 \text{ ή } |\lambda-2| = 2\sqrt{\lambda^2+1} \]
\[ |\lambda-2|^2 = (2\sqrt{\lambda^2+1})^2 \text{ ή } \lambda^2-4\lambda+4 = 4(\lambda^2+1) \text{ ή } 3\lambda^2+4\lambda = 0 \text{ ή } \lambda(3\lambda+4) = 0. \]
Έχουμε $\lambda = 0$ που απορρίπτεται λόγω της υπόθεσης ($\lambda \ne 0$) ή $\lambda = -\frac{4}{3}$.
