ΛΥΣΗ
\bigskip
α) Έχουμε την εξίσωση: $(2\lambda+1)x - (\lambda-2)y + \lambda - 7 = 0 (\text{E}), \lambda \in \mathbb{R}$ που είναι της μορφής $Ax + By + \Gamma = 0$, με $A = 2\lambda + 1$ και $B = \lambda - 2$.
Οπότε: $ \left\{ \begin{array}{l} A = 0 \\ B = 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} 2\lambda + 1 = 0 \\ \lambda - 2 = 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} \lambda = -\frac{1}{2} \\ \lambda = 2 \end{array} \right. $, άρα για κάθε $\lambda \in \mathbb{R}$ είναι $A \ne 0$ ή $B \ne 0$, επομένως η εξίσωση (E) παριστάνει ευθεία.
\bigskip
β) Η εξίσωση (E) γράφεται: $2\lambda x + x - \lambda y + 2y + \lambda - 7 = 0$ ή
$(2x - y + 1)\lambda + (x + 2y - 7) = 0$. Το να ικανοποιείται η τελευταία εξίσωση για κάθε $\lambda$, είναι ισοδύναμο με το να είναι μηδέν οι δύο παρενθέσεις. Δηλαδή:
\[
\left\{ \begin{array}{l} 2x - y + 1 = 0 \\ x + 2y - 7 = 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} y = 2x + 1 \\ x + 2(2x + 1) - 7 = 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} y = 2x + 1 \\ x + 4x + 2 - 7 = 0 \end{array} \right. \Leftrightarrow \left\{ \begin{array}{l} x = 1 \\ y = 3 \end{array} \right.
\]
Επομένως, όλες οι ευθείες που ορίζονται από την εξίσωση (Ε), διέρχονται από το σημείο $M(1, 3)$.
\bigskip
γ) Η ευθεία ($\zeta$) είναι παράλληλη στο διάνυσμα $\vec{\delta_1} = (B, -A) = (-8, -6)$.
Οι ευθείες της οικογένειας ευθειών (E), είναι παράλληλες στο διάνυσμα $\vec{\delta_2} = (B, -A) = (-\lambda + 2, -2\lambda - 1)$.
Οπότε: $\vec{\delta_1} // \vec{\delta_2} \Leftrightarrow \det(\vec{\delta_1}, \vec{\delta_2}) = 0 \Leftrightarrow \begin{vmatrix} -8 & -6 \\ -\lambda + 2 & -2\lambda - 1 \end{vmatrix} = 0 \Leftrightarrow$
$16\lambda + 8 - 6\lambda + 12 = 0 \Leftrightarrow 10\lambda = -20 \Leftrightarrow \lambda = -2$.
Για $\lambda = -2$ από την εξίσωση (Ε) παίρνουμε: $-3x + 4y - 9 = 0$.
Άρα $\varepsilon: -3x + 4y - 9 = 0$ είναι η ζητούμενη ευθεία.
\bigskip
δ) Είναι $(\zeta): 6x-8y+3=0$, οπότε $d(M, \zeta) = \frac{|6 \cdot 1 - 8 \cdot 3 + 3|}{\sqrt{6^2 + (-8)^2}} = \frac{|15|}{\sqrt{100}} = \frac{15}{10} = \frac{3}{2}$.
