\lysh{21154_SOLUTION}{1}
\textbf{ΛΥΣΗ}

\textbf{α)} Η εξίσωση (1) είναι της μορφής
\[ x^2 + y^2 + Ax + By + \Gamma = 0 \]
με $A = -4\alpha, B = -4\alpha$ και $\Gamma = 0$.
Για να παριστάνει κύκλο θα πρέπει $A^2 + B^2 - 4\Gamma > 0$. Είναι:
\[ A^2 + B^2 - 4\Gamma = ({-}4\alpha)^2 + ({-}4\alpha)^2 - 4 \cdot 0 = 16\alpha^2 + 16\alpha^2 = 32\alpha^2 \]
Επομένως, θα πρέπει
\[ 32\alpha^2 > 0 \implies \alpha^2 > 0 \]
Η τελευταία σχέση ικανοποιείται αν και μόνο αν $\alpha \ne 0$.

\textbf{β)} Τα κέντρα των κύκλων που παριστάνει η εξίσωση (1) για $\alpha \ne 0$, είναι
\[ K\left(-\frac{A}{2}, -\frac{B}{2}\right) = \left(-\frac{-4\alpha}{2}, -\frac{-4\alpha}{2}\right) = (2\alpha, 2\alpha) \]
και η ακτίνα
\[ R = \frac{\sqrt{A^2 + B^2 - 4\Gamma}}{2} = \frac{\sqrt{32\alpha^2}}{2} = \frac{\sqrt{16 \cdot 2 \cdot \alpha^2}}{2} = \frac{4\sqrt{2}|\alpha|}{2} = 2\sqrt{2}|\alpha| \]

\textbf{γ)} Για τα κέντρα των κύκλων έχουμε:
\[ \begin{cases} x = 2\alpha \\ y = 2\alpha \\ \alpha \ne 0 \end{cases} \]
Επομένως, τα κέντρα των κύκλων κινούνται πάνω στην ευθεία $y = x$ με εξαίρεση το σημείο $O(0,0)$, αφού είναι $x \ne 0$ και $y \ne 0$.

\textbf{δ)} Για να εφάπτεται κάποιος από τους κύκλους που ορίζονται από την εξίσωση (1) στον άξονα $x'x$, θα πρέπει να ισχύει:
\[ |y_K| = R \]
Έχουμε διαδοχικά:
\[ |2\alpha| = 2\sqrt{2}|\alpha| \quad \text{ή} \quad 2|\alpha| = 2\sqrt{2}|\alpha| \quad \text{ή} \quad |\alpha| = \sqrt{2}|\alpha| \quad \text{ή} \quad |\alpha| - \sqrt{2}|\alpha| = 0 \]
\[ \quad \text{ή} \quad |\alpha|(1 - \sqrt{2}) = 0 \quad \text{ή} \quad \alpha = 0 \]
Όμως, $\alpha \ne 0$, οπότε δεν υπάρχει τιμή του $\alpha$ ώστε ο αντίστοιχος κύκλος που ορίζεται από την εξίσωση (1) να εφάπτεται του άξονα $x'x$.
\end{lysh}
