\noindent
α) Οι συντελεστές διεύθυνσης των ευθειών ΑΒ και ΑΓ ορίζονται και είναι
\[
\lambda_{AB} = \frac{y_B - y_A}{x_B - x_A} = \frac{0-4}{-1-2} = \frac{-4}{-3} = \frac{4}{3}
\]
και
\[
\lambda_{A\Gamma} = \frac{y_\Gamma - y_A}{x_\Gamma - x_A} = \frac{-2-4}{3-2} = \frac{-6}{1} = -6
\]
Επειδή $\lambda_{AB} \neq \lambda_{A\Gamma}$ οι ευθείες ΑΒ και ΑΓ δεν είναι παράλληλες, οπότε τα σημεία Α,Β και Γ δεν είναι συνευθειακά και αποτελούν κορυφές τριγώνου.

\noindent
β) Η ευθεία ΑΒ έχει συντελεστή διεύθυνσης $\frac{4}{3}$ από το α) ερώτημα και διέρχεται από το σημείο Α(2,4), άρα η εξίσωσή της είναι: $(AB): y - y_A = \lambda(x - x_A)$ ή $y - 4 = \frac{4}{3}(x - 2)$ ή $3(y - 4) = 4(x - 2)$ ή $3y - 12 = 4x - 8$ ή $4x - 3y + 4 = 0$.

Η ευθεία ΑΓ έχει συντελεστή διεύθυνσης $-6$ από το α) ερώτημα και διέρχεται από το σημείο $\Gamma(3,-2)$, άρα η εξίσωσή της είναι: $(A\Gamma): y - y_\Gamma = \lambda(x - x_\Gamma)$ ή $y - (-2) = -6(x - 3)$ ή $y + 2 = -6x + 18$ ή $6x + y - 16 = 0$.

\noindent
i. Στην εξίσωση της ευθείας ΑΒ θέτουμε $x=0$ για να βρούμε το σημείο που τέμνει τον άξονα $y'y$ και έχουμε: $4 \cdot 0 - 3y + 4 = 0 \Leftrightarrow -3y = -4 \Leftrightarrow y = \frac{4}{3}$. Άρα $\Delta(0, \frac{4}{3})$. Ομοίως στην εξίσωση της ευθείας ΑΓ θέτουμε $y=0$ για να βρούμε το σημείο που τέμνει τον άξονα $x'x$ και έχουμε: $6x + 0 - 16 = 0 \Leftrightarrow 6x = 16 \Leftrightarrow x = \frac{16}{6} = \frac{8}{3}$. Άρα $E(\frac{8}{3}, 0)$.

\noindent
ii. $\vec{A\Delta} = (0-2, \frac{4}{3}-4) = (-2, \frac{4-12}{3}) = (-2, -\frac{8}{3})$ και $\vec{AB} = (-1-2, 0-4) = (-3, -4)$, οπότε προφανώς $\vec{A\Delta} = \frac{2}{3} \vec{AB}$.
Άρα τα σημεία A, B, $\Delta$ είναι συνευθειακά.

Και
$\vec{AE} = (\frac{8}{3}-2, 0-4) = (\frac{8-6}{3}, -4) = (\frac{2}{3}, -4)$
και
$\vec{E\Gamma} = (3-\frac{8}{3}, -2-0) = (\frac{9-8}{3}, -2) = (\frac{1}{3}, -2)$
και ισχύει επίσης ότι $\vec{AE} = 2\vec{E\Gamma}$.
Άρα τα σημεία A, E, $\Gamma$ είναι συνευθειακά.

\noindent
γ) $\lambda_{\Delta E} = \frac{\frac{4}{3}-0}{0-\frac{8}{3}} = \frac{\frac{4}{3}}{-\frac{8}{3}} = -\frac{4}{8} = -\frac{1}{2}$
και $\lambda_{B\Gamma} = \frac{-2-0}{3-(-1)} = \frac{-2}{4} = -\frac{1}{2}$
Άρα $\lambda_{\Delta E} = \lambda_{B\Gamma}$, επομένως η ευθεία $\Delta E$ είναι παράλληλη της ευθείας Β$\Gamma$.
\end{lysh}
