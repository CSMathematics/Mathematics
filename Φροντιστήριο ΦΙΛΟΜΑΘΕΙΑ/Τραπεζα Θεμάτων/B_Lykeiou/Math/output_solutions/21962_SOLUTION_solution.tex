\lysh{21962_SOLUTION}{1}
ΛΥΣΗ

α) Έχουμε ότι:
$\vec{AB} = (x_B-x_A, y_B-y_A) = (3-0, 4-3) = (3, 1),$
$\vec{A\Gamma} = (x_\Gamma-x_A, y_\Gamma-y_A) = (1-0, 0-3) = (1, -3).$
Οπότε $\vec{AB} \cdot \vec{A\Gamma} = 3 \cdot 1 + 1 \cdot (-3) = 3 - 3 = 0, \text{ άρα } \vec{AB} \perp \vec{A\Gamma} \text{ ή } \widehat{BA\Gamma} = 90^\circ.$

β) Το σημείο Κ που είναι το μέσο του τμήματος ΒΓ θα έχει συντεταγμένες:
$K\left(\frac{x_B+x_\Gamma}{2}, \frac{y_B+y_\Gamma}{2}\right) \text{ ή } K\left(\frac{3+1}{2}, \frac{4+0}{2}\right) \text{ ή } K(2, 2).$

γ) Από το α) ερώτημα έχουμε ότι η γωνία $\widehat{BA\Gamma}$ είναι ορθή και τα σημεία A, B και $\Gamma$ είναι σημεία του ζητούμενου κύκλου, άρα η γωνία $\widehat{BA\Gamma}$ είναι εγγεγραμμένη και βαίνει σε ημικύκλιο, συνεπώς η υποτείνουσα B$\Gamma$ του τριγώνου AB$\Gamma$, θα είναι διάμετρος του κύκλου και ισούται με:
\[ (\text{B}\Gamma) = \sqrt{(x_\Gamma - x_B)^2 + (y_\Gamma - y_B)^2} = \sqrt{(1-3)^2 + (0-4)^2} = \sqrt{4 + 16} = \sqrt{20} = 2\sqrt{5}. \]
Όμως $\text{B}\Gamma = 2R, \text{ άρα } 2R = 2\sqrt{5} \text{ ή } R = \sqrt{5}.$
Ο κύκλος που διέρχεται από τα σημεία A, B και $\Gamma$ θα έχει ακτίνα R και κέντρο το σημείο K του ερωτήματος β) και η εξίσωσή του θα είναι:
\[ (x - 2)^2 + (y - 2)^2 = 5. \]
