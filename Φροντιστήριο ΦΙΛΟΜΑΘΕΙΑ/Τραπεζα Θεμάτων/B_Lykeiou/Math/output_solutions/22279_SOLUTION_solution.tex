\begin{enumerate}[α)]
    \item Η εξίσωση (1) γράφεται διαδοχικά:
    \[ (y-1)^2 = (3+x)(1-x) \]
    \[ (y-1)^2 = 3 - 3x + x - x^2 \]
    \[ (y-1)^2 = 3 - 2x - x^2 \]
    \[ (x^2 + 2x + 1) + (y-1)^2 = 4 \]

    \[ OK = \sqrt{(x_K - x_O)^2 + (y_K - y_O)^2} = \sqrt{(-1 - 0)^2 + (1 - 0)^2} = \sqrt{2} < R = 2 \]
    Άρα, η αρχή Ο των αξόνων είναι εσωτερικό σημείο του κύκλου (K,R).

    Άρα, η ευθεία ($\varepsilon$) είναι τέμνουσα του κύκλου (K,R).
\end{enumerate}
