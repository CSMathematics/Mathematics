Δίνεται παραλληλόγραμμο ΟΑΓΒ με $\vec{OA} = \vec{a}$ και $\vec{OB} = \vec{b}$, όπου $\vec{a}$ και $\vec{b}$ είναι μη μηδενικά διανύσματα.
\begin{alist}
\item Να δείξετε ότι:
    \begin{rlist}
    \item $|\vec{O\Gamma}|^2 = |\vec{a}|^2 + 2\vec{a} \cdot \vec{b} + |\vec{b}|^2$. \monades{9}
    \item $|\vec{AB}|^2 = |\vec{a}|^2 - 2\vec{a} \cdot \vec{b} + |\vec{b}|^2$. \monades{9}
    \end{rlist}
\item Αν $|\vec{O\Gamma}| = |\vec{AB}|$, να δείξετε ότι το ΟΑΓΒ είναι ορθογώνιο. \monades{7}
\end{alist}
