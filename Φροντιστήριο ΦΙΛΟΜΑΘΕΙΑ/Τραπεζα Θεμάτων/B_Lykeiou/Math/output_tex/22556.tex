Η έλλειψη του παρακάτω σχήματος έχει κορυφές τα σημεία $A'(-5,0)$, $A(5,0)$, $B'(0,-4)$ και $B(0,4)$.
\begin{alist}
    \item Να αποδείξετε ότι:
    \begin{rlist}
        \item Τα μήκη των αξόνων της έλλειψης είναι $(A'A) = 10$ και $(B'B) = 8$. \monades{10}
        \item Οι εστίες της έλλειψης είναι τα σημεία $E'(-3,0)$ και $E(3,0)$. \monades{10}
    \end{rlist}
    \item Έστω $M$ ένα σημείο της έλλειψης. Να αποδείξετε ότι $(ME') + (ME) = 10$. \monades{5}
\end{alist}
