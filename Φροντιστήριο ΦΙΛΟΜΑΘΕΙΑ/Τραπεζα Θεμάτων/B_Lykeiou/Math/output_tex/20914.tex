Στο παρακάτω σχήμα, δίνονται τα διανύσματα $\vec{a}, \vec{\beta}$.
\begin{alist}
    \item Να σημειώσετε πάνω στο σχήμα τα διανύσματα $\overrightarrow{OA} = \vec{a}$, $\overrightarrow{OB} = \vec{\beta}$ όπου $O$ η αρχή των αξόνων. \monades{08}
    \item Να βρείτε τις συντεταγμένες των διανυσμάτων $\overrightarrow{OA} = \vec{a}$, $\overrightarrow{OB} = \vec{\beta}$ και $\overrightarrow{AB}$. \monades{09}
    \item Να αποδείξετε ότι το τρίγωνο $OAB$ είναι ορθογώνιο. \monades{08}
\end{alist}
