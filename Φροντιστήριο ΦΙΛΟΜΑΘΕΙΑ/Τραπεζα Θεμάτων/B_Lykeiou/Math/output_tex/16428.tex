\Askhsh{16428}{2}
\begin{ylh}{1}
    \item 1.5. Εσωτερικό Γινόμενο Διανυσμάτων.
\end{ylh}
Δίνονται τα διανύσματα $\vec{\alpha}$ και $\vec{\beta}$ με: $|\vec{\alpha}| = \frac{\sqrt{3}}{2}$, $|\vec{\beta}| = \frac{1}{2}$ και $|3\vec{\alpha} + 2\vec{\beta}| = |\vec{\alpha} - 2\vec{\beta}|.$
\begin{alist}
\item Να αποδείξετε ότι: $\vec{\alpha} \cdot \vec{\beta} = -\frac{3}{8}$. \monades{15}
\item Να υπολογίσετε τη γωνία των διανυσμάτων $\vec{\alpha}$ και $\vec{\beta}$. \monades{10}
\end{alist}
