Θεωρούμε μία ευθεία $\varepsilon: y = \lambda x$ με θετική κλίση $\lambda$.

\begin{alist}
\item Αν $\delta_1$ είναι η διχοτόμος της οξείας γωνίας που σχηματίζει η ευθεία $\varepsilon$ με τον $x'x$ άξονα, τότε να αποδείξετε ότι η εξίσωση της διχοτόμου $\delta_1$ είναι:
    \[ y = \lambda_1 x \quad \text{με} \quad \lambda_1 = \frac{\lambda}{1+\sqrt{1+\lambda^2}}. \] \monades{12}
\item Αν $\delta_2$ είναι η διχοτόμος της αμβλείας γωνίας που σχηματίζει η ευθεία $\varepsilon$ με τον $x'x$ άξονα, τότε να αποδείξετε ότι η εξίσωση της διχοτόμου $\delta_2$ είναι:
    \[ y = \lambda_2 x \quad \text{με} \quad \lambda_2 = \frac{\lambda}{1-\sqrt{1+\lambda^2}}. \] \monades{7}
\item Αν $\lambda = 1$, να εφαρμόσετε τους τύπους του α) ερωτήματος για να αποδείξετε ότι:
    \[ \varepsilon\varphi 22,5^\circ = \sqrt{2} - 1. \] \monades{6}
\end{alist}
