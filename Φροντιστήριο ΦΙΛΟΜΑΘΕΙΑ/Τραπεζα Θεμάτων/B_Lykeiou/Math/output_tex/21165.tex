Θεωρούμε το παραλληλόγραμμο $AB\Gamma\Delta$ και έστω $\vec{AB} = \vec{a}$ και $\vec{A\Delta} = \vec{\beta}$. Τα σημεία $E$ και $Z$ είναι τέτοια ώστε $\vec{AE} = -\frac{1}{2}\vec{AB}$ και $\vec{AZ} = \frac{1}{3}\vec{A\Delta}$.

\begin{alist}
    \item Να αποδείξετε ότι: $\vec{EZ} = \frac{1}{2}\vec{a} + \frac{1}{3}\vec{\beta}$ και $\vec{Z\Gamma} = \vec{a} + \frac{2}{3}\vec{\beta}$. \monades{10}
    \item Να αποδείξετε ότι: $\vec{Z\Gamma}=2\vec{EZ}$. \monades{9}
    \item Να δείξετε ότι τα σημεία $Z$, $E$ και $\Gamma$ είναι συνευθειακά. \monades{6}
\end{alist}
