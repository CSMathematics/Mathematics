\Askhsh{22044}{2}
\begin{ylh}{1}
    \item 1.4. Συντεταγμένες στο Επίπεδο.
\end{ylh}
Δίνονται τα σημεία $A(0,0)$, $B(4,0)$ και $\Gamma(5,1)$.
\begin{alist}
\item Να σχεδιάσετε ένα ορθοκανονικό σύστημα αξόνων και να τοποθετήσετε σε αυτό τα σημεία $A, B, \Gamma$.  \monades{10}
\item Να βρείτε τις συντεταγμένες ενός τέταρτου σημείου $\Delta$ έτσι ώστε το τετράπλευρο $AB\Gamma\Delta$ να είναι παραλληλόγραμμο. Να αιτιολογήσετε την απάντησή σας.  \monades{15}
\end{alist}
