\Askhsh{21696}{4}
\begin{ylh}{1}
    \item 3.1 Ο Κύκλος
\end{ylh}
Θεωρούμε την εξίσωση $x^2 + y^2 - 2x + 4y = 0$, (1) και την ευθεία $\varepsilon: x - 2y + 3 = 0$.
\begin{alist}
\item Να αποδείξετε ότι η εξίσωση (1) παριστάνει κύκλο C του οποίου να βρείτε το κέντρο Κ και την ακτίνα $\rho$. \monades{5}
\item Να εξετάσετε αν η ευθεία $\varepsilon$ έχει κοινά σημεία με τον κύκλο C. \monades{5}
\item Να βρείτε τις εφαπτόμενες $\varepsilon_1, \varepsilon_2$ του κύκλου C που είναι κάθετες στην ευθεία $\varepsilon$. \monades{7}
\item Να αποδείξετε ότι $d(\varepsilon_1, \varepsilon_2)=2\rho$. Πως αιτιολογείται γεωμετρικά το συμπέρασμα αυτό; \monades{8}
\end{alist}
