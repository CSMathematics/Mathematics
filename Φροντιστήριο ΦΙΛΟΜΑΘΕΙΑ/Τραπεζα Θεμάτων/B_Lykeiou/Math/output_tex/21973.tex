    \item 3.1 Ο Κύκλος
    \item 3.2 Η Παραβολή
    \item 3.3 Η Έλλειψη
    \item 3.4 Η Υπερβολή.

α) Να χαρακτηρίσετε τις προτάσεις που ακολουθούν γράφοντας στην κόλλα σας δίπλα στον αριθμό που αντιστοιχεί σε κάθε πρόταση τη λέξη \textbf{ΣΩΣΤΟ}, αν η πρόταση είναι σωστή ή \textbf{ΛΑΘΟΣ}, αν η πρόταση είναι λανθασμένη.
\begin{rlist}
\item Αν ισχύει $|\vec{\alpha}| = \lambda |\vec{\beta}|$ τότε υποχρεωτικά $\vec{\alpha} // \vec{\beta}$.
\item Η εφαπτομένη του κύκλου C: $x^2 + y^2 = \rho^2$ σε ένα σημείο του $A(x_1, y_1)$, έχει εξίσωση $xx_1 + yy_1 = \rho^2$.
\item Η διευθετούσα της παραβολής $y^2 = 2px$, έχει εξίσωση $x = -\frac{p}{2}$.
\item Η εκκεντρότητα μιας έλλειψης είναι μικρότερη της μονάδας.
\item Η εξίσωση: $x^2 + y^2 = \alpha^2$ είναι εξίσωση ισοσκελούς υπερβολής.
\end{rlist}

β) Να αποδείξετε ότι η εξίσωση της ευθείας που διέρχεται από το σημείο $A(x_0, y_0)$ και έχει συντελεστή διεύθυνσης $\lambda$ είναι $y - y_0 = \lambda(x - x_0)$.
