\begin{alist}
    \item Η συνάρτηση $f$ είναι παραγωγίσιμη για κάθε $x \in \mathbb{R}$ με
    \[
        f'(x) = (x^3 + 3x + 6)' = 3 \cdot x^2 + 3 \cdot 1 + 0 = 3x^2 + 3
    \]

    \item Είναι:
    \[
        f'(0) = 3 \cdot 0^2 + 3 = 0 + 3 = 3
    \]

    \item Παρατηρούμε ότι για κάθε $x \in \mathbb{R}$ είναι:
    \[
        f'(x) = 3x^2 + 3 > 0
    \]
    αφού $x^2 \ge 0$ για κάθε $x \in \mathbb{R}$.

    Επομένως, η συνάρτηση $f$ είναι γνησίως αύξουσα στο $\mathbb{R}$.
\end{alist}
