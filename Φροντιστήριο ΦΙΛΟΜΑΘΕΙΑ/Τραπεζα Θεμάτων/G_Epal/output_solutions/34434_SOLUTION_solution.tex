\lysh{34434}{2}
\begin{alist}
    \item Από το πολύγωνο συχνοτήτων παρατηρούμε ότι οι μαθητές που βαθμολογήθηκαν με άριστα είναι:

    Σε κανένα μάθημα: $\nu_1=15$, Σε ένα μάθημα: $\nu_2=45$,

    Σε δύο μαθήματα: $\nu_3=40$ και σε τρία μαθήματα: $\nu_4=20$.

    Οπότε το σύνολο των μαθητών του συγκεκριμένου δείγματος είναι :
    \[ \nu=\nu_1+\nu_2+\nu_3+\nu_4=15+45+40+20=120 \text{ μαθητές}. \]
    
    \item Για καθεμία ομάδα μαθητών του δείγματος, η συχνότητα $\nu_i$ και η σχετική συχνότητα $f_i$ συνδέονται από τον τύπο:
    \[ f_i = \frac{\nu_i}{\nu}. \]
    Οπότε για καθεμία από τις σχετικές συχνότητες θα έχουμε:

    Άριστα σε κανένα μάθημα: $f_1 = \frac{\nu_1}{\nu} = \frac{15}{120} = \frac{1}{8} = 0,125$

    Άριστα σε ένα μάθημα: $f_2 = \frac{\nu_2}{\nu} = \frac{45}{120} = \frac{3}{8} = 0,375$

    Άριστα σε δύο μαθήματα: $f_3 = \frac{\nu_3}{\nu} = \frac{40}{120} = \frac{1}{3} = 0,33\dots$

    Άριστα σε τρία μαθήματα: $f_3 = \frac{\nu_3}{\nu} = \frac{20}{120} = \frac{1}{6} = 0,16\dots$
\end{alist}
