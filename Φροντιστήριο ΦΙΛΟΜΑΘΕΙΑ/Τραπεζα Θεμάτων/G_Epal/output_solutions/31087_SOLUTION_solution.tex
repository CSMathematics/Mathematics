\begin{alist}
\item Οι ημέρες απουσίας των 11 μαθητών σε αύξουσα σειρά είναι:
\[ 1, 1, 2, 3, 3, 3, 4, 4, 6, 7, 10 \]
Η διάμεσος $\delta$ θα είναι η μεσαία παρατήρηση, δηλαδή η $6^{\eta}$ παρατήρηση που είναι ο αριθμός 3, άρα $\delta=3$.
\item Η μέση τιμή των ημερών απουσίας προκύπτει από τον τύπο:
\[ \bar{x} = \frac{t_1 + t_2 + \dots + t_{11}}{11} = \frac{1+1+2+3+3+3+4+4+6+7+10}{11} = \frac{44}{11} = 4. \]
