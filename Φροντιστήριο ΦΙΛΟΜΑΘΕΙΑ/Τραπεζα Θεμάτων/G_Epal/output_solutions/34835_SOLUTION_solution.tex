\begin{alist}
\item Αν $\mathrm{A}\Delta = \mathrm{B}\Gamma = x > 0$ και $\mathrm{AB} = \mathrm{ZE} = \mathrm{H}\Theta = \Delta\Gamma = y > 0$. Έχουμε:
\[ 2x + 4y = 200 \implies 2x = 200 - 4y \implies x = 100 - 2y \]
Είναι $y > 0$. Επίσης $x > 0 \implies 100 - 2y > 0 \implies 100 > 2y \implies y < 50$.
Είναι:
\[ y > 0 \implies 100 - x > 0 \implies x < 100 \]
Επομένως, το συνολικό εμβαδόν του ορθογωνίου $\mathrm{AB}\Gamma\Delta$, συναρτήσει του $x$, είναι:
\[ E(x) = x \cdot \frac{100-x}{2} = \frac{100x - x^2}{2}, \quad 0 < x < 100 \]
\item Η συνάρτηση $E(x)$ είναι παραγωγίσιμη για $x \in (0, 100)$ με:
\[ E'(x) = \left(\frac{100x - x^2}{2}\right)' = \frac{1}{2} (100 - 2x) = 50 - x \]
$E'(x) = 0 \implies 50 - x = 0 \implies x = 50$
$E'(x) > 0 \implies 50 - x > 0 \implies x < 50$
$E'(x) < 0 \implies 50 - x < 0 \implies x > 50$

Τα πρόσημα της παραγώγου της συνάρτησης $E(x)$ φαίνονται στον ακόλουθο πίνακα:

Για τη συνάρτηση $E$ ισχύουν $E'(x) > 0$ στο $(0,50)$ και $E'(x) < 0$ στο $(50,100)$. Επομένως, η συνάρτηση $E$ παρουσιάζει μέγιστο για $x=50$. Τότε είναι:
\[ y = \frac{100-50}{2} = \frac{50}{2} = 25 \]
\item Το μέγιστο εμβαδόν του ορθογωνίου $\mathrm{AB}\Gamma\Delta$ ισούται με:
\[ E(50) = \frac{100 \cdot 50 - 50^2}{2} = \frac{5000 - 2500}{2} = \frac{2500}{2} = 1250 \text{ m}^2 \]
\end{alist}
