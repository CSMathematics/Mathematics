    \item Ο ρυθμός μεταβολής της $f(x)$ ως προς $x$ όταν $x = 2$ ισούται με $f'(2)$. Από τη γραφική παράσταση της συνάρτησης $f'$ παρατηρούμε ότι $f'(2) = 1$.
    \item Από τη γραφική παράσταση της συνάρτησης $f'$ παρατηρούμε ότι:
    \[ f'(x) > 0 \text{ για κάθε } x \in (0,3) \]
    Άρα, η συνάρτηση $f$ είναι γνησίως αύξουσα στο διάστημα $[0,3]$.
    \item Από τη γραφική παράσταση της συνάρτησης $f'$ παρατηρούμε επίσης ότι:
    \[ f'(x) < 0 \text{ για κάθε } x \in (3,4) \text{ και } f'(3) = 0 \]
    Για τη συνάρτηση $f$ ισχύουν $f'(3) = 0$, $f'(x) > 0$ στο $(0,3)$ (η $f$ είναι γνησίως αύξουσα στο διάστημα $[0,3]$) και $f'(x) < 0$ στο $(3,4)$ (η $f$ είναι γνησίως φθίνουσα στο διάστημα $[3,4]$). Επομένως, η $f$ παρουσιάζει στο διάστημα $[0,4]$ μέγιστο για $x_o = 3$.
\end{alist}
