\lysh{24357}{2}
\begin{alist}
\item Για κάθε $x \in \mathbb{R}$ η συνάρτηση $f$ είναι παραγωγίσιμη με
\[ f'(x) = (-x^2 + 2x + 4)' = -2x + 2 . \]

\item Λόγω του ερωτήματος (α) είναι: $f'(5) = -2 \cdot 5 + 2 = -10 + 2 = -8$.

\item Η συνάρτηση $f$ είναι γνησίως φθίνουσα στα διαστήματα του πεδίου ορισμού της για τα οποία η $f'$ είναι αρνητική.

Επομένως $f'(x) < 0 \Leftrightarrow -2x + 2 < 0 \Leftrightarrow x > 1$.

Άρα η συνάρτηση $f$ είναι γνησίως φθίνουσα στο διάστημα $(1, +\infty)$.
\end{alist}
