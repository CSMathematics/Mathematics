\begin{ylh}{1}
    \item 2.3 Μέτρα Θέσης και Διασποράς
\end{ylh}
Στη διάρκεια του χειμώνα, από το σύνολο των μαθητών μιας τάξης, οι δέκα σημείωσαν τις εξής ημέρες απουσίας από το σχολείο: $6, 7, 1, 2, 3, 5, 2, 4, 4, 6$. Να βρείτε:
\begin{alist}
    \item το εύρος των ημερών απουσίας που σημειώθηκαν. \monades{8}
    \item τη διάμεσο των ημερών απουσίας που σημειώθηκαν. \monades{8}
    \item τη μέση τιμή των ημερών απουσίας που σημειώθηκαν. \monades{9}
\end{alist}
