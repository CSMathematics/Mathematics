\begin{alist}
    \item Να αποδείξετε ότι η απόσταση $AM$, συναρτήσει του $x$, είναι:
    \[ d(x) = \sqrt{x^2 - 2x + 9}, x \ge 0 \]
    \monades{09}
    \item Να βρείτε για ποιο σημείο $M$ η απόσταση $AM$ γίνεται ελάχιστη. Θεωρείστε ότι η ελάχιστη απόσταση θα παρουσιαστεί όταν το υπόριζο $x^2 - 2x + 9, x \ge 0$, γίνει ελάχιστο.
    \monades{10}
    \item Να βρείτε την ελάχιστη απόσταση $AM$.

\end{alist}
