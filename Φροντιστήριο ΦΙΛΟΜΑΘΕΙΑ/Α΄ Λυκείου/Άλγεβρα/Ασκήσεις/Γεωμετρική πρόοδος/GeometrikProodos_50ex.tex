\paragraph{Ομάδα Α: Βασικοί ορισμοί και αναγνώριση Γ.Π.}

\askhsh
Να εξετάσετε αν οι παρακάτω ακολουθίες είναι γεωμετρικές προόδοι:
\begin{multicols}{2}
\begin{alist}
  \item $2,\ 6,\ 18,\ 54,\ \ldots$
  \item $5,\ 10,\ 20,\ 40,\ \ldots$
  \item $1,\ -2,\ 4,\ -8,\ \ldots$
  \item $3,\ 6,\ 12,\ 15,\ \ldots$
  \item $81,\ 27,\ 9,\ 3,\ \ldots$
  \item $\dfrac{1}{2},\ \dfrac{1}{4},\ \dfrac{1}{8},\ \dfrac{1}{16},\ \ldots$
\end{alist}
\end{multicols}

\askhsh
Για κάθε γεωμετρική πρόοδο, να βρείτε τον λόγο $\lambda$:
\begin{multicols}{2}
\begin{alist}
  \item $4,\ 12,\ 36,\ 108,\ \ldots$
  \item $100,\ 50,\ 25,\ 12{,}5,\ \ldots$
  \item $-2,\ 6,\ -18,\ 54,\ \ldots$
  \item $\dfrac{1}{3},\ 1,\ 3,\ 9,\ \ldots$
\end{alist}
\end{multicols}

\askhsh
Δίνεται η γεωμετρική πρόοδος με πρώτο όρο $\alpha_1 = 3$ και λόγο $\lambda = 2$.
\begin{alist}
  \item Να βρείτε τους πέντε πρώτους όρους της.
  \item Να λύσετε την εξίσωση $\alpha_\nu = 192$.
\end{alist}

\askhsh
Δίνεται η γεωμετρική πρόοδος με πρώτο όρο $\alpha_1 = 64$ και λόγο $\lambda = \dfrac{1}{2}$.
\begin{alist}
  \item Να βρείτε τους έξι πρώτους όρους της.
  \item Να λύσετε την ανίσωση $\alpha_\nu > 1$.
\end{alist}

\askhsh
Έστω γεωμετρική πρόοδος $(\alpha_\nu)$ με $\alpha_2 = 6$ και $\alpha_3 = 18$.
\begin{alist}
  \item Να βρείτε τον πρώτο όρο $\alpha_1$ και τον λόγο $\lambda$.
  \item Να δείξετε ότι η ακολουθία $(\beta_\nu)$ με $\beta_\nu = \log_3 \alpha_\nu$ είναι αριθμητική πρόοδος.
\end{alist}

\askhsh
Έστω γεωμετρική πρόοδος $(\alpha_\nu)$ με $\alpha_4 = 24$ και $\alpha_6 = 96$.
\begin{alist}
  \item Να βρείτε τον λόγο $\lambda$ της Γ.Π.
  \item Να βρείτε τον πρώτο όρο $\alpha_1$ αν $\lambda > 0$.
  \item Να λύσετε την ανίσωση $\alpha_\nu < 1000$.
\end{alist}

\paragraph{Ομάδα Β: Ο ν-οστός όρος Γ.Π.}

\askhsh
Να υπολογίσετε τον $\alpha_{10}$ σε καθεμία από τις παρακάτω γεωμετρικές προόδους:
\begin{multicols}{2}
\begin{alist}
  \item $\alpha_1 = 2$ και $\lambda = 2$
  \item $\alpha_1 = 3$ και $\lambda = 3$
  \item $\alpha_1 = 1$ και $\lambda = -2$
  \item $\alpha_1 = 1024$ και $\lambda = \dfrac{1}{2}$
\end{alist}
\end{multicols}

\askhsh
Δίνεται η γεωμετρική πρόοδος με $\alpha_1 = 5$ και $\lambda = 3$. Να βρείτε:
\begin{alist}
  \item Τον γενικό όρο $\alpha_\nu$.
  \item Τον όρο $\alpha_7$.
\end{alist}

\askhsh
Δίνεται η γεωμετρική πρόοδος με $\alpha_1 = 2$ και $\lambda = -3$. Να βρείτε:
\begin{alist}
  \item Τον γενικό όρο $\alpha_\nu$.
  \item Τον όρο $\alpha_8$.
  \item Το πρόσημο του όρου $\alpha_{100}$.
\end{alist}

\askhsh
Ο 5ος όρος γεωμετρικής προόδου είναι $\alpha_5 = 48$ και ο λόγος της είναι $\lambda = 2$. Να βρείτε τον πρώτο όρο $\alpha_1$ και τον δέκατο όρο $\alpha_{10}$.

\askhsh
Σε γεωμετρική πρόοδο με $\alpha_3 = 12$ και $\alpha_6 = 96$, να βρείτε:
\begin{alist}
  \item Τον λόγο $\lambda$ της προόδου.
  \item Τον πρώτο όρο $\alpha_1$.
  \item Τον δέκατο όρο $\alpha_{10}$.
\end{alist}

\askhsh
Σε γεωμετρική πρόοδο ισχύει $\alpha_2 = 10$ και $\alpha_5 = 80$.
\begin{alist}
  \item Να βρείτε τον λόγο $\lambda$.
  \item Να βρείτε τον όρο $\alpha_8$.
  \item Να υπολογίσετε το άθροισμα $\alpha_1 + \alpha_2 + \ldots + \alpha_6$.
\end{alist}

\askhsh
Σε γεωμετρική πρόοδο με θετικούς όρους ισχύει $\alpha_1 \cdot \alpha_5 = 81$.
\begin{alist}
  \item Να βρείτε τον $\alpha_3$.
  \item Αν επιπλέον $\alpha_1 + \alpha_5 = 30$, να βρείτε τους $\alpha_1$ και $\alpha_5$.
\end{alist}

\askhsh
Σε γεωμετρική πρόοδο ισχύει $\alpha_3 \cdot \alpha_7 = 144$ και $\alpha_5 > 0$.
\begin{alist}
  \item Να βρείτε τον $\alpha_5$.
  \item Αν ο λόγος της Γ.Π. είναι $\lambda = 2$, να βρείτε τον $\alpha_1$.
\end{alist}

\paragraph{Ομάδα Γ: Άθροισμα όρων Γ.Π.}

\askhsh
Να υπολογίσετε το άθροισμα $S_\nu$ των πρώτων $\nu$ όρων:
\begin{multicols}{2}
\begin{alist}
  \item $1 + 2 + 4 + \ldots + 2^9$
  \item $3 + 9 + 27 + \ldots + 3^8$
  \item $1 - 2 + 4 - 8 + \ldots + 512$
  \item $1 + \dfrac{1}{2} + \dfrac{1}{4} + \ldots + \dfrac{1}{256}$
\end{alist}
\end{multicols}

\askhsh
Δίνεται η Γ.Π. με $\alpha_1 = 4$ και $\lambda = 3$.
\begin{alist}
  \item Να βρείτε το άθροισμα $S_6$.
  \item Να λύσετε την εξίσωση $S_\nu = 4 \cdot \dfrac{3^\nu - 1}{2} = 1456$.
\end{alist}

\askhsh
Δίνεται η Γ.Π. με $\alpha_1 = 2$ και $\lambda = 2$.
\begin{alist}
  \item Να βρείτε το άθροισμα $S_8$.
  \item Να βρείτε το πλήθος $\nu$ ώστε $S_\nu = 2046$.
\end{alist}

\askhsh
Σε μια Γ.Π. με $\alpha_1 = 6$ και $\lambda = \dfrac{1}{3}$:
\begin{alist}
  \item Να υπολογίσετε το $S_5$.
  \item Να λύσετε την ανίσωση $\alpha_\nu > \dfrac{1}{100}$.
\end{alist}

\askhsh
Δίνεται η Γ.Π. με $\alpha_1 = 1$ και $\lambda = -2$.
\begin{alist}
  \item Να βρείτε το άθροισμα $S_{10}$.
  \item Να εξετάσετε αν η ακολουθία $(|\alpha_\nu|)$ είναι Γ.Π. και να βρείτε τον λόγο της.
\end{alist}

\askhsh
Σε γεωμετρική πρόοδο με $\alpha_1 = 2$ και $\alpha_4 = 54$:
\begin{alist}
  \item Να βρείτε τον λόγο $\lambda$.
  \item Να βρείτε το άθροισμα $S_6$.
  \item Να συγκρίνετε το $S_6$ με το διπλάσιο του $\alpha_6$.
\end{alist}

\askhsh
Σε Γ.Π. με $S_4 = 40$ και $\lambda = 3$:
\begin{alist}
  \item Να βρείτε τον πρώτο όρο $\alpha_1$.
  \item Να βρείτε το άθροισμα $S_6 - S_4$.
\end{alist}

\askhsh
Σε γεωμετρική πρόοδο ισχύει $\alpha_1 = 1$, $\alpha_\nu = 256$ και $S_\nu = 511$. Να βρείτε τον λόγο $\lambda$ και το πλήθος $\nu$ των όρων.

\paragraph{Ομάδα Δ: Εύρεση παραμέτρου}

\askhsh
Οι αριθμοί $2,\ x,\ 8$ είναι διαδοχικοί όροι γεωμετρικής προόδου με $x > 0$.
\begin{alist}
  \item Να βρείτε την τιμή του $x$.
  \item Να βρείτε τον λόγο $\lambda$ της Γ.Π.
  \item Να εξετάσετε αν οι αριθμοί $2,\ x,\ 8$ μπορούν να είναι και σε Α.Π.
\end{alist}

\askhsh
Οι αριθμοί $3,\ x,\ 12$ είναι διαδοχικοί όροι γεωμετρικής προόδου με $x > 0$.
\begin{alist}
  \item Να βρείτε την τιμή του $x$.
  \item Να βρείτε τον 5ο όρο της Γ.Π.
\end{alist}

\askhsh
Οι αριθμοί $x-1,\ x+1,\ x+5$ είναι διαδοχικοί όροι γεωμετρικής προόδου.
\begin{alist}
  \item Να βρείτε την τιμή του $x$.
  \item Να γράψετε τους τρεις πρώτους όρους της Γ.Π.
  \item Να βρείτε το άθροισμα $S_5$.
\end{alist}

\askhsh
Αν οι αριθμοί $\alpha,\ 6,\ \beta$ είναι σε Γ.Π. με $\alpha + \beta = 15$, να βρείτε τους $\alpha$ και $\beta$ (δίνεται $\alpha < \beta$).\\\\

\askhsh
Τρεις αριθμοί είναι σε γεωμετρική πρόοδο. Το άθροισμά τους είναι 21 και το γινόμενό τους 216. Να βρείτε τους αριθμούς.\\\\

\askhsh
Τρεις θετικοί αριθμοί είναι σε Γ.Π., το άθροισμά τους είναι 26 και το άθροισμα των τετραγώνων τους είναι 364. Να βρείτε τους τρεις αριθμούς.\\\\

\askhsh
Να βρείτε τρεις θετικούς αριθμούς που είναι διαδοχικοί όροι γεωμετρικής προόδου, αν το άθροισμά τους είναι 14 και το άθροισμα των αντιστρόφων τους είναι $\dfrac{7}{8}$.

\paragraph{Ομάδα Ε: Ιδιότητες Γ.Π.}

\askhsh
Σε γεωμετρική πρόοδο $(\alpha_\nu)$ να δείξετε ότι:
\begin{alist}
  \item $\alpha_\mu \cdot \alpha_\nu = \alpha_1 \cdot \alpha_{\mu+\nu-1}$
  \item $\alpha_\nu^2 = \alpha_{\nu-1} \cdot \alpha_{\nu+1}$
\end{alist}

\askhsh
Σε Γ.Π. με λόγο $\lambda > 0$ να δείξετε ότι $\dfrac{\alpha_{\nu+2}}{\alpha_\nu} = \lambda^2$.

\askhsh
Σε γεωμετρική πρόοδο ισχύει $\alpha_5 = 48$ και $\alpha_8 = 384$.
\begin{alist}
  \item Να βρείτε τον λόγο $\lambda$.
  \item Να βρείτε το γινόμενο $\alpha_6 \cdot \alpha_7$.
  \item Να υπολογίσετε το άθροισμα $\alpha_5 + \alpha_6 + \alpha_7 + \alpha_8$.
\end{alist}

\askhsh
Σε γεωμετρική πρόοδο με $\alpha_3 = 8$ και $\alpha_7 = 128$:
\begin{alist}
  \item Να βρείτε τον λόγο $\lambda$ και τον πρώτο όρο $\alpha_1$.
  \item Να βρείτε το γινόμενο $\alpha_4 \cdot \alpha_6$.
  \item Να λύσετε την εξίσωση $\alpha_\nu = 512$.
\end{alist}

\askhsh
Σε μια Γ.Π. ισχύει $\alpha_2 + \alpha_4 = 30$ και $\alpha_3 + \alpha_5 = 60$. Να βρείτε τον $\alpha_1$ και τον λόγο $\lambda$.

\paragraph{Ομάδα ΣΤ: Εφαρμογές -- Πρακτικά προβλήματα}

\askhsh
Ένας πληθυσμός βακτηρίων διπλασιάζεται κάθε ώρα. Αν υπάρχουν αρχικά 500 βακτήρια, να βρείτε:
\begin{alist}
  \item Πόσα βακτήρια θα υπάρχουν μετά από 8 ώρες.
  \item Μετά από πόσες ώρες ο πληθυσμός θα ξεπεράσει τα 500\,000.
\end{alist}

\askhsh
Ένα αυτοκίνητο αξίας \EUR{20\,000} χάνει κάθε χρόνο το 20\% της αξίας του. Να βρείτε:
\begin{alist}
  \item Την αξία του μετά από 5 χρόνια.
  \item Μετά από πόσα χρόνια η αξία του θα πέσει κάτω από \EUR{5\,000}.
\end{alist}

\askhsh
Ένα ραδιενεργό στοιχείο έχει χρόνο ημίσειας ζωής 2 χρόνια.
\begin{alist}
  \item Αν αρχικά υπάρχουν 80 γραμμάρια, να βρείτε πόσα γραμμάρια θα απομείνουν μετά από 10 χρόνια.
  \item Μετά από πόσα χρόνια η μάζα θα πέσει κάτω από 1 γραμμάριο;
\end{alist}

\askhsh
Ένα bouncing ball πέφτει από ύψος 16 μέτρων. Κάθε φορά που αναπηδά φτάνει στο $\dfrac{3}{4}$ του προηγούμενου ύψους. Να βρείτε:
\begin{alist}
  \item Σε τι ύψος θα φτάσει μετά την 4η αναπήδηση.
  \item Μετά από ποια αναπήδηση θα φτάσει κάτω από 1 μέτρο.
\end{alist}

\askhsh
Ένα κεφάλαιο \EUR{8\,000} κατατίθεται με ετήσιο επιτόκιο 5\% (ανατοκισμός).
\begin{alist}
  \item Ποια θα είναι η αξία του μετά από 4 χρόνια;
  \item Μετά από πόσα χρόνια το κεφάλαιο θα διπλασιαστεί;
\end{alist}

\askhsh
Κάποιος καταθέτει στην αρχή κάθε έτους \EUR{1\,000} με ετήσιο επιτόκιο 4\% (ανατοκισμός).
\begin{alist}
  \item Ποια θα είναι η συνολική αξία μετά από 5 καταθέσεις;
  \item Να δείξετε ότι η τελική αξία κάθε κατάθεσης αποτελεί Γ.Π. και να βρείτε τον λόγο της.
\end{alist}

\paragraph{Ομάδα Ζ: Συνδυαστικές ασκήσεις (Γ.Π. \& Α.Π.)}

\askhsh
Οι αριθμοί $2,\ x,\ y,\ 16$ είναι σε Γ.Π.
\begin{alist}
  \item Να βρείτε τα $x$ και $y$.
  \item Να βρείτε το άθροισμα $S_4 = 2 + x + y + 16$.
  \item Να εξετάσετε αν υπάρχουν τιμές του $x$, $y$ ώστε να είναι και σε Α.Π.
\end{alist}

\askhsh
Οι αριθμοί $2,\ x,\ y,\ 54$ είναι σε Γ.Π.
\begin{alist}
  \item Να βρείτε τα $x$ και $y$.
  \item Να βρείτε τον 6ο όρο της Γ.Π.
\end{alist}

\askhsh
Τρεις αριθμοί $\alpha,\ \beta,\ \gamma$ είναι σε αριθμητική πρόοδο και τρεις αριθμοί $\alpha,\ \beta,\ \delta$ είναι σε γεωμετρική πρόοδο. Αν $\alpha = 1$, $\gamma = 5$ και $\delta = 9$, να βρείτε τον $\beta$.\\\\

\askhsh
Να βρείτε τρεις αριθμούς ώστε οι 1ος, 2ος, 3ος να είναι σε Α.Π. με διαφορά 2, ενώ οι 1ος, 2ος, 4ος ($4^{\text{ος}} = 3^{\text{ος}} + 5$) να είναι σε Γ.Π.\\\\

\askhsh
Σε μια ακολουθία οι όροι $\alpha_1,\ \alpha_2,\ \alpha_3$ είναι σε Α.Π. και οι όροι $\alpha_2,\ \alpha_3,\ \alpha_4$ είναι σε Γ.Π. Αν $\alpha_1 = 2$ και $\alpha_4 = 16$, να βρείτε τους $\alpha_2$ και $\alpha_3$.

\paragraph{Ομάδα Η: Σωστό -- Λάθος}

\askhsh
Να χαρακτηρίσετε τις παρακάτω προτάσεις ως Σωστές (\textbf{Σ}) ή Λανθασμένες (\textbf{Λ}):
\begin{alist}
  \item Σε Γ.Π. με λόγο $\lambda = 1$, όλοι οι όροι είναι ίσοι.
  \item Σε Γ.Π. με λόγο $\lambda < 0$, οι όροι εναλλάσσουν πρόσημο.
  \item Σε Γ.Π. με θετικούς όρους, ο λόγος είναι πάντα θετικός.
  \item Αν $\alpha_1 = 0$, τότε μπορεί να σχηματιστεί Γ.Π.
  \item Κάθε Γ.Π. έχει άπειρους όρους.
\end{alist}

\askhsh
Να χαρακτηρίσετε τις παρακάτω προτάσεις ως Σωστές (\textbf{Σ}) ή Λανθασμένες (\textbf{Λ}):
\begin{alist}
  \item Ο γενικός όρος Γ.Π. είναι $\alpha_\nu = \alpha_1 \cdot \lambda^{\nu-1}$.
  \item Αν $\lambda = 2$, τότε $\alpha_5 = 2 \alpha_4$.
  \item Σε Γ.Π. ισχύει πάντα $\alpha_{\nu}^2 = \alpha_{\nu-1} \cdot \alpha_{\nu+1}$.
  \item Αν $\lambda > 1$, τότε η Γ.Π. είναι γνησίως αύξουσα.
  \item Το άθροισμα $S_\nu = \alpha_1 \cdot \dfrac{1 - \lambda^\nu}{1 - \lambda}$ ισχύει για κάθε $\lambda$.
\end{alist}

\paragraph{Ομάδα Θ: Αποδείξεις}

\askhsh
\begin{alist}
  \item Να αποδείξετε ότι σε κάθε Γ.Π. ισχύει: $\alpha_\nu = \alpha_\mu \cdot \lambda^{\nu - \mu}$.
  \item Χρησιμοποιώντας τον παραπάνω τύπο, αν $\alpha_3 = 12$ και $\lambda = 2$, να βρείτε τους $\alpha_1$ και $\alpha_7$.
\end{alist}

\askhsh
Να αποδείξετε τον τύπο του αθροίσματος των $\nu$ πρώτων όρων Γ.Π.:
\[
S_\nu = \alpha_1 \cdot \frac{1 - \lambda^\nu}{1 - \lambda}, \quad \lambda \neq 1
\]

\askhsh
\begin{alist}
  \item Να δείξετε ότι αν $\alpha,\ \beta,\ \gamma$ είναι διαδοχικοί όροι Γ.Π., τότε ισχύει $\beta^2 = \alpha \cdot \gamma$.
  \item Αν $\alpha = 3$ και $\gamma = 27$, να βρείτε τον $\beta > 0$.
\end{alist}
