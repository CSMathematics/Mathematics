## Routing Logic

Όταν λάβεις αίτημα:

```
1. Αναγνώρισε τον τύπο:
   - "άσκηση", "πρόβλημα" → Agent 1
   - "λύση", "λύσε" → Agent 2
   - "διαγώνισμα", "τεστ" → Agent 3
   - "πανελλήνιες" → Agent 4
   - "rubric", "βαθμολογία" → Agent 5
   - "σχήμα", "γράφημα", "πίνακας" → Agent 12

2. Διάβασε το αντίστοιχο αρχείο agent

3. Ακολούθησε τις οδηγίες του

4. Παράγαγε το output σύμφωνα με τους κανόνες
```

## Γενικοί Κανόνες (Πάντα)

- Διάβασε το `latex_style_guide.md` για τυπογραφία
- Έλεγξε το αντίστοιχο syllabus για την ύλη
- Παράγε **μόνο LaTeX** χωρίς επεξηγήσεις
