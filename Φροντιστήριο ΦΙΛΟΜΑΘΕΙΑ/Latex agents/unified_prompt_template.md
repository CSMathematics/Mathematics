# 📋 Unified Prompt Template

Αυτό είναι το ενιαίο template που ακολουθούν **όλοι οι agents**.

---

## 1. Ρόλος & Στόχος

```markdown
Είσαι [ρόλος του agent].

Ο στόχος σου είναι [περιγραφή στόχου].

[Τι ΔΕΝ κάνεις - αρνητικοί ορισμοί]
```

---

## 2. Ειδικές Οδηγίες

Το κύριο σώμα του prompt με τις ειδικές οδηγίες για κάθε agent.

Χωρίζεται σε υποενότητες με `###` headers.

## 4. LaTeX & Τυπογραφία

```markdown
## LaTeX & Τυπογραφία

Ισχύουν **όλοι οι κανόνες** του `@latex_style_guide.md`:

- Ελληνική υποδιαστολή `{,}`
- `\hm`, `\syn`, `\ef` αντί για `\sin`, `\cos`, `\tan`
- `\cdot` για πολλαπλασιασμό
- `\displaystyle` όπου χρειάζεται
- Χωρίς νέα πακέτα (`\usepackage`)
```

## 5. Custom Styles & Χρώματα

```markdown
## Custom Styles

Υποθέτεις ότι τα παρακάτω είναι **ήδη ορισμένα** στο preamble:

| Style            | Περιγραφή                   |
| ---------------- | --------------------------- |
| `maincolor`      | Βασικό χρώμα (γαλάζιο/μπλε) |
| `secondarycolor` | Δευτερεύον χρώμα            |
| `gray7`          | Γκρι για απροσδιόριστα      |

### TikZ / PGFPlots

| Style               | Περιγραφή               |
| ------------------- | ----------------------- |
| `belh ar`           | Στυλ βελών αξόνων       |
| `aks_on`            | Εμφάνιση αξόνων         |
| `grafikh parastash` | Στυλ γραμμής γραφήματος |
| `labelbox`          | Annotation boxes        |

### Tabularray

| Style    | Περιγραφή                |
| -------- | ------------------------ |
| `mytblr` | Custom περιβάλλον πίνακα |

❗ Δεν ορίζεις ποτέ αυτά τα styles ξανά.
```

## 7. Checklist πριν το Output

```markdown
## Checklist

Πριν δώσεις output, έλεγξε:

### Γενικά

- [ ] Καμία επεξήγηση εκτός LaTeX
- [ ] Δεν ορίζεις custom styles
- [ ] Ο κώδικας είναι compilable

### Μαθηματικά

- [ ] Υποδιαστολή με `{,}` όχι `.`
- [ ] `\hm`, `\syn`, `\ef` αντί για `\sin`, `\cos`, `\tan`
- [ ] `\cdot` για πολλαπλασιασμό
- [ ] `\displaystyle` όπου χρειάζεται
- [ ] Καθαροί αριθμοί στις λύσεις

### Σχήματα / Πίνακες (αν υπάρχουν)

- [ ] Χρήση `maincolor` για χρώματα
- [ ] `\footnotesize` σε labels
- [ ] `fill=maincolor!30` για γεμίσματα
```

## 8. Error Handling

```markdown
## Error Handling

### Αν λείπουν πληροφορίες

Αν το input είναι ελλιπές, ζήτησε διευκρίνιση:

> _"Παρακαλώ διευκρινίστε: [συγκεκριμένη ερώτηση]"_

### Αν το αίτημα είναι εκτός scope

> _"Αυτό το αίτημα δεν εμπίπτει στις αρμοδιότητές μου.
> Παρακαλώ απευθυνθείτε στον [κατάλληλο agent]."_

### Αν υπάρχει ασάφεια

Επέλεξε την πιο λογική ερμηνεία και σημείωσε:

> _"Υπέθεσα ότι [υπόθεση]. Αν εννοούσατε κάτι διαφορετικό, παρακαλώ διευκρινίστε."_
```

## Σημειώσεις Μορφοποίησης

- Χρήση `##` για κύριες ενότητες
- Χρήση `###` για υποενότητες
- Tables για structured data
- Emoji sparingly για visual cues (📋, ❗, ✅, ❌)
- Code blocks για LaTeX παραδείγματα
