# 📘 LaTeX Style Guide για Εκπαιδευτικό Υλικό Μαθηματικών

Αυτό το αρχείο περιέχει όλους τους κανόνες LaTeX τυπογραφίας που ισχύουν για **όλους τους agents**.

---

## 1. Μαθηματικός Συμβολισμός

### Τριγωνομετρικές Συναρτήσεις

| Αντί για | Χρησιμοποίησε |
| -------- | ------------- |
| `\sin`   | `\hm`         |
| `\cos`   | `\syn`        |
| `\tan`   | `\ef`         |

### Πράξεις

| Αντί για        | Χρησιμοποίησε |
| --------------- | ------------- |
| `*` ή `x`       | `\cdot`       |
| φυσ. λογάριθμος | `\ln`         |

### Ελληνικές Παράμετροι

Χρησιμοποίησε: `\alpha`, `\beta`, `\lambda`, `\omega`

### Απαγορευμένα Σύμβολα σε Εκφωνήσεις

❌ `⇒`, `⇔`, `∀`, `∃`

---

## 2. Ελληνική Τυπογραφία (CRITICAL)

### Δεκαδικοί Αριθμοί

✅ **Σωστό:** `3{,}14`  
❌ **Λάθος:** `3.14`

### Διαστήματα Πραγματικών

✅ **Σωστό:** `[-1, 1]` ή `(-1, 1)`  
❌ **Λάθος:** `]-1,1[` (γαλλική γραφή)

### Νόμισμα

Χρήση `\euro` ή `\texteuro` όταν απαιτείται.

## 3. LaTeX Commands

### Εκφωνήσεις

```latex
\askhsh
```

### Λίστες

```latex
\begin{alist}    % ή
\begin{enumerate}
```

### Υποερωτήματα σε Στήλες

```latex
\begin{multicols}{2}
  ...
\end{multicols}
```

## 4. Style & Αναγνωσιμότητα

Χρησιμοποίησε `\displaystyle` όταν μαθηματικές εκφράσεις εμφανίζονται μικρές:

- Όρια: `\lim`
- Ολοκληρώματα: `\int`
- Κλάσματα: `\frac`

**Παράδειγμα:**

```latex
Η τιμή $\displaystyle\lim_{x \to 0} \frac{\hm x}{x} = 1$.
```

---

## 5. Απαγορεύσεις

### ❌ Νέα Πακέτα

Δεν εισάγεις ποτέ `\usepackage`. Ο κώδικας πρέπει να είναι συμβατός με το υπάρχον preamble.

### ❌ Αντίστροφες Τριγωνομετρικές

Μην χρησιμοποιείς `arcsin`, `arccos`, `arctan`.

### ❌ Σχόλια εκτός LaTeX

Δεν γράφεις επεξηγήσεις ή σχόλια εκτός του LaTeX κώδικα.

---

## 6. Καθαροί Αριθμοί (Clean Numbers)

Οι εξισώσεις πρέπει να έχουν «καθαρές» λύσεις:

✅ **Επιτρέπονται:**

- Ακέραιοι
- Απλά κλάσματα
- Γνωστές σταθερές ($e$, $\pi$, $\ln 2$)

❌ **Κακό παράδειγμα:**

```latex
x^2 - 7x + 1 = 0  % δίνει άσχημες ρίζες
```

✅ **Καλό παράδειγμα:**

```latex
x^2 - 5x + 6 = 0  % δίνει x=2, x=3
```

---

## 7. Τελικό Checklist

Πριν δώσεις output, έλεγξε:

- [ ] Υποδιαστολή με `{,}` όχι `.`
- [ ] `\hm`, `\syn`, `\ef` αντί για `\sin`, `\cos`, `\tan`
- [ ] `\cdot` για πολλαπλασιασμό
- [ ] Χωρίς νέα `\usepackage`
- [ ] Καθαροί αριθμοί στις λύσεις
- [ ] `\displaystyle` όπου χρειάζεται
